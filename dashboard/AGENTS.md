# Dashboard

Браузерное приложение на табличном выходе узла Loginom. Здесь сервис снимков (`server.mjs`), bootstrap клиента, шаблон React/TypeScript/Vite/Recharts и публикация. Исходники приложений лежат в `apps/`, шаблон и lockfile — в `template/`. Опубликованный каталог переключается только после успешной проверки типов и сборки Vite.

Если пользователь просит создать или изменить dashboard для узла Loginom, исполнитель (включая субагента) сам один раз читает JSON снимка. Для цели, приложенной Desktop к сообщению, используй http://127.0.0.1:32768/dashboard/targets/<ID> с её ID. При запросе из Codex без приложенной цели используй http://127.0.0.1:32768/dashboard/current. Назови узел и путь в первой строке ответа и сам отредактируй, проверь и опубликуй приложение командами этого снимка. До конца запроса используй только его ID, не запрашивай контекст у пользователя или другого агента и не входи в живую сессию Loginom.

- Путь исходников и команды `init`, `typecheck`, `build`, `publish` бери из снимка. Новое приложение начинается с `commands.init`.
- Данные экрана читай через `window.frameElement.dashboard`: `state()`, `change(value, name?)`, `run()`. Строки снимка — пример для чата; экран читает адаптер.
- Bootstrap до загрузки iframe сам выполняет неактивный узел или повторяет сохранённую ошибку. Активный узел без ошибки отдаёт готовый результат. Приложению достаточно `state()` при открытии: не добавляй начальную кнопку «Выполнить» и не вызывай `run()` сам.
- Порог передавай штатным `change` на Enter, уходе из поля или отпускании ползунка. Пока идёт расчёт, показывай «Идёт расчёт» и оставляй поле доступным. Пустая таблица — успешный результат. Пакет `.lgp` отсюда не записывай.
- Сервис снимков по умолчанию слушает только `127.0.0.1:8100`; стенд открывает его для Apache переменной `DASHBOARD_HOST=0.0.0.0`. В памяти хранятся последние 100 снимков.
- Проверки сервиса из `dashboard/`: `node --test server.test.mjs bootstrap.test.mjs`. Типы и сборка — `bun typecheck` и `npm run build` из `template/` или каталога приложения.
- Стенд и перенос — [README](README.md) и [HANDOFF](HANDOFF.md). Границы приёмки — [дизайн](../docs/superpowers/specs/2026-11-09-loginom-dashboard-design.md).
