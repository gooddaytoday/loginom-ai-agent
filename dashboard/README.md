# Dashboard в Loginom Studio

## Создать и опубликовать

1. В Desktop подключитесь к тому же стенду, который открыт в Studio. В Studio откройте пакет, выберите узел с первым табличным выходом и нажмите «Создать dashboard». Если Desktop не открылся автоматически, нажмите «Открыть чат в Desktop».
2. Опишите в чате, что хотите увидеть. Для [учебного пакета](fixture/README.md) выберите узел «По убыванию ROI» и попросите «Покажи число кампаний по каналам и общий итог».
3. Откройте ссылку из ответа агента. Черновик строится по строкам образца, в его шапке указаны путь к пакету и время снимка. Правки можно попросить в том же чате, открытая страница черновика обновится. После публикации Studio получает текущий выход узла.
4. Когда черновик устроит, напишите «Опубликовать». Проверьте имя узла и путь пакета в окне подтверждения и разрешите запись один раз. Если для нового черновика на стенде уже есть версия, окно покажет её имя и предложит «Опубликовать мою версию» или «Отмена». Отмена сохраняет черновик. Если версия на стенде изменится, пока вы принимаете решение, потребуется новое согласие. Автору нужны права записи в каталог пакета. Читателю нужен штатный доступ к пакету в Studio.
5. Когда сборка будет готова, дашборд появится или обновится в открытом окне Studio. Значения в шапке сохраняются, а дашборд получает текущие параметры и результат расчёта узла. Если окно закрыто, откройте Dashboard на узле. Метка «Версия» в шапке содержит дату и время UTC из имени открытой публикации.

Если чат сообщает, что готовность ещё не подтверждена, оставьте окно открытым. Пока новая версия собирается и загружается, можно пользоваться предыдущей и менять параметры. При временном сбое загрузки Studio повторит попытку. Если сборка завершилась ошибкой, Studio покажет сообщение рядом с дашбордом или, при первой публикации, рядом со ссылкой на чат. Попросите агента исправить причину, проверьте черновик и подтвердите новую публикацию.

## Сверить данные и изменить dashboard

- В учебном пакете установите `MinBudget` в 0 в шапке и дождитесь пересчёта. Откройте «Данные узла», найдите строку Email и сравните число кампаний с показателем dashboard. «Назад» и «Далее» листают строки, «К dashboard» возвращает к графику. Просмотр использует уже полученную таблицу.
- В шапке меняются целые и дробные параметры. Остальные параметры меняйте в сценарии. Во время пересчёта «Данные узла» показывает «Идёт расчёт», затем новый результат или ошибку. Кнопка «Вернуться к сценарию» или Esc закрывает dashboard, а расчёт и поставленные в очередь изменения продолжаются.
- Если часть строк не поместилась, Studio показывает полученное и исходное количества. Если все строки поместились, но отдельные значения укорочены, Studio сообщает об этом. Итоги «по полученным строкам» относятся к показанной части таблицы. Если из непустого результата не поместилась ни одна строка, итог недоступен. Пустой результат означает, что узел успешно вернул ноль строк.
- Если dashboard сообщает о пропавшем поле, нажмите «Изменить в чате» в шапке. Попросите адаптировать dashboard к новой схеме и снова явно опубликуйте результат. Тем же способом можно обновить старый dashboard. Если снимок истёк или уже использован, повторите клик в Studio для получения свежего.

Для администратора доступны [руководство по установке и обновлению](../packages/dashboard/deploy/README.md) и [рецепт отдельного dev-стенда](stand/README.md).
