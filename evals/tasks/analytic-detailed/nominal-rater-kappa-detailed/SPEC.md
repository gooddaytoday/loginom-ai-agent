Согласие номинальных оценок на каждой площадке с поправкой на случайное согласие по раздельным маргиналам. Native reference читает kappa_ratings.csv; категории A/B/C не упорядочены.

| Узел | Компонент | Фактический расчёт |
|---|---|---|
| Исходные пары оценок | Импорт текста | Исходные site_id,item_id,rater_a,rater_b, CSV UTF-8 |
| Флаг совпадения оценок | Калькулятор | agreement_flag=IFF(rater_a=rater_b,1,0) |
| Все площадки и совпадения | Группировка | site_id; COUNT(item_id) как items, SUM(agreement_flag) как matches |
| Частоты первого оценщика | Группировка | site_id,rater_a; COUNT(item_id) как freq_a |
| Частоты второго оценщика | Группировка | site_id,rater_b; COUNT(item_id) как freq_b |
| Общие категории площадки | Внутреннее соединение | site_id=site_id и rater_a=rater_b |
| Произведения частот | Калькулятор | 1.0*freq_a*freq_b |
| Сумма произведений по площадке | Группировка | site_id; SUM(frequency_product) как sum_products |
| Все площадки с частотами | Левое соединение | Полная сводка площадок слева; sum_products по site_id справа |
| Нет общих категорий означает ноль | Заполнение пропусков | Отсутствующий sum_products=0 |
| Каппа Коэна без весов | Калькулятор | observed_raw=matches/items; chance_raw=sum_products/(1.0*items*items); kappa=(observed_raw-chance_raw)/(1-chance_raw). При chance_raw=1 NULL/undefined, иначе ok; безопасный знаменатель внутри условного выражения. Выходные числа Round(...,6) |
| Итог по площадкам | Сортировка | site_id по возрастанию; точные выходные поля |
| Итоговый CSV UTF-8 | Экспорт текста | Один CSV с заголовком, запятой, десятичной точкой и пустым числом при NULL |

Исходный импорт питает ветвь совпадений и две ветви частот; их native-соединения сохраняют отдельные распределения. Суммирование произведений не требует строки категории с нулевой частотой. Левое соединение и заполнение нуля восстанавливают площадку вообще без общих категорий. Отрицательная kappa не обрезается.

Fixture различает raw agreement, pooled маргиналы, межплощадочное смешение, обрезку отрицательных значений и подмену NULL. S01: po=3/5, pe=17/25, kappa=-1/4. S02: маргиналы A=(5,1,0), B=(2,2,2); po=pe=1/3, kappa=0, а pooled-частоты дают иной ответ. S04 вырожденная, S05 без общих категорий. Независимый oracle использует Counter/Fraction по исходным строкам, а не XML или результат Loginom.

Reference проверен CLI и отдельным cold: все 13 исполняемых узлов, новый полный CSV/oracle, неизменный серверный SHA256, без настройки и Save, close/logout успешны. D/B используют общий reference; B не проходила отдельный авторский запуск. Эквивалентные native-композиции принимаются. Предметная rubric не требует этих имён или количества узлов.
