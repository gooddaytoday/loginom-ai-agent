# Отклики по специализациям

Импорт CSV → группировка → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Снимок вакансий уже лежит в CSV, запрос к API не нужен. Для каждой специализации считаются число вакансий, сумма откликов, средняя зарплата и среднее число дней.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт 150 вакансий | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Показатели по специализациям | Группировка | ключ `specialization`; число `vacancy_id`, сумма `application_count`, среднее `salary_avg`, среднее `days_open` |
| По убыванию откликов | Сортировка | `applications` по убыванию |
| CSV по специализациям | Текстовый файл | разделитель `,`, колонки `specialization`, `vacancies`, `applications`, `avg_salary`, `avg_days_open` |

Связи: Импорт 150 вакансий → Показатели по специализациям → По убыванию откликов → CSV по специализациям.

## Входные данные

`dataset.csv` — 150 вакансий, копия `analitic-tasks/task52-headhunter/data/dataset.csv` без изменений.

## Ожидаемый результат

8 строк по убыванию суммы откликов, допуск ±0.01. Первая — Sales: 23 вакансии, 1268 откликов. Последняя — DevOps: 14 вакансий, 754 отклика. У Product и Sales одинаково 23 вакансии.
