# Эффект и побочные эффекты по группе и дозе

Импорт CSV → калькулятор → группировка → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Для каждой пары группы и дозы считаются число пациентов, среднее улучшение и доля побочных эффектов. Текст `None` означает отсутствие эффекта и в долю не входит. Доза сортируется как число.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт пациентов | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Признак побочного эффекта (0 или 100) | Калькулятор | `IFF(side_effects = "None", 0, 100)` |
| Показатели по группе и дозировке | Группировка | ключи `treatment_group` и `dosage_mg`; число пациентов, среднее `improvement`, среднее признака как `side_effect_pct` |
| Сортировка группы и числовой дозировки | Сортировка | `treatment_group` по возрастанию, затем `dosage_mg` по возрастанию |
| Итоговый CSV | Текстовый файл | разделитель `,`, заголовок из имён колонок; имя файла задаёт harness |

Связи: Импорт пациентов → Признак побочного эффекта (0 или 100) → Показатели по группе и дозировке → Сортировка группы и числовой дозировки → Итоговый CSV.

## Входные данные

`dataset.csv` — 300 пациентов, копия `analitic-tasks/task46-clinical-trial/data/dataset.csv` без изменений.

## Ожидаемый результат

6 строк: Placebo 50, 100, 200, затем Treatment 50, 100, 200. Допуск ±0.01. Placebo/50: `patients` 51, `avg_improvement` 23.456863, `side_effect_pct` 49.019608.
