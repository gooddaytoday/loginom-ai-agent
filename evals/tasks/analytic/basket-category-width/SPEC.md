# Ширина корзины и возвраты

Импорт CSV → калькулятор → группировка → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Ширина заказа — сумма пяти флагов категорий. Доля возвратов — среднее отметки `returned * 100`. Свёртка столбцов не используется.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт заказов | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Количество категорий | Калькулятор | `has_electronics + has_clothing + has_books + has_home + has_sports` и `returned * 100` |
| Показатели по числу категорий | Группировка | ключ `category_count`; число заказов, среднее `order_value`, среднее отметки возврата |
| category_count от 0 до 5 | Сортировка | `category_count` по возрастанию |
| Выгрузка итогового CSV | Текстовый файл | разделитель `,`, заголовок из имён колонок; имя файла задаёт harness |

Связи: Импорт заказов → Количество категорий → Показатели по числу категорий → category_count от 0 до 5 → Выгрузка итогового CSV.

## Входные данные

`dataset.csv` — 500 заказов, копия `analitic-tasks/task34-cross-sell-analysis/data/dataset.csv` без изменений.

## Ожидаемый результат

6 строк, `category_count` от 0 до 5, допуск ±0.01. Ширина 0: 53 заказа, `return_pct` 16.981132. Ширина 5: 5 заказов, `return_pct` 20.
