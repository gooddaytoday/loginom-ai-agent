# Звёзды репозиториев по языку

Импорт CSV → группировка → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

По каждому языку считаются число репозиториев, сумма звёзд, среднее число форков и максимум звёзд. Имя `C++` сохраняется как в данных. Снимок не требует обращения к API.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт dataset.csv | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Показатели по language | Группировка | ключ `language`; число строк, сумма `stars`, среднее `forks`, максимум `stars` |
| Сортировка total_stars DESC | Сортировка | `total_stars` по убыванию |
| Экспорт результата CSV | Текстовый файл | разделитель `,`, заголовок из имён колонок; имя файла задаёт harness |

Связи: Импорт dataset.csv → Показатели по language → Сортировка total_stars DESC → Экспорт результата CSV.

## Входные данные

`dataset.csv` — 150 репозиториев, копия `analitic-tasks/task59-github/data/dataset.csv` без изменений.

## Ожидаемый результат

8 строк по убыванию суммы звёзд, допуск ±0.01. Первая — Rust, `total_stars` 10911. Последняя — Ruby, `total_stars` 6903. В списке есть `C++`.
