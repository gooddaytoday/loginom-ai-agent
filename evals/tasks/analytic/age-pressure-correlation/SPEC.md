# Корреляция возраста и давления

Источник: `analitic-tasks/task03-correlation`, 300 строк `data/dataset.csv`. Исходные байты сохранены. По всем строкам вычисляются средние age/blood_pressure и корреляция Пирсона; p-value и причинная интерпретация не входят в задачу.

## Фактический граф

Описание проверено по `Unit_0/Unit.xml` принятого пакета. Девять стандартных узлов, JavaScript отсутствует.

| Узел | Компонент | Настройка |
|:--|:--|:--|
| Импорт dataset.csv — age и blood_pressure | Импорт текстового файла | UTF-8, запятая, десятичная точка; активны age и blood_pressure. Загруженный CSV в `/user/` совпадает по SHA256 с входом. |
| Квадраты и произведение | Калькулятор | all_rows=1, x_squared=age*age, y_squared=blood_pressure*blood_pressure, xy=age*blood_pressure. |
| Все строки - число и суммы | Группировка | Единственный ключ all_rows; COUNT(age) → n; суммы age, blood_pressure, x_squared, y_squared, xy → sum_x, sum_y, sum_xx, sum_yy, sum_xy. Все исходные age заполнены. |
| Средние и корреляция без округления | Калькулятор | A=n*sum_xx−sum_x², B=n*sum_yy−sum_y², C=n*sum_xy−sum_x*sum_y; age_mean_raw=sum_x/n, pressure_mean_raw=sum_y/n, pearson_r_raw=C/Sqrt(A*B). |
| Итог - округление до 6 знаков | Калькулятор | n_result=n с целым типом; три окончательных величины через Round(raw,6). Служебный Expr1=0 в выгрузку не попадает. |
| Исключение служебных полей | Параметры полей | Исключает суммы, A/B/C, all_rows, raw и Expr1; четыре результата переименованы во внутренние count_rows, age_value, pressure_value, r_value. |
| Итоговая строка - формат CSV | Калькулятор | Боковая ветка: собирает строковое представление трёх уже округлённых величин с шестью знаками через Concat/Str/StrZero. Выполняется, но с экспортом не связана. |
| Итоговая таблица | Параметры полей | На основном пути переименовывает count_rows → n, age_value → age_mean, pressure_value → pressure_mean, r_value → pearson_r. Числовые типы сохраняются. |
| Итоговый CSV | Экспорт текстового файла | Подключён к числовой итоговой таблице, одна выгрузка; UTF-8, имена колонок в заголовке, запятая, десятичная точка. |

Основной путь: импорт → квадраты/произведение → общие суммы → неокруглённые средние/корреляция → итоговое округление → исключение служебных полей → числовая итоговая таблица → экспорт. Боковая ветка строкового представления начинается после исключения служебных полей. Фильтрации входных строк нет; остальные исходные признаки в вычислениях не участвуют.

## Результат и проверка

CSV: ровно одна строка и `n, age_mean, pressure_mean, pearson_r`. n целый, три остальных значения округлены явно в графе до шести знаков. Полный ожидаемый CSV — `oracle.csv`, абсолютный допуск `1e-6`; порядок колонок при сверке не важен.

CLI 0.2.2, `openai/gpt-6.1-sol/xhigh`, primary-попытка 1 без внешней подсказки. Модель самостоятельно восстановила настройку финальных калькуляторов; в сохранённом графе нет пустых выражений. Официальная проверка графа и всей CLI-выгрузки прошла. Пакет заново открыт через меню и выполнен в браузере: все девять узлов зелёные, включая боковую ветку, ошибок нет. Новый CSV целиком совпал с oracle. Пакет закрыт без сохранения изменений браузерной сессии. Подробности версий, SHA256 и независимой слепой сверки — в provenance.
