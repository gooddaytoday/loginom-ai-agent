# Риск дефолта по сроку кредита

Импорт CSV → признак высокого риска → группировка по сроку → сортировка по сроку → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

По каждому сроку кредита считаются средний риск и доля кредитов со риском строго выше 0.5. Этот кейс заменяет `retention-curve`: свёртка двенадцати флагов за три попытки пакет не сохранила.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт 300 кредитов | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок; `loan_term_months` — целое, `default_risk_score` — вещественное |
| Высокий риск строго больше 0.5 | Калькулятор | `high_risk_percent_flag = IFF(default_risk_score > 0.5, 100, 0)` |
| Показатели по срокам кредита | Группировка | ключ `loan_term_months`; `loans` — количество `loan_id`, `avg_default_risk` — среднее `default_risk_score`, `high_risk_pct` — среднее `high_risk_percent_flag` |
| Срок кредита по возрастанию | Сортировка | `loan_term_months` по возрастанию |
| Экспорт итоговой CSV | Текстовый файл | разделитель `,`, заголовок из имён колонок; имя файла задаёт harness |

Связи: Импорт 300 кредитов → Высокий риск строго больше 0.5 → Показатели по срокам кредита → Срок кредита по возрастанию → Экспорт итоговой CSV.

## Входные данные

`dataset.csv` — 300 кредитов, колонки `loan_id, customer_age, loan_amount, credit_score, annual_income, default_risk_score, loan_term_months, collateral_value`; копия `analitic-tasks/task21-financial-risk/data/dataset.csv` без изменений.

## Ожидаемый результат

4 строки в порядке срока 12, 24, 36, 60 месяцев, допуск ±0.01. Срок 12: `loans` 68, `avg_default_risk` 0.547559, `high_risk_pct` 54.411765. Срок 24: `loans` 83, `avg_default_risk` 0.471916, `high_risk_pct` 50.60241.
