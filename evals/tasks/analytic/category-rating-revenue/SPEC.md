# Рейтинг и выручка по категориям

Импорт CSV → группировка → калькулятор → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Категории упорядочены по среднему `rating`. `recommended_pct` — доля товаров с `is_recommended = 1`, в процентах. Сумма выручки остаётся в выгрузке.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт dataset.csv | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Показатели по category | Группировка | ключ `category`; число товаров, среднее `rating`, сумма `revenue`, среднее `is_recommended` как доля |
| Доля рекомендованных в процентах | Калькулятор | `recommended_pct * 100`, с заменой этой колонки; число товаров, средний рейтинг и сумма выручки не скрываются |
| avg_rating по убыванию | Сортировка | `avg_rating` по убыванию |
| Экспорт результата CSV | Текстовый файл | разделитель `,`, колонки `category`, `products`, `avg_rating`, `total_revenue`, `recommended_pct` |

Связи: Импорт dataset.csv → Показатели по category → Доля рекомендованных в процентах → avg_rating по убыванию → Экспорт результата CSV.

## Входные данные

`dataset.csv` — 300 товаров, копия `analitic-tasks/task32-product-recommendations/data/dataset.csv` без изменений.

## Ожидаемый результат

5 строк по убыванию среднего рейтинга, допуск ±0.01. Первая — Sports, `avg_rating` 3.13. Последняя — Clothing, 2.955738. По выручке Clothing выше Books, по рейтингу наоборот.
