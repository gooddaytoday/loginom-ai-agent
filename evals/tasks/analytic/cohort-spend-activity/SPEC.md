# Расходы и активность по когорте

Импорт CSV → калькулятор → группировка → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

`cohort` остаётся текстовой меткой ГГГГ-ММ. Доля активных — среднее отметки `is_active * 100`.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт пользователей | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок; `cohort` остаётся текстом |
| Активность 100 или 0 | Калькулятор | `is_active * 100` |
| Показатели по когортам | Группировка | ключ `cohort`; число пользователей, среднее `months_active`, сумма `total_spend`, среднее отметки активности |
| Cohort по возрастанию текста | Сортировка | `cohort` по возрастанию |
| Экспорт показателей CSV | Текстовый файл | разделитель `,`, заголовок из имён колонок; имя файла задаёт harness |

Связи: Импорт пользователей → Активность 100 или 0 → Показатели по когортам → Cohort по возрастанию текста → Экспорт показателей CSV.

## Входные данные

`dataset.csv` — 800 пользователей, копия `analitic-tasks/task07-cohort-analysis/data/dataset.csv` без изменений.

## Ожидаемый результат

5 строк по возрастанию метки, допуск ±0.01. Первая — `2023-01`: 170 пользователей, `total_spend` 16541.88, `active_pct` 56.470588. Последняя — `2024-01`.
