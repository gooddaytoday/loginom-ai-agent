# Конверсия по использованию восьми функций

Источник: `analitic-tasks/task40-product-analytics`, 500 пользовательских строк `data/dataset.csv`. Исходные байты сохранены. Для каждой из восьми исходных `feature_*`-колонок рассчитывается конверсия групп с `used=0` и `used=1`; это описательное сравнение.

## Фактический граф

Описание проверено по `Unit_0/Unit.xml` принятого пакета. Шесть стандартных узлов связаны в цепочку; JavaScript отсутствует.

| Узел | Компонент | Настройка |
|:--|:--|:--|
| Импорт dataset.csv | Импорт текстового файла | UTF-8, запятая, десятичная точка; читает загруженный в `/user/` dataset.csv с подтверждённым SHA256. |
| Развернуть 8 функций | Развёртка столбцов | Сохраняет `user_id` и `converted`; разворачивает ровно feature_dashboard, feature_reports, feature_settings, feature_integrations, feature_api, feature_notifications, feature_export, feature_team в `Names` и `Values`. Нули не отбрасываются; получается 4000 строк. |
| Клиенты и конверсии по feature, used | Группировка | Ключи `Names`, `Values`; `COUNT(user_id)` → `users`, `SUM(converted)` → `converters`; ключи переименованы в `feature`, `used`. Все исходные user_id заполнены. |
| feature ASC, used DESC | Сортировка | `feature` по возрастанию, `used` по убыванию; `LocaleAware=false`. |
| Итог: целые счётчики и conversion_pct (6 знаков) | Калькулятор | Приводит `converters` к целому через `Int(converters)` с заменой поля; добавляет `conversion_pct=Round(100.0*converters/users,6)`. |
| Итоговый CSV | Экспорт текстового файла | Одна выгрузка, UTF-8, заголовки из имён колонок, запятая, десятичная точка. |

Связи: импорт → развёртка → группировка → сортировка → калькулятор → экспорт. Фильтрации по signup_date, days_active или plan_type нет. `feature` содержит полное имя исходной колонки, `used` — её исходный целый флаг.

## Результат и проверка

CSV содержит ровно `feature, used, users, converters, conversion_pct` и 16 строк, по две на функцию. Внутри каждой функции сначала used=1, затем used=0. Полный oracle — `oracle.csv`; все числа сверяются с абсолютным допуском `1e-6`.

CLI 0.2.2, `openai/gpt-6.1-sol/xhigh`, primary-попытка 1 без подсказки. Официальная проверка графа и всех ячеек CLI-выгрузки пройдена. Пакет повторно открыт через меню «Пакеты → Открыть» и полностью выполнен в браузере: шесть узлов активны, ошибок нет. Новый CSV полностью совпал с oracle; пакет закрыт без сохранения изменений браузерной сессии. Версии, SHA256 и независимая слепая сверка зафиксированы в provenance.
