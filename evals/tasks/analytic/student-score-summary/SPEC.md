# Сводка оценок по трём предметам

Источник: `analitic-tasks/task01-basic-statistics`, 200 строк data/dataset.csv. Исходный CSV сохранён побайтово. Все три оценки каждого студента входят в расчёт; внешние данные не используются.

## Фактический граф

Описание проверено по Unit_0/Unit.xml принятого пакета. Девять стандартных узлов образуют один линейный путь; JavaScript отсутствует.

1. «Импорт dataset.csv — все студенты» — импорт UTF-8 с запятой и десятичной точкой, student_id и оценки целые. Загруженная копия совпадает с источником по SHA256.
2. «Три предмета — все 600 оценок» — Транспонирование столбцов math_score, reading_score, writing_score; student_id/name сохраняются как групповые поля, SkipNullCases=false. Выход Names содержит исходное имя предмета, Values — оценку.
3. «Квадрат каждой исходной оценки» — Калькулятор: score_squared=Values*Values, Names сопоставлено с subject.
4. «По предмету: n, сумма, min, max, сумма квадратов» — Группировка по subject: COUNT(student_id) → students; SUM(Values) → sum_score; MIN/MAX(Values) → min_score_raw/max_score_raw; SUM(score_squared) → sum_squared. Все 200 student_id заполнены, поэтому счётчик равен числу строк.
5. «Среднее и генеральное σ без округления» — Калькулятор: mean_score_raw=sum_score/students; population_stddev_raw=Sqrt(sum_squared/students-(sum_score/students)*(sum_score/students)). Сохранившийся пустой служебный Expr1 исключается ниже.
6. «subject ASC — до округления» — сортировка subject по возрастанию, LocaleAware=false.
7. «Шесть итоговых колонок — точные значения» — Параметры полей: исключает Expr1 и суммы, переименовывает четыре итоговых показателя; students остаётся целым.
8. «Финальное округление: 6 знаков и десятичная точка» — Калькулятор округляет четыре показателя через Round(value*1000000), затем Div/Mod/StrZero формируют десятичную запись с точкой и шестью знаками. На этом последнем шаге показатели становятся строками для выгрузки; все предыдущие вычисления выполняются по числам без округления. Выходное сопоставление задаёт точные шесть колонок.
9. «Итоговый CSV — 3 предмета» — единственная выгрузка, UTF-8, заголовки из имён колонок, запятая и десятичная точка.

## Результат и проверка

Колонки: subject,students,mean_score,min_score,max_score,population_stddev. Три строки: math_score, reading_score, writing_score; students=200 в каждой. Полный oracle находится в oracle.csv, числовой допуск 1e-6.

CLI 0.2.2, openai/gpt-6.1-sol/xhigh, primary-попытка 1 без внешней подсказки. Модель самостоятельно восстановила локальные остановки UI при открытии калькулятора, сопоставлении выхода сортировки и размещении экспорта. Пакет сохранён с exit=0; упрощение не применялось.

Официальная проверка графа и полного CSV прошла. Сохранённый пакет заново открыт через меню и выполнен целиком: девять узлов активны, ошибок нет. Новый CSV полностью совпал с oracle; пакет закрыт без сохранения изменений браузерной сессии. Версии, SHA256, независимая слепая проверка и evidence приведены в provenance.
