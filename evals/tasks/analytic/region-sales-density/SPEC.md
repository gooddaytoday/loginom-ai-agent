# Выручка на квадратный метр по региону

Импорт CSV → группировка по региону → калькулятор → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Плотность считается из сумм региона: сумма `monthly_sales` делится на сумму `store_area`. Среднее частных по магазинам задачу не выполняет.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт dataset.csv | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Итоги по region | Группировка | ключ `region`; число магазинов, сумма `monthly_sales`, сумма `store_area` |
| sales_per_sqm = total_sales / total_area | Калькулятор | одно новое поле `sales_per_sqm` = `total_sales / total_area`; исходные итоги не скрываются |
| По убыванию sales_per_sqm | Сортировка | `sales_per_sqm` по убыванию |
| Экспорт итогов CSV | Текстовый файл | разделитель `,`, заголовок из имён колонок; имя файла задаёт harness |

Связи: Импорт dataset.csv → Итоги по region → sales_per_sqm = total_sales / total_area → По убыванию sales_per_sqm → Экспорт итогов CSV.

## Входные данные

`dataset.csv` — 400 магазинов, копия `analitic-tasks/task17-geographic/data/dataset.csv` без изменений.

## Ожидаемый результат

7 строк по убыванию `sales_per_sqm`, допуск ±0.01. Первая — Siberia, `sales_per_sqm` 10614.062359. Последняя — Volga, `sales_per_sqm` 7829.510449.
