# Кривая удержания по доступным срокам

Источник: `analitic-tasks/task38-retention-analysis`, 596 клиентских строк `data/dataset.csv`. Исходный CSV сохранён побайтово. Пакет создаёт кривую для месяцев наблюдения 1–12; знаменатель включает только клиентов с `cohort_month + month_no <= 13`.

## Фактический граф

Описание проверено по `Unit_0/Unit.xml` принятого `reference.lgp`. Все десять узлов связаны в одну цепочку; JavaScript отсутствует.

| Узел | Компонент | Настройка |
|:--|:--|:--|
| Исходные клиенты dataset.csv | Импорт текстового файла | UTF-8, запятая, десятичная точка; читает загруженную CLI копию dataset.csv в `/user/`, совпадающую с входом по SHA256. |
| Месяцы наблюдения в строки | Развёртка столбцов | Ключи `customer_id`, `cohort_month`; значения `m_1`–`m_12` превращаются в `Names` и `Values`; нулевые значения сохраняются. |
| Номер месяца и доступность наблюдения | Калькулятор | `month_no=Val(SubStr(Names,3,2))`, `is_eligible=cohort_month+Val(SubStr(Names,3,2))<=13`, `customer_row=1`. |
| Только наступившие месяцы | Фильтр строк | Выход соответствующих условию: `is_eligible=true`. |
| Клиентские счётчики по месяцам | Группировка | Ключ `month_no`; сумма `customer_row` отображается в `eligible_customers`, сумма `Values` — в `active_customers`. |
| Целочисленные клиентские счётчики | Параметры полей | `eligible_customers` и `active_customers` преобразуются в целые; `month_no` сохраняется. |
| Месяцы по возрастанию | Сортировка | `month_no` по возрастанию. |
| Итоговая кривая удержания | Калькулятор | `retention_unrounded=100.0*active_customers/eligible_customers`; `retention_pct=Round(100.0*active_customers/eligible_customers,6)`. |
| Итог: четыре требуемых колонки | Параметры полей | Сохраняет четыре итоговых поля, исключает `retention_unrounded`. |
| CSV: monthly retention curve | Экспорт текстового файла | Одна выгрузка, UTF-8, заголовки из имён полей, запятая, десятичная точка. |

Связи: импорт → развёртка → калькулятор доступности → фильтр → группировка → целые счётчики → сортировка → калькулятор удержания → отбор полей → экспорт. `customer_id` не является агрегируемой мерой. Доли когорт не усредняются, будущие месяцы исключаются до вычисления обоих счётчиков.

## Результат и проверка

Одна CSV-таблица: `month_no, eligible_customers, active_customers, retention_pct`, 12 строк в порядке месяцев. Полный ожидаемый результат — `oracle.csv`; числовой допуск `1e-6`, колонки сопоставляются по именам. Например, месяц 1: 596 доступных, 401 активный, 67.281879%; месяц 12: 101 доступный, 7 активных, 6.930693%.

CLI 0.2.2, модель `openai/gpt-6.1-sol/xhigh`, primary-попытка 1 без подсказки. Полная выгрузка CLI совпала с независимым oracle. Пакет повторно открыт через меню «Пакеты → Открыть», все узлы выполнены в браузере; десять рамок зелёные, ошибок нет. Получен новый CSV, весь файл повторно совпал с oracle. Пакет закрыт без сохранения изменений браузерной сессии. Provenance содержит версии, SHA256 и сведения о независимой сверке.
