# Отток по группам клиентского стажа

Источник: analitic-tasks/task05-prediction, 1000 строк data/dataset.csv. Исходный файл сохранён побайтово. Все contract_type/payment_method пустые; эти поля не используются, строки не удаляются.

## Фактический граф

Описание проверено по Unit_0/Unit.xml принятого пакета. Восемь стандартных узлов образуют линейный путь, JavaScript отсутствует.

1. «dataset.csv — все строки» — импорт UTF-8, запятая и десятичная точка; загруженный CSV совпадает с исходником по SHA256.
2. «Группа стажа и индикатор churn=1» — Калькулятор: IF(tenure_months<=12,"01_le12",IF(tenure_months<=36,"02_13_36","03_gt36")); churn_flag=IF(churn=1,1,0).
3. «Показатели по tenure_band без округления» — Группировка по tenure_band. COUNT(churn_flag) → customers; SUM(churn_flag) → churned; AVG(monthly_charges) → avg_monthly_charges; AVG(support_calls) → avg_support_calls. churn_flag заполнен для каждой строки, поэтому customers считает всех клиентов.
4. «Процент оттока без округления» — Калькулятор: churn_pct=100.0*churned/customers; churned заменяется на Int(churned). Служебное Expr1=0 исключается следующим узлом.
5. «Только поля итогового отчёта» — Параметры полей исключают Expr1 и оставляют шесть требуемых полей.
6. «tenure_band по возрастанию до округления» — Сортировка tenure_band ASC, LocaleAware=false.
7. «Округление» — Калькулятор заменяет churn_pct, avg_monthly_charges, avg_support_calls через Round(...,6) после сортировки. customers/churned остаются целыми.
8. «CSV итогового профиля оттока» — единственная выгрузка UTF-8, заголовки из имён колонок, запятая и десятичная точка.

## Результат и проверка

Колонки: tenure_band,customers,churned,churn_pct,avg_monthly_charges,avg_support_calls. Три строки 01_le12, 02_13_36, 03_gt36; количество клиентов 110, 202, 688. Процент оттока рассчитан из счётчиков; промежуточного округления нет. Полный oracle находится в oracle.csv, числовой допуск 1e-6.

CLI 0.2.2, openai/gpt-6.1-sol/xhigh, primary-попытка 1 без внешней подсказки. Модель самостоятельно исправила параметры запросов, сопоставление выходных полей калькулятора и локальные остановки открытия мастера через штатные inspect/recover/prepare. Пакет сохранён с exit=0; упрощения не применялись.

Официальная проверка графа и полного CSV прошла. Пакет заново открыт через меню и выполнен целиком: восемь узлов активны, ошибок нет. Новый CSV полностью совпал с oracle; пакет закрыт без сохранения изменений браузерной сессии. Версии, SHA256 и независимая слепая сверка приведены в provenance.
