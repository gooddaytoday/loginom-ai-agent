# ABC-анализ товаров по годовой выручке

Импорт CSV → сортировка по выручке → калькулятор накопленной доли → калькулятор класса → группировка → сортировка классов → экспорт.

Имена файла пакета и файла результата задаёт harness (см. TASK.md); при оценке имена файлов не учитываются.

## Назначение

Накопленная доля зависит от порядка строк, общая выручка берётся из данных, классы режутся порогами 0.8 и 0.95.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Каталог товаров — CSV | Текстовый файл | `dataset.csv`, первая строка — заголовок; `annual_revenue`, `profit` и `total_storage_cost` — вещественные |
| Выручка по убыванию | Сортировка | `annual_revenue` по убыванию |
| Накопленная доля выручки | Калькулятор | накопленная сумма `CumulativeSum("annual_revenue")`; доля `CumulativeSum("annual_revenue") / Stat("annual_revenue", "Sum")` |
| Классы ABC по накопленной доле | Калькулятор | `IF(cumulative_share <= 0.8, "A", IF(cumulative_share <= 0.95, "B", "C"))`; доля строки `annual_revenue / Stat("annual_revenue", "Sum") * 100` |
| Итоги по классам ABC | Группировка | ключ класса; число товаров, суммы `annual_revenue`, `profit` и `total_storage_cost`; `revenue_share_pct` — сумма долей строк класса |
| Классы A, B, C | Сортировка | класс в порядке A, B, C |
| Экспорт ABC итогов CSV | Текстовый файл | колонки `abc_class`, `items`, `revenue`, `revenue_share_pct`, `profit`, `storage_cost` |

Связи: Каталог товаров — CSV → Выручка по убыванию → Накопленная доля выручки → Классы ABC по накопленной доле → Итоги по классам ABC → Классы A, B, C → Экспорт ABC итогов CSV.
