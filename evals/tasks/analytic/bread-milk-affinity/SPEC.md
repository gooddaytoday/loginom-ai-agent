# Связь Bread и Milk в корзинах магазинов

Источник: `analitic-tasks/task10-market-basket`, 1500 строк `data/dataset.csv`. CSV сохранён побайтово. Товары разделены строкой ` | `; членство Bread и Milk определяется по полному названию между разделителями, включая начало и конец списка.

## Фактический граф

Описание проверено по `Unit_0/Unit.xml` принятого пакета. Восемь стандартных узлов образуют один линейный путь; JavaScript отсутствует.

1. «Корзины из CSV» — импорт UTF-8, запятая, десятичная точка. Загруженный dataset.csv совпадает с источником по SHA256.
2. «Флаги корзин» — Калькулятор: basket_one=1; bread_flag и milk_flag через Find полного названия в Concat(" | ",items," | "); both_flag=bread_flag*milk_flag. Строки не удаляются.
3. «Счётчики по магазинам» — Группировка по store, суммы basket_one, bread_flag, milk_flag, both_flag; выходные имена n, bread_count, milk_count, both_count.
4. «Целые счётчики» — Параметры полей, перевод четырёх счётчиков в dtInteger.
5. «Показатели Bread–Milk» — Калькулятор без промежуточного округления: support=100*both_count/n; confidence=100*both_count/bread_count; lift=both_count*n/(bread_count*milk_count).
6. «Порядок по lift и store» — Сортировка неокруглённого lift по убыванию, затем store по возрастанию; LocaleAware=false.
7. «Итоговая таблица» — Калькулятор заменяет support, confidence, lift через Round(...,6), выходное сопоставление оставляет восемь требуемых колонок.
8. «Итоговый CSV» — единственная выгрузка, UTF-8, заголовки из имён колонок, запятая и десятичная точка.

## Результат и проверка

Колонки: `store,n,bread_count,milk_count,both_count,support,confidence,lift`. Три строки, Store_A → Store_C → Store_B. Support и confidence выражены в процентах, lift — отношение. Полный oracle находится в oracle.csv; числовой допуск 1e-6.

CLI 0.2.2, openai/gpt-6.1-sol/xhigh, принята primary-v2 попытка 4 с технической подсказкой о нейтральном названии узла. Попытки 1–2 остановились из-за UI-навигации; попытка 3 прервана после исправления авторской спецификации единиц, без признания содержательной неудачи модели. Исходная редакция и evidence сохранены; упрощение задачи не применялось.

Официальная проверка графа и всего CSV прошла. Сохранённый пакет заново открыт через меню и выполнен целиком: восемь узлов активны, ошибок нет. Новый CSV полностью совпал с oracle, пакет закрыт без сохранения браузерных изменений. Версии, SHA256, независимая слепая проверка primary-v2 и история попыток приведены в provenance.
