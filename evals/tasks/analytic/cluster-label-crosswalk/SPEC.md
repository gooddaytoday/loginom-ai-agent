# Соответствие готовых меток сегментов

Источник: analitic-tasks/task08-clustering, 500 строк data/dataset.csv. Исходный CSV сохранён побайтово. Используются только готовые целочисленные segment и predicted_segment. Остальные признаки, включая отрицательные синтетические значения, не исправляются и не служат фильтрами.

## Фактический граф

Описание проверено по Unit_0/Unit.xml принятого пакета. Шесть стандартных узлов образуют линейный путь; JavaScript и обучение отсутствуют.

1. «Исходные данные dataset.csv» — импорт UTF-8, запятая и десятичная точка; загруженная копия совпадает с исходником по SHA256.
2. «Индикаторы predicted_segment 0–3» — Калькулятор: indicator_k=IF(predicted_segment=k,1,0) для k=0,1,2,3. Существующие поля и все строки сохраняются.
3. «Частоты по исходному segment» — Группировка по segment, суммы четырёх индикаторов; выходные имена predicted_0, predicted_1, predicted_2, predicted_3. Суммирование нулевых индикаторов даёт явный 0 отсутствующему сочетанию. В исходном CSV представлены все четыре segment.
4. «segment по возрастанию» — Сортировка целочисленного segment ASC.
5. «Целочисленные счётчики результата» — Параметры полей переводят четыре суммы из dtFloat в dtInteger; segment уже целый.
6. «Экспорт таблицы частот CSV» — единственная выгрузка UTF-8 с заголовками из имён колонок, запятой и десятичной точкой.

## Результат и проверка

Колонки: segment,predicted_0,predicted_1,predicted_2,predicted_3. Ровно четыре строки segment=0,1,2,3. Все значения целые; округление не требуется. Метки не переупорядочиваются и accuracy не вычисляется. Полный oracle находится в oracle.csv, числовой допуск 1e-6.

CLI 0.2.2, openai/gpt-6.1-sol/xhigh, primary-попытка 1 без внешней подсказки. Модель самостоятельно восстановила остановку настройки выходного сопоставления калькулятора штатными inspect/recover. Пакет сохранён с exit=0, упрощение не применялось.

Официальная проверка графа и полного CSV прошла. Сохранённый пакет заново открыт через меню и выполнен целиком: шесть узлов активны, ошибок нет. Новый CSV полностью совпал с oracle; пакет закрыт без сохранения изменений браузерной сессии. Версии, SHA256 и независимая слепая сверка приведены в provenance.
