# Рейтинг отзывов и готовый признак негативных слов

Источник: analitic-tasks/task09-sentiment-analysis, 400 строк data/dataset.csv. Исходный CSV сохранён побайтово. has_negative_words используется как готовая целочисленная метка; текст отзывов не классифицируется повторно, противоречия текста и рейтинга не исправляются.

## Фактический граф

Описание проверено по Unit_0/Unit.xml принятого пакета. Семь стандартных узлов образуют линейный путь; JavaScript отсутствует.

1. «dataset.csv — исходные 400 отзывов» — импорт UTF-8, запятая и десятичная точка. Загруженная копия совпадает с источником по SHA256.
2. «Счётчики строк и низких оценок» — Калькулятор: row_unit=1, low_rating_flag=IFF(rating<=2,1,0). Все 400 строк сохранены, граница rating=2 включена.
3. «Группы по категории и готовому признаку» — Группировка по product_category и исходному has_negative_words. SUM(row_unit) → reviews; AVG(rating) → avg_rating; AVG(helpful_votes) → avg_helpful_votes; SUM(low_rating_flag) → low_reviews.
4. «Категория ASC затем признак ASC» — Сортировка обоих ключей по возрастанию до округления, LocaleAware=false.
5. «Итоговый процент и округление до 6 знаков» — Калькулятор: reviews=Int(reviews); avg_rating/avg_helpful_votes заменяются через Round(...,6); low_rating_pct=Round(100.0*low_reviews/reviews,6). Промежуточного округления нет. Выходное сопоставление также сохраняет low_reviews и пустой служебный Expr1 для последующего исключения.
6. «Ровно шесть итоговых колонок» — Параметры полей исключают low_reviews и Expr1; в результат не попадают служебные поля.
7. «analytic-evals-negative-words-rating-2.result.csv» — единственная выгрузка UTF-8 с заголовками из имён колонок, запятой и десятичной точкой.

## Результат и проверка

Колонки: product_category,has_negative_words,reviews,avg_rating,avg_helpful_votes,low_rating_pct. Ровно восемь строк, категории Books, Clothing, Electronics, Home; внутри каждой признак 0, затем 1. Счётчики целые, процент низких рейтингов умножен на 100. Полный oracle находится в oracle.csv, числовой допуск 1e-6.

CLI 0.2.2, openai/gpt-6.1-sol/xhigh, принята primary-попытка 2 без подсказки. Попытка 1 завершилась технической блокировкой graph-effect при перемещении существующего узла; пакет и CSV не создала. Её evidence, диагноз и подтверждённый штатный cleanup сохранены. Во второй попытке модель самостоятельно восстановила открытие калькулятора и исправила выходное сопоставление. Аналитика не упрощалась.

Официальная проверка графа и полного CSV прошла. Сохранённый пакет заново открыт через меню и выполнен целиком: семь узлов активны, ошибок нет. Новый CSV полностью совпал с oracle; пакет закрыт без сохранения изменений браузерной сессии. Версии, SHA256, независимая слепая сверка и история попыток приведены в provenance.
