# Наценка динамической цены по сезонам

Импорт CSV → группировка → калькулятор → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

`markup_pct` — среднее `dynamic_price`, делённое на среднее `base_price`, умноженное на 100, минус 100. Это не среднее частных отношений и не отношение, взвешенное продажами.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт dataset.csv | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Показатели по сезонам | Группировка | ключ `season`; число товаров, сумма `units_sold`, среднее `base_price`, среднее `dynamic_price` |
| Наценка из средних цен | Калькулятор | `avg_dynamic_price / avg_base_price * 100 - 100`; средние цены и сумма единиц не скрываются |
| Сезоны по убыванию наценки | Сортировка | `markup_pct` по убыванию |
| Итоговый CSV по сезонам | Текстовый файл | разделитель `,`, колонки `season`, `products`, `units`, `avg_base_price`, `avg_dynamic_price`, `markup_pct` |

Связи: Импорт dataset.csv → Показатели по сезонам → Наценка из средних цен → Сезоны по убыванию наценки → Итоговый CSV по сезонам.

## Входные данные

`dataset.csv` — 400 товаров, копия `analitic-tasks/task24-dynamic-pricing/data/dataset.csv` без изменений.

## Ожидаемый результат

4 строки по убыванию наценки, допуск ±0.01. Первая — Spring, `markup_pct` 22.204473. Последняя — Summer, 11.622879.
