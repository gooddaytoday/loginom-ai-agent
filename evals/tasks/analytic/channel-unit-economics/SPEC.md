# Экономика привлечения по каналам

Источник: analitic-tasks/task36-unit-economics, 300 строк data/dataset.csv. Исходный CSV сохранён побайтово. Используется готовый ltv без пересчёта из остальных полей.

## Фактический граф

Описание проверено по Unit_0/Unit.xml принятого пакета. Семь стандартных узлов образуют один линейный путь; JavaScript отсутствует.

1. «dataset.csv — все исходные строки» — импорт UTF-8 с запятой и десятичной точкой. Загруженный CSV совпадает с источником по SHA256; фильтра нет.
2. «По каналам: количество и средние исходных значений» — единственный ключ acquisition_channel; Count(customer_id)→customers, Avg(cac)→mean_cac, Avg(ltv)→mean_ltv, Avg(gross_margin)→mean_gross_margin. Все 300 customer_id заполнены, поэтому count соответствует числу строк.
3. «LTV/CAC, разность средних и маржа в процентах» — Калькулятор: ltv_cac_ratio=mean_ltv/mean_cac, ltv_cac_difference=mean_ltv-mean_cac, mean_gross_margin_pct=100*mean_gross_margin. Отношение и разница вычисляются из групповых средних до округления; индивидуальные отношения не усредняются.
4. «Семь итоговых колонок» — Параметры полей исключают вспомогательный mean_gross_margin и оставляют семь требуемых колонок; customers имеет целый тип.
5. «По неокруглённому LTV/CAC ↓, затем канал ↑» — Сортировка ltv_cac_ratio DESC, acquisition_channel ASC, LocaleAware=false.
6. «Финальное округление и формат: 6 знаков, десятичная точка» — пять показателей заменяются строками. Для каждого x вычисляется Round(x*1000000); целая часть получается через Int(.../1000000), затем добавляются точка и шесть дробных цифр через StrZero(Mod(...,1000000),6). Это окончательное округление до шести знаков после сортировки. Все пять показателей положительны на фиксированном входе. Выходное сопоставление сохраняет семь требуемых колонок и целый customers.
7. «analytic-evals-channel-unit-economics-1.result.csv» — единственная выгрузка UTF-8 с заголовками из имён колонок, запятой и десятичной точкой.

## Результат и проверка

Колонки: acquisition_channel,customers,mean_cac,mean_ltv,ltv_cac_ratio,ltv_cac_difference,mean_gross_margin_pct. Пять строк: social, email, organic, referral, paid_search. Полный oracle находится в oracle.csv, числовой допуск 1e-6.

CLI 0.2.2, openai/gpt-6.1-sol/xhigh, primary-попытка 1 без внешней подсказки, exit=0. Модель штатно восстановила настройку выходных полей внутри попытки; упрощение не применялось.

Официальная проверка графа и полного CSV прошла. Сохранённый пакет отдельно открыт через меню браузера и выполнен целиком: семь узлов активны, ошибок нет. Новый CSV полностью совпал с oracle; пакет закрыт без сохранения браузерных изменений. Версии, SHA256 и независимая слепая сверка приведены в provenance.
