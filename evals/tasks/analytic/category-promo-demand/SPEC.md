# Акции и спрос по категориям

Импорт CSV → группировка → калькулятор → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

`promo_pct` — доля товаров с `promotion = 1`, в процентах. Сумма спроса остаётся в выгрузке. Эластичность цены не считается.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт товаров dataset.csv | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Показатели по категориям | Группировка | ключ `category`; число товаров, сумма `promotion`, сумма `demand` |
| Доля товаров в акции, % | Калькулятор | `100.0 * promo_products / products`; число товаров, число акционных и сумма спроса не скрываются |
| Категории по убыванию promo_pct | Сортировка | `promo_pct` по убыванию |
| Экспорт результата CSV | Текстовый файл | разделитель `,`, колонки `category`, `products`, `promo_products`, `promo_pct`, `total_demand` |

Связи: Импорт товаров dataset.csv → Показатели по категориям → Доля товаров в акции, % → Категории по убыванию promo_pct → Экспорт результата CSV.

## Входные данные

`dataset.csv` — 250 товаров, копия `analitic-tasks/task16-price-elasticity/data/dataset.csv` без изменений.

## Ожидаемый результат

3 строки по убыванию доли акций, допуск ±0.01. Первая — Standard, `promo_pct` 30.487805. Последняя — Premium, 24.731183. Суммарный спрос при этом максимален у Premium.
