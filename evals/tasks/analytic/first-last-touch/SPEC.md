# Первое и последнее касание по каналам

Импорт CSV → последнее касание → две группировки → соединение по каналу → состав колонок → фильтр канала None → порядок колонок → сортировка → экспорт. Отдельно от экспорта посчитан контроль сумм.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Последнее касание пропускает строку None, а две сводки сходятся по каналу.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт 500 конверсий | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Последнее ненулевое касание | Калькулятор | `IF(touchpoint_3 <> "None", touchpoint_3, IF(touchpoint_2 <> "None", touchpoint_2, touchpoint_1))` |
| First-touch по каналам | Группировка | ключ `touchpoint_1`: число конверсий и сумма `conversion_value` |
| Last-touch по каналам | Группировка | ключ — последнее касание: число конверсий и сумма `conversion_value` |
| First-touch и last-touch | Слияние | соединение двух сводок по каналу |
| Пять колонок отчёта | Калькулятор | имена колонок задания; суммы округлены до 2 знаков |
| Исключить канал None | Фильтр | канал None не проходит |
| Имена и состав колонок CSV | Параметры полей | итоговые имена `channel, first_touch_conversions, first_touch_value, last_touch_conversions, last_touch_value` |
| Убывание first_touch_conversions | Сортировка | `first_touch_conversions` по убыванию |
| CSV first-touch и last-touch | Текстовый файл | разделитель `,`, заголовок из имён колонок |
| Контроль итогов двух моделей | Группировка | контрольная свёртка, в файл результата не входит |

## Входные данные

`dataset.csv` — 500 конверсий, колонки `conversion_id, touchpoint_1, touchpoint_2, touchpoint_3, conversion_value, conversion_type, customer_segment, days_to_convert`; копия `analitic-tasks/task37-channel-attribution/data/dataset.csv` без изменений.
