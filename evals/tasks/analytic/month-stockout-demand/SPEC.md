# Спрос и дефицит по месяцам

Импорт CSV → группировка → калькулятор → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Месяц — текстовая колонка `month`. `month_num` во всех строках равен 12 и ключом группировки не является. `stockout_pct` — доля строк с `stockout = 1`.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт запасов — dataset.csv | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Показатели по month | Группировка | ключ `month`; число строк, сумма `demand`, сумма `stockout` |
| Доля дефицита, % — без округления | Калькулятор | `stockout_records / records * 100`; число строк, сумма спроса и число дефицитов не скрываются |
| По убыванию total_demand | Сортировка | `total_demand` по убыванию |
| CSV — месячный спрос и дефицит | Текстовый файл | разделитель `,`, колонки `month`, `records`, `total_demand`, `stockout_records`, `stockout_pct` |

Связи: Импорт запасов — dataset.csv → Показатели по month → Доля дефицита, % — без округления → По убыванию total_demand → CSV — месячный спрос и дефицит.

## Входные данные

`dataset.csv` — 180 строк, копия `analitic-tasks/task33-seasonal-inventory/data/dataset.csv` без изменений.

## Ожидаемый результат

12 строк по убыванию суммы спроса, допуск ±0.01. Первая — May, `total_demand` 12699. Последняя — Dec, 5288.
