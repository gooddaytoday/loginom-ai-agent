# Путь клиента по готовому исходу

Источник: analitic-tasks/task44-customer-journey, 600 строк data/dataset.csv. Исходный CSV сохранён побайтово. Группы определяются исходным journey_stage_4: Purchase или Abandoned. Исходный total_days не заменяется суммой длительностей стадий.

## Фактический граф

Описание проверено по Unit_0/Unit.xml принятого пакета. Пять стандартных узлов образуют один линейный путь; JavaScript отсутствует.

1. «dataset.csv — все исходные строки» — импорт UTF-8 с запятой и десятичной точкой. Загруженный CSV совпадает с источником по SHA256; фильтра нет.
2. «outcome — количество и средние исходных полей» — единственный ключ journey_stage_4, переименованный в outcome. Count(customer_id)→customers; пять отдельных Avg исходных days_in_awareness, days_in_consideration, days_in_decision, total_days и touchpoints дают соответствующие mean_* поля. Все 600 customer_id заполнены, поэтому count соответствует числу строк. Mean_total_days напрямую сопоставлен с total_days_Avg; вычисления суммы стадий в графе нет.
3. «outcome ASC — до округления» — Сортировка outcome ASC, LocaleAware=false.
4. «Финальное округление — шесть знаков для CSV» — пять средних заменяются строками. Для каждого x вычисляется Round(x*1000000); целая часть получается через Div(...,1000000), затем добавляются точка и шесть дробных цифр через StrZero(Mod(...,1000000),6). Это окончательное округление до шести знаков после сортировки. Все пять средних положительны на фиксированном входе. Счётчик customers остаётся целым.
5. «Итоговый CSV — journey outcome profile» — единственная выгрузка UTF-8 с заголовками из имён колонок, запятой и десятичной точкой.

## Результат и проверка

Колонки: outcome,customers,mean_awareness_days,mean_consideration_days,mean_decision_days,mean_total_days,mean_touchpoints. Две строки: Abandoned (200 клиентов), Purchase (400 клиентов). Полный oracle находится в oracle.csv, числовой допуск 1e-6.

CLI 0.2.2, openai/gpt-6.1-sol/xhigh, primary-попытка 1 без внешней подсказки, exit=0. Упрощение не применялось.

Официальная проверка графа и полного CSV прошла. Сохранённый пакет отдельно открыт через меню браузера и выполнен целиком: пять узлов активны, ошибок нет. Новый CSV полностью совпал с oracle; пакет закрыт без сохранения браузерных изменений. Версии, SHA256 и независимая слепая сверка приведены в provenance.
