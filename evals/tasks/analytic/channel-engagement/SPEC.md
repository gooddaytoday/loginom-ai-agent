# Просмотры и вовлечённость по каналу

Импорт CSV → калькулятор → группировка → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

`engagement_rate` в данных — доля. `avg_engagement_pct` — простое среднее этой доли, умноженной на 100 до группировки. Среднее не взвешивается по просмотрам.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт dataset.csv — 200 сообщений | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Вовлечённость в процентах | Калькулятор | `engagement_rate * 100` |
| Показатели по channel — простое среднее | Группировка | ключ `channel`; число сообщений, сумма `views`, сумма `forwards`, среднее процента |
| Сортировка по total_views ↓ | Сортировка | сумма просмотров по убыванию |
| Экспорт итогов — CSV | Текстовый файл | разделитель `,`, заголовок из имён колонок; имя файла задаёт harness |

Связи: Импорт dataset.csv — 200 сообщений → Вовлечённость в процентах → Показатели по channel — простое среднее → Сортировка по total_views ↓ → Экспорт итогов — CSV.

## Входные данные

`dataset.csv` — 200 сообщений, копия `analitic-tasks/task56-telegram-bot/data/dataset.csv` без изменений.

## Ожидаемый результат

5 строк по убыванию суммы просмотров, допуск ±0.01. Первая — channel_news, `avg_engagement_pct` 8.680435. Последняя — channel_business, 8.095946.
