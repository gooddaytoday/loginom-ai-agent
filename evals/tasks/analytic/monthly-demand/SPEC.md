# Спрос по месяцам 2025 года

Импорт CSV → месяц из даты → группировка по месяцу → сортировка по месяцу → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Месяц получается из даты, а по месяцу считаются сумма, среднее, максимум и число дней акции.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт ежедневного спроса | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок; `date` — дата/время, `promotion` — целое, `daily_demand` — вещественное |
| Месяц из даты | Дата и время | из `date` получается номер месяца; выход `month` сопоставлен с `date_M_1` |
| Показатели по месяцам | Группировка | ключ `month`; `days` — количество `date`, `total_demand` — сумма `daily_demand`, `avg_demand` — среднее `daily_demand`, `max_demand` — максимум `daily_demand`, `promo_days` — сумма `promotion` |
| Месяцы по возрастанию | Сортировка | `month` по возрастанию |
| Экспорт месячного спроса CSV | Текстовый файл | разделитель `,`, заголовок из имён колонок; имя файла задаёт harness |

Связи: Импорт ежедневного спроса → Месяц из даты → Показатели по месяцам → Месяцы по возрастанию → Экспорт месячного спроса CSV.

Эталон импортирует `date` как дату/время и берёт месяц узлом «Дата и время». Задание тип колонки не фиксирует: строка `ГГГГ-ММ-ДД`, из которой получен номер месяца, тоже подходит. Проверяются месяц и агрегаты, а не тип `date`.

## Входные данные

`dataset.csv` — 365 дней 2025 года, колонки `date, day_of_week, is_weekend, temperature, promotion, competitor_promo, daily_demand`; копия `analitic-tasks/task27-demand-forecasting/data/dataset.csv` без изменений.

## Ожидаемый результат

12 строк в порядке месяца от 1 до 12, допуск ±0.01. `days` — 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31. Январь: `total_demand` 9194.5, `avg_demand` 296.596774, `max_demand` 495.1, `promo_days` 9. Июнь: `max_demand` 631.9. Июль и ноябрь: `promo_days` 14.
