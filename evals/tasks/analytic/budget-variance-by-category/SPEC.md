# Отклонения бюджета и доля перерасхода по категориям

Импорт CSV → калькулятор отклонения статьи → группировка по `category` → сортировка → экспорт результата.

Имена файла пакета и файла результата задаёт harness (см. TASK.md); при оценке имена файлов не учитываются.

## Назначение

Расчёт после группировки и отрицательные отклонения: среднее считается по строкам, доля перерасхода — как среднее признака в процентах.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Статьи бюджета — dataset.csv | Текстовый файл | `dataset.csv`, первая строка — заголовок; `budgeted`, `actual` — вещественные, `is_over_budget` — целое |
| Отклонение и перерасход по статье | Калькулятор | `row_variance = actual - budgeted`; `row_over_budget_pct = is_over_budget * 100` |
| Показатели по категориям | Группировка | ключ `category`; `items` — количество `budget_id`, `total_budgeted` — сумма `budgeted`, `total_actual` — сумма `actual`, `avg_variance` — среднее `row_variance`, `over_budget_pct` — среднее `row_over_budget_pct` |
| По убыванию среднего отклонения | Сортировка | `avg_variance` по убыванию |
| CSV — бюджет по категориям | Текстовый файл | текстовый файл результата (имя задаёт harness) |

Связи: Статьи бюджета — dataset.csv → Отклонение и перерасход по статье → Показатели по категориям → По убыванию среднего отклонения → CSV — бюджет по категориям.

## Входные данные

`dataset.csv` — 120 статей, колонки `budget_id, category, quarter, budgeted, actual, department, variance, variance_pct, is_over_budget`; копия `analitic-tasks/task47-budget-variance/data/dataset.csv` без изменений.
