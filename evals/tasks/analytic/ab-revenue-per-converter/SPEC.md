# Выручка на конверсию в A/B-тесте

Импорт CSV → группировка → калькулятор → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

`revenue_per_converter` — сумма `revenue`, делённая на число конверсий, а не на число пользователей. Обе суммы остаются в выгрузке.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт dataset.csv | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Пользователи, конверсии и выручка по группам | Группировка | ключ `group`; число пользователей, сумма `conversion`, сумма `revenue` |
| Конверсия в процентах и выручка на конвертера | Калькулятор | `conversions / users * 100` и `total_revenue / conversions`; суммы не скрываются |
| Сортировка по conversion_pct по убыванию | Сортировка | `conversion_pct` по убыванию |
| Экспорт итогового CSV | Текстовый файл | разделитель `,`, заголовок из имён колонок; имя файла задаёт harness |

Связи: Импорт dataset.csv → Пользователи, конверсии и выручка по группам → Конверсия в процентах и выручка на конвертера → Сортировка по conversion_pct по убыванию → Экспорт итогового CSV.

## Входные данные

`dataset.csv` — 2000 пользователей, копия `analitic-tasks/task06-ab-testing/data/dataset.csv` без изменений.

## Ожидаемый результат

2 строки по убыванию конверсии, допуск ±0.01. Первая — B: 1013 пользователей, 157 конверсий, `conversion_pct` 15.498519, `total_revenue` 9714.82, `revenue_per_converter` 61.877834.
