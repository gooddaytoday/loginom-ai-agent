# Сегменты NPS по тарифу

Импорт CSV → калькулятор → группировка → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Промоутер — балл не меньше 7, противник — балл меньше 0. Доли в процентах — средние отметок 100 и 0, посчитанных до группировки.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Ответы опроса — dataset.csv | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Признаки промоутера и противника | Калькулятор | `IFF(nps_score >= 7, 100, 0)` и `IFF(nps_score < 0, 100, 0)` |
| Показатели по тарифам | Группировка | ключ `customer_tier`; число ответов, среднее `nps_score`, средние обеих отметок |
| Средний nps_score по убыванию | Сортировка | `avg_nps_score` по убыванию |
| Результат по тарифам — CSV | Текстовый файл | разделитель `,`, заголовок из имён колонок; имя файла задаёт harness |

Связи: Ответы опроса — dataset.csv → Признаки промоутера и противника → Показатели по тарифам → Средний nps_score по убыванию → Результат по тарифам — CSV.

## Входные данные

`dataset.csv` — 400 ответов, копия `analitic-tasks/task35-nps-csat/data/dataset.csv` без изменений.

## Ожидаемый результат

3 строки по убыванию среднего балла, допуск ±0.01. Первая — basic: `avg_nps_score` 6.345946, `promoters_pct` 56.756757, `detractors_pct` 1.081081.
