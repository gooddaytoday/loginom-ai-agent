# Одобренные заявки с высоким фрод-скором

Импорт CSV → фильтр по статусу и фрод-скору → группировка по типу полиса → сортировка по сумме выплат → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

В выборку входят только статус Approved и fraud_score строго больше 0.8.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт страховых заявок | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Одобренные заявки с высоким fraud_score | Фильтр | `claim_status` равно `Approved` (с учётом регистра) и `fraud_score` строго больше 0.8; условия соединены через «и» |
| Итоги по типу полиса | Группировка | ключ `policy_type`; число заявок, сумма `claim_amount`, сумма `payout_amount`, среднее `fraud_score` |
| По убыванию суммы выплат | Сортировка | сумма выплат по убыванию |
| Экспорт итогового CSV | Текстовый файл | разделитель `,`, заголовок из имён колонок; колонки `policy_type, claims, total_claimed, total_payout, avg_fraud_score` |

Связи: Импорт страховых заявок → Одобренные заявки с высоким fraud_score → Итоги по типу полиса → По убыванию суммы выплат → Экспорт итогового CSV.

## Входные данные

`dataset.csv` — 400 заявок, колонки `claim_id, policy_type, claim_amount, claim_status, payout_amount, processing_days, policyholder_age, claims_history, fraud_score, agent_id, region`; копия `analitic-tasks/task49-insurance-claims/data/dataset.csv` без изменений.

4 строки по убыванию выплат: Home, Life, Auto, Health. Home: `claims` 23, `total_claimed` 1854751.31, `total_payout` 1204828.25. Health: `claims` 12, `total_claimed` 1014516.87, `total_payout` 573068.73. Допуск ±0.01.
