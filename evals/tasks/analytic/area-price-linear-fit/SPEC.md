# Линейная зависимость цены от площади

Источник: analitic-tasks/task11-regression, 400 строк data/dataset.csv. Исходный CSV сохранён побайтово. Рассчитывается OLS price~area_sqm с intercept по всем строкам; другие признаки не используются.

## Фактический граф

Описание проверено по Unit_0/Unit.xml принятого пакета. Восемь стандартных узлов образуют линейный путь; JavaScript отсутствует.

1. «dataset.csv — исходные данные» — импорт UTF-8, запятая и десятичная точка. Загруженная копия совпадает с источником по SHA256.
2. «x², y², xy — без округления» — Калькулятор: all_rows=1; x_squared=area_sqm*area_sqm; y_squared=price*price; xy=area_sqm*price.
3. «Все строки: n и суммы для OLS» — Группировка по постоянному all_rows; COUNT(house_id) → houses; суммы area_sqm, price, x_squared, y_squared, xy → sum_x, sum_y, sum_xx, sum_yy, sum_xy. Все house_id заполнены, houses=400 соответствует всем входным строкам.
4. «A, B, C → OLS с intercept» — Калькулятор: A=houses*sum_xx−sum_x²; B=houses*sum_yy−sum_y²; C=houses*sum_xy−sum_x*sum_y; slope_raw=C/A; intercept_raw=sum_y/houses−slope_raw*sum_x/houses; r_squared_raw=C²/(A*B). Пустой служебный Expr1 исключается ниже.
5. «Сортировка по неокруглённым OLS» — Сортировка slope_raw, intercept_raw, r_squared_raw по возрастанию. На единственную строку результата порядок не влияет.
6. «Четыре итоговых показателя» — Параметры полей исключают Expr1, A/B/C, постоянный ключ и суммы, оставляют houses и три неокруглённых коэффициента.
7. «Round6» — Калькулятор заменяет три коэффициента через Round(...,6); выходное сопоставление даёт houses,slope,intercept,r_squared. houses остаётся целым, остальные поля числовые.
8. «CSV result» — единственная выгрузка UTF-8, заголовки из имён колонок, запятая и десятичная точка.

## Результат и проверка

Колонки: houses,slope,intercept,r_squared. Одна строка; округление выполняется только в последнем вычислительном узле. Полный oracle находится в oracle.csv, числовой допуск 1e-6.

CLI 0.2.2, openai/gpt-6.1-sol/xhigh, primary-попытка 1 без внешней подсказки. Модель самостоятельно восстановила локальные остановки открытия калькуляторов и настройки сортировки через штатные inspect/recover. Повторное открытие Round6 удалось в той же попытке; пакет сохранён с exit=0. Упрощение не применялось.

Официальная проверка графа и полного CSV прошла. Сохранённый пакет заново открыт через меню и выполнен целиком: восемь узлов активны, ошибок нет. Новый CSV полностью совпал с oracle; пакет закрыт без сохранения изменений браузерной сессии. Версии, SHA256 и независимая слепая сверка приведены в provenance.
