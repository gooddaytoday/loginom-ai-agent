# Статьи по авторам, включая неизвестного

Импорт CSV → замена пустого автора и признак positive → группировка по автору → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Пустой автор заменяется на Unknown, строки не отбрасываются. Доля positive считается среди статей автора.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт статей | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Unknown и признак positive | Калькулятор | `IF(NVL(author, "") = "", "Unknown", author)`; `IF(sentiment = "positive", 100.0, 0.0)` |
| Показатели по авторам | Группировка | ключ — автор после замены; число статей, среднее `popularity_score`, среднее признака positive |
| По убыванию числа статей | Сортировка | число статей по убыванию |
| CSV по авторам | Текстовый файл | разделитель `,`, заголовок из имён колонок; колонки `author, articles, avg_popularity, positive_pct` |

Связи: Импорт статей → Unknown и признак positive → Показатели по авторам → По убыванию числа статей → CSV по авторам.

## Входные данные

`dataset.csv` — 180 статей, колонки `article_id, title, source, category, published_at, word_count, popularity_score, sentiment, author, url`; копия `analitic-tasks/task63-newsapi/data/dataset.csv` без изменений. У 33 строк `author` пустой.

## Ожидаемый результат

4 строки: Author_B 57, Author_A 54, Author_C 36, Unknown 33. Author_B: `avg_popularity` 49.707018, `positive_pct` 29.824561. Unknown: `avg_popularity` 60.687879, `positive_pct` 30.30303. Допуск ±0.01.
