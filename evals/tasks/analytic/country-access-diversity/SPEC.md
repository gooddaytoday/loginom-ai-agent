# Разнообразие сетевых меток по странам

Источник: `analitic-tasks/task64-ipapi`. Фиксированный вход — `data/dataset.csv`, все 200 строк. country_code, ip, isp и timezone используются как исходные синтетические метки. Геолокация, сетевые вызовы и исправление географии не выполняются.

## Фактический граф

В `reference.lgp` 12 стандартных узлов, три ветки от одного импорта, два объединения и один итоговый экспорт. Все узлы входят в связный граф от входа до выгрузки.

1. Импорт UTF-8 CSV с заголовком, запятой и точкой.
2. Группировка по country_code и точному ip: Count(request_id) → ip_requests, то есть число исходных строк для пары. Во всех 200 строках request_id заполнен.
3. Группировка результата по country_code: Sum(ip_requests) → requests; Count(ip) → unique_ips. Число записей не подменяется числом уникальных IP.
4. Параллельно от импорта группировка по country_code и isp создаёт уникальные пары (также сохраняет вспомогательный Count(request_id) → isp_requests).
5. Группировка этих пар по country_code: Count(isp) → providers.
6. Третья ветка от импорта: группировка по country_code и timezone создаёт уникальные пары (вспомогательный Count(request_id) → timezone_requests).
7. Группировка этих пар по country_code: Count(timezone) → timezones.
8. Соединение requests/unique_ips с providers по равенству country_code.
9. Соединение результата с timezones по тому же ключу. Все три сводки имеют одну строку для каждой исходной страны; строки не теряются и не размножаются.
10. Сортировка requests по убыванию, country_code по возрастанию; LocaleAware=false.
11. Параметры полей переводят requests из типа вещественной суммы в целый; остальные три счётчика уже целые. Выход содержит ровно пять заданных колонок. Вещественных показателей для округления нет.
12. Единственный UTF-8 CSV-экспорт с заголовками, запятой и точкой: `/user/analytic-evals-country-access-diversity-1.result.csv`.

JavaScript и подставленные итоговые строки отсутствуют. CLI 0.2.2, модель openai/gpt-6.1-sol/xhigh, primary-попытка 1 без подсказки и без упрощения. Внутри попытки один жест графа был отклонён до эффекта из-за недоступного элемента навигации; агент обновил наблюдение и успешно повторил действие с новым operation_id. Аналитика не менялась.

## Результат и проверки

Семь строк; колонки `country_code,requests,unique_ips,providers,timezones`. Полный oracle.csv с абсолютным допуском 1e-6 подтверждён независимым слепым SQL-расчётом. Все итоговые числа целые; фактические CSV совпали с oracle точно, включая порядок колонок и строк.

Проверены SHA256 исходного CSV, отдельные группировки уникальных значений, сохранение числа исходных строк, ключи соединений, связность и одна итоговая выгрузка. После CLI сохранённый пакет заново открыт и выполнен в браузере: все 12 узлов активны, ошибок нет. Пакет закрыт без сохранения, новый CSV повторно совпал с oracle и побайтово с результатом CLI. Пути доказательств и история — в provenance.json.
