# Текучесть по отделам

Импорт CSV → группировка → калькулятор → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Доля ушедших — число сотрудников с `left_company = 1`, делённое на число сотрудников отдела и умноженное на 100.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт сотрудников — dataset.csv | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Сотрудники и ушедшие по отделам | Группировка | ключ `department`; число сотрудников, сумма `left_company` |
| Доля ушедших — turnover_pct | Калькулятор | `100 * leavers / employees`; колонки числа сотрудников и ушедших остаются |
| Отделы по убыванию текучести | Сортировка | `turnover_pct` по убыванию |
| CSV — текучесть по отделам | Текстовый файл | разделитель `,`, заголовок из имён колонок; имя файла задаёт harness |

Связи: Импорт сотрудников — dataset.csv → Сотрудники и ушедшие по отделам → Доля ушедших — turnover_pct → Отделы по убыванию текучести → CSV — текучесть по отделам.

## Входные данные

`dataset.csv` — 450 сотрудников, копия `analitic-tasks/task43-employee-turnover/data/dataset.csv` без изменений.

## Ожидаемый результат

6 строк по убыванию `turnover_pct`, допуск ±0.01. Первая — Finance, 35.483871. Последняя — Sales, 20.731707.
