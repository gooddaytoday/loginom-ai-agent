# Маржа групп ценового теста

Импорт CSV → группировка → калькулятор → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

`margin_pct` — простое среднее `profit_margin`, умноженное на 100, а не среднее, взвешенное `units_sold`.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт dataset.csv | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Показатели по price_test_group | Группировка | ключ `price_test_group`; число товаров, сумма `units_sold`, простое среднее `profit_margin`, среднее `customer_satisfaction` |
| margin_pct = средняя маржа × 100 | Калькулятор | `margin_pct * 100`, с заменой этой колонки; число товаров, сумма единиц и средняя удовлетворённость не скрываются |
| margin_pct по убыванию | Сортировка | `margin_pct` по убыванию |
| CSV результатов | Текстовый файл | разделитель `,`, колонки `price_test_group`, `products`, `units`, `margin_pct`, `avg_satisfaction` |

Связи: Импорт dataset.csv → Показатели по price_test_group → margin_pct = средняя маржа × 100 → margin_pct по убыванию → CSV результатов.

## Входные данные

`dataset.csv` — 350 товаров, копия `analitic-tasks/task42-pricing-strategy/data/dataset.csv` без изменений.

## Ожидаемый результат

4 строки по убыванию маржи, допуск ±0.01. Первая — test_increase_10, `margin_pct` 37.631461. Последняя — control, 33.186207. По числу единиц первым был бы test_decrease_10.
