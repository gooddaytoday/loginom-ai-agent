# Продажи праздничных месяцев

Импорт CSV → группировка → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Резерв вместо `sector-average-return`: тот за три попытки пакет не сохранил. Здесь праздничные и обычные месяцы сравниваются без калькулятора после группировки.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт dataset.csv | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Показатели по holidays | Группировка | ключ `holidays`; число месяцев, сумма `sales`, среднее `sales`, сумма `advertising_budget` |
| total_sales по убыванию | Сортировка | `total_sales` по убыванию |
| Экспорт итогового CSV | Текстовый файл | разделитель `,`, колонки `holidays`, `months`, `total_sales`, `avg_sales`, `advertising_budget` |

Связи: Импорт dataset.csv → Показатели по holidays → total_sales по убыванию → Экспорт итогового CSV.

## Входные данные

`dataset.csv` — 36 месяцев, копия `analitic-tasks/task04-time-series/data/dataset.csv` без изменений.

## Ожидаемый результат

2 строки по убыванию суммы продаж, допуск ±0.01. Первая — `holidays` 0: 30 месяцев, `total_sales` 380856.81. Последняя — `holidays` 1: 6 месяцев, 70711.52.
