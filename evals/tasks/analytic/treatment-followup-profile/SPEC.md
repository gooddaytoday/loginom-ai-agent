# События и сроки наблюдения по treatment

Источник: analitic-tasks/task13-survival-analysis, 350 строк data/dataset.csv. Исходный CSV сохранён побайтово. Это описательная сводка наблюдения по treatment; оценка выживаемости не строится.

## Фактический граф

Описание проверено по Unit_0/Unit.xml принятого пакета. Девять стандартных узлов образуют линейный путь; JavaScript отсутствует.

1. «dataset.csv — исходные наблюдения» — импорт UTF-8 с запятой и десятичной точкой, загруженная копия совпадает с источником по SHA256.
2. «Индикаторы строк, событий и цензурирования» — Калькулятор: row_count=1; event_count=IFF(event_occurred=1,1,0); censored_count=IFF(event_occurred=0,1,0). Все строки сохраняются.
3. «Профиль наблюдения по treatment — все строки» — Группировка по treatment, суммы трёх индикаторов → patients/events/censored; AVG(time_months) → avg_time_months по всем строкам, включая цензурированные.
4. «Доля цензурированных — без округления» — Калькулятор: censored_pct=100.0*censored/patients.
5. «treatment по возрастанию — до округления» — Сортировка treatment ASC, LocaleAware=false.
6. «Финал: целые счётчики и округление до 6 знаков» — Калькулятор переводит patients/events/censored через Int(...), заменяет censored_pct/avg_time_months через Round(...,6). Выходное сопоставление задаёт шесть итоговых полей.
7. «CSV: десятичная точка и ровно 6 знаков» — Калькулятор преобразует уже округлённые censored_pct/avg_time_months в строки через Concat(Str(Int(value)),".",StrZero(Round(Frac(value)*1000000),6)). Это только финальное представление для CSV; последующих вычислений по этим значениям нет.
8. «Итоговые 6 колонок в заданном порядке» — Параметры полей исключают пустой служебный Expr1, оставляют treatment,patients,events,censored,censored_pct,avg_time_months.
9. «analytic-evals-treatment-followup-profile-1.result.csv» — единственная выгрузка UTF-8 с заголовками из имён колонок, запятой и десятичной точкой.

## Результат и проверка

Три строки: Drug_A, Drug_B, Placebo; количество наблюдений 121,108,121. Censored_pct выражен в процентах; patients/events/censored целые. Полный oracle находится в oracle.csv, числовой допуск 1e-6.

CLI 0.2.2, openai/gpt-6.1-sol/xhigh, primary-попытка 1 без внешней подсказки. Модель самостоятельно восстановила локальные остановки настройки форматирования и размещения экспорта штатными inspect/recover/observe. Пакет сохранён с exit=0; упрощение не применялось.

Официальная проверка графа и полного CSV прошла. Сохранённый пакет заново открыт через меню и выполнен целиком: девять узлов активны, ошибок нет. Новый CSV полностью совпал с oracle; пакет закрыт без сохранения изменений браузерной сессии. Версии, SHA256 и независимая слепая сверка приведены в provenance.
