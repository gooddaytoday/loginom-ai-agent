# Конверсия вариантов сайта

Импорт CSV → группировка → калькулятор → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

`conversion_pct` — доля пользователей с `converted = 1`, в процентах. Статистическая значимость не проверяется. Среднее число просмотров остаётся в выгрузке.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт пользователей A/B-теста | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Показатели по variant | Группировка | ключ `variant`; число пользователей, сумма `converted`, среднее `page_views` |
| Доля конверсий в процентах | Калькулятор | `conversions / users * 100`; число пользователей, число конверсий и среднее просмотров не скрываются |
| conversion_pct по убыванию | Сортировка | `conversion_pct` по убыванию |
| CSV результата A/B-теста | Текстовый файл | разделитель `,`, колонки `variant`, `users`, `conversions`, `conversion_pct`, `avg_page_views` |

Связи: Импорт пользователей A/B-теста → Показатели по variant → Доля конверсий в процентах → conversion_pct по убыванию → CSV результата A/B-теста.

## Входные данные

`dataset.csv` — 600 пользователей, копия `analitic-tasks/task30-ab-test-multi/data/dataset.csv` без изменений.

## Ожидаемый результат

4 строки по убыванию конверсии, допуск ±0.01. Первая — Variant_B, `conversion_pct` 27.848101. Последняя — Control, 16.129032.
