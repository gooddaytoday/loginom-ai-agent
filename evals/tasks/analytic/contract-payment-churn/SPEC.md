# Отток по договору и способу оплаты

Источник: analitic-tasks/task25-churn-prediction, 500 строк data/dataset.csv. Исходный CSV сохранён побайтово. Используется готовый churn, без обучения или прогнозирования.

## Фактический граф

Описание проверено по Unit_0/Unit.xml принятого пакета. Восемь стандартных узлов образуют один линейный путь; JavaScript отсутствует.

1. «Импорт dataset.csv — все исходные строки» — импорт UTF-8 с запятой и десятичной точкой. Загруженный CSV совпадает с источником по SHA256; фильтра нет.
2. «Единица строки и индикатор churn = 1» — Калькулятор: row_one=1, churn_flag=IFF(churn=1,1,0), оба целые.
3. «Группировка contract_type × payment_method» — только два исходных строковых ключа; Count(row_one)→customers, Sum(churn_flag)→churned, Avg(monthly_charges)→avg_monthly_charges.
4. «Процент оттока без округления» — Калькулятор: churn_pct=100.0*churned/customers. Churned заменяется на Int(churned), customers уже целый. Служебный row_check=1 не участвует в показателях.
5. «Сортировка по неокруглённому churn_pct» — Сортировка churn_pct DESC, contract_type ASC, payment_method ASC, LocaleAware=false.
6. «Финальное округление до 6 знаков» — Калькулятор заменяет churn_pct и avg_monthly_charges через Round(...,6) после сортировки.
7. «Итоговые 6 колонок в заданном порядке» — Параметры полей исключают служебный row_check, оставляют шесть требуемых колонок; customers и churned имеют целый тип.
8. «Экспорт результата CSV» — единственная выгрузка UTF-8 с заголовками из имён колонок, запятой и десятичной точкой.

## Результат и проверка

Колонки: contract_type,payment_method,customers,churned,churn_pct,avg_monthly_charges. Двенадцать строк, отсортированных по неокруглённому проценту оттока и ключам. Полный oracle находится в oracle.csv, числовой допуск 1e-6.

CLI 0.2.2, openai/gpt-6.1-sol/xhigh, primary-попытка 1 без внешней подсказки. Модель самостоятельно восстановила технические шаги импорта и настройки процента в пределах попытки; пакет сохранён с exit=0. Упрощение не применялось.

Официальная проверка графа и полного CSV прошла. Сохранённый пакет отдельно открыт через меню браузера и выполнен целиком: восемь узлов активны, ошибок нет. Новый CSV полностью совпал с oracle; пакет закрыт без сохранения браузерных изменений. Версии, SHA256 и независимая слепая сверка приведены в provenance.
