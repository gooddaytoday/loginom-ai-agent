# Переработка по отделам

Импорт CSV → калькулятор → группировка → калькулятор → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Тяжёлая переработка — `overtime_hours` строго больше 20. Значение 20 в долю не входит. Доля считается после группировки, исходные суммы остаются в выгрузке.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт dataset.csv | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Признак большой переработки | Калькулятор | `IF(overtime_hours > 20, 1, 0)` |
| Показатели по отделам | Группировка | ключ `department`; число сотрудников, сумма признака, среднее `kpi_score` |
| Итоговые колонки и доля | Калькулятор | `heavy_overtime * 100.0 / employees`; колонки отдела, числа сотрудников, числа тяжёлых переработок и среднего KPI не скрываются |
| По убыванию доли переработок | Сортировка | `heavy_overtime_pct` по убыванию |
| Выгрузка итогового CSV | Текстовый файл | разделитель `,`, колонки `department`, `employees`, `heavy_overtime`, `heavy_overtime_pct`, `avg_kpi` |

Связи: Импорт dataset.csv → Признак большой переработки → Показатели по отделам → Итоговые колонки и доля → По убыванию доли переработок → Выгрузка итогового CSV.

## Входные данные

`dataset.csv` — 150 сотрудников, копия `analitic-tasks/task23-employee-performance/data/dataset.csv` без изменений.

## Ожидаемый результат

5 строк по убыванию доли, допуск ±0.01. Первая — Finance, `heavy_overtime_pct` 96.774194. Последняя — Sales, 91.176471. У Sales ровно одна строка с `overtime_hours` = 20.
