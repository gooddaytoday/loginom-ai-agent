# Продажи по категориям: транзакции, выручка и средние

Импорт CSV → группировка по `category` → сортировка по выручке → экспорт результата.

Имена файла пакета и файла результата задаёт harness (см. TASK.md); при оценке имена файлов не учитываются.

## Назначение

Несколько агрегатов в одной группировке и сортировка по вычисленной мере, а не по ключу.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Продажи: dataset.csv | Текстовый файл | `dataset.csv`, первая строка — заголовок; `quantity` — целое, `unit_price` и `total` — вещественные, `date` — дата/время |
| Показатели по категориям | Группировка | ключ `category`; `transactions` — количество строк, `revenue` — сумма `total`, `avg_quantity` — среднее `quantity`, `avg_unit_price` — среднее `unit_price` |
| По убыванию выручки | Сортировка | `revenue` по убыванию |
| CSV: продажи по категориям | Текстовый файл | текстовый файл результата (имя задаёт harness) |

Связи: Продажи: dataset.csv → Показатели по категориям → По убыванию выручки → CSV: продажи по категориям.

## Входные данные

`dataset.csv` — 500 транзакций, колонки `transaction_id, category, region, quantity, unit_price, date, total`; копия `analitic-tasks/task02-group-analysis/data/dataset.csv` без изменений.
