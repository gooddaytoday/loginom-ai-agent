# ROI рекламных каналов по суммам бюджета и выручки

Импорт CSV → группировка по `channel` → калькулятор ROI по суммам → сортировка → экспорт результата.

Имена файла пакета и файла результата задаёт harness (см. TASK.md); при оценке имена файлов не учитываются.

## Назначение

ROI считается из сумм бюджета и выручки канала. Готовая колонка `roi` не усредняется.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт кампаний | Текстовый файл | `dataset.csv`, первая строка — заголовок; `budget` и `revenue` — вещественные |
| Итоги по каналам | Группировка | ключ `channel`; `campaigns` — количество `campaign_id`, `total_budget` — сумма `budget`, `total_revenue` — сумма `revenue` |
| ROI по суммам | Калькулятор | `roi_pct = (total_revenue - total_budget) / total_budget * 100` |
| По убыванию ROI | Сортировка | `roi_pct` по убыванию |
| CSV по каналам | Текстовый файл | текстовый файл результата (имя задаёт harness) |

Связи: Импорт кампаний → Итоги по каналам → ROI по суммам → По убыванию ROI → CSV по каналам.

## Входные данные

`dataset.csv` — 500 кампаний, колонки `campaign_id, channel, budget, impressions, clicks, conversions, revenue, target_audience, duration_days, ctr, conversion_rate, roi`; копия `analitic-tasks/task19-campaign-roi/data/dataset.csv` без изменений.
