# Уровень брака по линии и смене из сумм

Импорт CSV → группировка по линии и смене → процент брака из сумм → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Группировка идёт по двум ключам, а уровень брака считается из сумм, не из среднего готовой колонки `defect_rate`.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Импорт производственных партий | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Показатели по линии и смене | Группировка | ключи `production_line` и `shift`; число партий, сумма `total_produced`, сумма `defect_count` |
| Процент брака по суммам | Калькулятор | `defects / total_produced * 100` |
| Рейтинг по проценту брака | Сортировка | `defect_rate_pct` по убыванию |
| Экспорт рейтинга в CSV | Текстовый файл | разделитель `,`, заголовок из имён колонок; колонки `production_line, shift, batches, total_produced, defects, defect_rate_pct` |

Связи: Импорт → Показатели по линии и смене → Процент брака по суммам → Рейтинг → Экспорт.

## Входные данные

`dataset.csv` — 500 партий, колонки `product_id, production_line, shift, defect_count, total_produced, defect_rate, inspection_score, temperature, humidity, operator_experience, material_batch`; копия `analitic-tasks/task48-quality-control/data/dataset.csv` без изменений.

## Ожидаемый результат

9 строк. Первая — Line_C, Morning, `defect_rate_pct` 0.416069. Последняя — Line_B, Afternoon, `defect_rate_pct` 0.325163. Допуск ±0.01.
