# Долгие доставки по поставщику

Импорт CSV → калькулятор → группировка → калькулятор → сортировка → экспорт.

Имена файла пакета и файла результата задаёт harness; при оценке они не учитываются.

## Назначение

Долгая доставка — `delivery_days` строго больше 15. Доля считается после группировки из числа долгих доставок и числа заказов. Значение ровно 15 в долю не входит.

## Сценарий

| Узел | Компонент | Настройка |
|:-----|:----------|:----------|
| Заказы — dataset.csv | Текстовый файл | загруженная копия `dataset.csv`, разделитель `,`, первая строка — заголовок |
| Долгая доставка — строго больше 15 дней | Калькулятор | `IF(delivery_days > 15, 1, 0)` |
| Показатели по поставщикам | Группировка | ключ `supplier`; число заказов, сумма признака, среднее `quality_score`, сумма `order_cost` |
| Доля долгих доставок и колонки отчёта | Калькулятор | `slow_pct` = `100 * slow_orders / orders`; колонки отчёта не скрываются |
| Рейтинг — slow_pct по убыванию | Сортировка | `slow_pct` по убыванию |
| Итоговый CSV | Текстовый файл | разделитель `,`, заголовок из имён колонок; имя файла задаёт harness |

Связи: Заказы — dataset.csv → Долгая доставка — строго больше 15 дней → Показатели по поставщикам → Доля долгих доставок и колонки отчёта → Рейтинг — slow_pct по убыванию → Итоговый CSV.

## Входные данные

`dataset.csv` — 250 заказов, копия `analitic-tasks/task22-supply-chain/data/dataset.csv` без изменений.

## Ожидаемый результат

5 строк по убыванию `slow_pct`, допуск ±0.01. Первая — Supplier_C, 82.5. Supplier_E — 74.468085: строка со значением 15 не входит. Последняя — Supplier_A, 66.
