Ошибка готового прогноза в масштабе train-only naive MAE при лаге m=1. Данные синтетические; native reference читает mase_training.csv и mase_forecasts.csv, не обучает новую модель.

| Узел | Компонент | Фактическая настройка |
|---|---|---|
| Обучение CSV | Импорт текста | series_id,t,value, CSV UTF-8 |
| Готовые прогнозы CSV | Импорт текста | series_id,t,actual,predicted, CSV UTF-8 |
| Обучение сдвиг t на 1 | Калькулятор | Заменить t на t+1 в копии training |
| Только соседние train пары | Внутреннее соединение | Исходное training и сдвинутое training по series_id,t; значение предшественника previous_value |
| Абсолютные train изменения | Калькулятор | train_abs_change=Abs(value-previous_value) |
| Масштаб только по обучению | Группировка | series_id; COUNT пар как train_pairs, AVG(train_abs_change) как train_naive_mae |
| Абсолютные test ошибки | Калькулятор | test_abs_error=Abs(actual-predicted) |
| Количество и MAE теста | Группировка | series_id; COUNT test точек как test_points, AVG(test_abs_error) как test_mae |
| Train и test сводки по ряду | Внутреннее соединение | series_id, каждый ряд присутствует в обеих сводках |
| MASE без округления и статус | Калькулятор | IF(train_naive_mae=0,Null,test_mae/train_naive_mae); undefined при нулевом масштабе, иначе ok |
| Ряды по возрастанию | Сортировка | series_id по возрастанию; точная итоговая схема |
| Итог округление до 6 знаков | Калькулятор | Заменить train_naive_mae,test_mae,mase на Round(...,6), после решения о NULL/status |
| Итог MASE CSV | Экспорт текста | Один CSV UTF-8 с заголовком, запятой, десятичной точкой, пустым числом для NULL |

Ветка train строит только соседние пары одного ряда; первая train-точка не является парой. Ветка test содержит только предоставленные ошибки. Масштаб не использует test, промежуточные значения не округлены. Соединение на соседний t содержит series_id; никаких межрядовых пар. T01 имеет train scale=7/3, test MAE=3/2, MASE=9/14; T02 имеет тот же test MAE, но иной train scale. T03 имеет нулевой scale и ненулевую ошибку, T04 точный прогноз при положительном scale. Файл перемешан, поэтому исходный порядок строк не заменяет t.

Независимый oracle читает исходные CSV, сортирует train-списки по t и использует zip соседних точек/Fraction; он не использует join-граф, LGP или экспорт Loginom. Полный результат (4 строки × 7 колонок, абсолютный допуск 0.000001):

```csv
series_id,train_pairs,test_points,train_naive_mae,test_mae,mase,status
T01,3,2,2.333333,1.500000,0.642857,ok
T02,3,2,10.000000,1.500000,0.150000,ok
T03,2,2,0.000000,4.500000,,undefined
T04,2,3,1.000000,0.000000,0.000000,ok
```

Reference прошёл CLI-check и отдельный cold: все 13 исполняемых узлов, новый полный CSV/oracle, неизменный серверный SHA256, без настройки/Save, close/logout успешны. Обе формы используют тот же reference, отдельной авторской B-попытки не было. Имена и число узлов не являются требованиями rubric; эквивалентные native-композиции принимаются.
