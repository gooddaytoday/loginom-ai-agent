# P42. Разброс индивидуальных изменений

> Сведения о локальном окружении обезличены. Приватные подтверждения, упомянутые в документе, не включены в репозиторий.

Назначение: сравнить парные изменения измерений одних и тех же машин по группам настройки. Изменение — after минус before, разброс — выборочное стандартное отклонение индивидуальных изменений, SE — стандартная ошибка их среднего.

## Происхождение и границы

Обе формы используют один reference первой авторской CLI-попытки detailed (D). Отдельная авторская сборка business (B) не выполнялась. Описание основано на фактически сохранённом `reference.lgp`, содержащем один `Unit_0/Unit.xml`. Независимый браузерный cold rerun выполнил все шесть узлов без настройки и сохранения; root отдельно подтвердил неизменность серверного LGP до/после и совпадение нового полного CSV с независимым oracle. Калибровка и измерения учитываются отдельно в карточке P42.

Это один допустимый native-путь без JavaScript. Эквивалентные native-композиции принимаются; имена, число узлов и внутренний граф reference не являются требованиями к решению. Имена пакета и файла результата задаёт harness.

## Вход

`data/machines.csv` — синтетические полные пары: `id`, `setting_group`, `before`, `after`. `id` уникален, каждая строка описывает одну машину. В каждой группе не менее двух машин; единица измерения общая. CSV UTF-8 с заголовком, разделителем `;` и десятичной точкой. В импорте `id` и `setting_group` имеют тип `dtString`, вид `dkDiscrete`; `before` и `after` — `dtInteger`, `dkContinuous`.

## Сохранённые узлы и настройки

| Узел | Реальный компонент (`xsi:type` Engine) | Существенные настройки |
| --- | --- | --- |
| Машины | `TBGImportTextFile` | Путь `PRIVATE_STORAGE`; `CodePage=65001`, `DelimiterChar=;`, `DecimalSeparator=.`, пустой `ValueNull`; четыре поля входной схемы. |
| Изменение машины | `TBGCalcData` | Новое поле `change`, `dtFloat`, выражение `after - before`; исходные пары сохраняются построчно. |
| Статистика изменений | `TBGCrossTabEngine` | `setting_group` — активное строковое измерение, измерений колонок нет; `change` — значение с `AggregationTypes="ctatCount ctatAvg ctatStdDev"` в `TBGCrossTabColumnDefExtension`. Выходы `change_Count`, `change_Avg`, `change_StdDev`. |
| Стандартная ошибка | `TBGCalcData` | `se_change`, `dtFloat`, выражение `change_StdDev / Sqrt(change_Count)`; mapping `change_Count` → `pairs`, `change_Avg` → `mean_change`, `change_StdDev` → `sample_sd_change`. На выходе пять итоговых полей. |
| Порядок групп | `TBGSortingEngine` | `SortingColumns`: `setting_group`; `LocaleAware=false`. Отдельного атрибута направления нет; фактический CSV имеет требуемый порядок по возрастанию. |
| Итоговый CSV | `TBGExportTextFile` | Один `*.result.csv`; `CodePage=65001`, `CaptionType=ctUseColumnNames`, `DelimiterChar=;`, `DecimalSeparator=.`, пустой `ValueNull`. Атрибут строкового квалификатора в XML не записан. |

В принятом reference `ctatStdDev` фактически даёт выборочное отклонение с делителем n−1: это подтверждено полным сравнением результатов CLI и cold rerun с независимым `statistics.stdev` по всем трём группам. XML не содержит отдельного атрибута выбора делителя.

## Связи

Единственная последовательная цепочка: `Машины → Изменение машины → Статистика изменений → Стандартная ошибка → Порядок групп → Итоговый CSV`. Все пять связей передают табличные данные. Сначала рассчитываются индивидуальные подписанные разности, затем групповые показатели и SE; before и after не агрегируются независимо.

## Ожидаемый результат

Одна строка на `setting_group`, ключ уникален, порядок по возрастанию с учётом регистра без локали. Ровно поля `setting_group, pairs, mean_change, sample_sd_change, se_change`; порядок колонок не оценивается. `pairs` — число полных пар своей группы; `mean_change` — среднее индивидуальных after−before; `sample_sd_change` — их выборочное стандартное отклонение с делителем pairs−1; `se_change=sample_sd_change/sqrt(pairs)` своей группы.

Один CSV UTF-8 с заголовками имён, разделителем `;`, десятичной точкой, строковым квалификатором `"`, без разделителей тысяч и промежуточного округления. Источник всех ожидаемых строк и чисел — соседний `oracle.csv`. Сверяются все строки и поля: точные имена колонок и текст, точный состав и порядок строк, числа с абсолютным допуском `0.001`, одинаковым для D/B. Лишние, пропущенные или повторяющиеся колонки и лишние/пропущенные строки недопустимы.
