# CSV: Многострочные примечания и логические записи

Импортируй записи с многострочными примечаниями. Физический перенос внутри ограниченного текста относится к одной ячейке: сохрани его, встроенный разделитель и кавычки. Сохрани Unicode, строковые ключи и точные числа. В ответе различи логические записи и физические строки; не выдавай усечённый просмотр за полный результат.

Вход: `pipe_multiline.csv`.

Известный формат входа: `utf-8`, разделитель `'|'`, ограничитель `"`, десятичный разделитель `.`, заголовок в первой строке; даты год-месяц-день, разделитель дефис; маркер NULL `?`.

Выходные имена в порядке входа: Id, Name, Amount, Date, Note; метки сохранить по заголовкам. Никаких фильтров, группировок или калькуляторов.
Работай с оригинальным вложением: без переименования, переписывания байтов и скрытой конвертации. Используй «Импорт из текстового файла» (`imports.text / delimited`), один настоящий узел импорта. Доставь каждый вход ровно один раз с проверкой серверных байтов. Путь источника возьми из подтверждённой доставки, явно передай его в правильный/исправляющий запрос. Намеренно неполный первый шаг, если он задан в этом TASK, выполняется без пропущенного параметра. Не используй локальный путь этого корпуса как серверный путь.

При известном отказе сообщи точную причину. При неопределённом эффекте остановись: не повторяй upload/create/apply автоматически. После успешного выполнения прочитай всю доступную таблицу, сохрани новый пакет как `{{PACKAGE_PATH}}`; не перезаписывай чужой пакет. Для проверки большого результата разрешён связанный текстовый экспорт. Не добавляй аналитические преобразования.

Передай сохранённый пакет и доказательства проверяющему для независимого cold rerun; не объявляй непроведённую проверку выполненной.
