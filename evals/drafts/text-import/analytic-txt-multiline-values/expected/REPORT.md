# Критерии аналитического ответа

Логических записей данных: 3. Примечание последней записи содержит CRLF внутри одного строкового значения, встроенный | и кавычки. Все символы сверяются строго с table.json. Количество физических строк исходного файла не используется как число записей; общий текстовый CSV экспорт не заменяет native exact cell readback.

Аналитический успех требует одновременно полной верности table.json и отсутствия ложных/неподтверждённых утверждений ответа. Технический успех сохраняется отдельно; противоречащий данным ответ проваливает аналитическую ось даже при верно настроенном узле. Не требовать конкретной формулировки ответа; считать только подтверждённые утверждения. LLM judge может помогать, но не выдаёт единственный окончательный PASS.
