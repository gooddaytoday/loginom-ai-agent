## Результат текущего этапа и границы

При реализации этого плана выполнить только два шага:

1. **Подготовить весь необходимый код от ветки `evals`** для создания и проверки новых node evals в Multica: контракты заданий, harness, валидаторы, сбор evidence, reference/cold-помощники, тесты, skill и документацию. **На этом остановиться. Из согласованных восьми карточек карточка 0 теперь проверяет уже подготовленный комплект и допуск среды перед будущей серией; семь остальных содержат группы кейсов. Незавершённая реализация harness не является результатом подготовки и не передаётся карточке 0 как обязательная будущая разработка.
