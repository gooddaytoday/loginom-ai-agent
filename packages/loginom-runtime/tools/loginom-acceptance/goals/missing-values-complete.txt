Подготовь воспроизводимый пакет проверки заполнения пропусков в Loginom и сохрани его в __PACKAGE_PATH__. Работай в /test-4. Используй предоставленные CSV, загрузи их в __STORAGE_DIRECTORY__, не меняя байты. Формат: UTF-8, разделитель «;», заголовок в первой строке, qualifier двойная кавычка, Null-маркер NULL, десятичная точка. Пустая строка и текст null — значения, не пропуски.

Создай импорты: «База» из __CORE_CSV__, «Точные числа» из __PRECISION_CSV__, «Асимметрия» из __SKEW_CSV__, «Граница» из __BOUNDARY_CSV__, «Сто двадцать» из __ONE_IN_120_CSV__, «Все пропуски» из __ALL_NULL_CSV__, «Без строк» из __EMPTY_CSV__, «Перестановка» из того же __PRECISION_CSV__, «Изменяемый источник» первоначально из __CORE_CSV__. Файл __CHANGED_CSV__ понадобится позднее. Во всех импортах Amount — вещественный непрерывный, Count — целый непрерывный; Id и Untouched — целые дискретные; Note — строка дискретная. Все поля используются, имена и порядок из CSV. Метки совпадают с именами, без исключений. Выполни импорты и проверь источники. Полный обработчик возвращает не больше10 строк образца: для результатов до10 строк проверяй все значения, для12 и120 строк проверяй число строк и доступные первые10, явно отмечая ограничение. Полное чтение всех строк больших результатов выполнит независимый проверяющий после сохранения; не заявляй, что образец доказывает весь набор.

Для всех следующих узлов набор неупорядочен, порог указан явно. Если не оговорено иначе, обрабатывай только Amount и Count средним арифметическим, Note — заданной строкой MISSING; Id и Untouched выключены. Сохраняй все входные и выходные поля, их имена, метки, порядок, типы и виды, кроме явно заданной ниже перестановки и меток Same у «Переставленных полей»; отключи автосинхронизацию входного и выходного mapping для точного сохранения. Среднее вычисляет Loginom. Для Integer проверь округление 1.5 до 2 и −1.5 до −2. Не используй медиану или другие методы.

Создай «Основной» от «Базы», порог100, выполни и проверь все4 строки. Затем у этого же узла измени строковую замену на NEW_NODE, сохрани GUID и связь, снова выполни и проверь полный результат. Null строки заменяется, но пустая строка, literal null, нули и Null выключенного Untouched сохраняются.

На том же «Основном» примени настройку с NEW_NODE через «Готово», без выполнения. Затем открой его для изменения строковой замены на DISCARD_ME и заверши «Закрыть» без применения. Эти две операции не должны запускать узел или выдавать свежий выход. После отмены выполни существующий узел без переустановки настроек и проверь, что сохранена NEW_NODE, а DISCARD_ME не появилась.

Остальные результаты создай отдельными узлами и сохрани их все в пакете:
- «Только строка» от «Базы»: только Note заменять на NOTE_ONLY, порог100, числовые поля не обрабатывать.
- «Точность» от «Точных чисел»: порог100. Полностью проверь3 строки, отрицательное целое среднее и вещественную точность более двух знаков.
- «Среднее не медиана» от «Асимметрии»: порог100. Для 0,0,9,Null среднее3; сохрани нули.
- «Порог 40», «Порог 41», «Порог 42» от «Границы»: соответствующие пороги40/41/42. Проверь число12 строк и доступный образец; ожидаемые остаточные Null во всём наборе: при40 пять пропусков сохраняются, при41/42 заполняются.
- «Округлённый ноль» от «Сто двадцать»: порог0. Проверь число120 строк и первые10; для независимого полного чтения всех120 ожидается: один пропуск заполняется, остальные119 строк не меняются.
- «Полностью пустые поля» от «Всех пропусков»: порог100. Зафиксируй оставшиеся Null даже у выбранной строковой замены: нельзя обещать полную очистку поля без исходных значений.
- «Пустой результат» от «Без строк»: порог100. Проверь0 строк при сохранённых5 полях.
- «Переставленные поля» от «Перестановки»: порог100. Явно настрой входное сопоставление этого узла: порядок Note,Untouched,Count,Id,Amount, у Amount и Note одинаковая метка Same; имена, типы и виды сохрани. Проверь весь выход3×5 в порядке Note,Untouched,Count,Id,Amount; одинаковые метки Same не объединяют поля.

Создай «Смена источника» от «Изменяемого источника», порог100, выполни и проверь все4 строки. Потом измени только файл этого же импорта на __CHANGED_CSV__, сохраняя GUID, имена/порядок/типы/виды/формат и связь. Выполни изменённый импорт и тот же «Смена источника» без перенастройки его обработки. Свежий полный результат должен использовать новую среднюю Amount=20, а не старую5; строковая константа остаётся MISSING. Не используй старый кэш как результат нового выполнения.

В конце проверь, что все перечисленные результаты и их источники остаются в пакете. Выполни одно отдельное финальное сохранение через package.save_checkpoint по пути __PACKAGE_PATH__, без закрытия и переоткрытия. Подтверди завершение сохранения; не подменяй его Save As с reopening. После твоего завершения независимая проверка сама откроет сохранённый пакет и повторно выполнит результаты без перенастройки. Тебе переоткрывать пакет не требуется.

Работай самостоятельно в одной рабочей сессии через Loginom Dock и полные обработчики. Можно изучать закреплённые Help/E2E через Dock. Не используй другой браузер, терминал, UI-резерв, дочерних агентов или другую модель. При неизвестном исходе проверяй исходную операцию и доступное продолжение, не дублируй действие. Не имитируй сбои. В финале сообщи путь, результаты полных проверок, оставшиеся Null и ограничения. Сбой сохранения или незавершённую проверку сообщи явно.
