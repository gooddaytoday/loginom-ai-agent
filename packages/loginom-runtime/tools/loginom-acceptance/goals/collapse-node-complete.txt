# Замороженное задание будущего запуска — не запускать до допуска

В Loginom создайте новый пакет для преобразования широких выгрузок в длинные
таблицы. Используйте только переданные оператором свежие входные файлы и выделенное
хранилище; старые диагностические пакеты и пути не используйте.

Для mixed.csv задайте Id целым, I целым, R вещественным, S строкой, B логическим,
D датой/временем с форматом DD.MM.YYYY hh:mm:ss.zzz; разделитель «;», UTF-8,
первая строка содержит имена, NULL обозначает Null, кавычки сохраняют пустую строку.
Преобразуйте I,R,S,B,D в этом порядке, сохранив Id. Получите поля Names («Имена»),
DisplayNames («Метки»), Values («Значения»), исключите DataTypes. Создайте варианты
с обоими значениями «Игнорировать пустые значения». Верните все точные значения
и исходные типы каждой ячейки, отдельно сохранив ограничения дат.

Так же обработайте header-only.csv и all-null.csv в обоих режимах. Пустой результат
подтвердите полной схемой и нулём строк. Непрочитанный выход не считайте пустым.

В mapped.csv сохраняйте Id и Zone, транспонируйте S,I,R,B,D. Полям S и I задайте
одинаковую метку «Общий»; связывайте значения по именам, а не по меткам. Проверьте
оба режима пропусков. Затем в отдельной копии результата измените существующую
свёртку: оставьте информационным только Id, транспонируйте B,S в таком порядке,
игнорирование выключите. Старые роли должны быть заменены полностью.

В wide.csv задайте целый тип всем полям; сохраните Id, транспонируйте M1…M24
в указанном числовом порядке. Прочитайте все 48 строк и четыре колонки.
Используйте Done и Close с самостоятельной проверкой сохранности настроек и
не выполняйте узел, если запрос требует только сохранения настройки.

Проверьте, что конфликт ролей одного поля, отсутствующее имя и пустой список
транспонируемых полей отклоняются до изменения. При неоднозначной операции
проверьте её исходное состояние, не повторяйте жест с новым идентификатором.

Сохраните итоговые пакеты в выданном каталоге. Сообщите их пути, результаты,
ограничения и всё незавершённое. Не подменяйте точные значения отображаемым текстом.
Дальнейшее независимое открытие пакетов и аудит выполнит оператор.
