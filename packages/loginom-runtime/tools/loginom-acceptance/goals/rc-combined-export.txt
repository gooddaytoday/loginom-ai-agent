Создай в Loginom новый пакет __PACKAGE_PATH__. Работай через Loginom Dock и готовые обработчики узлов. Доставь входной __WIDE_CSV__ в __STORAGE_DIRECTORY__ под его уникальным именем. CSV UTF-8, ;, первая строка заголовок, десятичная точка, NULL — пропуск.

В формате каждого текстового импорта явно задай параметр null_marker со значением "NULL" (четыре символа).

Создай ровно четыре связанных узла:
1. Wide — импорт: Id целый дискретный, Jan и Feb вещественные непрерывные; имена и метки совпадают. Три строки: 1;10.5;20.25, 2;0;-5.5, 3;7.25;9.5.
2. Fields — Параметры полей после Wide: Jan переименовать в Actual с меткой Actual, Feb — в Plan с меткой Plan. Id сохранить. Порядок Id, Actual, Plan, все поля включены, типы не менять.
3. Long — Свёртка столбцов после Fields: информационное поле Id, транспонируемые Actual затем Plan, ignore_empty=false. Выход Id (целый), Names (строковый), Values (вещественный); явно задай всем трём полям совпадающие имена и метки Id, Names, Values. В сопоставлении выхода оставь включёнными ровно Id, Names, Values; DisplayNames и DataTypes исключи, автосинхронизацию выключи. Ожидаются шесть строк: 1;Actual;10.5, 1;Plan;20.25, 2;Actual;0, 2;Plan;-5.5, 3;Actual;7.25, 3;Plan;9.5. Используй обычное чтение sample_rows=10, без coverage=full; небольшой результат должен быть прочитан целиком.
4. Export — Текстовый экспорт после Long в __EXPORT_PATH__, UTF-8 без BOM, разделитель ;, заголовок names, перевод строк LF, десятичная точка, null_marker=NULL, text_qualifier=". Назначение новое и уникальное, overwrite=reject. Ожидается файл с заголовками Id;Names;Values и шестью строками результата Long. Прочитай подтверждённый файловый результат обработчика; у экспорта нет табличных выходов.

Выполни все узлы; табличные результаты прочитай целиком с точными числами. Один раз сохрани итоговый пакет через package.save_checkpoint без закрытия: __PACKAGE_PATH__. Независимая диагностика затем проверит сохранённый пакет и байты экспортированного файла. Не используй терминал, другой браузер, модель или субагентов. При ошибке сначала выясни реальное состояние. Сообщи пути пакета и экспорта, подтверждённый результат и ограничения.
