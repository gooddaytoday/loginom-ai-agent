Создай в новом черновике проверяемый сценарий разметки дубликатов и противоречий. Используй три выданных файла __MAIN_CSV__, __NULL_CSV__, __EMPTY_CSV__. Загрузи их в __STORAGE_DIR__ с проверкой байтов. Для каждого создай текстовый импорт с именем соответственно «Node12-main10», «Node12-null8», «Node12-empty». Формат: UTF-8, разделитель ;, ограничитель текста двойная кавычка, десятичный разделитель точка, маркер Null __NULL__, заголовки в первой строке, пропуск 0 строк. Исходные имена и метки сохрани. Id, Sub, Amount — целые непрерывные; Key и Value — строки дискретные. Полностью выполни и прочитай импорты: 10, 8 и 0 строк соответственно.

Затем создай три узла «Дубликаты и противоречия»: «Node12-main10-mark», «Node12-null8-mark», «Node12-empty-mark», каждый подключён только к соответствующему импорту. Основной узел: входные Key и Sub, выходные Value и Amount, Id не участвует. Другие два: входное Key, выходное Value, Id не участвует. Сохрани все исходные поля и строки, без переименований и исключений. Выполни и полностью прочитай все результаты, включая четыре служебных столбца. Основной результат: группы дублей Id {1,2}, {4,5,6}, {9,10}; группа противоречий {1,2,3}. Набор с Null: группы дублей {1,2}, {5,6}, {7,8}; противоречия {1,2,3,4}. Null, пустая строка и текст null различаются. Пустой результат содержит 0 строк и полную схему. Все экземпляры дублей должны оставаться в выходе; номера групп могут отличаться, состав групп — нет.

На существующем основном узле убери выходные роли, оставив входные Key и Sub. Выполни и полностью проверь 10 строк: группы дублей {1,2,3}, {4,5,6}, {9,10}, противоречий нет. Затем отдельной полной операцией заверши те же настройки через «Готово» без выполнения. Следующей операцией запроси входное Id и выходное Key, но закончи через «Закрыть» без применения. Эти две операции не должны заявлять свежие данные. Верни основной узел к исходным ролям Key/Sub и Value/Amount, выполни и проверь исходные группы.

Сохрани пакет __PACKAGE_PATH__ штатным checkpoint без закрытия. Для этой проверки явно переоткрой тот же пакет отдельным действием. Убедись, что сохранены ровно шесть аналитических узлов, три связи и все назначения. После переоткрытия повторно выполни сначала три существующих импорта без изменения их настроек, затем три существующих узла разметки с исходными полными списками ролей. Сохрани GUID и связи, не добавляй узлы повторно. Полностью проверь свежие 10, 8 и 0 строк и состав групп; прежний кеш не доказывает новое выполнение.

Работай самостоятельно в одной сессии через полные операции Loginom Dock. Используй только закреплённые Help/E2E при необходимости. UI-резерв, другой браузер, терминал, дочерние агенты и другие модели не допускаются. При неизвестном эффекте проверяй ту же операцию, не повторяй действие под новым ID. В конце сообщи путь пакета, подтверждённые результаты и ограничения. Разметка не удаляет дубликаты; фильтр Дубликат=false удалил бы все копии повторяющихся групп.
