Создай в Loginom один узел «Текстовый файл» с именем «Продажи» из предоставленного CSV __UPLOAD_NAME__. Размести исходный файл в __STORAGE_DIRECTORY__, сохрани исходные байты и подтверди их размер и SHA-256. Другие аналитические узлы не нужны.

Настройки импорта: UTF-8; первая строка содержит заголовок; пропуск строк 0; разделитель полей «;»; ограничитель — двойная кавычка; десятичный разделитель «.»; Null-маркер — \N. Все пять исходных полей используются, имена и метки совпадают. Id и Quantity — целые, вид «Непрерывный»; UnitPrice — вещественный, вид «Непрерывный»; Region и Comment — строки, вид «Дискретный».

Выходной порт должен иметь выключенную автосинхронизацию и следующий порядок полей: UnitPrice переименовать в Price с меткой «Цена», затем Id, Region, Quantity, Comment с исходными именами и метками. Значения не преобразовывай. Выполни импорт и проверь все шесть строк, включая пустую строку, Null, кавычки с разделителем, отрицательное количество и точные дробные цены.

После готового импорта сохрани промежуточный пакет __PACKAGE_PATH__.draft.lgp без закрытия. Затем сохрани окончательный пакет __PACKAGE_PATH__, переоткрой именно этот файл и убедись, что граф, источник, все настройки и выходной mapping сохранились. После переоткрытия повторно выполни тот же узел без изменения его настроек и сравни новый результат со всеми шестью исходными строками. Старый кешированный выход не доказывает повторного выполнения. Итоговый пакет должен содержать один указанный узел с согласованными настройками.

Работай самостоятельно через доступные инструменты Loginom Dock в одной сессии. Используй полный локальный обработчик поддержанного импорта. По необходимости изучай E2E и Loginom Help через Dock; не используй другой браузер, терминал, дочерних агентов или другую модель. Исправляй проверяемые ошибки в той же сессии, сохраняя идентичность операций с неизвестным результатом. В конце кратко сообщи точный путь итогового пакета, размер таблицы и обнаруженные ограничения точности.
