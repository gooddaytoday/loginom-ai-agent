Создай в Loginom новый пакет __PACKAGE_PATH__ с одним сценарием очистки данных. Используй только Loginom Dock и его готовые обработчики узлов. Все CSV лежат среди входных артефактов: доставь их в __STORAGE_DIRECTORY__ с исходными уникальными именами. Формат UTF-8, разделитель ;, заголовки в первой строке, точка для десятичной части, NULL — пропуск.

В формате каждого текстового импорта явно задай параметр null_marker со значением "NULL" (четыре символа).

Создай ровно семь узлов с указанными именами:
1. Orders — импорт __ORDERS_CSV__. Id целый дискретный, Client строковый дискретный, Amount вещественный непрерывный. Имена и метки совпадают.
2. Lookup — импорт __LOOKUP_CSV__. Client и Segment — строковые дискретные, имена и метки совпадают.
3. Names — Замена после Orders: в Client точное old заменить на A, с учётом регистра; остальные значения сохранить. Режим замены существующего поля. Явно настрой выход: только Id, Client, Amount в этом порядке, имена и метки совпадают; служебное Client_Replaced исключить, метку Client восстановить в Client. При явной схеме выхода выключи автосинхронизацию.
4. Filled — Заполнение пропусков после Names. Неупорядоченный вход, максимальная доля пропусков 100%, единственное обрабатываемое поле Amount, метод среднее. Остальные поля сохранить. Результат Amount по Id: 10, 10, 20, 30, 30.
5. Duplicates — Дубликаты и противоречия после Filled: входное поле Client, выходное Amount, Id не участвует. Сохранить все исходные поля и четыре стандартных служебных поля. Строки Id 1/2 — дубликаты одной группы; Id 3/4 — противоречия одной группы; Id 5 — ни то ни другое.
6. Enriched — Слияние Filled (левый) и Lookup (правый) по Client=Client, inner, с учётом регистра, правый ключ не включать в результат. Выход Id, Client, Amount, Segment с исходными именами и метками; пять строк.
7. Combined — Объединение append_all: два отдельных входа от выхода Enriched, то есть его пять строк повторяются два раза. Префиксы выключены, каждый столбец второго входа сопоставлен одноимённому столбцу первого. Сохранить порядок четырёх столбцов, десять строк.

Каждый узел выполни и прочитай полный небольшой результат, максимум 10 строк, с точными числами. Не добавляй лишних узлов и не выполняй неподдерживаемые режимы. После всей работы один раз сохрани итог через package.save_checkpoint без закрытия. Путь пакета: __PACKAGE_PATH__. Повторное открытие и независимую проверку выполнит координатор после твоего завершения. Не используй терминал, другой браузер, модель или субагентов. При ошибке сначала выясни реальное состояние, не повторяй создание вслепую. В конце сообщи путь пакета и фактический результат.
