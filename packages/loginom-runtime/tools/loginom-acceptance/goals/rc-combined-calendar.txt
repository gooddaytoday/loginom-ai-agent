Создай в Loginom новый пакет __PACKAGE_PATH__ с одним сценарием продаж. Работай через Loginom Dock и готовые обработчики узлов. Доставь входной __SALES_CSV__ в __STORAGE_DIRECTORY__ под этим уникальным именем. CSV: UTF-8, ;, первая строка заголовок, десятичная точка, NULL — пропуск; даты имеют вид 05.01.2026 12:00:00.

В формате каждого текстового импорта явно задай параметр null_marker со значением "NULL" (четыре символа).

Создай ровно шесть узлов:
1. Sales — импорт: Id целый дискретный, SaleDate дата/время непрерывный, Amount вещественный непрерывный. Имена и метки совпадают.
2. Calculated — Калькулятор после Sales: новое вещественное поле Gross / Gross = Amount * 2; остальные поля сохранить. Gross: 200, 100, 120, -20.
3. Calendar — Дата и время после Calculated: единственное преобразование SaleDate — номер месяца, новое поле Month / Month целого типа. Сохранить исходные поля. Итоговый порядок: Id, SaleDate, Amount, Gross, Month; при явном сопоставлении выхода выключить автосинхронизацию. Month: 1, 1, 2, 2.
4. Positive — Фильтр строк после Calendar, условие Gross > 0 вещественного типа. Прочитай оба выхода: прошедшие Id 1/2/3 и отвергнутый Id 4.
5. Monthly — Группировка прошедшего выхода Positive: ключ Month, единственный показатель сумма Gross с именем и меткой Total. Выход Month целый, Total вещественный, ровно две строки: 1;300 и 2;120.
6. Sorted — Сортировка после Monthly по Total DESC. Выход Month, Total: сначала 1;300, затем 2;120.

Выполни каждый узел и полностью прочитай его результат (до 10 строк, точные числа). После завершения один раз сохрани пакет через package.save_checkpoint без закрытия в __PACKAGE_PATH__. Повторное открытие выполнит независимая диагностика после завершения. Не используй терминал, другой браузер, модель или субагентов. При неопределённости выясни состояние исходной операции. Сообщи сохранённый путь и фактические результаты.
