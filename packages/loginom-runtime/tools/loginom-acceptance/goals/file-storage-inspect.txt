Через Loginom Dock выполни dock_prepare, затем открой файловое хранилище и перейди в __STORAGE_DIRECTORY__. Это чтение интерфейса перед реализацией загрузки: ничего не загружай, не создавай каталогов, не удаляй, не переименовывай, не сохраняй и не запускай узлы. Разрешены только click по кнопке файлового хранилища и double_click по сегментам указанного пути __STORAGE_SEGMENTS__. Для каждого действия используй ref из доставленного наблюдения. Если нужный элемент не попал в первую страницу наблюдения, дочитай страницы по cursor.

Полный обход после перехода в каталог может превысить бюджет из-за большого списка. Для поиска каталога используй dock_workspace_observe со scope=roots и storage_name, равным имени очередного сегмента __STORAGE_SEGMENTS__. Полученный region ref не допускает жестов: прочитай его через root_ref и observation_id discovery, затем выполни double_click по ref из подробного чтения. При UI_EPOCH_CHANGED обнови наблюдение и повтори только явно не выполненное действие.

В конечном каталоге найди NavigationBar;NavigationPanel через scope=roots без storage_name, прочитай эту область через root_ref и observation_id discovery. Не делай полный обход списка ради чтения адреса. Проверь file_storage: status=observed, directory=__STORAGE_DIRECTORY__, source=visible_breadcrumbs, listing_complete=false. После этого не выполняй действий в браузере. Если адрес не наблюдается, сообщи это без выдумывания результата. Наличие видимых строк не доказывает отсутствие одноимённого файла во всём хранилище. Это ещё не приёмка загрузки.

При нехватке сведений используй подключённые источники E2E и Help. Работай только инструментами Loginom Dock, без терминала, другого браузера, агента или смены модели. В конце кратко сообщи наблюдаемый каталог и ограничения проверки.
