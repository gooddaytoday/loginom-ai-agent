Через подключённый Loginom Dock подготовь новый пустой черновик, добавь один узел «Текстовый файл» из группы «Импорт» и открой его мастер настройки. Не используй существующие пакеты. На первой странице мастера проверь флажок «Параллельная обработка»: прочитай исходное значение, установи противоположное через set_checked, повторно задай это же значение через set_checked и затем верни исходное через set_checked. Перед каждым действием используй свежее наблюдение и ref из доставленной страницы; при наличии следующих страниц дочитай нужную область. Подтверди, что повторная установка не вызвала лишнего клика, а последнее значение совпало с исходным. После этого оставь мастер открытым: не применяй настройки, не отменяй мастер, не сохраняй пакет и не запускай вычисления. Это проверка одного флажка, а не готовности импорта данных.

Самостоятельно выбирай наблюдения и способы открытия мастера. При нехватке сведений используй подключённые источники E2E и Help. Работай только инструментами Loginom Dock, без терминала, другого браузера, агента или смены модели. При неподтверждённом результате явно сообщи ограничение. В конце сообщи исходное и итоговое значения и результат повторной установки.

Перед КАЖДЫМ из трёх set_checked сначала используй dock_workspace_observe со scope=roots. Найди область мастера, затем запроси её подробное чтение с root_ref и observation_id этого discovery. Для set_checked используй observation_id и ref флажка именно из подробного чтения области. После действия повторяй discovery и подробное чтение: старые refs/pages могут быть недействительны. Не подменяй чтение области полным наблюдением. Отметь границы проверки: текущий живой мастер не является доказательством работы на всех больших документах.
