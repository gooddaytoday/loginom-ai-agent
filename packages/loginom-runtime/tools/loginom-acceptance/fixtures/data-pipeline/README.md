# Первая цепочка P3: контролируемые данные

Статус: fixture подготовлен, **Loginom live acceptance не выполнен**.
Каталог подключён к diagnostic goal data-pipeline в run.py. Harness фиксирует
SHA CSV, expected.json, task.txt и задания. Transfer prefix проверяется;
настройки, execution identity, полный output и save/reopen proof пока не имеют
независимого verifier, поэтому аудит не может выдать P3 PASS.

`sales.csv` — UTF-8 без BOM, LF, разделитель `;`, заголовок, десятичная точка,
ограничитель строк `"`, явный null marker `\N`. Пустой Comment первой строки
должен остаться пустой строкой, Comment строк 2 и 6 — null. Маркер не заменять
пустотой ради прохождения импорта. Строка 3 содержит разделитель внутри кавычек.

`expected.json` — зафиксированные входные параметры, SHA/размер и все строки
после импорта, Калькулятора и Группировки. Проверять весь набор и типы, а не
только выборку. Порядок вывода не существенен: сравнивать по заданным ключам,
но не удалять дубликаты. Числа подобраны с точным двоичным представлением.

Калькулятор добавляет вещественный Amount = Quantity * UnitPrice. Группировка
по Region возвращает QuantitySum, AmountSum, RowCount. Итог: Запад 1/0/2,
Север 5/52/2, Юг 4/10/2 соответственно. Полученные результаты нужно повторить
после сохранения, закрытия и открытия точного пути пакета.

## Незакрытые условия приёмки

- Отдельная загрузка разрешённого локального artifact: идентификатор, SHA,
  размер, destination и запрет overwrite по умолчанию. Не передавать модели
  произвольный filesystem path или generic file input.
- E2E `bg/helpers/filestorage.ts:350` использует input под
  `FileStorageForm;tbrActions` и проверяет существование имени. Это источник
  механики UI, но не доказательство размера/SHA/содержимого серверного файла.
- После apply нужно прочитать реальные настройки импорта, формулу и mappings.
- Новый execution identity и полный result proof на каждом выполнении;
  старый зелёный значок узла не доказывает новый запуск.
- Политика конфликтов путей, save/reopen/reexecute и сохранность настроек.
- Отдельные негативные варианты delimiter/type/formula и пустой результат:
  задания/expected/fault injection должны быть зафиксированы до model run.

openai-codex / gpt-5.6-luna / medium. Dock server models не меняются.
