# Снимок операторского R2 live harness

Файлы — точные копии выполненных операторских шагов сеанса
`aa03cb93-8df3-4b1c-808e-6a13e835caf4`, сохранённые для проверки доказательств.
Это не продуктовый workflow interpreter и не автоматический новый прогон.
Общий драйвер: `tools/loginom-acceptance/date-time-live.mjs`, public MCP wire:
`tools/loginom-acceptance/public-node-wire.mjs`. Их ревизии фиксируются отчётом.

Исходные `.dock/` пути в коде, test-3, имена файлов, вкладки и конкретные пакеты
намеренно сохранены. Каждый шаг исполнялся отдельной командой harness с проверкой
ответа перед следующим действием. Для нового прогона нужны новая собственная
копия пакета/CSV и повторное наблюдение реальных UI-привязок; нельзя запускать
этот снимок вслепую поверх чужого или уже завершённого сеанса.

r2-upload → открыть/наблюдать импорт → r2-import-controls/setup/confirm/path/next/finish →
r2-tabs → r2-hide-source → r2-failure → r2-repeat → r2-restore-source → r2-restored.
