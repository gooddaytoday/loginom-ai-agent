# Платформа dashboard

Служба HTTP — в `src/web`, схемы обмена — в `src/contract`, код оболочки и адаптер Studio — в `src/shell`. Bun собирает `dist/server.mjs` для Node и единый `dist/shell.js` для браузера. Для разработки приложений по снимку соблюдайте [инструкции в dashboard/apps](../../dashboard/AGENTS.md); исходники по-прежнему находятся в `dashboard/apps/<ключ>`. Шаблон и npm lockfile — в `template`, публикация — `script/publish.mjs`. До M2 открывайте только свои доверенные dashboard.

- Из `packages/dashboard`: `bun typecheck`, `bun run test` (включает сборку и покрытие web), `bun run check:size`, `bun run test:browser`. Укажите `LOGINOM_AI_AGENT_TEST_NODE` и `PLAYWRIGHT_BROWSERS_PATH` для закреплённых Node и Chromium; установите зависимости шаблона через `npm ci --ignore-scripts` из `template`.
- Стенд: из корня `./packages/dashboard/deploy/dev-master.sh install|check|uninstall`. Перед изменением стенда выполните `bash -n packages/dashboard/deploy/dev-master.sh` и `shellcheck packages/dashboard/deploy/dev-master.sh`. Конфигурация живой пробы и запуск для 7.4.2 — в [рецепте стенда](../../dashboard/stand/README.md#проверка-и-удаление).
- Node по умолчанию слушает только `127.0.0.1:8100`; контейнер использует `DASHBOARD_HOST=0.0.0.0` для Apache. Последние 100 снимков хранятся в памяти. Для отладки запускайте отдельный `DASHBOARD_ALLOW_CURRENT=1 node packages/dashboard/dist/server.mjs` из корня: `/dashboard/current` требует флага и loopback TCP-соседа. Штатная установка выключает флаг.
