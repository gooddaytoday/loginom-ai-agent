`abc-xyz-analysis.lgp_report.pdf` / tools.loginom.ru `ai_report.md`).

Этот раздел ссылок относится только к `external_references`. Например,
`FileName: data.lgd` — файловая зависимость даже при пустом списке ссылок.
Укажи её в описании пакета/модуля, не заменяя список ссылок общим утверждением
«нет внешних зависимостей».

В описании модуля различай связь и выполненный расчёт. Например, при связи
Источник → Калькулятор и пустых настройках Калькулятора: «Источник настроен
на импорт из `data.lgd`; его выход связан со входом Калькулятора. Калькулятор
предназначен для вычисления полей, но формулы в пакете не указаны».
Название «Демо» само по себе не подтверждает демонстрационное назначение;
описание модуля в этом случае начинается с его состава, а не выдуманной цели.

Do **not** include in the final report:

- `Используемая модель:` line (omit even if the model name is known)
- node inventory tables
- visualizer lists
- Engine / settings attribute dumps
- Help `Источники:` section
- GUIDs in prose
