# variables.calculator / expression

<!-- mode: expression -->
Для скалярных параметров сценария выбери `dock_node_apply` с
`target.type="variables.calculator"`, `mode="expression"`.
Табличные выражения относятся к `transform.calculator`; скалярные
переменные настраивай этим типом без табличного входа.
Передай `parameters.expressions`: 1–32 изменения с `target:{kind:"new"}`
и полями `name`, `label`, `type`, `formula`. Для целых, строк,
логических и вещественных переменных явно задавай техническое имя, метку,
тип и формулу Loginom. Строковые литералы заключай в кавычки; TRUE/FALSE —
логические значения, NULL — отсутствие. Для зависимости используй Expr.name
предыдущего выражения. Сохраняй порядок; у нового узла замени пустое Expr1.

Обновляя существующее выражение, передай
`target:{kind:"existing",name:"сохранённое_имя"}` внутри элемента
`parameters.expressions` и меняй
только нужные свойства. Не добавляй ещё одну переменную вместо изменения
значения. Пропущенные выражения должны сохраняться. Этап 1 не поддерживает
datetime, Variant, промежуточные выражения, замену входных переменных,
кэширование, перестановку и JavaScript.

`finish:"execute"` пересчитывает значения без обучения.
Передай `read:{ports:[],variable_ports:[0]}`; повторное чтение —
`dock_node_read` с `source_operation_id` подтверждённого результата. Читай именно выход переменных
0: имя, метку, тип и значение каждого элемента в порядке. Отличай NULL,
пустую строку, false и ноль. Форматированный текст 0.13 может означать 0.125;
используй typed reader, а при невозможности точного чтения сообщи отказ.
После изменения снова выполни узел, проверь результат и сохрани пакет.
