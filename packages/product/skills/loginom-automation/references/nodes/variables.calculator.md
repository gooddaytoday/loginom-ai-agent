# variables.calculator / expression

<!-- mode: expression -->
Для скалярных параметров сценария выбери `dock_node_apply` с
`target.type="variables.calculator"`, `mode="expression"`.
Табличные выражения относятся к `transform.calculator`; скалярные
переменные настраивай этим типом без табличного входа.
Передай `parameters.expressions`: 1–32 изменения с `target:{kind:"new"}`
и полями `name`, `label`, `type`, `formula`. Явно задавай техническое имя,
метку, тип (`integer`, `real`, `string`, `boolean`, `datetime`) и формулу Loginom.
Строковые литералы заключай в кавычки; TRUE/FALSE — логические значения,
NULL — отсутствие. Для зависимости используй Expr.name предыдущего выражения,
включая промежуточное. Сохраняй порядок; у нового узла замени пустое Expr1.

Дату/время задай типом `datetime` и формулой
`EncodeDateTime(2026,11,7,23,59,58,123)`. Читай календарную дату до миллисекунд
без часового пояса: `2026-11-07T23:59:58.123`; не переводи её в UTC.
Промежуточному выражению передай `intermediate:true`: оно участвует в
последующих формулах, но отсутствует в выходных переменных. Например,
`base` типа integer с формулой `2` и `intermediate:true`, затем `total`
типа integer с формулой `Expr.base+1`. В конфигурации остаются оба выражения,
а в выходе только total. При добавлении `intermediate` по умолчанию false;
у существующего выражения пропущенный флаг сохраняется. Явный false снимает его.

Обновляя существующее выражение, передай
`target:{kind:"existing",name:"сохранённое_имя"}` внутри элемента
`parameters.expressions` и меняй только нужные свойства. Например, для
изменения промежуточного base на 4 передай только его target и `formula:"4"`.
Не добавляй ещё одну переменную вместо изменения значения.
Пропущенные выражения должны сохраняться вместе с ID, типами, флагами и порядком.
Variant, замена входных переменных, кэширование, перестановка и JavaScript
не поддерживаются.

`finish:"execute"` пересчитывает значения без обучения.
Передай `read:{ports:[],variable_ports:[0]}`; повторное чтение —
`dock_node_read` с `source_operation_id` подтверждённого результата. Читай именно выход переменных
0: имя, метку, тип и значение каждого элемента в порядке. Отличай NULL,
пустую строку, false и ноль. Форматированный текст 0.13 может означать 0.125;
используй typed reader, а при невозможности точного чтения сообщи отказ.
После изменения снова выполни узел, проверь результат и сохрани пакет.
