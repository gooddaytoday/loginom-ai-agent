# Правила в карточке узла

Перед `dock_node_apply` получи карточку через `dock_action_describe` с
`node_types:[тип]`. Карточка содержит `parameter_schema`, `guidance` и
`guidance_modes`. Без `modes` возвращаются общие правила и список режимов;
запроси нужные `modes:[режим]`, чтобы прочитать их правила.

В `<тип>.md` текст вне блоков — общий. Блок начинается отдельной строкой
`<!-- mode: имя_режима другой_режим -->` и заканчивается `<!-- /mode -->`.
Имена — точные значения `modes` карточки, через пробел. Один блок может
относиться к нескольким режимам; вложенные блоки запрещены. Возвращается
общий текст и каждый выбранный блок один раз, в порядке файла, без маркеров.
Все режимы типа должны иметь блок. Схема и правила не обрезаются ради бюджета:
тесты проверяют карточку без режимов, каждый режим и их совместную выдачу.

Источник — только проверенный пакет навыка, закреплённый текущим `dock_prepare`.
Новая подготовка сбрасывает отметки полученных карточек; внутреннее оглавление
prepare не заменяет describe. После восстановления с новым runtime запроси
карточки снова. Для продолжения незавершённой операции используй её исходный
resume, сохраняя правила восстановления.
