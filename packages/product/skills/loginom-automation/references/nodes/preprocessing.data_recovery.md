# Заполнение пропусков (`preprocessing.data_recovery`)

## Заполнение пропусков

Для замены числовых NULL нулём выбирай `preprocessing.data_recovery`, `mode:"impute"`,
`parameters:{fields:[{field:{kind:"input_field",name:"Amount"},method:"zero"}],max_nulls_percent:100,ordered:false}`.
`zero` — нативный метод для integer/real обоих видов данных; `value` не передавай.
`mean` требует непрерывное числовое поле, `constant` — дискретную строку и строковое
`value`. Переданный `fields` полностью заменяет обработку: неперечисленные поля
выключаются. Для сохранения настроек существующего узла передай `parameters:{}`.
Порог — явное целое 0–100; при `mean` выше порога NULL сохраняются. Нативный
`zero` заполняет NULL независимо от порога, включая полностью пустое числовое поле. Существующие нули и
необрабатываемые поля сохраняются. Используй
`finish:"execute"`, читай порт 0. Median/mode, ordered и интерполяция не поддержаны.
