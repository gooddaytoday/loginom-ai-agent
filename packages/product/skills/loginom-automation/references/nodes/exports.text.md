# Текстовый файл (`exports.text`)

<!-- mode: delimited -->
Для текстового экспорта по умолчанию используй UTF-8. Только по явной просьбе
пользователя укажи `encoding:"Windows-1251"` (как в Текстовом импорте).
В Loginom 7.4.2 BOM для CP1251 игнорируется; выбирай `bom:false`.
Символы вне CP1251 заменяются байтом `0x1A` (SUB): наблюдалось для `漢` и emoji.
Предупреди пользователя об этой потере; не обещай сохранность произвольного Unicode.

Если в выгружаемых данных есть NULL и пустые строки, а пользователь не задал маркер выгрузки,
для `exports.text` явно передай в параметре `null_marker` непустой маркер,
не совпадающий с не-NULL значениями. По умолчанию выбери тот же непустой маркер, что при импорте,
если он был задан; иначе `NULL`. Назови выбранный маркер пользователю.

У нового текстового экспорта требуется destination в назначенной папке. Обычный
CSV по умолчанию: UTF-8, запятая, header=names, bom=false, LF, десятичная точка,
пустой NULL и двойная кавычка. Явный формат сохраняется; существующий узел
получает только заданные изменения. Перезапись существующего файла не включается
автоматически: для неё нужны overwrite=replace и явный destination.
Даже `finish=done` проверяет конфликт `parameters.destination`; это не обход
`overwrite=reject`. В продолжении сохраняй требуемый итоговый путь, не возвращай
старый destination без требования задания. `overwrite=replace` применяй только
при разрешённой пользователем замене этого файла; иначе сообщи конфликт пути.

Источник `inputs[0].source.node_id` Экспорта бери из успешного результата узла, давшего запрошенный итог.
Для количества и сумм по группам подключай сводку Группировки, а не предшествующую детализацию Калькулятора.
Используй тот же `node_id` и выход, для которых проверены смысл строк, схема и агрегаты; совпадения одного поля или имени файла недостаточно.
Перед выполнением Экспорта прочитай таблицу, поданную на его вход, и сверь
имена и порядок колонок с заданием. При расхождении исправь их через
Reform/Параметры полей, повторно прочитай результат и проверь входное
`configuration.readback.input_mapping.fields` Экспорта; заявляй нужный порядок
только после подтверждения.
В продолжении повторно используй существующий Export для той же выгрузки:
`target.kind=existing`, его точный `target.ref`, `inputs:[]` для прежнего источника
и новый `operation_id`. Смена имени файла или upstream-полей сама по себе не
требует нового Export. После отказа `mappings` исправь upstream и повтори
тот же Export с `mappings:[]`; не создавай второй Export на тот же destination.
Порядок колонок меняй лишь по требованию задания; сохранение порядка строк
не требует перестановки колонок. Если сохранённое входное соответствие Export
не позволяет получить требуемую раскладку, сообщи ограничение.
Экспорт текста exports.text возвращает output.file_artifacts с размером и SHA-256
фактического файла после Execute; портов данных на выходе у него нет. Сверь
назначение и формат с заданием. Done и Close файл не подтверждают.
