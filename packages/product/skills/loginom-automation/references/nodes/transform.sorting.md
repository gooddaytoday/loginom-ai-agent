# Сортировка (`transform.sorting`)

Для нового порядка сохранённого отчёта не перенастраивай Сортировку с исключёнными вспомогательными полями:
добавь новую Сортировку от полного подтверждённого выхода её предшественника; прежний узел и нужные колонки сохрани.
Кэш только ключей не является полной схемой; если полный источник недоступен по правилам активации, сообщи блокер.

## Продолжение пакета

В продолжении после открытия пакета сохранение не доказывает активность выхода.
Перед новым `transform.sorting` подтверди нужный выход того же существующего табличного
источника. Используй `loginom_dock_node_read` с успешной локальной операцией
текущей подготовки; если её нет — existing apply с точным ref, прежним типом/mode,
`inputs:[]`, пустым patch по схеме и `finish=execute`. Дождись подтверждённого
выполнения/чтения источника; примеры пустого patch — [Граф и узлы](../canvas.md#продолжение-пакета).
Отказ `sorting preflight requires an active source output` с `NOT_APPLIED`,
`effect_possible=false`, `cleanup_complete=true` означает, что новый узел ещё не
создан: после выполнения источника повтори запрос с новым operation_id, не
пересоздавая источник и не освобождая несуществующий целевой узел. Это не разрешает
повтор неизвестного запуска или автоматический запуск REST/JS/экспорта вне просьбы.

## Порядок строк по локали

Порядок строк задаёт «Сортировка» (`dock_node_apply`, тип `transform.sorting`, режим `keys`), а не Калькулятор или JavaScript: не вычисляй веса букв сам.
`compare_with_locale` — один флаг на весь узел: `true` — сравнение строк по локали пользователя (у нового узла по умолчанию), `false` — бинарное. Просьба «с учётом русской локали» — `true`; «отключи учёт локали» — `false`.
Смена локали — на том же узле: передай `compare_with_locale` с `keys`, затем выполни и прочитай результат. Без флага существующий узел сохраняет прежнюю локаль.
`case_sensitive` задаётся отдельно у каждого строкового ключа: «регистр не учитывай» — `false`. Без локали регистр игнорируется только у латиницы, кириллица остаётся различной.
Добавь однозначный вторичный ключ (например RowID). NULL и пустая строка — разные значения: не сортируй текст «NULL».
Идентификатор локали узел не отдаёт: порядок проверяй по полному чтению результата.
