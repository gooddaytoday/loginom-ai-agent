# variables.replace / exact

Заменяет значения выбранных переменных по точным парам. Нужен один вход
переменных W1; выход переменных 0. Таблица не является входом этого узла.
Выбирай переменную по техническому имени из полного входного набора.

Для каждой переменной задай тип integer/real/string/boolean, пары from/to
и other=keep. Строкам нужен case_sensitive=true, числам precision=0.
С обеих сторон пары должен быть тип переменной; NULL передаётся JSON null.
Пустая строка, false и 0 — самостоятельные значения. Ключи уникальны.
Каждое исходное значение ищется один раз: пары red→blue и blue→green
превратят исходное red в blue. Без совпадения значение сохраняется.

Новый узел сохраняет все имена, метки, типы и входной порядок. Native-мастер
добавляет к меткам изменённых переменных «Замена»: обработчик восстанавливает выходные метки автоматически. При обновлении заменяется полная таблица пар только
для перечисленных переменных; остальные правила и mapping сохраняются.
Не меняй тип, порядок, имена или связи ради результата.

Done сохраняет настройки, Execute вычисляет значения без обучения.
После Execute читай полный typed-набор с порта 0 через W1; текст preview
не доказывает точность real или отличие NULL от пустой строки.
При смене исходных значений выполняй тот же узел без перенастройки.
Сохрани пакет после последнего чтения.

Regex, нечувствительность к регистру, ненулевая точность сравнения,
смена типа, datetime/Variant, импорт/экспорт правил и политика остальных
кроме keep не входят в этап 1. Дубликаты и неверные типы отклоняй до
изменения узла. При native-отказе читай причину кнопкой ошибки мастера;
не обходи её через «Всё равно далее».

Инструмент: `dock_node_apply`, target.type=`variables.replace`, mode=`exact`, inputs=[], variable_inputs=[{source:<ref>,output:0,input:0,kind:"variables"}], read={ports:[],variable_ports:[0]}, finish="execute". Сначала `dock_action_describe({node_types:["variables.replace"]})`.

parameters.rules: [{variable:{kind:"input_variable",name:"Count"},type:"integer",pairs:[{from:2,to:5}],other:"keep",precision:0}]. При patch того же ref передавай только изменяемые rules; для Execute после смены источника передавай parameters={} без variable_inputs. Значения и real/метки исходного JSON создай в variables.calculator/expression через name,label,type,formula; NULL — формула NULL, строки — строковые литералы. Для замены выбирай variables.replace/exact; Калькулятор служит только источником.
