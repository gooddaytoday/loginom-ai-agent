## Выполнение и чтение

Сначала выполни и полностью прочитай источник. Требуется одна строка с
непустым строковым значением, содержащим один JSON-объект или корневой массив
объектов. Корневой массив из файла импортируй одной строкой в строковый
столбец, без разбиения по запятым. Для REST бери фактический `Response` с
выхода 0. Для проверки `HttpStatusCode` используй выход 1 и связь по
`RequestID`. Несколько документов во входном порте не поддерживаются.

Укажи `mode:"auto_structure"`, `parameters:{json_field:"Document",root_mode:"auto"}`
с точным техническим именем входного столбца, `finish:"execute"`. Выход 0 —
нативное типизированное дерево. Для передачи полного дерева следующему узлу
используй `read:{ports:[],sample_rows:0,require_exact_numbers:false}`.
На [Дерево в таблицу](trees.to_table.md) подай выход 0 этого же выполненного
узла в пределах текущего сценария. Dock проверит схему порта по завершённому
выполнению. Не восстанавливай дерево из текста задачи.

Для чтения небольшого дерева запроси
`read:{ports:[0],sample_rows:100,require_exact_numbers:true}`.
`tree.schema` содержит порядок, имена, типы и контейнеры, `tree.instances` —
все экземпляры и их пути, значения и NULL. Полное чтение Dock ограничено
256 экземплярами, глубиной 16 и 1 MiB результата. При превышении Dock
отказывает в чтении. Loginom 7.4.2 обработал 257 записей через связку узлов.
При отказе с неизвестным эффектом следуй подсказке `operation.recover`.

## Поддерживаемый JSON

До 1 MiB входного JSON, 256 узлов **схемы** и глубина JSON 16. Поддерживаются
вложенные и соседние массивы объектов, однородные массивы скаляров
и одноимённые листья в разных ветвях. Для пустого массива нужен непустой
типизированный массив по тому же пути в другой записи. У пустого массива
ноль экземпляров. `details:{}` даёт контейнер с NULL в полях из других записей.
Дубликат ключа в одном объекте, смешанные массивы скаляров, ручная схема, XSD и
forced root не поддерживаются. `parameters:{}` сохраняет настройки узла.

Целые Int64 передаются точными десятичными строками. Пустая строка, false и
ноль различимы. Missing scalar и JSON null дают типизированный NULL.
Значения DateTime используют `YYYY-MM-DDThh:mm:ss` и возвращаются как
civil `YYYY-MM-DDTHH:MM:SS.mmm` с `precision:"millisecond"` и
`representation:"local_datetime"`. Сохраняй локальное время.

Смешанные скаляры одного поля дают лист `variant` с подтипом `cell_type`
(integer, real, string, boolean, datetime, null). `precision:"exact_native"`
подтверждает чтение подтипа. Integer и real передаются десятичными строками,
boolean — логическим значением, NULL — `is_null:true,value:null`.
