# Конечные классы

Для одного дискретного строкового признака и бинарной строковой цели выбери
`preprocessing.coarse_classes`, режим `internal`. Сначала прочитай карточку через
`dock_action_describe({node_types:["preprocessing.coarse_classes"]})`.
В `parameters.coarse_classes` задай точные технические имена `input_field`,
`target_field`, строку `event_value`, `partition:"automatic"`,
`min_class_percent`, `max_classes`, `uniformity_percent`.
Остальные поля получают роль unused и сохраняются без изменений.
Числа в процентах: 5 означает 5%, 0 — оптимизацию IV.

`internal` явно обучает текущий вход перед выполнением. Настроенный узел
и материализованные классы — разные состояния. Для нового входа без обучения
примени существующий узел с `mode:"apply"`, `parameters:{}`, `inputs:[]`,
`mappings:[]`, `finish:"execute"`. Требуются сохранённые классы. Apply читает
состояние, закрывает draft без коммита и выполняет; команда Train не вызывается.
Новая целевая колонка может содержать NULL. Предиктор должен содержать только
известные непустые категории обучения. Пустые строки и NULL в прочих полях
сохраняй раздельно. В обучении каждая категория должна содержать события и
не-события; нулевые частоты и сглаживание в этот срез не входят.

Явно запроси `read.ports:[0,1,2]`: порт 0 — строки с ClassNum/ClassMark/
ClassSignificant, порт 1 — параметры классов и WoE/IV, порт 2 — общий IV и
значимость признака. Новые поля следуют сразу за преобразуемым исходным полем.
Номер класса начинается с нуля и не означает порядок категорий исходного CSV.
ClassSignificant здесь содержит вклад класса в IV. Доли EventRate/NonEventRate
считаются внутри класса; WoE использует доли относительно общих событий/
не-событий. Не вычисляй WoE из округлённых UI-значений.

Сохрани пакет отдельно после проверки всех выходов. Для экспорта всех трёх
выходов сохраняй порядок: строки, классы, значимости. Точные значения, типы,
NULL, порядок и численные допуски проверяет существующий reader/cold-check.
Внешние диапазоны, continuous-признаки, ручные и замороженные разбиения,
переменные и неизвестные категории требуют отдельного назначения.
