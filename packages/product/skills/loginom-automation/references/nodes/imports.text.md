# Текстовый файл (`imports.text`)

<!-- mode: delimited -->
Для изменения существующего Импорта сначала получи подтверждённый исходный CSV.
Без него запроси файл до Execute/чтения: чтение добавляет таблицу визуализатора
в пакет даже при последующем отказе настройки. После `NOT_APPLIED` с
`effect_possible=false` не выполняй baseline/Save ради cleanup: сообщи отказ,
попроси исходный CSV.

Для серверного текста сначала вызови `dock_node_apply` для `imports.text` с
`parameters:{source:{kind:"storage",server_source_ref:"…"},preview_only:true,settings:{source:{source_path:"…"}}}`,
`finish:"close"`, `inputs:[]`, `mappings:[]`, `read:{ports:[]}`. Это открывает
мастер и возвращает `output.server_profile`, затем закрывает черновик без Execute.
Если кодировка известна, укажи её в `settings.source.encoding` (например, `CP1251`). Если кириллица preview искажена при UTF-8, снова найди исходный путь через `dock_storage_source` и повтори preview с `CP1251`; не считай искажённый текст данными файла.
Preview ≤25 строк, неполный: N и редкие типы не доказаны. После скачивания и
выборки переиспользуй узел по ref: после Close пустому узлу нужны полные
настройки импорта выборки из локального профиля.

Если подготовленная таблица — непосредственный выход существующего текстового
Import и нужны только переименования/смена типов её полей, правь этот Import через
`settings.columns`; не добавляй Reform в обход этой правки. Просьбу не перенастраивать
загрузку CSV выполняй сохранением `settings.source` и `settings.format`, остальных
полей и их порядка; запрошенные имена/типы и необходимые output mappings меняй
на том же Import. Получи проверенную доставку исходного вложения текущей сессии
с `overwrite=reject`: повтор по прежнему пути runtime принимает только после
сравнения серверных байтов. При `UPLOAD_PATH_CONFLICT` не меняй путь или политику
перезаписи ради обхода отказа.

Для неизменённого существующего текстового Import используй `mode=delimited`,
`parameters:{settings:{}}`, `inputs:[]`, `mappings:[]`, `finish=execute` и
`read:{ports:[0]}`. Этот путь выполняет текущую конфигурацию без открытия мастера.
Не передавай `source` и прежний `upload_operation_id`, не доставляй тот же CSV
заново: upload-квитанция старой сессии здесь не нужна. `UPLOAD_PATH_CONFLICT`
не является причиной включать перезапись файла для активации сохранённого узла.
Изменение источника, колонок, формата или mappings Import по-прежнему требует
проверенную загрузку текущей сессии.

У нового текстового импорта source_path можно опустить после успешной доставки:
Dock возьмёт точный путь по upload_operation_id. По умолчанию UTF-8, заголовок
в первой строке, пропуск0, разделитель запятая, десятичная точка, пустой NULL,
двойная кавычка; явные значения сохраняются. Типы и имена колонок задаёшь ты.
