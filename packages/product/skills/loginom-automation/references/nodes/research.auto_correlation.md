## Автокорреляция

Для зависимости числового ряда от предыдущих значений выбирай `dock_node_apply`
с `target.type:"research.auto_correlation"`, `mode:"time_domain"`.
В `parameters.autocorrelation` нового узла передай `field` — одно точное
техническое имя integer/real поля — и `lag_count` — число отсчётов от 1,
включая лаг 0. Используется порядок записей входа; отдельную сортировку добавляй
по просьбе пользователя. Подключи таблицу к входу 0; остальные поля, например
RowID, в расчёт не входят. `finish:"execute"`, `read.ports:[0]`; для полного
результата задай достаточное `sample_rows` (до 100). Временная область и ЧАКФ off
входят в режим. Этот расчёт выполняй узлом Автокорреляция; Калькулятор, JavaScript
и корреляция сдвинутых полей для него не нужны.
Выход содержит Lag и native поля АКФ, ошибки и Boolean значимости в порядке
возрастания лагов. Число строк ограничено длиной входа, исходные поля не проходят.
На существующем узле пропуск `field`/`lag_count` сохраняет поддержанную настройку;
для замены входного файла обнови исходный импорт и выполни тот же existing узел
с прежними параметрами, `inputs:[]`, `mappings:[]`. Новый узел для этого не создавай.
Если Импорт обновлён с `finish:"done"` (в том числе `source_switch`) или пакет открыт заново, перед повторным выполнением существующего узла выполни Импорт с `finish:"execute"`.
Отказ `requires an active source output` не итог: выполни узел, питающий вход 0,
и повтори тот же existing узел с новым operation_id.
Поддержан ряд из минимум двух конечных непустых значений с положительной
дисперсией. Пустой вход не поддержан: узел отказывает до выполнения. NULL вызывает
отказ «Данные содержат пустые значения»; сохрани NULL, не подставляй ноль.
При любой ошибке покажи пользователю её текст дословно, сохрани пакет и не
экспортируй старый результат: прежняя таблица не является новым результатом.
Частотная область, ЧАКФ и несколько серий пока не поддержаны.

В Loginom 7.4.2 нет начала диапазона, шага и списка лагов. `lag_count`
задаёт 0…min(lag_count,N)−1: для N=5 и count=10 это все лаги 0…4.
Объясни ограничение, если запрошен диапазон, шаг или список; не подменяй запрос
первым числом отсчётов. Среднее и знаменатель АКФ берутся по всему ряду;
перекрытые срезы и края не нормируются заново.

Для зависимости ряда от предыдущих значений выбирай `research.auto_correlation` / `time_domain`; перед настройкой прочитай [детали параметров, NULL и выходов](research.auto_correlation.md). Не заменяй узел корреляцией сдвинутых полей, Калькулятором или JavaScript.
