# Цикл

Для перебора строк через Подмодель используй `control.loop`, mode `group_rows`.
Сначала прочитай карточку `dock_action_describe` с `node_types:["control.loop"]`,
`modes:["group_rows"]` и карточку `control.supernode` / `tabular_boundary`.

<!-- mode: group_rows -->
Сначала построй тело: Подмодель с одним обязательным табличным входом и одним
табличным выходом. Свяжи внешний импорт с её входом для схемы. Войди через
`dock_prepare.graph_navigation`, получи свежие refs и наблюдай внутренний граф.
Создай нужный поддержанный узел внутри Подмодели, свяжи InputNode→обработчик→
существующий OutputNode (`control.supernode_output`). Выходом может быть
Калькулятор или REST. Для Калькулятора явно задай output mapping всех полей
в требуемом порядке с `autosync:false`; новое поле по умолчанию стоит первым.
Для REST нужен вход таблицы 2, выход ответа 0; запрос выполняется для каждой
входной строки. Вернись в родительский workflow и снова наблюдай граф.

Создай Цикл: `target:{kind:"new",type:"control.loop"}`, `mode:"group_rows"`,
`parameters:{body:<свежий scoped ref Подмодели в родительском workflow>}`,
`inputs:[]`, `mappings:[]`, `finish:"done"`, `read:{ports:[],sample_rows:0}`.
Порты появятся после этой настройки. Затем apply на ТОМ ЖЕ существующем Цикле,
с тем же `parameters.body`, `inputs:[{source:<импорт>,output:0,input:0}]`,
`mappings:[]`, `finish:"execute"`, `read:{ports:[0],sample_rows:100}`.
Не создавай второй Цикл. Ref тела нельзя брать из вложенного workflow.

Групповая обработка фиксирована: размер группы 1, единственный табличный вход 0;
без параллельности, идентификаторов итераций, игнорирования ошибок и собственной
конфигурации тела. Другие параметры не передавай. Выход Цикла — объединение
выходов всех итераций в порядке строк. Для полного чтения небольшого результата
используй `dock_node_read` с новой operation_id и source_operation_id успешного
Execute. Для трёх страниц полный результат содержит три строки; RequestID REST
в каждой итерации начинается с 0. Сравнивай текст ответа без разбора/нормализации.

Тело живое: правь исходную Подмодель, затем заново выполняй Цикл. Сам исходный
экземпляр Подмодели при этом не активируется. Повторная конфигурация Цикла с
parameters:{} не поддержана: используй body снова или dock_node_read по квитанции.
После последнего полного чтения добавь стандартный Export, выполни и сохрани
пакет штатным Save.

HTTP 404 и другие HTTP-ошибки REST возвращаются данными дополнительного выхода
REST, а не обязательно исключением тела. Не обещай прерывание Цикла из-за HTTP
статуса. Не поддержаны FOR, постусловие, параллельность, ключевые поля групп,
переменные, несколько/древовидные портов и тела другого типа. Не входи в Цикл:
вложенный граф принадлежит исходной Подмодели.
