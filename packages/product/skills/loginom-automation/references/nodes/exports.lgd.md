# Экспорт LGD

Получай parameter_schema через dock_action_describe(node_types:["exports.lgd"]).
Один табличный input 0, режим native. lgd_export: destination — новый .lgd
в собственном каталоге; compression="none"/"lzo"/"lz4", overwrite="reject".
checksum="none"/"compressed"/"all" для LZ4; для none/lzo только "none".
Все четыре поля обязательны при создании; {} сохраняет существующие настройки.
У экспорта нет табличного выхода: read.ports=[], результат output.file_artifacts.
Execute создаёт файл; Done сохраняет настройки; Close отменяет черновик.
Сохраняй имена, метки, виды, типы, порядок полей/строк и NULL/пустые строки.
Никакого обучения, перезаписи, append, DDF и переменных.
На стенде используется 64-битный писатель; 32-битный Loginom и Deductor
недоступны для проверки. Разрядность задаёт сервер, переключателя в узле нет.
Не обещай совместимость с 32-bit или Deductor ≤5.3: LGD не является DDF.
Запрос DDF или такой совместимости отклоняй с объяснением ограничения.
Сохрани пакет отдельным Save. Обратный импорт сам по себе не доказывает
независимую правильность формата файла.

Выбирай этот нативный узел через `dock_node_apply`, `mode:"native"`. Калькулятор и JavaScript не нужны для чтения или записи LGD. Для обратного импорта собственного экспорта выбери файл через `dock_storage_source`, затем `parameters.source:{kind:"storage",server_source_ref:...}`. Не загружай и не конвертируй его повторно.
