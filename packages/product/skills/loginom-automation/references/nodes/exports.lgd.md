# Экспорт LGD

Получай parameter_schema через dock_action_describe(node_types:["exports.lgd"]).
Один табличный input 0, режим native. lgd_export: destination — абсолютный .lgd
в собственном каталоге; compression="none"/"lzo"/"lz4", overwrite="reject".
checksum="none"/"compressed"/"all" для LZ4; для none/lzo только "none".
После reopen Loginom может показать прежний checksum в disabled-поле:
для none/lzo он не используется, эффективный checksum остаётся "none".
При создании обязательны compression, checksum, overwrite и один источник пути:
destination ИЛИ bindings:{destination:{variable:"LgdPath"}}. {} сохраняет настройки.
У экспорта нет табличного выхода: read.ports=[], результат output.file_artifacts.
Execute пишет файл; Done сохраняет настройки; Close отменяет черновик.
Сохраняй имена, метки, виды, типы, порядок полей/строк и NULL/пустые строки.


Перезапись требует ЯВНОГО overwrite="replace" и явного destination или bindings
в КАЖДОМ запросе. {} использует reject даже после предыдущей перезаписи.
Разрешается только точный файл в собственном каталоге; неожиданный диалог
не подтверждается. Дозаписи в нативном «Экспорте в Loginom Data» Loginom нет:
диалог предлагает только «Да/Нет» перезаписи. Составной импорт/объединение
не является режимом этого узла; append не поддерживается.

Для пути из переменной подключи выполненный выход variables.calculator или
другого штатного источника к variable_inputs:[{source:...,output:0,input:0,kind:"variables"}].
bindings.destination.variable — точное имя во входном сопоставлении. Требуется
наблюдаемая строка, не NULL, содержащая собственный абсолютный .lgd путь.
Встроенный выход переменных сценария может передавать NULL; видимость имени
в списке не доказывает значение. Сначала выполни и прочитай источник.
После изменения переменной выполни источник и тот же экспорт: {} сохраняет
привязку и читает актуальный путь. Сохранение пакета и reopen проверяй отдельно.

На стенде используется 64-битный писатель; 32-битный Loginom и Deductor
недоступны для проверки. Разрядность задаёт сервер, переключателя в узле нет.
Не обещай совместимость с 32-bit или Deductor ≤5.3: LGD не является DDF.
Запрос DDF или такой совместимости отклоняй с объяснением ограничения.
Другие алгоритмы сжатия этим срезом не заявляются.
Независимая правильность формата не следует только из обратного импорта.
Выбирай нативный узел через dock_node_apply, mode:"native"; табличный Калькулятор
и JavaScript для записи LGD не нужны. Для обратного импорта выбери файл через
dock_storage_source, затем parameters.source:{kind:"storage",server_source_ref:...}.
Не загружай и не конвертируй его повторно. Сохрани пакет отдельным Save.
