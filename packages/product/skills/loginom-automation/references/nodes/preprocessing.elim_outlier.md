# Редактирование выбросов (`preprocessing.elim_outlier`)

Используй `dock_node_apply`, `target.type:preprocessing.elim_outlier`, один
табличный вход. Обрабатывай только выбранные непрерывные integer/real поля;
остальные сохраняй. NULL не участвует в статистике. `finish:execute`,
`read.ports:[0,1,2]`: 0 — результат обработки, 1 — исходные выбросы без
экстремумов, 2 — исходные экстремальные строки. Боковые выходы сохраняют
исходные значения. Эту операцию выполняй данным узлом; Калькулятор и JavaScript
для её самостоятельного вычисления не нужны.

<!-- mode: detect -->
`mode:detect`, `parameters.outlier`: `fields` (технические имена только
непрерывных числовых полей), `method:sd|iqr`, явные `outlier_factor`,
`extreme_factor` (не меньше первого) и `ordered` для нового узла.
Входной флаг ordered не сортирует данные. Оба действия — keep.
Перед Execute узел обучается на текущем входе. Patch сохраняет неуказанные
настройки обнаружения. IQR: Q(p)=sorted_non_null[min(floor(n*p),n-1)],
строгие границы Q1−k*(Q3−Q1), Q3+k*(Q3−Q1); квантили не интерполируются.
<!-- /mode -->

<!-- mode: edit -->
`mode:edit`, `parameters.outlier`: `fields` (технические имена), `method:sd|iqr`,
явные `outlier_factor`, `extreme_factor` (не меньше первого) и `ordered` для
нового узла. Дополнительно задай независимые `outlier_policy` и `extreme_policy`:
`keep`, `mean`, `median`, `most_probable`, `limit`, `delete`, `constant`. Для нового узла нужны обе политики;
patch существующего узла сохраняет пропущенное отдельно для каждого поля и
класса. Для вновь включаемого поля задай обе политики, метод и оба множителя.
Перед Execute узел обучается на текущем входе. При SD с множителями 1/2 mean считается по
нормальным значениям; median — верхнее среднее наблюдение всей non-NULL
выборки, most_probable — центр первого самого частого интервала Sturges всей
выборки. После выполнения прочитай полные результаты всех трёх портов,
выгрузи каждый в CSV и сохрани пакет. Повторное чтение сохранённого узла
выполняется без перенастройки. `delete` удаляет всю запись только с порта 0;
боковые порты сохраняют исходные аномальные строки. `constant` требует конечное
число `outlier_constant` для выбросов и отдельно `extreme_constant` для экстремумов;
эти параметры допустимы только при constant своего класса. Например, политики
constant/constant с `outlier_constant:0, extreme_constant:100` независимы.
При patch неуказанная константа своего активного класса сохраняется; при смене
политики скрытая константа не используется. `limit` заменяет выброс ближайшей границей нормального класса
для SD и IQR; экстремальные значения ограничиваются той же границей.
<!-- /mode -->

Quality недоступен через видимый UI Loginom 7.4.2. После смены входа Execute
пересчитывает границы: применение сохранённой модели без обучения недоступно.
