# Слияние (`transform.join_data`)

## Декартово произведение / полное слияние без ключей

Для каждой строки левой таблицы со всеми строками правой используй
`loginom_dock_node_apply`: `target.type:"transform.join_data"`, `mode:"full"`,
`parameters:{keys:[],case_sensitive:true,include_joined_keys:true}` и оба
`inputs` (`input:0` слева, `input:1` справа). Это также «полное слияние без
ключевых полей». Повторы сохраняются, выход содержит все поля обеих сторон.
Не задавай пары ключей по похожим именам. Выбирай Слияние, а не Калькулятор
или JavaScript. Отдельного `mode:"cross"` нет. Пустые ключи разрешены только
для `full`; остальные режимы требуют ключи одинаковых типов.
Для чтения существующего полного слияния без перенастройки используй
`mode:"full"`, `parameters:{}`, `inputs:[]`, `mappings:[]`, `finish:"execute"`.
Порядок строк не гарантирован; конфликты имён устраняй входными mappings.

## Слияние

Для сопоставления двух таблиц по ключам используй `loginom_dock_node_apply` с
`target.type:"transform.join_data"`: `mode:"right"` сохраняет все строки правого
входа, `"full"` — обоих входов, `"difference"` — только строки левого входа без
пары справа. Укажи `inputs` с портами `input:0` для левой таблицы и `input:1`
для правой, `parameters.keys:[{left,right}]` для всех частей ключа одновременно,
явные `case_sensitive` и `include_joined_keys`. Повторные ключи сохраняют все
совпавшие пары; отсутствующая сторона заполняется NULL. В `difference` выход
содержит только поля левой таблицы при любом `include_joined_keys`. Для этих
операций выбирай Слияние; Калькулятор предназначен для формул по строкам.
Имена полей ключей должны иметь одинаковые типы; конфликты выходных имён
устрани через входные `mappings`. Существующий узел без перенастройки выполняй
с его фактическим `mode`, `parameters:{}`, `inputs:[]`, `mappings:[]`.

### Слияние двух таблиц по ключам

Все правые / обе стороны / левые без пары. Типы ключей совпадают.

Для нового Слияния (`transform.join_data`) укажи оба входа, mode `inner` или `left` и
все три параметра: `keys:[{left:имя,right:имя}]`, `case_sensitive` и
`include_joined_keys`. Имена — фактические имена полей каждой стороны, оба флага —
явные boolean по задаче; не заменяй их несхемными `on` или `join_type`.
