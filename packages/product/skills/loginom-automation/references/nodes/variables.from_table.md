# Таблица в переменные

<!-- mode: aggregate -->
Для суммы, количества, минимума, максимума и среднего текущей таблицы
используй `dock_node_apply` с `type:"variables.from_table"`, `mode:"aggregate"`.
Узел получает таблицу через `inputs:[{source:NodeRef,output:0,input:0}]`
и создаёт исходный порт переменных 0. Обучение не требуется.

Полная настройка выбранного поля:
`parameters:{fields:[{field:{kind:"input_field",name:"X"},aggregations:["sum","count","min","max","avg"]}]}`.
Бери точное техническое имя из прочитанной схемы входа. Поддерживаются
числовые поля integer/real и эти пять функций. При изменении настройки
указывай весь набор выбранных полей и функций. Для повторного выполнения
прежнего узла с сохранением функций передавай `target` существующего узла,
`parameters:{}`, `inputs:[]`, `mappings:[]` и `finish:"execute"`.

Внутри поля native-порядок функций: sum,count,min,max,avg. Count считает
все строки, включая NULL; остальные функции пропускают NULL. Сумма и
среднее имеют тип real, количество integer, min/max сохраняют числовой тип
входа. На пустой таблице count равен нулю, остальные значения NULL.
Для целого X и пяти функций наблюдены X_Sum, X_Count, X_Min, X_Max, X_Avg.
Читай действительные имена и метки из результата; не назначай суффиксы сам.

Для полного набора переменных передавай `read:{ports:[],variable_ports:[0]}`.
Проверяй полный упорядоченный набор, имена, метки, типы и точные значения
в `output.variable_ports`. Для нового чтения успешной операции используй
`dock_node_read` с её `source_operation_id`: этот путь повторно выполняет
исходный узел. После смены CSV сохраняй прежний узел и набор агрегатов,
повторно выполни его и прочитай переменные. Затем сохрани пакет штатным
действием `package.save_as` или `package.save_checkpoint`.

Калькулятор таблицы вычисляет поля строк, JavaScript задаёт код; запрос
агрегированных переменных направляй в `variables.from_table`.
