# Дерево в таблицу (`trees.to_table`)

<!-- mode: selected_nodes -->
## Настройка

Подключи к входу 0 нативный выход дерева. Для [JSON в дерево](trees.from_json.md)
сначала выполни источник с `finish:"execute"`. Чтобы передать большое дерево,
задай на источнике `read:{ports:[],sample_rows:0,require_exact_numbers:false}`.
Dock проверяет схему того же завершённого выполнения перед созданием связи.
Привязка также работает после частичного предпросмотра того же JSON-источника.
Для других источников требуется успешное полное чтение исходного порта.
Разбор нескольких документов в строках REST описан в [карточке REST](integration.rest_request.md).
Если пользователь просил дерево, не подменяй дерево JavaScript.

На новом узле укажи `mode:"selected_nodes"` и параметры `selected_paths`,
`repeat_parents`, `composite_names`, `composite_labels`, `label_separator`.
Указывай пути листьев в порядке нативной схемы и без индексов массива. Например,
для `carts[].products[]` выбери `["/carts/id","/carts/products/id","/carts/products/quantity"]`,
`repeat_parents:true`, `composite_names:true`, `composite_labels:true` и
`label_separator:"."`. Loginom 7.4.2 выдаёт `Root_carts_id`,
`Root_carts_products_id`, `Root_carts_products_quantity` и повторяет ID корзины
для каждой позиции. При `repeat_parents:false` значение родителя присутствует в
первой строке его группы, далее NULL.

Составные имена объединяют корень и путь через `_`. Без них имена берутся из
листьев. Выбранные технические имена должны быть уникальны. Составные метки
объединяют путь через `label_separator` (`.`, `|`, пробел, `-`, `_`).
Имя и порядок проверь на выходе 0. `global_index_paths:["/items"]` добавляет
нативную целочисленную колонку «Глобальный индекс узла» для одного массива
объектов. Колонка встаёт первой в ветви массива, имя читай из выхода.
Явный `[]` убирает индекс. При обновлении `parameters:{}` сохраняет настройки,
а `selected_paths` заменяет выбор полностью.

## Выполнение и проверка

Dock поддерживает выбор листьев во вложенных массивах объектов и в соседних
массивах. Нативный Loginom разворачивает соседние ветви подряд, с NULL для
полей другой ветви. Выбор скалярного массива не входит в область Dock.
DateTime и Variant сохраняют нативные типы. Пустая строка, ноль и false
сохраняются, missing scalar и JSON null дают NULL.

В связке с JSON Dock показывает до 256 экземпляров в предпросмотре дерева.
Выполнение и передача через порт используют полное нативное дерево.
Для проверки типов и порядка прочитай выход 0 с `sample_rows:100`.
Табличное чтение возвращает `row_count` и максимум 100 строк в `sample`.
При `sample_complete:false`, если пользователь просит сверить все строки,
используй текстовый экспорт с реального выхода и скачанный файл.
Для экспорта NULL и пустых строк явно выбери непустой маркер NULL.
Если чтение завершилось с неизвестным эффектом, следуй подсказке
`operation.recover`.
