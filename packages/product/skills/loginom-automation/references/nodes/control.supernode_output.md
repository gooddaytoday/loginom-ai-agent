Сервисный выход внутри Подмодели — `control.supernode_output`, режим `tabular_boundary`.

Сначала прочитай [Подмодель](control.supernode.md). После входа в её внутренний граф получи свежий `workflow_ref` и native ref выходного узла с ролью `output`. Этот узел создаётся самой Подмоделью; новый сервисный узел не создавай.

Подключи выход внутреннего табличного узла к входу 0 этого существующего узла через `dock_node_apply`: target `existing`, mode `tabular_boundary`, parameters `{}`, mappings `[]`, finish `done`, read.ports `[]`. Источник, цель и workflow_ref должны принадлежать одному вложенному графу. Исполнение, чтение выхода и изменение границы через этот обработчик не поддерживаются.

После подтверждения связи вернись в родительский граф по NW1, выполни и прочитай внешнюю Подмодель. Сохрани пакет обычным `package.save_checkpoint`.
