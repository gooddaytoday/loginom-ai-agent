# Синтетические данные

Собери спецификацию или возьми пресет, проверь её и выпусти файлы через
`synthetic_data_run`. Краткий формат — в [спецификации](references/spec.md),
дефекты — в [каталоге](references/defects.md), файлы — в
[форматах](references/formats.md), готовый розничный набор — в
[пресетах](references/presets.md). Уже написанный сценарий — в
[режиме существующего сценария](references/existing-scenario.md).

Генератор детерминирован: один `seed` повторяет те же байты. Не выдумывай
строки в ответе вместо файлов и не вызывай shell, Python или свой скрипт.
[Исполняемый генератор](scripts/synthetic-data.mjs) запускает только
`synthetic_data_run`.

## Когда какой режим

- Сценария ещё нет. Уточни предмет, период, объёмы, форматы и нужные дефекты,
  если запрос этого не задаёт. Для запроса вроде «три файла продаж за год по
  трём магазинам, справочник товаров, склад и логистика» достаточно пресета
  `retail`.
- Сценарий уже есть. Возьми имена колонок, типы, разделитель и кодировку
  существующих входов. Источник — `inspect` по приложенному `.lgp` или, в
  профиле `loginom-automation`, чтение узла. Черновик из `inspect` не содержит
  колонок: их нужно дописать до `generate`.

## Выпуск

1. Запиши спецификацию JSON в каталог сессии обычным инструментом записи
   либо передай пресет `retail` и JSON параметров.
2. `validate` со `spec` — абсолютный или относительный путь к JSON.
   Пока `ok` не станет `true`, файлы не создавай.
3. `generate` с тем же `spec` или с `preset`. Каталог набора —
   `<каталог сессии>/synthetic-data/<имя>/`. Повторное имя не перезаписывает
   набор: выбери новое `name`.
4. В ответе перечисли файлы данных из `files`, `seed`, число строк и
   `defect_count`. `manifest.json` и `defects.csv` — эталон дефектов, их не
   нужно импортировать в сценарий, если пользователь не просит сверку.
5. Попроси приложить файлы данных следующим сообщением. В CLI это `--file`
   с абсолютным путём каждого файла. Не говори, что файлы уже загружены в
   Loginom или видны как `input_artifacts`.
6. После вложения активируй `loginom-automation` и строй новый сценарий или
   добавляй импорт в существующий. Настройки текстового импорта возьми из
   `output` спецификации: кодировка, разделитель, заголовок, десятичный знак.

Отказ инструмента — это ошибка. Не подменяй набор вручную набранной таблицей.
