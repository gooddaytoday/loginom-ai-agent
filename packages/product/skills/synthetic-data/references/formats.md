# Форматы

Текстовые `csv`, `tsv` и `txt` читаются импортом Loginom. По умолчанию UTF-8, заголовок в первой строке, перевод строки LF, десятичная точка, кавычка `"`. Разделитель CSV — запятая, TSV — табуляция, TXT — точка с запятой. Это совпадает с новым текстовым импортом в `loginom-automation`, кроме TXT: для него в узле нужно явно поставить разделитель `;`.

| Поле output | Значение |
| --- | --- |
| `encoding` | `utf-8` или `cp1251` |
| `bom` | `true` добавляет UTF-8 BOM |
| `delimiter` | один символ |
| `quote` | один символ |
| `decimal` | `.` или `,`. Запятая в CSV с разделителем-запятой заключается в кавычки |
| `dateFormat` | шаблон из `YYYY`, `MM`, `DD`, `HH`, `mm`, `ss`. По умолчанию `YYYY-MM-DD`; у datetime к шаблону без времени дописывается `HH:mm:ss` |
| `newline` | `lf` или `crlf` |
| `header` | `false` убирает строку имён |

`xlsx` — книга с типизированными числами, датами как серийный номер Excel и текстом. Один файл может содержать несколько листов, если таблицы ссылаются на одно имя файла. `json` — массив объектов, `jsonl` — объект на строку, `xml` — элементы `table/row/cell`.

`manifest.json` и `defects.csv` лежат рядом с данными и не входят в список файлов для импорта. Их имеет смысл приложить отдельно, только если сценарий должен найти внесённые дефекты.
