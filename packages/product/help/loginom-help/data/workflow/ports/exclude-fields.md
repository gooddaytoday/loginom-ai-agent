# Исключенные поля

Исключение позволяет удалять поля из набора данных, при этом не нарушая работу [Автосинхронизации](automapping-of-fields.md).

> **Примечание**: Действие Добавить в исключенные доступно только в мастере настройки Выходных портов. Если все поля обязательные (выделены жирным шрифтом), то элементы интерфейса этого действия не отображаются, поскольку исключение недоступно для таких полей.

- Исключенные поля в списке показываются курсивом в отдельной группе Исключенные.
- В группе Исключенные можно менять порядок полей и удалять их из группы.
- При выборе Исключенного поля подсвечивается соответствующее ему Входное поле.
- Нельзя добавить отсутствующее или потерянное поле в группу Исключенные.
- При выполнении действия Связать автоматически не выполняется связывание исключенных Входных полей.
- Выходное поле удаляется при добавлении в группу Исключенные:
  - Входного поля, связанного с Выходным полем
  - Выходного поля.

Нельзя добавить в группу Исключенные:

- Обязательное Входное поле или Выходное поле, связанное с обязательным Входным.
- Отнаследованное Выходное поле или Входное поле, связанное с отнаследованным Выходным.

**Обязательное поле** — это поле, которое было добавлено алгоритмом узла, либо параметры этого поля переопределены пользователем.

**Отнаследованное** — это поле в [Производном компоненте](../derived-component.md), которое было унаследовано от базового узла.
