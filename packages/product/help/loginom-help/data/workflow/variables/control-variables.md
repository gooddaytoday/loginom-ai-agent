# Управляющие переменные

Порт управляющих переменных принимает переменные, с помощью которых можно задать параметры настроек узлов. Таким образом, настройки узлов могут быть предметом вычисления в ходе выполнения Сценария. Это позволяет более гибко реализовывать логику обработки данных.

> **Примечание:** порт управляющих переменных есть не у всех узлов. Для узлов, имеющих порт управляющих переменных, он по умолчанию может быть скрыт. Для его отображения необходимо в контекстном меню узла выбрать пункт «Показать порт управляющих переменных».

Управляющие переменные не обязательно принимать от другого узла. При настройке порта возможно задать их перечень и значения по умолчанию.

Если хотя бы для одной из управляющих переменных узла задано значение, то в мастере настройки появляются переключатели выбора способа задания значений его параметров:

- — значение параметра задается вручную;
- — значение параметра задается переменной. В этом случае в поле параметра пользователь выбирает переменную, содержащую значение параметра.

Передать значение с порта управляющих переменных в какой-либо параметр в настройках узла можно с помощью подстановки вида:

`%VAR%`, где `VAR` — имя управляющей переменной.

Данный функционал доступен для задания имени файла в узлах на основе компонентов для работы с файловыми источниками данных из групп [Импорт](../../integration/import/README.md) и [Экспорт](../../integration/export/README.md), а также для названия таблицы в узле экспорта в [Базу данных](../../integration/export/database.md).

Примеры использования управляющих переменных:

- Переменная может выступать параметром условия в компоненте [Фильтр строк](../../processors/transformation/row-filter/README.md).
- Переменная в качестве параметра SQL-запроса при [Импорте из базы данных](../../integration/import/database.md) (переменная содержит текст SQL-запроса).
- Переменную можно использовать в качестве макроподстановки для динамического задания имени экспортируемого файла. Например, если необходимо сформировать имя [Excel-файла](../../integration/export/excel.md) с текущей датой, то это можно сделать следующим образом: `Имя_файла_%today%.xlsx`, где `today` — переменная, содержащая текущую дату.
