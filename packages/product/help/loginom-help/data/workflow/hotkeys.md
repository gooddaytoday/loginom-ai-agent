# Горячие клавиши

При проектировании сценария поддерживаются следующие горячие клавиши:

- Ctrl+X — вырезать выделенное;
- Ctrl+С — скопировать выделенное;
- Ctrl+V — вставить содержимое буфера обмена (вставка происходит в текущих координатах курсора мыши);
- Ctrl+A — выделить все узлы сценария;
- Del — удалить выделенное;
- F2 — переименовать узел;
- F3 — открыть быстрый просмотр выходных данных;
- F9 — запустить выбранный узел на выполнение;
- Shiht+Enter — войти в настройку узла;
- Enter — войти в подмодель;
- Ctrl+Enter — войти в подмодель и открыть в новом окне;
- Backspace — выйти из подмодели;
- Ctrl+Backspace — выйти из подмодели и открыть в новом окне.
