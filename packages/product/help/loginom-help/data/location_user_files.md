# Файловое хранилище

В редакциях Enterprise, Standard и Team (включающих в комплект поставки сервер Loginom) все пользовательские файлы хранятся на сервере Loginom. Таким образом, перед тем, как использовать какой-либо файл в сценарии, его необходимо предварительно поместить в файловое хранилище на сервере. Для работы с файловым хранилищем в этих редакциях предусмотрен файловый менеджер.

> **Примечание:** в настольных редакциях Personal и Community файловый менеджер отсутствует, пользователь имеет доступ ко всему файловому пространству локального компьютера.

При работе с сервером Loginom каждый из пользователей имеет личную [папку](admin/parameters/folders.md) в файловом хранилище. Файловый менеджер вызывается по кнопке Главного меню и предоставляет необходимый инструментарий для работы с файловым хранилищем.

В интерфейсе файлового менеджера отображается иерархическая структура доступных пользователю папок и файлов в виде таблицы с полями: Имя, Тип, Размер, Дата изменения, Только чтение и Путь. Переход внутрь папки осуществляется двойным кликом курсора по ней, а переход в папку уровнем выше — двойным кликом по кнопке **..**. Для перехода между папками можно также использовать панель Навигация, в которой отображается иерархия папок пользователя в виде дерева.

**Панель инструментов** файлового менеджера содержит следующие команды:

- **Загрузить (Insert)** — позволяет загрузить файл в открытую на текущий момент директорию, файл для загрузки следует выбрать в открывшемся окне проводника ОС.
- **Создать каталог** — создает папку в текущей директории.
- **Скачать** — позволяет скачать выбранный элемент из файлового хранилища в системную папку загрузок пользователя (аналогичное действие выполняется по двойному клику левой кнопкой мыши).
- **Скачать ZIP** — позволяет скачать выбранный элемент из файлового хранилища в системную папку загрузок пользователя в виде ZIP-архива.
- **Переименовать...(F2)** — изменить имя выбранного элемента.
- **Копировать (Ctrl+C)** — пометить выбранный элемент для копирования.
- **Вставить (Ctrl+V)** — вставить элемент, помеченный для копирования или для вырезания, в текущую директорию. Если файл вставляется в ту же директорию откуда он был скопирован, то к его имени через тире добавляется слово «копия» и индекс, например: `Файл — копия.txt`, `Файл — копия (2).txt` и т.д. (нельзя вставить файл в ту же папку после операции Вырезать). После копирования файл можно вставить несколько раз подряд (повторная вставка недоступна после команды Вырезать). Все вставленные файлы выделяются для удобства пользователя (при повторной вставке выделяются последние вставленные файлы).
- **Вырезать (CTRL+X)** — пометить выбранный элемент для вырезания.
- **Удалить...(Delete)** — удалить выбранный элемент.
- **Обновить список (Alt+F5)** — отображает актуальное содержание текущей директории.

> **Примечание:** кнопки **Копировать**, **Вырезать** и **Вставить** как на **Панели инструментов**, так и в **Контекстном меню** работают только внутри файлового менеджера и не связаны с буфером обмена ОС.

Клик правой кнопкой мыши по элементу в файловом менеджере вызывает **Контекстное меню**, которое содержит следующие команды:

- **Распаковать** — распаковать .zip архив. Команда доступна в контекстном меню при выделении одного .zip файла. Позволяет при выборе пункта Распаковать здесь извлечь содержимое архива в текущую папку, а при выборе Распаковать в папке — в папку с именем, идентичным имени архива.
- **Скачать** — позволяет скачать выбранный элемент из файлового хранилища в системную папку загрузок пользователя (аналогичное действие выполняется по двойному клику левой кнопкой мыши).
- **Скачать ZIP** — позволяет скачать выбранный элемент из файлового хранилища в системную папку загрузок пользователя в виде ZIP-архива.
- **Переименовать...(F2)** — изменить имя выбранного элемента.
- **Открыть** — открывает выделенную папку или пакет.
- **Перейти (Enter)** — позволяет перейти в папку. Доступно для элементов, находящихся в папке «Избранное».
- **Открыть пакет (Enter)** — открывает выбранный пакет. Команда доступна для пакетов, находящихся в папке «Избранное».
- **Добавить в избранное** — добавляет папку/файл в папку «Избранное» (не более 20 элементов).
- **Убрать из избранного (Delete)** — убирает папку/файл из папки «Избранное». Доступно для элементов, уже находящихся в избранном.
- **Очистить избранное…** — убирает все элементы из папки «Избранное».
- **Создать каталог** — создает папку в текущей директории.
- **Создать пакет** — создает новый пакет в текущей директории.
- **Копировать полный путь** — копирование полного имени выделенного элемента в буфер обмена. Если выделено несколько элементов, то скопирует полные имена всех элементов через разделитель «перевод строки».
- **Копировать (Ctrl+C)** — пометить выбранный элемент для копирования.
- **Вставить (Ctrl+V)** — вставить элемент, помеченный для копирования или для вырезания, в текущую директорию.
- **Вырезать (CTRL+X)** — пометить выбранный элемент для вырезания.
- **Удалить...(Delete)** — удалить выбранный элемент.
- **Обновить список (Alt+F5)** — отображает актуальное содержание текущей директории.

> **Примечание:** копирование полного пути файла возможно только при подключении по протоколу HTTPS. Если будет подключение по протоколу HTTP, то Loginom выдаст предупреждение: «Для данной операции необходимо соединение по протоколу HTTPS».

Клик правой кнопкой мыши по свободной области файлового менеджера вызывает **Контекстное меню**, которое содержит следующие команды:

- **Загрузить (Insert)** — позволяет загрузить файл в открытую на текущий момент директорию, файл для загрузки следует выбрать в открывшемся окне проводника ОС.
- **Создать каталог** — создает папку в текущей директории.
- **Создать пакет** — создает новый пакет в текущей директории.
- **Вставить (Ctrl+V)** — вставить элемент, помеченный для копирования или для вырезания, в текущую директорию.
- **Обновить список (Alt+F5)** — отображает актуальное содержание текущей директории.

Поддерживается загрузка файлов методом Drag and Drop, т. е. путем перетаскивания файлов в окно файлового менеджера. Файлы при этом копируются.

Для выделения нескольких элементов можно:

- каждый из них отметить флагом в чекбоксе;
- выделить их поочередно, зажав клавишу Ctrl;
- выделить первый элемент и затем, зажав клавишу Shift, выделить последний элемент в последовательности файлов.

> **Примечание:** выделение с файлов/папок сбрасывается, если после выбора нескольких элементов кликнуть мышкой на один из них или в любое место экрана.

Поддерживается возможность перехода между первым и последним объектом посредством кнопок Home (начало списка) и End (конец списка).

Для сортировки элементов текущей директории по определенному параметру следует нажать на заголовок одного из столбцов таблицы файлового менеджера: Имя, Тип, Размер, Дата изменения, Только чтение или Путь.

При первом нажатии на заголовок столбца выполняется сортировка по возрастанию , при втором — по убыванию .

В заголовке таблицы файлового менеджера слева от поля Имя присутствует чекбокс, а справа от поля Путь — кнопка **Удалить все**:

- при выставлении флага выделяются все элементы в текущей директории;
- при нажатии на кнопку **Удалить все** — удаляются все элементы текущей директории.

Отображение каждого столбца таблицы файлового менеджера можно включить или отключить. Для этого следует навести курсор на заголовок любого столбца и нажать на появившуюся кнопку , затем перевести курсор на строку Столбцы и в появившемся списке выставить флаги для тех столбцов, которые нужно отобразить, или снять флаги для тех столбцов, которые нужно скрыть.
