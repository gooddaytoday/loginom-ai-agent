# Коэффициенты регрессии

Описание коэффициентов представлено в таблице:

Поле | Описание
Имена входных полей | Список имен входных полей
Метки входных полей | Список меток (названий) входных полей
Уникальные значения | Список уникальных значений полей
Коэффициенты | Оценки значений коэффициентов при независимых переменных
Стандартное отклонение | Стандартная ошибка оценки коэффициента
Статистика Вальда | Статистика Вальда для оценки значимости переменной
P-значение | Оценка значимости переменной. Чем меньше Значимость (Р-значение), тем меньше вероятность нулевой гипотезы о том, что коэффициент при независимой переменной равен 0. Вычисляется по z-статистике.
Отношение шансов | Отношение шансов наступления события к шансу наступления не-события для каждого увеличения переменной на одну единицу, при условии, что все другие переменные остаются постоянными
Нижняя граница д.и. отношения шансов | Нижняя граница доверительного интервала отношения шансов
Верхняя граница д.и. отношения шансов | Верхняя граница доверительного интервала отношения шансов
