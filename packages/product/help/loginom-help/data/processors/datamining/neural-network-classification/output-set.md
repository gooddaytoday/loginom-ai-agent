# Выход нейросети

В выходном наборе к входному добавляются следующие поля:

Метка | Описание
Класс | Прогноз | Обозначение прогнозируемого класса
ID класса | Прогноз | Идентификатор прогнозируемого класса
Класс | Факт | Фактический класс. Выходное поле обучающего набора данных (данное поле выводится только при обучении Нейросети)
ID класса |Факт | Идентификатор, присвоенный фактическому классу (данное поле выводится только при обучении Нейросети).
Апостериорная вероятность | Вычисленная по результатам обработки вероятность принадлежности текущего набора параметров прогнозируемому классу
Индекс Джини | Показывает характер изменения одной величины относительно изменения другой
