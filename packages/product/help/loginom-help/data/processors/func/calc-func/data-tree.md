# Дерево данных

Нижеперичисленные функции являются специфическими для [Калькулятор (дерево)](../../data-trees/calculator-tree/README.md).

## ItemCount

**ItemCount()**

- Аргументы отсутствуют.

Функция возвращает количество узлов-элементов массива.

## ItemIndex

**ItemIndex()**

- Аргументы отсутствуют.

Функция возвращает индекс выражения внутри массива. Нумерация начинается с 0.

## Location

**Location()**

- Аргументы отсутствуют.

Функция возвращает путь от корня дерева до узла выражения.

## Parent

**Parent()**

- Аргументы отсутствуют.

Функция возвращает родительский узел текущего узла выражения.

## DisplayName

**DisplayName(["ПутьУзла"])**

- ПутьУзла - строковое значение, представляющее путь к узлу, переменной или выражению. Необязательный.

Функция возвращает метку (отображаемое имя) по пути узла, выражения или имени переменной. Если функция вызывается без аргументов, то она возвращает метку текущего вычисляемого выражения.

Пример: `DisplayName("Root.Node1")`.
