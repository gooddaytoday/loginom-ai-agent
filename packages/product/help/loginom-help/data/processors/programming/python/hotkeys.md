# Горячие клавиши

В редакторе кода поддерживаются следующие горячие клавиши:

- Ctrl+Space — автодополнение кода
- Ctrl+/ — закомментировать/раскомментировать код
- Shift+Tab — уменьшить уровень отступа в выделенном коде
- Tab — ввод 4 пробелов (если выделено более одной строки, то выполняется индентация строк выделенного кода)
