# Общие папки

Данная страница используется для управления общими папками и правами доступа к ним. В верхней части страницы расположена панель инструментов, содержащая следующие управляющие элементы:

- **Добавить** — добавить новую папку;
- **Редактировать** — редактировать выделенную папку;
- **Удалить** — удалить выделенную папку;
- **Обновить** — обновить список папок.

**Горячие клавиши**
- **Up** — перейти на строку выше;
- **Down** — перейти на строку ниже;
- **Insert** — добавить новую папку;
- **F2** — редактировать папку;
- **Delete** — удалить папку;
- **Alt + F5** — обновить список папок и их параметров.

При нажатии на кнопку Добавить/ Редактировать появляется окно Добавить общую папку/Настройка общей папки.

Состав окна Добавить общую папку/Настройка общей папки:

- **Имя** — в этом поле задается имя новой общей папки, в окне редактирования это поле не доступно.
- **Путь** — здесь отображается как будет выглядеть путь к папке относительно корня.
- **Права доступа** — таблица со списком пользователей.
  - **Чекбокс** — поле указывает наличие прав у пользователя на использование папки. Если в чекбоксе заголовка поля поставить флажок, то все пользователи будут выделены как имеющие права на доступ к папке.
  - **Пользователь** — в этом столбце отображаются все зарегистрированные пользователи. Поле имеет также возможность ввода фильтра для поиска определенного пользователя.
  - **Полное имя** — в этом столбце отображается полное имя пользователя, если оно задано на странице [Пользователи](users/README.md). Как и поле Пользователь имеет возможность поиска через поле фильтра.

> **Примечание:** Имя общей папки не может содержать следующие символы: `\`, `/`,`:`, `*`, `?`, `"`, `<`, `>`, `|` и не может оканчиваться точкой или пробелом. Максимальная длина имени не должна превышать 256 символов UTF-16.
>
> Если нужно переименовать папку, то создается новая папка куда копируется содержимое старой, затем старая папка удаляется.
