# Администрирование

Данная страница в интерфейсе программы нужна для управления [пользователями](users/README.md), [рабочими папками](shared-folder.md), [параметрами](parameters/README.md) работы сервера, просмотра открытых сессий и пакетов, мониторинга и управления их активностью в [диспетчере](dispatcher.md). В отличие от серверных редакций поставки (Team, Standard, Enterprise), настольные (Community, Personal) имеют всего один пункт на странице — Параметры.

В серверных редакциях доступ на страницу имеют только пользователи с ролью Администратор.

> **Внимание:** по умолчанию в системе задан пользователь admin с правами Администратор и паролем: admin. После установки системы в обязательном порядке необходимо заменить пароль этого пользователя.
