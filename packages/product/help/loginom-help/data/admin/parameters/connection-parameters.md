# Параметры подключения

Изменения параметров подключения вступают в силу после перезапуска службы сервера.

Параметры данной группы отсутствуют в настольных редакциях Loginom.

Параметр | Значение по умолчанию | Описание
IP адрес | 0.0.0.0 | Адрес или адреса, проверяемые на наличие сервера
TCP порт | 4580 | Порт, используемый для соединения с сервером
Unix socket | Для Windows: C:\ProgramData\Loginom\loginomd.socket Для Linux: /run/loginom/loginomd.socket | Путь к файлу, содержащему информацию о связи между процессами Loginom Server и Integrator. Файл создается автоматически после указания пути и имени файла. В редакции Team используется только unix socket (файл сокета создаётся в рабочей директории Loginom Server и имеет имя loginomd.socket). Протокол подключения настраивается в файле конфигурации Integrator.dll.config.
Unix socket permissions | 770 | Loginom Server и Loginom Integrator работают от разных пользователей с общей основной группой, которая используется для связи через файл Unix socket. Параметр определяет какие пользователи имеют право использовать Unix Socket. Для подключения необходимы права на запись файла. Значение задаётся числом в восьмеричном формате от 000 до 777. Данный параметр доступен только для Linux.
WebSocket порт | 8080 | Порт, используемый для обмена сообщениями с сервером
WebSocket SSL/TLS порт | если настроено WSS (WebSocket Secure), то 8443, иначе null | Защищенный порт, используемый для обмена сообщениями с сервером
Имя файла сертификата |  | Путь к файлу сертификата, используемого для SSL-соединения. Задается абсолютным путем или относительным (корневой каталог `"C:\ProgramData\Loginom\Server"`).
Имя файла закрытого ключа |  | Путь к файлу ключа, используемого для SSL-соединения. Задается абсолютным путем или относительным (корневой каталог `"C:\ProgramData\Loginom\Server"`).
Период проверки соединения (сек) | Отключено | Промежуток времени между проверками соединения с клиентом. Необходим для автоматического определения разрыва сетевого соединения и закрытия соответствующей сессии клиента вместе с открытыми в ней пакетами. Проверка состояния канала связи сервера с клиентом реализуется с помощью специального сообщения, которое периодически отправляется клиенту в том случае, если в течение заданного интервала времени на сервер не приходит ни одного сообщения с клиента. Если же с клиента приходит любое сообщение, то таймер сбрасывается, т.е. специальное сообщение отправляется только в том случае, если по каналу связи долго не приходило ни одного входящего сообщения. Проверку соединения сервера с клиентом можно отключить, для этого необходимо стереть значение периода проверки, сохранить настройки и перезагрузить сервер. Отключение проверки соединения может привести к блокировке пакетов сервером, т.к. сервер не сможет определить разрыв связи с клиентом и будет считать, что пакет все еще используется клиентом. Если параметр включен, а Время жизни сессии после разрыва маленькое, то связь после разрыва соединения может не восстановиться. Максимальное значение — 2000000 секунд (23 дня).
Время жизни сессии после разрыва | 1800 | Промежуток времени, в течение которого сервер хранит сессию после обнаружения разрыва соединения с клиентом. Параметр применяется для возможности повторного подключения пользователя к той же сессии после временной потери сетевого соединения. Если сервер обнаружил разрыв соединения, сессия не удаляется сразу, а остается доступной в течение времени, указанного в параметре. Пока это время не истекло, пользователь может повторно подключиться к прежней сессии и продолжить работу. Если задано значение 0, сессия не сохраняется после разрыва соединения, и повторно подключиться к ней нельзя. Отсчет времени начинается только после того, как сервер обнаружил разрыв соединения. Если разрыв не был обнаружен, сервер может продолжать считать сессию активной, и она будет сохраняться дольше заданного значения. Для корректного определения разрыва соединения используется параметр Период проверки соединения (сек). Максимальное значение — 43200 секунд (12 часов). Параметр не применяется к сессиям, завершённым из-за отсутствия активности в рамках действия Тайм-аута закрытия сессии (сек) из раздела [Параметры безопасности](security-parameters.md).

Возможные значения портов задаются в числовом формате в интервале от 0 до 65535.
