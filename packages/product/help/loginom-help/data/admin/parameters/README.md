# Параметры

На странице «Параметры» можно просмотреть и изменить общие настройки сервера/приложения.

В верхней части страницы расположено три кнопки:

- **Сохранить** — сохраняет полученные изменения параметров.
- **Поиск** — поиск параметров по имени или значению. В окне настройки из выпадающего списка можно задать режим поиска: Везде, Параметр, Значение и искомое значение. Горячая клавиша для действия Ctrl+F
- **Обновить** — подгружает параметры, используемые в данный момент.

> **Примечание:** по завершении корректировки параметров необходимо нажать кнопку Сохранить.
