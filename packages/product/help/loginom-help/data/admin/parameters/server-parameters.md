# Параметры сервера

Изменения параметров, определяющих режим функционирования сервера, вступают в силу после нажатия кнопки Сохранить.

> **Примечание:** в настольных редакциях данная группа параметров называется Параметры приложения и включает в себя только параметры Размер пула потоков и Локаль.

Параметр | Значение по умолчанию | Описание
Максимум используемой памяти (KB) | Без ограничений | Только для OS Linux. Ограничение объёма памяти, используемого приложением (позволяет снизить для него риск быть завершенным OOM Killer'ом) ^2. Ограничение действует на виртуальную память, а не резидентную. Работает только если "Доля используемой памяти" настроена по умолчанию "Без ограничений".
Доля используемой памяти | Без ограничений | Только для OS Linux. Ограничение объёма памяти, используемого приложением (позволяет снизить для него риск быть завершенным OOM Killer'ом) ^2. Имеет приоритет над "Максимум используемой памяти". Доля используемой памяти вычисляется от доступной RAM (как множитель от 0 до 10 с шагом 0.01).
Размер пула пакетов | 10 | Количество часто используемых в пакетной обработке пакетов Loginom Integrator, сохраненных для быстрого вызова
Размер пула потоков | По умолчанию | Максимальное количество ставших неактивными после использования потоков, которые не удаляются и держатся в памяти для возможного последующего использования. Значение по умолчанию — Количество ядер CPU * 32. Максимальное значение — 1 000 000. Увеличение параметра позволяет быстрее работать при большом количестве параллельных операций. Уменьшение параметра — это потенциальное снижение потребления памяти.
Период проверки изменения веб-сервисов (сек) | 60 | Период времени, через который выполняется проверка изменений опубликованных пакетов. Если в течении данного промежутка времени были зафиксированы изменения, то будет выполнено обновление соответствующих веб-сервисов. Минимальное значение равно 1.
Таймаут остановки сервера (сек.) | 10 | Время, выделяемое серверу на завершение работы. Минимальное значение равно 0.
Хранение истории [Планировщика](../../scheduler/scheduler.md) (дней) | Без ограничений | Время хранения логов Журнала сессий для Планировщика задач. При перезапуске Loginom Server выполняется очистка лога. Данный лимит является приблизительным и в некоторых случаях может быть превышен. Минимальное значение равно 1.
Деактивация групп узлов по завершению | False | Автоматическая цепная деактивация групп узлов после их полного выполнения для освобождения используемой сценарием памяти. Применяется при [пакетном выполнении сценария](../../scheduler/batchlauncher.md). Параметр может принимать одно из двух значений: True — активирует механизм автоматической цепной деактивации узлов для всех пакетов на сервере. False — значение по умолчанию, отключает механизм автоматической деактивации для всех пакетов на сервере. Опцию «Деактивация групп узлов по завершению» также можно задать для [пакета](../../interface/packages.md), в Планировщике и в строке запуска утилиты BatchLauncher.
Локаль | Не задана(...)^1 | Задаёт локаль сервера/приложения Loginom. Локаль применяется только после перезагрузки сервера/приложения Loginom. **После смены локали некоторые узлы, например, [Сортировка](../../processors/transformation/sorting.md), [Экспорт в текстовый файл](../../integration/export/txt-csv.md) и др. могут работать по-другому.**

^1 В серверных редакциях локаль задаётся в процессе установки, в настольных — определяется при первом запуске в соответствии с региональными настройками текущего пользователя.

^2 Ограничение на используемую память процесса вносится с помощью soft limit RLIMIT_DATA.

> **Примечание:** при вычислении размера ограничения памяти учитываются ограничения cgroups (версии 1 и 2) на память.
>
> **Важно:** Минимальное значение ограничения памяти - 300 Мб. При поднятии лимита использования памяти новое значение применяется сразу, но при уменьшении лимита, требуется перезапуск приложения.
