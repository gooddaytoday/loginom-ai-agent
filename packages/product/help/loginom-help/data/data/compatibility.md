# Совместимость типов данных

Допустимо сопоставление полей (переменных) следующих типов данных:

Поле (переменная) входного набора порта | Поле (переменная) выходного набора порта
Логический | Логический, Переменный
Дата/время | Дата/время, Переменный
Вещественный | Вещественный, Переменный
Целый | Целый, Вещественный, Переменный
Строковый | Строковый, Переменный
Переменный | Переменный
