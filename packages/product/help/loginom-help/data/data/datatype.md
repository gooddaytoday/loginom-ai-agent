# Типы данных

Знак | Тип | Описание
 | Логический | Данные могут принимать только два значения True или False
 | Дата/время | Данные, содержащие информацию о дате и времени. Минимальное значение даты - 30.12.1899 00:00:00, максимальное - 31.12.9999 23:59:59.999 (точность 1 мс).
 | Вещественный | Данные, представляющие собой числа с плавающей точкой, соответствующие стандарту IEEE 754-2008. Имеется возможность записи числа в компьютерном представлении экспоненциальной формы.
 | Целый | Данные представляют собой целые числа в диапазоне от -2^63 до 2^63-1
 | Строковый | Данные, являющиеся произвольной последовательностью символов (строка). Максимальная длина строки 2 147 483 647 символов.
 | Переменный | Данные, которые могут хранить все вышеперечисленные типы. Каждая ячейка хранит значение и тип данных.

> **Примечание**: в узлах [Калькулятор](../processors/transformation/calc/README.md), [Калькулятор (переменные)](../processors/variables/variables-calc.md), [JavaScript](../processors/programming/java-script/README.md) все числовые значения представляются в виде вещественного формата двойной точности, соответствующего стандарту IEEE 754-2008. При этом для целых чисел за пределами диапазона [-(2^53 - 1), 2^53 - 1] происходит потеря точности.
