# Запуск сценариев по расписанию

В серверных редакциях Loginom ([Team](../compare-editions.md), [Standard](../compare-editions.md) и [Enterprise](../compare-editions.md)) имеется возможность [пакетного выполнения сценариев](batchlauncher.md). Для запуска пакетного выполнения по расписанию можно использовать встроенный [планировщик задач](scheduler.md) или сторонний, например, планировщик заданий Windows.
