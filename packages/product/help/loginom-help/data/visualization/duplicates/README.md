# Дубликаты и противоречия

Предназначен для просмотра дублирующих, противоречивых записей исходного набора данных.

## Интерфейс

После добавления в узел визуализатора откроется главное окно (Рис. 1):

[Рисунок: Рисунок 1. Главное окно визуализатора "Дубликаты и противоречия".]

Главное окно условно можно разделить на 2 области (см. рисунок 1):

1. **Панель инструментов** — содержит следующие управляющие элементы:
  - **Номер строки** — показать/скрыть сквозной номер строки;
  - **Номер записи** — показать/скрыть номер записи;
  - **Типы данных** — показать/скрыть типы данных;
  - **Показать значения null** — показать/скрыть null-значения;
  - **Формат** — открыть [окно настройки формата](format.md) отображения данных;
  - **Сортировка** — открыть [окно настройки сортировки](sorting.md) данных по столбцам;
  - **Фильтр** — открыть [окно настройки фильтрации](filter.md);
  - **Поиск** — найти значение; открыть [окно настройки поиска](search.md);
  - **Экспорт** — экспортировать таблицу в файл выбранного формата (XLS или HTML);
  - **Детализация** — показать/скрыть детализацию по строке таблицы;
  - **Перейти к строке** — перейти к строке с заданным номером (доступно в контекстном меню).
2. **[Основная таблица](main-table.md)** — содержит информацию о дубликатах и противоречиях в исходном наборе данных.
