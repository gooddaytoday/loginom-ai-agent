# Фильтр

Позволяет выделить записи, которые удовлетворяют одному или нескольким условиям. Несколько условий объединяются в сложное условие с помощью логических операторов И/ИЛИ.

## Окно настройки

В окне располагается область настройки условий фильтрации в виде таблицы. Каждая строка таблицы представляет собой [условие](../../processors/transformation/row-filter/filtering-criteria.md) фильтрации либо служебную строку с оператором ИЛИ. Если между условиями нет строки ИЛИ, то считается, что они объединены через логическое И.

Новое условие добавляется нажатием на кнопку Добавить условие.

На панели инструментов и в контекстном меню доступны следующие команды:

- **Добавить условие (Alt+N)** — добавляет новую строку условия.
- **Добавить оператор ИЛИ (Alt+O)** — добавляет логический оператор ИЛИ в конец таблицы с условиями.
- **Добавить оператор ИЛИ выше/ниже** — добавляет логический оператор ИЛИ на одну позицию выше или ниже выделенной строки.
- **Клонировать (Ctrl+D)** — добавляет новое условие с параметрами, как у выбранного условия, клон добавляется в конец таблицы.
- **Переместить вверх (Ctrl+Up)** — поднять условие или логический оператор ИЛИ на одну позицию вверх по списку.
- **Переместить вниз (Ctrl+Down)** — опустить условие или логический оператор ИЛИ на одну позицию вниз по списку.

> **Примечание**: Также поля и операторы можно перемещать перетягиванием выше или ниже.

- **Переносить текст** — активирует перенос слов или блоков текста в колонке Значение на следующую строку (но не больше чем на 3 строки), если текст выходит за пределы текущей строки. Более длинные значения можно просматривать с помощью всплывающей подсказки, которая появляется при наведении курсора на поле Значение.
- **Включить фильтр** — если убрать галочку, то будут отключены корректно настроенные условия и можно посмотреть данные без фильтра. Настроенные фильтры сохраняются в окне настройки.
- **Удалить все... (Shift+Delete)** — удаляет все имеющиеся условия.
- **Удалить выражение (Delete)** — удаляет выбранное условие.

В зависимости от условия, [вида](../../data/datakind.md) и [типа](../../data/datatype.md) данных поля, значение можно задать с помощью переключателя или выбрать из предлагаемого списка. Также можно ввести данные с клавиатуры.

Для условий `<`,`<=`,`>`,`>=`,`=`,`<>` значения задаются из выпадающего списка или вручную. Значения добавляются по клавише Enter, удаляются — по клавишам Backspace или Delete.

Для условий пустой, не пустой значение не задается.

Для условий в интервале, вне интервала значения границ интервала задаются в появляющемся окне. Добавить значение можно вручную либо из выпадающего списка.

Для условий содержит, не содержит, начинается с, не начинается с, заканчивается на, не заканчивается на добавить значение можно вручную либо из выпадающего списка.

Для условий в списке, вне списка значения выбираются в окне Список значений.

В окне Список значений на панели инструментов доступны следующие команды:

- **Получить список** — выводит список всех уникальных значений поля. Максимальное количество уникальных значений в списке: 10000.
- **Выбрать все** — выбирает все значения из списка.
- **Инвертировать выбор** — деактивирует/активирует выбранное значение активируя/деактивируя все остальные значения. Если не одно значение в списке не выбрано, то при инвертировании выбора, все значения будут активированы и наоборот.
- **Отменить выбор всех** - отменяет все выбранные значения из списка.
- **Добавить...** — добавляет новое значение в список.
- **Редактировать... (F2)** — редактирует добавленное значение.
- **Копировать (Ctrl+C)** — копирует выбранное значение из списка.
- **Вставить (Ctrl+V)** — вставляет скопированное значение в список.
- **Фильтрация** — позволяет найти поле по имени или его части.

При ручном вводе значения доступна вставка из буфера обмена.

После установки настроек фильтрации нужно нажать кнопку **Фильтровать**.
