# Настройка аутентификации

Модальное окно, которое используется при настройке аутентификации в узлах [REST-сервис](rest-service.md) и [SOAP-сервис](soap-service.md).

- **Тип аутентификации** — поле задает тип аутентификации необходимый для подключения к сервису. Значение поля выбирается из выпадающего списка:
  - **Не требуется** — при выборе этого пункта Loginom не проводит аутентификацию при подключении к сервису.
  - **Имя пользователя и пароль** — выбирается, если требуется аутентификация по имени/паролю. Поддерживаются следующие типы аутентификации по имени пользователя и паролю: Negotiate, NTLM, Basic, Digest. Если выбран данный тип аутентификации, то в окне появляются дополнительные поля:
    - **Имя пользователя** — имя пользователя, заданное при его регистрации в системе веб-сервиса.
    - **Пароль** — пароль этого пользователя.
  - **Basic** — выбирается при подключении к REST-сервису посредством Basic-аутентификации. При выборе этого типа в дополнительных полях нужно указать имя пользователя и пароль.
  - **Токен OAuth** — выбирается при подключении к веб-сервису посредством протокола OAuth версии 2.0. Если выбран данный тип аутентификации, то в окне появляется дополнительное поле:
    - **Токен OAuth** — поле для введения строки токена.
  - **Клиентский сертификат из хранилища** — выбирается для аутентификации по SSL посредством сертификата. Данный тип аутентификации используется для операционной системы Windows. Если выбран данный тип аутентификации, то в окне появляется дополнительное поле:
    - **Хранилище сертификатов** — выпадающий список. Из списка выбирается одно из хранилищ сертификатов, имеющихся в системе. Затем в таблице под списком выбирается используемый для аутентификации сертификат.
  - **Файлы сертификата клиента** — выбирается, если требуется аутентификация по сертификату клиента. При этом типе аутентификации требуется указать расположение нужного сертификата и приватного ключа, а также ввести пароль приватного ключа. Если выбран данный тип аутентификации, то в окне появляются дополнительные поля:
    - **Сертификат пользователя** — в поле указывается расположение сертификата, используемого для подключения к REST-сервису или SOAP-сервису.
    - **Приватный ключ** — в поле указывается расположение приватного ключа, используемого для подключения к REST-сервису или SOAP-сервису.
    - **Пароль приватного ключа** — пароль, позволяющий расшифровать ключ.
  Чтобы сохранить изменённые параметры аутентификации на сервере необходимо нажать кнопку OK. Если изменения настроек сохранять не требуется, то — Отмена, в этом случае при последующем открытии окна останутся прежние настройки.
