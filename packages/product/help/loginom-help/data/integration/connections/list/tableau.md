# Подключение к серверу Tableau

Используется для подключения к серверу Tableau.

## Параметры подключения

При настройке подключения задаются следующие параметры:

- **Автоматическая метка** — переключатель режима формирования метки узла. Если выбран режим Автоматическая метка, то она формируется по правилу: `Адрес сервера Tableau`. Если выбран режим Пользовательская метка — метка задается пользователем.
- **Адрес сервера** — содержит URI сервера Tableau.
- **Тестировать** — тест подключения к серверу.
- **Сайт** — название страницы сайта, через которую происходит работа с сервером Tableau.
- **Имя пользователя** — имя пользователя на сервере.
- **Пароль** — пароль пользователя.
- **Не проверять сертификат сервера** — если данный флаг установлен, то ошибки при проверке сертификата сервера, к которому производится подключение, игнорируются.

> **Важно**: функционал доступен только при работе под ОС Windows. Перед настройкой подключения необходимо расположить динамические библиотеки Tableau SDK (папки TableauExtractAPI_64 и TableauSDK_64) в ту же папку, где лежит исполняемый файл Loginom.exe, сохраняя внутреннюю структуру папок. Например, для редакции Server папка по умолчанию - C:\Program Files\Loginom\Server, а для Community - C:\Program Files\Loginom\Community.
