# Подключение к 1C:Предприятие 8.x

Используется для подключения к базам данных платформы 1С:Предприятие версий 8.x.

> **Примечания:**
>
> - Для подключения ​к базе данных необходима установка толстого клиента 1С той же разрядности, что и разрядность приложения/сервера Loginom.
> - Компонент доступен только для ОС Windows, так как подключение реализовано через COM-соединение, которое в ОС Linux отсутствует. Для версий Loginom под Linux можно использовать альтернативные механизмы интеграции, такие как OData, протокол HTTP.

## Параметры подключения

При настройке подключения задаются следующие параметры:

- **Автоматическая метка** — переключатель режима формирования метки узла. Если выбран режим Автоматическая метка, то она формируется по правилу: `Строка подключения к серверу 1С`. Если выбран режим Пользовательская метка — метка задается пользователем.
- **Версия платформы** — версия платформы 1С:Предприятие, к которой настраивается подключение.
- **Строка подключения** — содержит параметры подключения к базе данных. Параметры можно ввести вручную или нажатием кнопки вызвать окно Выбор информационной базы, предоставляющее следующие варианты подключения:
  - **Настроенная информационная база** — выбор из списка базы данных, подключение к которой уже было настроено через клиент 1С, установленный на той же машине, что и Loginom (в этом случае Loginom обращается к файлу ibases.v8i со списком баз данных, который формируется клиентом 1С). По умолчанию список баз данных 1С содержится в файле `"C:\Users\%username%\AppData\Roaming\1C\1CEStart\ibases.v8i"`, где `%username%` — имя пользователя, из-под которого запускается клиент 1С. Loginom ожидает этот файл по тому же пути, поэтому для получения базы данных из списка необходимо, чтобы `%username%` совпадало с именем пользователя, из под которого запущен Loginom Server. При необходимости этот файл можно скопировать в расположение пользователя Loginom Server:
    - **Наименование** — отображает список выбора.
  - **В файловом хранилище или локальной сети** — подключение к файловому варианту базы данных через указание пути к каталогу информационной базы:
    - **Каталог базы данных** — путь к каталогу информационной базы 1С:Предприятие. В серверной редакции Loginom каталог ИБ должен располагаться в пределах [UserStorage](../../../admin/parameters/folders.md).
  - **На сервере 1С:Предприятия** — подключение через указание имени кластера и названия базы:
    - **Кластер серверов** — доменное имя кластера или его IP-адрес.
    - **Имя базы** — системное наименование базы данных, может состоять только из символов английской раскладки клавиатуры.
- **Тестировать** — тест указанных настроек подключения.
- **Имя пользователя** — имя пользователя БД.
- **Пароль** — пароль пользователя БД.
- **Параметры пула:**
  - **Размер** — максимальное число соединений в пуле (значение по умолчанию — 10). Чтобы отключить пул подключений, нужно указать 0.
  - **Тайм-аут (с)** — время жизни неиспользуемого соединения (значение по умолчанию — 60).
> **Важно:** если пул подключений включен (значение параметра Размер > 0), то при завершении работы всех узлов 1С Запрос, одно подключение гарантированно не будет завершено, вне зависимости от значения параметра Тайм-аут. Последнее подключение будет завершено только при деактивации самого узла Подключение к 1С.
- **Комментарий** — в этой форме можно оставить любую справочную информацию о подключении.
