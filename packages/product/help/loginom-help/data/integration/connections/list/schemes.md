# Подключение набора XSD-схем

Используется для подключения к файлам XSD-схем. Содержит параметры подключения к списку (набору) файлов.

## Настройка набора XSD-схем

При настройке подключения задаются следующие параметры:

- **Автоматическая метка** — переключатель режима формирования метки узла. Если выбран режим Автоматическая метка, то она формируется по правилу: `Перечисление используемых XSD-файлов`. Если выбран режим Пользовательская метка — метка задается пользователем.
- **Имя файла** — список путей к файлам XSD-схем.
- **Комментарий** — в этой форме можно оставить любую справочную информацию о подключении.

Панель инструментов диалога настройки содержит следующие команды:

- **Добавить** — добавляет в список новый файл XSD-схемы, выбранный пользователем в диалоге выбора файла.
- **Переместить вверх/вниз** — изменяет позицию выделенного элемента списка.
- **Изменить** — открывает диалог выбора файла для редактирования пути к файлу XSD-схемы.

Команды списка:

- **Удалить все...** — удаляет все позиции списка.
- **Удалить** — удаляет выделенную позицию в списке.
