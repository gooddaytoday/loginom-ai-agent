Импортируйте variant.csv с разделителем «;», десятичной точкой и маркером
пустого значения \N. В Value встречаются целое число, текст, дробное число
и пустое значение: сохраните их собственные типы в одном переменном поле.
Покажите результат и выгрузите все строки в `variant-on.csv`. Затем в этом же узле отключите
распознавание переменного типа и заново определите типы: Value должен стать
строковым, пустое значение должно остаться пустым. Снова покажите и выгрузите
данные в `variant-off.csv`. Сохраните пакет в {{PACKAGE_PATH}}.
