# Задание агенту: синонимы для поиска по справке Loginom

Входные данные: строки JSON из `python3 -I scripts/loginom-help/aliases.py missing`.

1. Для строки с `fn` (функция Калькулятора) напиши алиасы: имена этой функции
   в других системах, где у неё есть настоящий аналог (Delphi/Pascal, Excel,
   SQL, Python/pandas, JavaScript, 1С), и 2–4 короткие фразы на русском и
   английском о её назначении — так, как пользователь или ИИ-агент описал бы,
   что он ищет. Пиши только об этой функции, по её тексту в `text`.
2. Для строки без `fn` (страница) напиши 4–6 поисковых формулировок: как
   спросили бы, чтобы попасть на эту страницу, на русском и английском. Добавляй
   общеупотребимые термины (pivot, left join, k-means, CSV), только если они
   действительно соответствуют странице. Заголовок страницы не повторяй.
3. Результат — строки JSON, по одной на вход: для функции
   `{"path": "…", "fn": "…", "aliases": ["…"]}`, для страницы
   `{"path": "…", "aliases": ["…"]}`. Допиши их в
   `packages/product/help/aliases.jsonl`, затем выполни
   `python3 -I scripts/loginom-help/aliases.py check` — код выхода 0.
