# Исправление подтверждённых замечаний PR №712

Цель — корректный отчёт `package-linter` для проверенных форматов Loginom и проходящий тест дедупликации навыков. Основание — подтверждённые замечания к PR и уточнения по идентичности и порядку модулей. План выполняется по частям с независимой проверкой.

1. Красный сквозной результат — `inspect` считает связь с отсутствующим портом подтверждённой и пропускает визуализаторы `GolfViews.lgp`. Проверить копию штатного пакета по XSD и валидатором ссылок, исходные пакеты оставить неизменными.
2. Исправить извлечение XML. Проверять порты по направлениям с учётом служебных и существующего чтения сокетов. Только разрешённые связи образуют группы и счётчики, возможные роли при неполных данных остаются неизвестными. Для целей рекомендаций учитывать уже вычисленный признак наследования сценария. Показывать `ModelViews` отдельно от узлов сценария и восстанавливать имена уникальных собственных типов по существующим правилам разрешения. В ссылках использовать идентификатор целевого пакета из `Item/Name`. Проверить исходные пакеты из ревью и неоднозначность.
3. Сохранить порядок индекса, использовать точный путь ZIP-записи при сопоставлении принадлежности. Ограничить оба чтения файла. Публиковать отчёт целиком с сохранением эксклюзивного создания, использовать обычный абзац для заключения. Сравнивать метки без повторного поиска и распознавать кириллические буквы по Unicode. Проверить `report` при сбое записи, занятый путь и корректный Markdown.
4. Исправить ожидание числа каталогов в Bun-тесте. Обновить хеши изменённых файлов в манифесте поставки, сохранив происхождение исходного экспорта. Выполнить целевые регрессии и независимое ревью diff.

Изменения — два скрипта Python, манифест поставки, Bun-тест, план и один небольшой набор регрессий, ориентир 6 файлов и 250 строк. Дополнительные данные нужны только для отличия неразрешённых связей и проверки наследования. Временный файл нужен для публикации после успешного закрытия с сохранением запрета перезаписи. Новые зависимости, поддержка нестандартных XML/ZIP, запуск сценариев, редактирование обсуждений и слияние вне задачи.
