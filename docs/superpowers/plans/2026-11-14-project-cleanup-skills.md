# Проектные навыки очистки

С 16 ноября 2026 навыки перенесены во внутренний комплект
[Branch Cleaner](../../branch-cleaner.md). Ниже сохранён результат первоначальной
установки; актуальные команды и размещение описаны в новом руководстве.

Цель: установить `design-cleanup` и `harmonize-docs` для Claude Code, Codex и Cursor.
Критерий готовности: оба `SKILL.md` доступны из проектных каталогов всех трёх агентов; ссылки относительные и разрешаются внутри проекта.

Источники: [design-cleanup](https://github.com/gjkim42/kanon-repo/tree/main/skills/design-cleanup), [harmonize-docs](https://github.com/sjunepark/agent-scripts/tree/main/skills/harmonize-docs).
Хранение: `.agents/skills/<name>/`; Claude Code и Cursor используют ссылки из `.claude/skills/` и `.cursor/skills/`.
Одна копия исключает расхождение инструкций; установщик `skill-installer` поддерживает проектный каталог через `--dest`.
Оценка: 7 файлов, около 250 добавленных строк, включая этот план и четыре ссылки; без зависимостей приложения.

- [x] Независимо проверить план: достаточность каталогов, переносимость ссылок, сохранность чужих изменений. Обязательных замечаний нет.
- [x] Установить оба каталога из источников и создать ссылки; первый проверяемый результат — чтение обоих навыков через все три пути.
- [x] Проверить метаданные, доступность дополнительных файлов, обнаружение через Skills CLI и состав изменений Git.

Риски: навыки применяют изменения по умолчанию; для отчёта указывать «только аудит». Для `design-cleanup` явно задавать базу `origin/dev` или `dev`; сохранять исторические записи согласно `AGENTS.md`.
За рамками: запуск очистки, изменение upstream-инструкций, глобальная установка, коммит и изменения приложения.
Проверки: `quick_validate.py` для обоих навыков; `npx skills list --agent claude-code codex cursor --json`; чтение всех путей и локальных ссылок. Фактический вызов в приложениях не проверялся.
