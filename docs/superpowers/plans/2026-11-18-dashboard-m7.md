# Dashboard M7 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Пользователь может опубликовать dashboard по инструкции, проверить цифру в доверенной таблице и понять, когда данных недостаточно для вывода.

**Architecture:** Шапка Studio использует результат существующего чтения узла и сведения о готовой публикации из `lookup`. Приложения отвечают за свои формулы, нужные колонки и подписи. Административное руководство входит в существующий архив.

**Tech Stack:** TypeScript, DOM Studio, SDK v1, React/Recharts в примерах, Bun 1.3.14, Node и Chromium из пинов продукта, node:test и Playwright.

**Spec:** [Согласованный состав M7 и бэклог](../specs/2026-11-18-dashboard-m7-design.md). План подготовлен 18 ноября 2026 года.

## Global Constraints

- База продукта — принятая M6 `2b0dc121c948b1550e188297c4b714ef6badd197`. Перед работой прочитать [правила платформы](../../../packages/dashboard/AGENTS.md), [инструкцию приложений](../../../dashboard/AGENTS.md) и [checkpoint M6](../../testing/loginom-ai-agent/dashboard-m6-checkpoint.md).
