# Закрытие пульта клавишей Esc

Результат — Esc закрывает dashboard, когда фокус находится в его шапке или внутри приложения iframe. При фокусе за пределами пульта Esc его не закрывает.

Обработчик keydown принадлежит контейнеру пульта и документу его same-origin iframe после загрузки. Используется существующий close. Обработчики уходят вместе с DOM пульта, глобальные слушатели не нужны. Приложения и Desktop не меняются. Ожидаемый diff — bootstrap и этот план, 2 файла / 25–45 строк.
