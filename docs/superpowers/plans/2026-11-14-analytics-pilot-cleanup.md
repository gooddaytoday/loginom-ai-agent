# Уборка аналитического пилота

## Результат и границы

Убрать черновые подписи и неиспользуемые `io`/`here` из десяти oracle пяти пар,
обновить только соответствующие `sources["oracle.py"]` в калибровочных manifests.
В действующей инструкции защиты Git описать уже установленную защиту после PR #185.
Вычисления, постановки, входы, reference, CSV, рубрики и исторические результаты сохраняются.
Замечание о выборе базы навыка и прочие улучшения не входят в эту задачу.

## Исполнение и проверяемые результаты

1. Проверить чистоту worktree, hooks, Gitleaks и актуальные tips `origin/loginom`
   и `origin/analytics-pilot`; сохранить локальную резервную ссылку исходного HEAD.
   Результат: известны безопасная база и точный remote SHA для lease.
2. После независимого ревью плана исправить oracle, source pins и текущий статус
   защиты. Первый сквозной результат: штатный offline пересчёт обеих форм проходит,
   все результаты CSV и AST вычислительных функций совпадают с исходными.
3. Встроить изменения каждой пары в её исходный feature-коммит через fixup/autosquash,
   документацию — в завершающий docs-коммит. Сохранить остальные коммиты ветки.
   Результат: range-diff содержит только согласованную уборку; в добавлениях истории
   новых oracle отсутствуют черновые подписи и неиспользуемые строки.
4. Проверить обе коллекции, десять self-check, 38 near-miss, package-local typecheck,
   ссылки и diff; перед каждым коммитом проверить только собственный staged index.
   Результат: проверки проходят, входные и эталонные артефакты неизменны.
5. Отправить ветку с точным `--force-with-lease`, подтвердить remote HEAD и PR.
   Дождаться всех применимых тестов и candidate-сборок для нового SHA; разбирать
   реальные падения по логам. Результат: зелёные проверки и сборки точного HEAD PR.

Оценка: 22 файла, около 60 добавленных и 40 удалённых строк с этим планом.
Новых механизмов и зависимостей нет. Fixup сохраняет смысл существующих коммитов;
точный lease защищает параллельные remote-изменения. Риски: конфликты при rebase,
устаревшие source pins и внешние отказы CI. Обход hooks и ослабление проверок запрещены.
Слияние PR, выпуск, публикация релиза и новые живые измерения не входят в задачу.
