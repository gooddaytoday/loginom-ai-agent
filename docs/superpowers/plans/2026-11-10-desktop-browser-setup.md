Первый проверяемый путь — поднять только существующие контейнеры dashboard-master-20261109, открыть dashboard и перейти в Desktop по системной ссылке. Ожидаемые изменения Git — этот план и короткая актуализация инструкции, 2 файла / 20–40 строк. Продуктовый код, зависимости и другие стенды за границами.

## Результат

- Поднят текущий стенд и сервис снимков. В открытом dashboard пять каналов и 500 кампаний из Loginom.
- Пользовательский обработчик системных ссылок установлен. Готовая сборка с предоставленным владельцем действующим ключом находится в каталоге передачи, в подкаталоге ready. Штатный verifier проверил 4828 ресурсов. Ключ включён только в локальный ресурс, в Git его нет.
- В обычном профиле Desktop сохранён адрес http://127.0.0.1:32768/app/, состояние ready и проверенный вход пользователя user. Модель OpenAI GPT-6.1 Sol ответила на проверочный запрос. Авторизация взята из текущего входа Codex, без изменения исходных токенов; при её истечении потребуется новый вход.
- Системный переход доставил цель dashboard в пользовательский черновик. Desktop оставлен открытым в обычном режиме. Резервная копия исходного профиля сохранена приватно рядом с каталогом передачи.
