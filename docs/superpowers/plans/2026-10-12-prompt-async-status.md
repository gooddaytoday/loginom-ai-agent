# Prompt async status recovery

**Goal:** Исправить гонку PR #59: ошибка подготовки второго `prompt_async` не должна переводить активную сессию в `idle`.

**Architecture:** Проверять занятость через существующий `SessionRunState.assertNotBusy`, который наблюдает runner, а не оптимистичный статус клиента. При `SessionBusyError` сохранять статус; при отсутствии активного выполнения публиковать `idle`, как в исходном исправлении PR.

**Tech Stack:** TypeScript, Effect, Bun 1.3.14; реальные HTTP-запросы SDK и тестовый поток модели.

## Constraints

- Не менять публичный HttpApi, SDK, оркестрацию runner и CI workflows.
- Не отменять выполняющийся запрос из-за ошибки другого prompt.
- Сохранить сообщение `session.error` и восстановление статуса свободной сессии.
- Проверки запускать из `packages/agent`.
