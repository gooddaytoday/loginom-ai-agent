# Пульт Loginom в чате Desktop — план реализации

> Исполнитель ведёт разработку, сборку и приёмку в этом чате по шагам. Стенд и Desktop можно готовить параллельно после независимого ревью.

**Цель** — создать и изменить приложение по обычной просьбе в Loginom AI Agent Desktop. Проверить заказанную правку живого пульта через браузер и сохранение адресата при переключении на другой узел. [Утверждённый дизайн](../specs/2026-11-10-dashboard-desktop-design.md)

**Устройство** — bootstrap локального стенда выдаёт системную ссылку `loginom-ai-agent://dashboard?id=<uuid>&action=create|edit`. Electron доставляет её один раз нужному окну. Desktop читает снимок по ID с фиксированного loopback-адреса и прикладывает цель к одной отправке. Используются существующие Electron, Solid, API сообщений и публикация Node.js.

**Границы** — брендированный Linux Desktop 0.3.9 из ветки `loginom` в отдельном рабочем каталоге, стенд в `dashboard-app`. Один пользователь. Собственные пакеты и профиль для проверки. Оценка двух diff вместе с тестами и документами — 14–22 файла, примерно 330–580 изменённых строк. Публичный релиз, изменения API платформы, удалённые стенды и новые зависимости в этап не входят.

**Особые случаи при ревью** — холодный запуск с URI, быстрое переключение A/B, медленный ответ после смены черновика, истёкший ID, ошибка отправки или постановка сообщения в очередь. Проверить, что запрос не может задавать адрес сервиса или исполняемую команду и что уже набранный текст и файлы сохраняются.

## Как открыть со своего Desktop

Настройка для владельца уже выполнена. Браузер использует новую локальную AppImage из подкаталога ready каталога передачи, Desktop подключён к стенду и оставлен открытым. [Результат настройки](2026-11-10-desktop-browser-setup.md)

Описанные ниже команды нужны при повторной настройке или переносе.

Сборка находится в [каталоге передачи]($HOME/Documents/Codex/2026-11-10/dashboard-desktop). Полностью закройте ранее запущенный Loginom AI Agent Desktop. Для подключения проверенной AppImage к браузеру этого пользователя один раз выполните команды в терминале:

```sh
desktop-file-install --dir="$HOME/.local/share/applications" "$HOME/Documents/Codex/2026-11-10/dashboard-desktop/com.loginom.aiagent.desktop"
xdg-mime default com.loginom.aiagent.desktop x-scheme-handler/loginom-ai-agent
```

Теперь «Изменить в чате» откроет эту сборку. Если браузер запросит подтверждение, выберите открытие Loginom AI Agent. Для возврата к установленному Desktop закройте AppImage и удалите добавленный файл `~/.local/share/applications/com.loginom.aiagent.desktop`. Системная запись с тем же именем указывает на установленный пакет.

## Точка продолжения

- Финальная AppImage собрана из продуктовой ветки `dashboard-desktop`. Обе версии bootstrap на стенде совпадают с веткой `dashboard-app`. Штатный verifier проверил содержимое AppImage и 4827 ресурсов.
- В финальной сборке один клик из A сохранил текущий чат и введённый текст. ID в принятой просьбе совпал с ID снимка A. Исполнитель открыл B до окончания запроса; в пульте A появилась заказанная надпись «Отчёт проверен», в B сохранился прежний график. Оба показали 500 кампаний.
- «Создать dashboard» с главного экрана и при закрытом Desktop открыл два разных черновика нужного проекта с русской меткой. В обоих случаях курсор оказался в поле ввода. Проверены исчезновение снимка, повторный Enter, очередь и восстановление черновика. Обязательные замечания независимого ревью закрыты.
- После холодного старта штатный агент создал и опубликовал «Сводку по каналам». В обычном клиенте без тестовых флагов пять строк таблицы и итог 500 совпали с живым выходом. [Открыть проверенный пример](http://127.0.0.1:32768/app/#packages/user/dashboard-desktop-20261110-d/campaign.lgp/Unit1/workflow) — выбрать «По убыванию ROI» и нажать Dashboard.
- Файл подключения из каталога передачи прошёл проверку настоящим кликом через Linux. На машине остаётся системный Desktop 0.3.2. При первоначальной отладке браузер один раз открыл его; дальнейшие проверки шли в изолированном профиле. Все тестовые пакеты закрыты, подготовительные копии A–C и временная авторизация удалены. Исходники демонстрационного D оставлены в локальном каталоге пультов и в архиве рядом со сборкой.
- [Сообщение и переключение A/B]($HOME/Documents/Codex/2026-11-10/dashboard-desktop/final-a.json), [сообщение создания]($HOME/Documents/Codex/2026-11-10/dashboard-desktop/final-d.json), [сверка экрана с портом]($HOME/Documents/Codex/2026-11-10/dashboard-desktop/live-creation.json). Независимая проверка доказательств завершена. Область приёмки — Linux, нынешний стенд и штатный сервер Desktop V1. Экспериментальный сервер V2 для slash-команд теряет привязку.
- Объём превысил оценку из-за двух редакторов и регрессий отправки. Проверка обоих экземпляров редактора позволила объединить защиту от повторной отправки в одном месте при переходе из черновика в чат. Новых служб и зависимостей не потребовалось.
