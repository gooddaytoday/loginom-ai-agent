# Подписи ROI и сортировка каналов

1. Добавить постоянно видимую подпись ROI для каждого канала через Recharts, используя существующее форматирование. Оставить место для подписи, проверить обычные проценты, отрицательные, ноль и неопределённое значение в изолированном iframe.
2. В заголовках пяти столбцов сделать кнопки с направлением сортировки. До первого нажатия сохранить порядок узла. Сортировать строки по исходным числам или названию канала, оставлять пропуски в конце, повторным нажатием менять направление. Проверить оба направления, неизменность графика, отсутствие вызовов Loginom при кликах и сохранение сортировки при смене порога.
3. Выполнить проверку типов, сборку и публикацию dashboard командами снимка. Сверить опубликованные файлы и привязку по HTTP.

Изменения ограничены двумя исходными файлами dashboard и этим планом, оценка 45–80 строк. Изменения сценария, адаптера и живой сеанс Loginom исключены.
