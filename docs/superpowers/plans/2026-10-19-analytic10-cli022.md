## Техническая приёмка

- Ровно десять итоговых попыток выбранных задач, без пропусков/дублей/подмены.
- Обе launcher-цепочки реально перекрываются; максимум одновременно две.
  Источник: `process-cleanup.json`/`run.json`, `lifetime.owner/started_at/finished_at`.
- Слоты повторно используются после завершения собственной цепочки, судьи и
  cleanup. Для порядка использовать также текущий filesystem mtime `cleanup.json`;
  сам JSON не содержит времени финализации. Переход между раундами при repeat=1
  не проверяется live, он покрыт существующим scheduler test.
- Попытки, архивы, profiles, inputs и artifacts связаны правильным slot_id;
  прежняя история не остаётся доступной следующей попытке.
- Каждый полученный артефакт имеет verdict/oracle либо явную ошибку.
  Завершение вызванных systemd units проверяет harness; home judge освобождён.
  Live serialization по времени подтверждать системным journal при доступности;
  иначе явно оставить источник unit/gate code, а не выдумывать JSON receipt.
  При no_artifact судья может не вызываться; отсутствие покрытия не равно PASS.
- Десять cleanup confirmed, slots closed, reservations released, собственные
  sessions/work leftovers отсутствуют. Затем verify двух слотов проходит.
- Полные измерения и утверждённые bounds PASS; без OOM/ENOSPC/license/rate/quota.

Низкая оценка, неверный CSV и no_artifact могут быть ошибками качества.
Harness/infra errors, карантин, unknown cleanup и неполная очередь исключают
успешную техническую приёмку. Дефекты harness исправляются по TDD отдельными
коммитами; после исправления — новая полная серия той же десятки, без склеивания.
CLI версии и задания ради прохождения не меняются.

## Ограничения и checkpoint

Обычный рабочий путь и reuse проверяются live; аварии/SIGINT — отдельными тестами.
Shared OAuth refresh этим CLI не покрывается. Новая калибровка судьи не выполнена.
Повтор неизменённых unit suites не нужен без конкретного нового риска.

1. План принят; исполнение начато, модельных попыток ещё нет.
2. Независимое ревью: учтены границы timing evidence, judge journal и repeat=1.
