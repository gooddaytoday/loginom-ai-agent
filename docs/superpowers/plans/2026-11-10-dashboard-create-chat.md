# Отдельный чат для нового dashboard

**Цель:** `action=create` всегда открывает отдельный черновик, включая переход из занятого чата другого dashboard. `action=edit` сохраняет прежний выбор адресата.

**Решение:** использовать существующую ветку создания черновика в `packages/app/src/pages/layout/dashboard-links.ts`; исключить `create` из повторного использования текущего маршрута. Не добавлять проверки занятости, новый протокол или автоматическую отправку сообщения. Снимок и локальный проект определяются прежним проверенным способом.

**Ограничения:** не перезапускать пользовательский Desktop/backend, не менять его черновики, сохранить чужие изменения; временные файлы только в `/home/kiselev/storage/tmp/`.

## Результат

Ревью: разделить наличие текущего чата (`current`) и его повторное использование (`existing`), чтобы выбор сервера и проверка localOnly сохранились. Production baseline: первый видимый контент/вкладка225,9мс, стабильный258мс; один существующий сценарий `opens a home session and paints its titlebar tab`, production bundle и Chromium1246. Raw evidence: `/home/kiselev/storage/tmp/dashboard-create-chat-20261110/`.

RED: настоящая ссылка `create` через second-instance прикладывает новую метку в прежний чат; новых вкладок0 вместо1. GREEN: отдельная вкладка создана, прежние текст/метка и busy state сохранены. Busy и HTTP-ответы заданы fixture, модель не запускалась. Snapshot service и `loginom-read` заменены IPC fixture в отдельном профиле. App56/56, Desktop4/4, оба typecheck PASS. После изменения benchmark:222,7/243,5мс; по одному измерению нельзя делать вывод об ускорении.

Критерий завершения — проверенное разделение нового dashboard и прежнего чата, с явным указанием, применяется ли исправление к уже запущенной сборке.

Завершено: отдельная копия Desktop и готовая AppImage прошли полную GUI-регрессию без подмены renderer.5976 остальных файлов ASAR совпали побайтно. Launcher переключён для следующего ручного запуска; пользовательское приложение/backend не перезапускались.
