# Подготовка analytics-expansion к PR в loginom

**Цель:** перенести ветку на актуальную origin/loginom, открыть PR и получить успешные применимые тесты и сборки.
**Границы:** сохранить очищенную историю,33пары/66evals, проверенные исправления скриптов и посторонние незавершённые файлы. Не выполнять merge, auto-merge, релиз или публикацию продукта.
**Подход:** адресно закоммитить уже проверенные исправления; сохранить закрытый Git bundle и fingerprints посторонних файлов; выполнить обычный rebase с отключённым updateRefs. При конфликтах сохранить действующие контракты обеих сторон и проверить изменения независимо.
**Оценка:** один новый документ; при конфликтах до20 существующих файлов/1000 строк. Изменения CI допустимы только при установленном дефекте, не ради обхода падающей проверки.

1. Независимо проверить план, выбрать существующие тестовые/build workflows и сохранить исходное состояние.
2. Закоммитить исправления двух служебных скриптов и rebase на закреплённый актуальный tip origin/loginom. Результат: база — предок HEAD; range-diff и сохранность eval-данных/посторонних файлов проверены.
3. Выполнить локальные проверки затронутых пакетов, контрольные суммы/secret scan и нужную подготовку зависимостей; открыть один PR в loginom и прикрепить к чату. Результат: опубликован только проверенный branch HEAD, PR имеет верную базу.
4. Дождаться всех применимых CI tests/builds, при необходимости запустить существующие безопасные candidate workflows без выпуска. Исправлять подтверждённые ошибки с адресной проверкой. Результат: свежий PR HEAD имеет успешные проверки, конфликты отсутствуют.

Риски: upstream мог изменить startup/close contracts; сохранять семантику, а не старые строки. Старые исходы evals не перезапускаются. Успех CI/offline smoke не означает новую установленную GUI/live-model приёмку. Закрытый backup не публикуется; секреты и локальные данные в новые коммиты не добавляются.

Локальная проверка завершена: независимый review rebase одобрен, eval-данные и посторонние файлы сохранены; адресные Runtime/Host/evals тесты, typecheck и secret scan успешны. Актуальный статус публикации и общих CI-проверок отслеживается в PR.
