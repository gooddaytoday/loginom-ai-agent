## Изменение skill

Только `packages/product/skills/loginom-automation/SKILL.md` и
`references/workflow.md`. Общее правило и explicit-JS исключение прежние.
Перед JS при функциональном пробеле агент отделяет недоступную операцию от
каждого поддержанного преобразования и проверяет фактический код перед apply.
Утверждение «JS только разворачивает строки» должно соответствовать всему коду,
включая вложенные циклы и условные операторы. Нормализация и отбрасывание значений
не считаются автоматической частью разворачивания, если они доступны стандартно.

В workflow нужен небольшой пример: JS выдаёт исходные части строки, включая
пробелы и пустые части; Calculator/Filter затем очищают значения, Group/Sort/Export
выполняют остальные операции. Для данного пробела `.trim()` и `continue` по
пустому значению в JS нарушают границу. Технические действия объявления схемы,
чтения и выдачи строк не дают разрешения добавлять аналитические преобразования.
Если стандартный следующий шаг отказал, исправить его либо сообщить блокер;
не переносить его обратно в JS. Полный текст кода в пользовательский ответ
не требуется, достаточно содержательного обоснования роли перед применением.

Не добавлять универсальные запреты при explicit request пользователя,
предписания новых узлов вне каталога, механические проверки фраз или новые
runtime/handler ограничения. Реальный tags/2 — отрицательный поведенческий
пример; положительное подтверждение будет новым live выполнением skill.
