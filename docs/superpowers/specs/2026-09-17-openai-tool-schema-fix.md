# Совместимость схем Dock с ChatGPT

17 сентября 2026 пользователь подтвердил успешное подключение подписки и сообщил отказ `Invalid schema for function loginom_dock_ui_action`. Исправление сохраняет существующие инструменты и их runtime-проверки.

## Причина

Исходный `action.expected_stage` допускает название этапа или `const: ["output_mapping", "done"]`. Это допустимый JSON Schema. Преобразователь OpenAI заменял const на enum и при отсутствии type назначал string, даже для массива. Кроме того, ChatGPT не принимает структурированные значения внутри enum: исправления одного type оказалось недостаточно.

Контрольные запросы к подключённому `gpt-5.6-sol` с `tool_choice: none`: старая схема — 400; исправление только типа — 400; замена oneOf на anyOf при сохранении array enum — 400; обычная схема массива без array enum — 200 и завершённый ответ. Таким образом oneOf не является причиной данного отказа.

## Исправление

OpenAI-преобразователь выводит тип из фактических const/enum-значений, включая number, boolean, null и array. Для массивов выводит items. Структурированные enum-значения переносит в описание допустимых вариантов; для массивов одинаковой длины сохраняет minItems/maxItems. Исходная схема и `validateUiAction` остаются неизменными: неправильные значения и обратный порядок этапов отвергаются при выполнении.

Изменение действует только на существующем пути нормализации OpenAI/Azure. Другие провайдеры и контракты Dock не меняются. Desktop patch-версия — 0.1.2.

## Проверка

Регрессия использует реальный экспорт `uiActionSchema`, проверяет неизменность оригинала и строгую проверку этапов настоящим `validateUiAction`. Дополнительно проверяются числовые/логические/null/смешанные enum и числовой array const. Полная suite преобразования: 568 PASS; agent typecheck PASS.

Реальный изолированный runtime выдал 34 инструмента. После текущего преобразования весь набор отправлен в ChatGPT с запретом tool calls: HTTP 200, response.completed, 0 вызовов. Пользовательский сценарий и его возможные операции не повторялись. Готовые DEB/AppImage и installed version проверяются в отчёте выпуска; пользователь должен перезапустить приложение для загрузки новой версии.

Дополнительная сквозная проверка: `packages/desktop/test/loginom/chatgpt-schema.mjs` запускает packaged приложение в отдельном профиле, выполняет check/save Loginom, передаёт только свежий access token (без возможности refresh) и создаёт собственный чат с обязательным разрешением любых инструментов. Запрос «ответь OK без действий» прошёл через реальный backend: версия 0.1.2, ответ OK, 0 tool calls. Тест удаляет свой профиль; исходный файл авторизации не изменяется.
