# Параллельные evals на одном Loginom Server

Редакция 2026-10-19. Решения владельца 2026-10-16 реализованы; N1/N2 прошли
техническую приёмку. Нормативный текст — [контракт](../../evals/docs/parallel-users-contract.md),
проверки/pins — [план](../superpowers/plans/2026-10-16-evals-parallel.md),
команды — [runbook](../testing/loginom-ai-agent/parallel-evals.md).
Предыдущие варианты и хроника — в [архиве](../archive/2026-10-16-evals-parallel-history.md).

## 1. Результат

Два слота одновременно выполняют очередь небольших задач. Для каждого отдельны
пользователь, профиль, workspace и закрытый архив. Судья последовательно оценивает
артефакты; общая сводка честно сохраняет ошибки качества и инфраструктуры.
Сравнение качества N1/N2 — следующая задача (контракт п.30).

## 2. Рабочий путь

`environment-preparation` подготавливает пользователей и проверяет окружение.
`prepared-run` открывает admin до слотов, запускает `runSlotQueue`, вызывает
`runAttempt`, cleanup и запись summary. Агент и management используют прямой
`superviseProcess`; inventories/census не решают исход попытки.
`startup-reconciliation` разбирает прежние остатки перед следующим run.
Текущие гарантии владения и процессов — контракт п.1–19.

## 3. Владение и удаление

Один server lock на run плюс locks профилей и home судьи. User lock и slot epoch
recovery удалены. Правила автоматической очистки своего, чужих и удержанных
ресурсов — только контракт п.20/24. Список сохранённых ресурсов —
[отдельный документ](../testing/loginom-ai-agent/2026-10-16-evals-parallel-retained.md).

## 4. Судья и измерения

Home судьи `/home/kiselev/.local/state/loginom-evals/parallel/judge-codex`;
граница VPN — ограниченный именованный systemd unit. Login, lockdown, ожидание
wrapper и запрет root signals — контракт п.26.
Run запускает и останавливает resource sampler; приёмка — п.27–30.
Бюджет утверждён до N2, числовые границы и evidence — в плане.

## 5. Завершение и отказы

`slot-storage` закрывает точные сессии, перечитывает список, проверяет backup,
FD/maps и владение перед удалением. Unknown сохраняет данные и карантин;
здоровый слот продолжает очередь. Полные правила — контракт п.20/24.
Ограничение SESSION_NOT_IDLE после аварии остаётся явным.
После успешного N2 неиспользуемые механизмы удалены; unit, typecheck,
четыре native A/B и независимое ревью прошли. Evidence — в плане.
