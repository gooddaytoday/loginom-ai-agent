# Архив проверок старых интеграций

`codex-native-hook.test.mjs.txt` сохраняет две проверки manifest/hook Codex из `client/test/hooks.test.mjs` выбранного исходного Dock. Они требуют архивного `plugins/loginom-dock`, который по согласованному решению не входит в активный продукт. Остальная проверка архивации, редактирования секретов и восстановления hook остаётся активной. Исходный полный файл и плагин также сохранены в migration bundle; это не замена проверкам нового desktop host.
