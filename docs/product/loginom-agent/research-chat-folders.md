# Отдельная папка для каждого разговора без проекта?

Исследование 18.11.2026 по первичным источникам (справка и документация вендоров, открытый код). Ничего не
запускалось. Заметки с полными ссылками — [research-chat-folders/](research-chat-folders/).

Вопрос владельца: «давай подумаем не лучше ли будет делать отдельные папки для разговоров без проекта, будет легче
всем управлять или сложнее? изучи как это сделано у больших вендоров».

## Короткий ответ

Да, отдельная папка на каждый разговор без проекта — проще для пользователя и почти бесплатно для нас. Так делают
настольные агенты, ближайшие к нашему приложению: у разговора без папки в GitHub Copilot для VS Code своя временная
папка, у сессий Claude для компьютера — своя рабочая папка с `outputs/`. Файлы разговора лежат вместе, перенос и
удаление понятны: «папка разговора». В OpenCode 2 это поведение по умолчанию: обычная папка — это отдельный проект,
правок не нужно. Наша работа — прятать эти служебные проекты в своей панели и собирать из них раздел «Разговоры».
В отличие от вендоров, папку стоит сделать видимой: аналитику нужны результаты.

## Как это у других

| Продукт | Где файлы разговора без проекта | Своя папка у разговора | Перенос | Удаление |
|---|---|---|---|---|
| ChatGPT | В разговоре и в общей «Библиотеке» аккаунта ([Library](https://help.openai.com/en/articles/20001052-using-library-to-manage-files-in-chatgpt)) | Нет | Разговор получает инструкции и файлы проекта; про свои файлы не сказано | Копии в «Библиотеке» остаются |
| Codex (в приложении ChatGPT) | Папка для разговоров без проекта задаётся настройкой ([config](https://learn.chatgpt.com/docs/config-file/config-reference)); по папке на разговор — не сказано | В режиме worktree — да, своя рабочая копия ([worktrees](https://learn.chatgpt.com/docs/environments/git-worktrees)) | — | Рабочая копия удаляется при архивации (по документации) |
| Claude (сайт, приложение) | В разговоре; артефакты — во вкладке «Артефакты» аккаунта ([artifacts](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them)) | В режиме «чат + Cowork» — своя машина на разговор ([enterprise](https://support.claude.com/en/articles/17444462-set-up-and-manage-the-new-unified-claude-experience-for-your-enterprise-organization)) | Не сказано | В Enterprise файлы удаляются вместе с разговором, артефакты — нет |
| Claude для компьютера, локально | `…/sessions/<разговор>/outputs/` ([data storage](https://claude.com/docs/third-party/claude-desktop/data-storage)) | **Да** | — | Папка разговора удаляется вместе с ним |
| Claude Code | Рабочая папка сессии; черновая папка на сессию ([.claude](https://code.claude.com/docs/en/claude-directory)) | Черновая — да | Исправлено: файлы сессии без папки больше не удаляются при переносе в папку ([changelog](https://claude.com/docs/cowork/changelog)) | Черновая папка чистится через 30 дней |
| GitHub Copilot в VS Code | «Отдельная временная папка» на разговор без открытой папки ([docs](https://code.visualstudio.com/docs/agents/run/sessions/manage-sessions#run-multiple-chats-in-a-session)) | **Да** | Файлы не переносятся | Рабочие копии сессии удаляются |
| Microsoft 365 Copilot | OneDrive пользователя ([docs](https://learn.microsoft.com/en-us/copilot/plan/architecture-data-protection-auditing)) | Нет | — | Не сказано |
| Gemini | Canvas — внутри разговора, экспорт — в Google Drive ([docs](https://support.google.com/gemini/answer/16047321?hl=en&co=GENIE.Platform%3DDesktop)) | Нет | — | Canvas удаляется вместе с разговором |

Два подхода:
- **облачные ассистенты** (ChatGPT, Claude на сайте, Microsoft, Gemini) держат файлы в разговоре и в общей
  «библиотеке» аккаунта, своей папки нет;
- **настольные агенты** (Copilot, Claude для компьютера, Claude Code, Codex) дают разговору без папки свою папку и
  часто удаляют её вместе с разговором. Мы — настольный агент.

## OpenCode 2 (по коду, v2.3.0)

- Проект определяется папкой; обычная папка без git — всегда отдельный проект
  (`packages/core/src/project.ts:426-459`). Две сессии одного проекта в разных папках бывают только в git-проекте.
- **Своя папка на разговор = свой скрытый проект на разговор.** Это поведение по умолчанию, правок OpenCode не нужно.
  Одна скрытая папка с подпапками на разговоры тоже превращает подпапки в отдельные проекты.
- Перенос сессии есть: `POST /api/session/:id/move` пересчитывает проект по новой папке, файлы не переносит
  (`packages/core/src/session/move.ts`) — файлы переносит приложение.
- Удаление сессии файлов не трогает; удалить проект нельзя — он архивируется, когда папки нет.
- По умолчанию агент может без вопроса читать соседние папки — чтобы разговоры не видели файлы друг друга, нужно
  правило разрешений для внешних папок.

## Сравнение для нас

| | Одна общая папка «Без проекта» | Своя папка у каждого разговора (рекомендую) |
|---|---|---|
| Найти файлы разговора | Вперемешку с другими разговорами | Все в папке разговора |
| Одинаковые имена файлов | Перезаписывают друг друга | Не мешают |
| Перенос в проект | Нужно вычислять, какие файлы «его», по истории | Переносим содержимое папки |
| Удаление | Нужно вычислять, какие файлы «его» | Удаляем или оставляем папку |
| Чужие файлы в разговоре | Агент видит файлы всех разговоров | Только свою папку (с правилом разрешений) |
| Работа для нас | Один скрытый проект | Прятать много служебных проектов, собирать «Разговоры» из них; на каждый активный разговор — свой набор служб OpenCode (по коду, не измерено) |

## Рекомендация

- **Своя папка у каждого разговора без проекта**, видимая: «Документы → Loginom AI Agent → Без проекта → <дата и
  название разговора>»; у файлов в ленте — «Открыть папку».
- **Перенос в проект:** содержимое папки разговора переезжает в папку проекта, в подпапку с названием разговора;
  затем разговор переносится в проект (`move`). «Убрать из проекта» создаёт разговору новую папку; файлы, сделанные
  в проекте, остаются в проекте.
- **Удаление:** по умолчанию папка остаётся (результаты часто уже нужны); в окне удаления — флажок «Удалить и папку
  разговора (N файлов)». Claude для компьютера удаляет её сразу, ChatGPT оставляет копии — мы выбираем осторожный
  вариант.
- **Изоляция:** правило разрешений — к папкам других разговоров агент обращается только с вопросом.
- **Проверить на этапе C:** сколько служб OpenCode поднимается на каждый активный разговор.

## Что не проверено

- Как Codex раскладывает разговоры без проекта внутри своей папки — закрытый код приложения.
- Что ChatGPT и Claude делают с файлами при переносе разговора в проект — в справке не сказано.
- Справка OpenAI отвечает роботам 403, статьи прочитаны по копиям Internet Archive 28.10–17.11.2026.
- Нагрузка «служба на разговор» в OpenCode 2 — вывод по коду, не измерена.
