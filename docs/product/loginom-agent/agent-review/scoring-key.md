## Ожидаемые пути по задачам 1–8 (задание оценщику 1)

### Задание 1. Подключить свой сервер Loginom

**Подготовка.** Сброс, стартовый экран «Новый разговор».

**Ожидаемый путь.**
1. В поле ввода справа — метка «Loginom не подключён». Нажать. Другие входы: «Настройки» внизу панели (раздел
   «Loginom» открыт сразу) или карточка «Подключиться к Loginom» в разговоре, если участник сначала написал задачу.
2. В окне или карточке — «Свой сервер Loginom» (до `d0d6cb6d53` включительно — «Изменить»). Не «Подключить
   публичный стенд» (раньше — «Подключить»): оно подключает публичный стенд, адрес которого подставлен заранее.
3. Открываются «Настройки → Loginom». В «Адрес» вместо адреса публичного стенда ввести адрес с карточки,
   в «Пользователь» вместо `user` — `ivanova`.
4. Снять «Пароль не нужен» — поле «Пароль» станет активным. Ввести пароль.
5. «Проверить» → «Проверка прошла» (необязательно: «Сохранить» проверяет сам).
6. «Сохранить» → всплывает «Loginom подключён». Если настройки открыты через «Изменить» — возврат на стартовый экран.

**Признак успеха.** Метка в поле ввода — зелёная точка и «Loginom». По нажатию на неё: «Подключено · Адрес
loginom.romashka.example · Пользователь ivanova · Папка /ivanova». В «Настройки → Loginom» —
«Подключён как ivanova · папка /ivanova».

Не успех: метка зелёная, но в окне адрес публичного стенда, а пользователь `user`.

**Где можно застрять.**
- «Подключить публичный стенд» — главная кнопка окна. Метка сразу зеленеет, и участник может решить, что готово.
  Адрес в уведомлении «Loginom подключён: …» это выдаёт.
- «Пароль не нужен» отмечено заранее, поле пароля серое — непонятно, как ввести пароль.
- Прототип принимает любой адрес, а с отметкой «Пароль не нужен» — и без пароля. Если участник не ввёл пароль,
  засчитывайте по адресу и логину и запишите это.

**Что было бы подсказкой:** показать метку Loginom, кнопку «Свой сервер Loginom», отметку «Пароль не нужен».

### Задание 2. Задокументировать пакет

**Подготовка.** Loginom подключён (после задания 1). Если задание 1 не выполнено — подключите сами: метка
«Loginom не подключён» → «Подключить публичный стенд» (подключится публичный стенд, «Качество данных.lgp» там тоже есть) →
закройте окно. Стартовый экран «Новый разговор».

**Ожидаемый путь.**
1. «+» слева в поле ввода → «Пакет из Loginom…».
2. Окно «Открыть из Loginom», «Моя папка» → «Качество данных.lgp» (или поиск «качество»).
3. Над полем — карточка пакета и строка «Что сделать с пакетом» → «Документировать».
4. Мастер «Документировать пакет», шаг «Параметры». «Формат документа»: отметить «Word» (PDF отмечен заранее,
   его можно снять). «Содержание» — любое. «Далее: доступ».
5. Шаг «Доступ» — что сделает приложение и агент → «Разрешить и запустить».
6. Этапы выполняются за несколько секунд, открывается «Результат».

**Признак успеха.** «Результат · Готово», среди файлов — «Качество данных — описание.docx» и путь «Документы →
Loginom AI Agent → Без проекта → <дата> Документировать пакет» (если PDF не сняли, рядом ещё «….pdf»), «Проверено
приложением: ✓ Описаны 14 из 14 узлов…». До исправления — «Качество данных.lgp_report.docx · Папка проекта».

Тоже успех: пакет выбран через «+», участник написал в поле запрос со словом «документ» («Задокументируй…»)
и отправил. В разговоре — «Пакет
задокументирован», файл «Качество данных — описание.md». Word в разговоре не получить (ограничение прототипа):
запишите, заметил ли участник.

**Где можно застрять.**
- Выбрать пакет из Loginom можно только через «+». Отдельного раздела пакетов в панели нет.
- Запрос без выбранного пакета («Сделай описание сценария «Качество данных»») ведёт к заготовке про ABC-анализ:
  макет не ищет пакет по названию. Скажите «в макете агент понимает не все слова, выберите пакет» — это
  вмешательство из-за прототипа, запишите его. С выбранным пакетом «описание», «опиши», «документ…» работают.
- Пример «Задокументировать пакет» на стартовом экране берёт учебный пакет «Продажи», а не «Качество данных».
- PDF отмечен по умолчанию — Word легко пропустить.
- «Открыть» у документа показывает только «В приложении файл откроется в программе по умолчанию. В демо файла нет».
  Оценщики считают это тупиком: не путайте с неуспехом задачи, успех — экран «Готово» с файлом.

**Что было бы подсказкой:** показать «+», строку «Что сделать с пакетом», флажок «Word».

### Задание 3. Проверить сценарий и улучшить его

В. Через мастер «Проверить»:

- После мастера «Проверить» не видно, как перейти к исправлению.
- Выбор между «Сохранить новой версией» и «Заменить исходный…».
- Улучшать прототип умеет только «Продажи.lgp». На любой другой пакет ответ «Замечаний нет».

**Что было бы подсказкой:** показать «Внести улучшения», «Улучшить», «Обсудить в чате», «Сохранить новой версией».

### Задание 5. Перенести исправления в исходный, не сломав другие пакеты

**Подготовка.** После задачи 3: в разговоре карточка «Сохранено новой версией «Продажи — v2.lgp»» (или черновик
копии, если участник не сохранил).

**Ожидаемый путь.**
1. В карточке правки — «Заменить исходный…». Окно «Заменить исходный пакет?», блок «Ссылки из других пакетов»:
   «Отчёт директору.lgp» — узел есть; «Города — неделя.lgp» — «В копии этого узла нет — ссылаться будет не на что».
2. Из черновика копии: «Попросить агента оставить узел» → окно закрывается, в поле ввода «Не удаляй «Фильтр по
   дате (ветка «Города»)» — на него ссылается «Города — неделя.lgp»» → отправить. Ответ «Изменил копию
   «Продажи.lgp» ещё раз», строка «в этом ответе»: узел оставлен; прежняя карточка — «продолжено ниже».
3. В новой карточке «Заменить исходный…» → обе ссылки рабочие («Этот узел в копии оставлен…») → «Заменить
   исходный» → ««Продажи.lgp» заменён, прежняя версия — «Продажи — до правки.lgp»».

Из сохранённой версии в окне кнопки «Попросить…» нет — только «не заменяйте исходный: новая версия уже
сохранена». Пути дальше: «Удалить новую версию» (изменения снова в копии) и шаги 1–3; или просьба агенту оставить
узел → ответ «Изменения из копии … уже сохранены новой версией…» → «Внеси улучшения…» (новая копия «… правка
агента 2») → шаги 1–3.

**Признак успеха.** Карточка «Исходный «Продажи.lgp» в Loginom заменён этими изменениями», среди строк —
«Фильтр по дате (ветка «Города»)» — оставлен. Перед заменой окно показало обе ссылки рабочими.

**Ложный успех:** заменить исходный, когда окно показывало ✗ у «Города — неделя.lgp», — отчёт по городам сломан.
**Не успех:** только новая версия без замены (исправления не в самом пакете).

**Где можно застрять.**
- Окно замены из сохранённой версии — тупик: советует не заменять и не предлагает, как оставить узел.
- Просьба оставить узел распознаётся по словам «не удаляй / оставь / верни» вместе с «фильтр / узел»; вопрос со
  знаком «?» правкой не считается (макет).
- «Заменить исходный» невозможен, если исходный уже заменён — тогда «Вернуть прежнюю версию» в карточке.

**Что было бы подсказкой:** показать блок «Ссылки из других пакетов», «Попросить агента оставить узел», «Удалить
новую версию».

## Что не работает в прототипе

- **Свободный текст.** Ответ подбирается по словам в запросе: документ — «документ…», «описание», «опиши» с
  выбранным пакетом; проверка — «провер…», «оптимиз…», «лучше»; правка — «исправь», «улучш», «измени», «доработ»
  и т. п. Остальное про сценарий или пакет, а также всё при выбранном пакете — заготовка ABC-анализа. Пакет по
  названию в тексте макет не находит. «Установи навык из этого файла» получает общую фразу.
- **Документ в разговоре** — всегда «… — описание.md», даже если просили Word. «Открыть» у документа в мастере
  документ не показывает.
- **Проверить и улучшить** работает только для «Продажи.lgp»; для остальных — «Замечаний нет».
- **Свой навык и инструкции проекта.** Применение видно только в проверке «Продажи.lgp»; на других задачах ответ
  обычный. Осмысленный ответ пробы — только если в «Что делать» есть про названия узлов.
- **«Обсудить в чате»** после мастера «Проверить» подставляет вопрос «Что стоит сделать дальше?», и агент сразу
  правит копию, не спросив.
- **Состояние** (подключение, свои навыки, установленное) живёт до перезагрузки страницы. Переход на сайт каталога
  в той же вкладке его сбрасывает.
- **Проверка подключения** принимает любой адрес, а с «Пароль не нужен» — и без пароля.
- **Расхождения в заготовках:** проверка в мастере — «12 из 12 узлов», 2 замечания, в разговоре — 6 узлов,
  3 замечания; документ — 14 узлов в мастере, 12 в разговоре. Папка `/user` при пользователе ivanova исправлена.
- **Сайты в разговоре.** Если сайты запрещены (закрытый контур или «Запрещено»), на «открой сайт…» агент отвечает
  отказом и называет, кто запретил. Если стоит «Спрашивать» — обычная заготовка, запроса разрешения нет.
- **Итерация 8.** «Скачать на компьютер…» файл не сохраняет. Снимки копии агента («Вернуть изменения», «Изменить»
  сообщение) описаны, а не сделаны: в прототипе копия возвращается по состоянию карточки. Лимит бесплатной модели
  держится до перезагрузки страницы. Просьба оставить узел распознаётся только для «Фильтр по дате (ветка
  «Города»)».
- **Служебные элементы на виду у участника:** «Прототип 2 · что решить», «Только для прототипа: чем закончится
  запуск», «Только для прототипа: примеры файлов».
