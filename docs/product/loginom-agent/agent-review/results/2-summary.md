## Решить владельцу

Решено 18.11.2026 (В-67…В-69): первое и третье — как рекомендовано, «Терминал» остаётся у пользователя.

Вопросы были такими:
1. **Глубина Loginom — следующая итерация прототипа.** Рекомендую: замечание подсвечивает узел, в правке — настройки
   и порты «было / стало», перед заменой — узлы-ссылки. Расписание и сервер — отдельным исследованием API.
2. **«Терминал».** Рекомендую убрать его из настроек пользователя: включить его может только администратор.
3. **«Разрешения» и кнопки пользователя.** Рекомендую: разрешения — только про то, что агент делает сам; кнопки — решение
   человека по правам его учётной записи Loginom.
