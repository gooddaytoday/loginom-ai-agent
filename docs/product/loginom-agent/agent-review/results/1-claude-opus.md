## 5. Что работает и что не трогать

1. **Окно «Заменить исходный пакет?»** Список зависимых пакетов с последствиями для каждого, резервная копия «до правки», «Вернуть прежнюю версию» и честное «Не проверено: …». Это лучший экран прототипа.
2. **Экран «Доступ» перед запуском действия** («Агент сможет / не сможет / Что увидит модель») и строка над полем «Модель в облаке: … уйдут в «Облако OpenCode»». Сразу понятно, что уходит с компьютера.
3. **Карточка правки** (+/~/− по узлам, «Настройки и связи» с «Было / Стало», сверка на данных) и обещание «исходный не изменён», которое подтверждается датами в окне выбора.
4. **Остановка по лимиту модели.** Карточка ошибки ведёт к ключу, «Продолжить с другой моделью» продолжает с того же места, подпись «Бесплатная модель OpenCode → GPT-5.4» показывает, кто что сделал. После подключения Loginom из разговора агент сам продолжает работу.
5. **Импорт файла администратора:** состав, подпись, «Интернет не нужен», «Установка только добавляет это в приложение…».

  - Т6: файл коллеги «Продажи.lgp» на компьютере не изменён, рядом «скачан» исправленный «Продажи — v2.lgp». Копия, которую агент загрузил на сервер, по словам приложения удалена.
