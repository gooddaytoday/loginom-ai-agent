В каждой паре одни входные байты, определения, схема, порядок строк, NULL policy,
oracle, допуск `0.000001` и rubric. Только D содержит вычислительный путь; B
содержит бизнес-вопрос и необходимые точные определения. Обе формы требуют
native LGP и ровно один полный CSV. Fixtures полностью искусственные, без
внешних сервисов и персональных данных.

Offline selection: все пять draft oracle дали различимые содержательные ошибки;
20/20 синтетических near-miss CSV отвергнуты существующим `compareCsv` при заданном
допуске. Это ещё не judge calibration: распознавание предметных ошибок по rubric
проверяется после появления reference. Источники native-пути — текущие handlers,
schemas и validators в `packages/loginom-runtime/client/lib/`, включая
`node-support.mjs`, `grouping-parameters.mjs`, `join-parameters.mjs` и
`calculator-parameters.mjs`. Статическая доступность не заменяет live-проверку.
