В sales.csv перед заголовком находятся три строки служебного описания. Заголовок Region;Amount;Comment. N/A обозначает отсутствующее значение, комментарий может содержать перенос строки внутри кавычек. Рассчитайте сумму Amount по Region, не включая отсутствующие суммы. Итоговые поля Region и Total (вещественное), порядок по Region по возрастанию.
