На основе JSON из единственного строкового поля Document файла flat.csv построй таблицу из одной целочисленной колонки id. Возьми все записи корневого массива без выборки. Сохрани короткое имя id.

Используй штатную цепочку «Импорт из текстового файла» → «JSON в дерево» → «Дерево в таблицу» → «Экспорт в текстовый файл», без JavaScript. Сохрани порядок записей и технические имена столбцов в result.csv. Сохрани пакет.
