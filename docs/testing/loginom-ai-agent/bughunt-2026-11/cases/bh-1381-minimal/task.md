На основе JSON из единственного строкового поля Document файла minimal.csv построй таблицу позиций корзин. Нужны ID корзины, ID товара и количество, в этом порядке. Повтори ID корзины для каждой её позиции; два поля id должны иметь разные составные технические имена.

Используй штатную цепочку «Импорт из текстового файла» → «JSON в дерево» → «Дерево в таблицу» → «Экспорт в текстовый файл», без JavaScript. Сохрани порядок записей и технические имена столбцов в result.csv. Сохрани пакет.
