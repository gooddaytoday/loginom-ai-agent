В книге sales.xlsx первый лист содержит справку. Используйте второй лист «Продажи 2026». Заголовок занимает две строки: группа Sale и поля Date, Amount, Paid. Рассчитайте суммы продаж только с логическим Paid=true по календарным месяцам. Итоговые поля Month (текст ГГГГ-ММ) и Total (вещественное), сортировка по Month по возрастанию.
