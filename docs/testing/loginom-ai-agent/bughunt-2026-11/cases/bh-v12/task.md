В новом сценарии подготовьте на узле Python небольшой реестр расчётных строк. Число строк задайте в целочисленной пользовательской переменной сценария Count со значением 4. Возьмите её через вход переменных Python. Табличный вход можно оставить свободным. Нужны поля Line (целое, нумерация с единицы) и Units (целое, Line × 10). Если вход переменных Python недоступен, объясните ограничение и остановитесь до создания узлов.

Перед сохранением проверьте состав узлов и связи в сценарии.
