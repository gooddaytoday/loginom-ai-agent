Очисти приложенный quality.csv. RowID — целое, Account — строка, Amount — вещественное. Удали полные дубликаты строк, затем заполни пустые Amount медианой непустых Amount уже после удаления дубликатов. После заполнения убери строки, где Amount меньше нуля или больше 100. Эти границы фиксированы для проверки качества данных. Сохрани столбцы RowID, Account, Amount, их имена и подписи, расположи строки по возрастанию RowID. Нужен отдельный этап удаления дубликатов, отдельный этап заполнения пропусков и отдельный этап исключения значений вне диапазона.
