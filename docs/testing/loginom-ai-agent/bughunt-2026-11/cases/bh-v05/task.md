Импортируйте приложенный справочник. Отсортируйте Word по возрастанию с учётом регистра, при равенстве по Ticket по возрастанию. Для признака «сравнение с учётом локали» в узле Сортировки используйте логическую пользовательскую переменную сценария UseLocale со значением «истина». Сохраните оба исходных поля.

Перед сохранением проверьте состав узлов и связи в сценарии.
