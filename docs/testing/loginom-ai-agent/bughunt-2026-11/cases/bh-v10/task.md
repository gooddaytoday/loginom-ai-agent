В приложенном файле — идентификатор и тело тестового запроса. Выполните нативный REST-запрос POST к https://httpbin.org/anything, передав Body из файла как тело. Значение заголовка X-Report-Stage возьмите из строковой пользовательской переменной сценария ReportStage со значением trial-1983. Используйте переменный вход REST. Из фактического JSON-ответа выделите значение этого заголовка в строковое поле HeaderValue и выгрузите таблицу с этим полем.

Перед сохранением проверьте состав узлов и связи в сценарии.
