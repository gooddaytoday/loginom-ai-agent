# LAB-2041. Пошаговая сборка на dbseed

Каждый `task.md` содержит один ход аналитика. Передавайте раннеру имя последнего хода. Он открывает один чат на цепочку и прикладывает исходные CSV на первом ходе. Точный граф проверяет состав узлов, связи и идентичность сохранённых узлов. Эталоны выходов задают типы, строки и порядок в тех шагах, где порядок запрошен.

| Цепочка | Последний ход | Проверка |
| --- | --- | --- |
| Региональная выручка | `bh-w401-t6` | Два импорта, внутреннее слияние, сумма, ручное переименование группировки, сортировка, книга Excel |
| Топ товаров | `bh-w402-t5` | NULL-скидка, сумма строки, ручное переименование калькулятора, порог, сумма по товару, топ-10 |
| Ранг товара | `bh-w403-t4` | JavaScript, смена критерия и повторный запуск после ручного переименования импорта |
| Помесячная выручка | `bh-w404-t4` | Python, окна 3 и 6, NULL для неполного окна, ручное переименование импорта |
| Порог из переменной | `bh-w405-t5` | Оба выхода фильтра, управляющая связь, изменение порога, ручное переименование фильтра |
| Правка схемы | `bh-w406-t5` | Исходная группировка, вставка и ручное переименование фильтра, замена суммы на среднее, удаление фильтра и восстановление связи |

Для быстрых проверок используются детерминированные выборки из `dbseed/gen.py`. Выручка заказа рассчитана из всех его позиций с учётом скидки. Количество для ранжирования рассчитано по всем позициям каждого выбранного товара. У помесячной выборки два заказа на каждый месяц 2025 года. В последней цепочке первые два хода создают заготовку, которую аналитик затем меняет в том же пакете.

Раннеру нужна поддержка `manual_edit`, `output_mode: ports`, точного графа и проверки Excel из PR #1353. Последний ход каждой цепочки рассчитан на проверку с `--cold`. Сохранение между ходами добавляет раннер.

Проверить зафиксированные CSV и эталоны, либо сгенерировать их заново, можно из корня репозитория.

```sh
wave=docs/testing/loginom-ai-agent/bughunt-2026-11
python3 "$wave/wave4/oracle.py" --check "$wave/cases"
python3 "$wave/wave4/oracle.py" --out "$wave/cases"
```
