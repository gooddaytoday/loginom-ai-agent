Подготовь список десяти товаров с наибольшей выручкой.
Подключение: MySQL, сервер [[DB:DB_HOST]], порт [[DB:DB_MYSQL_PORT]], база [[DB:DB_NAME]], пользователь [[DB:DB_USER]], пароль [[DB:DB_PASSWORD]].
В SQL-запросе соедини order_items с products. Суммируй количество, умноженное на цену с учётом скидки в процентах. Если discount_pct пуст, используй нулевую скидку. Округли итог по каждому товару до копеек.
Нужны product_id, product_name и revenue. Отсортируй по выручке по убыванию, при равенстве по product_id по возрастанию. Выгрузи результат в bh-d103-top-products.csv.
