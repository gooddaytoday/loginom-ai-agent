Подготовь отчёт о выручке по регионам клиентов и месяцам заказов.
Подключение: PostgreSQL, сервер [[DB:DB_HOST]], порт [[DB:DB_PG_PORT]], база [[DB:DB_NAME]], пользователь [[DB:DB_USER]], пароль [[DB:DB_PASSWORD]].
В одном узле импорта выполни один SQL-запрос, который соединяет orders, customers и order_items. Учти заказы всех статусов. Выручку по строке считай как количество, умноженное на цену с учётом скидки в процентах. Пропуск скидки означает, что скидки не было. Округли сумму по группе до копеек.
В отчёте нужны region, month в формате ГГГГ-ММ и revenue. Выгрузи отчёт в bh-d101-revenue.csv.
