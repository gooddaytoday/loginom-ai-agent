Собери в Loginom сводку по клиентам и передай её в базу для коллег.
Подключение: PostgreSQL, сервер [[DB:DB_HOST]], порт [[DB:DB_PG_PORT]], база [[DB:DB_NAME]], пользователь [[DB:DB_USER]], пароль [[DB:DB_PASSWORD]].
Загрузи customers в узел «Клиенты» и собери сводку «Сводка клиентов» с количеством клиентов (customer_count) по каждому region. Через узел экспорта в базу создай таблицу public.{{EXPORT_TABLE}} и запиши туда сводку.
Проверь таблицу отдельным импортом «Проверка таблицы». В запросе прочитай region и customer_count из новой таблицы. Добавь поле table_name с именем таблицы, полученным из каталога PostgreSQL для этой таблицы в схеме public. Выгрузи результат проверки в bh-d106-readback.csv.
