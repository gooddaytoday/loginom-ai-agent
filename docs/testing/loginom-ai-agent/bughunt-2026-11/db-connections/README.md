# Подключения к тестовым базам sales

| Запуск | СУБД | Проверка |
| --- | --- | --- |
| `bh-d101` | PostgreSQL | Один SQL-запрос с тремя таблицами, выручка по регионам и месяцам |
| `bh-d102` | PostgreSQL | Вся таблица customers с датой и NULL, затем сводка в Loginom |
| `bh-d103` | MySQL | Топ-10 товаров, выручка с десятичной ценой и NULL в скидке |
| `bh-d104` | MS SQL Server | SQL-запрос со статусом «Возврат», число заказов по сегментам |
| `bh-d105` | PostgreSQL | Привязка параметра SQL к строковой переменной сценария |
| `bh-d106` | PostgreSQL | Создание таблицы, экспорт, проверка строк и имени через отдельный импорт |
| `bh-d110` | PostgreSQL | Четыре хода в одном чате через `bh-d107` → `bh-d108` → `bh-d109` → `bh-d110` |

Эталоны вычисляются до прогона из четырёх CSV, которыми наполнили базы.
В `--seed` передаётся каталог, полученный командой `python3 gen.py OUT_DIR`.
[PR с генератором dbseed](https://github.com/gooddaytoday/loginom-ai-agent/pull/1354)

Команда ниже создаёт отдельный каталог `--cases` из шаблонов заданий и
эталонов. Файлы CSV и эталоны остаются на хосте раннера.

```bash
python3 docs/testing/loginom-ai-agent/bughunt-2026-11/db-connections/oracle.py \
  --seed /absolute/path/to/seed --out /absolute/path/to/bh-d1-cases
```

Для запусков с `--cold` используйте пакеты `bh-d101,bh-d102,bh-d103,bh-d104` и
`bh-d105,bh-d106,bh-d110`. Параметры подключения берутся из
`~/.config/loginom-run-check/db-test.conf`. Подключения к БД идут со стороны
app.loginom.ai. При повторе `bh-d106` соберите новый каталог `--cases`, чтобы
получить свободное имя таблицы `bh_d106_…` в схеме `public`.
