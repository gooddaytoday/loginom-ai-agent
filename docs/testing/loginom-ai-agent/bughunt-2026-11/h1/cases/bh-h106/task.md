Найдите в Loginom выбросы среди показаний из sensors.csv. Повторный замер с тем же номером учитывайте один раз. Пропустите строки без датчика или показания. Дата во времени замера записана как ДД.ММ.ГГГГ или ГГГГ-ММ-ДД, показания — с десятичной запятой.

Для каждого датчика отдельно посчитайте среднее и стандартное отклонение по всем его непустым показаниям. Для дисперсии делите на число показаний. Считайте z-score как разность показания и среднего, делённую на стандартное отклонение. Выведите замеры с абсолютным z-score строго больше 3. Если отклонение равно нулю, выбросов у датчика нет.

Верните поля Sensor (код датчика), Measurement (номер замера), MeasuredAt (строка ГГГГ-ММ-ДД ЧЧ:ММ:СС), Reading (показание) и ZScore (со знаком). Отсортируйте по Sensor, затем по Measurement по возрастанию.
