Подготовьте в Loginom недельный отчёт по магазинам из stores.csv. Повторяющиеся продажи с тем же номером учитывайте один раз. Пропустите строки без магазина, даты или выручки. В файле два формата дат (ДД.ММ.ГГГГ и ГГГГ-ММ-ДД) и десятичная запятая.

Для каждого магазина покажите выручку за каждую календарную неделю начиная с недели 5 января 2026 года и заканчивая неделей 29 июня 2026 года включительно. Неделя начинается в понедельник. При отсутствии продаж укажите нулевую выручку. Для каждой недели посчитайте среднее выручки за текущую и три предыдущие недели этого же магазина. Для первых трёх недель используйте столько недель, сколько есть с начала отчёта.

Оставьте поля Store, WeekStart (понедельник, строка ГГГГ-ММ-ДД), Revenue и MovingAverage4. Отсортируйте по магазину и дате начала недели по возрастанию.
