Проведите в Loginom ABC-анализ товаров по выручке из приложенного products.csv. Одинаковые строки учитывайте один раз. Пропустите строки без товара или выручки. Выручка указана с десятичной запятой.

Посчитайте выручку каждого товара и его долю в общей выручке. Упорядочьте товары по убыванию выручки, при равенстве — по коду товара. Посчитайте накопленную долю в этом порядке. Отнесите к A товары до накопления 80%, к B — следующие до 95%, к C — остальные. Товар, на котором достигнут или пересечён порог, входит в завершаемую группу.

В итоговой таблице оставьте поля Product (код товара), Revenue (выручка), Share (доля от 0 до 1), CumulativeShare (накопленная доля от 0 до 1), Class (A, B или C) в указанном порядке. Возьмите одну строку на товар и сохраните порядок ABC-расчёта.
