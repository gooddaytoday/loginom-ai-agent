По приложенному purchases.csv подготовьте в Loginom когорты удержания покупателей. Одинаковые покупки учитывайте один раз. Пропустите записи без клиента или даты покупки. Даты записаны как ДД.ММ.ГГГГ или ГГГГ-ММ-ДД, сумма покупки для этой задачи не нужна.

Когорта — календарный месяц первой покупки клиента. Месяц жизни 0 — месяц первой покупки. Для каждого месяца жизни посчитайте число уникальных клиентов когорты с хотя бы одной покупкой в этом месяце и разделите его на размер когорты. Включите все месяцы жизни до последнего календарного месяца с покупками во всём наборе, в том числе месяцы с нулём вернувшихся.

В итоговой таблице нужны Cohort (строка ГГГГ-ММ), Age (номер месяца жизни), CohortSize (число клиентов в когорте), Active (число клиентов с покупкой) и Retention (доля от 0 до 1). Отсортируйте по Cohort и затем по Age по возрастанию.
