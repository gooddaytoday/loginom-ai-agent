Подключи файл `orders.db` как базу SQLite. Одним SQL-запросом соедини `orders` и `customers` по `customer_id`. Учти только оплаченные заказы (`status = 'paid'`), для каждого региона посчитай количество заказов и выручку по `amount_cents` в копейках. Регионы без оплаченных заказов не включай.

Выведи `Region` (строка), `PaidOrders` и `RevenueCents` (целые) в таком порядке. Отсортируй по `Region` по возрастанию, выгрузи в `bh-i101-result.csv` и сохрани пакет.
