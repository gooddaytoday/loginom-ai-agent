response and unchanged bytes are passed to fulfill. Decoding-specific encoding,
length and transfer headers are removed, other original headers preserved. A
second hash checks that the SDK did not mutate the private body during fulfillment.
This is response-byte custody, not proof of script execution. Receipt records
are frozen and remain private on the original owner. responseBytesComplete means
20 fulfilled selected responses; sourceExecutionQualified, closureIdentityQualified,
native/content/save/close remain false. Existing sourceBytesVerified stays false.

may abort only the same still-qualified intercepted network route; foreign
methods/descriptors are never overwritten or invoked for recovery. If that route
cannot be safely aborted, it remains unresolved. No synthetic task completion,
new acquisition, reader replay, cleanup, release or ACK is inferred.
