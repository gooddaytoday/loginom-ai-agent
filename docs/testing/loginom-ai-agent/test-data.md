# Приёмка скилла генерации тестовых данных

Скилл: `packages/desktop/resources/skills/test_data/SKILL.md`.
Имя в каталоге: `test_data`.

Проверка в установленном или собранном Desktop. Скрипт генерации
вызывает системный `python3` и пишет CSV в каталог, который назвал
пользователь. Окно сценария Loginom открывать не нужно: скилл туда
файл не кладёт.

Исходная проверка без Desktop:

```bash
python3 packages/desktop/resources/skills/test_data/scripts/test_generate_dataset.py
```

Из `packages/desktop`:

```bash
bun test electron-builder.config.test.ts
```

Вторая команда проверяет, что у каждой папки в `resources/skills` есть
`SKILL.md` с `name` папки и непустым `description`.

## Вопросы

1. «Создай тестовый набор данных для интернет-магазина на 1000 строк.
   Колонки: ID заказа, Дата, Сумма, Статус. В 5% строк сумма
   отрицательная, в 2% статус пустой.»
   Ожидание: пути к CSV и манифесту, 50 отрицательных сумм и 20 пустых
   статусов, seed, типы колонок и параметры импорта из текстового
   файла. Файл в сценарий агент не загружает. Вызовов `loginom_dock_*`
   нет.

2. «Сделай тестовые данные.»
   Ожидание: один уточняющий вопрос. Скрипт не запускается, пока нет
   числа строк и нет ни колонок, ни предметной области.

3. «Загрузи этот набор в сценарий Loginom.»
   Ожидание: запрос вне первой версии. Узел импорта не создаётся,
   вызовов `loginom_dock_*` нет.

4. «Колонка „Комментарий“, тип строка, в 5% строк сделай отрицательные
   значения.»
   Ожидание: скрипт завершается с кодом 2, CSV нет. Агент пересказывает
   отказ и не подменяет его выдуманной таблицей. После двух неудачных
   правок спецификации новые попытки не делает.

5. Повторить вопрос 1 с тем же seed.
   Ожидание: побайтно тот же CSV. Доли, которые пользователь не называл,
   в спецификацию не добавляются.

## Прогон из этой ветки

Живые пять вопросов в Desktop ещё не прогнаны: нет сборки с
`test_data`. Ручной импорт CSV в Loginom тоже не прогнан. На нём нужно
отдельно увидеть, что дата ISO читается как `datetime`, а пустое поле
при пустом маркере NULL — как NULL.

Автотест генератора в этом дереве: 7 тестов, OK. Проверка frontmatter
`electron-builder.config.test.ts`: 5 тестов, OK, папка `test_data` входит
в каталог скиллов.
