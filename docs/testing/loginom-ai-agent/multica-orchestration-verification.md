## Изменения и границы

Общий процесс опубликован через API сразу для всего сквада. Манки самостоятельно устраняет технические препятствия; Ловец возвращает локальные замечания и продолжение прямо Манки. Регистратура назначает одного автора общего исправления в существующей карточке и передаёт проверенный результат зависимым узлам, освобождая слот. Генератор отвечает за подготовку, доступ и действительно необходимые решения владельца.

Внутренние зависимости сохраняют `in_progress`. Три неудачи одним способом вызывают адресное техническое ревью; неизвестный эффект останавливает опасную операцию, сохраняя безопасный анализ. Исторические UNKNOWN, журналы и ограничения текущих ресурсов сохраняются. Изменение критериев, публичных контрактов, прав, merge и выпуск остаются за владельцем.

Согласованы RUNBOOK, шаблон, CLI-регламент, подготовка новых подпланов, все 78 подпланов и 34 README. Критерии и ожидаемые результаты не изменены. Проверки документации и независимого проверяющего кода не требуют полной продуктовой сборки; runtime и итоговая приёмка сохраняют проверку точного опубликованного кандидата. Новый процесс не подтверждает приёмку какого-либо узла.
