# Ручная проверка Dashboard на campaign-roi.lgp

В Studio откройте пакет `campaign-roi.lgp` из папки `dashboard-demo-roi` и перейдите в **Модуль1 → Сценарий**. Во всех кейсах используйте узел **«По убыванию ROI»**.

Кейсы 1–3 пройдите на исходном пакете. Для кейсов 4–6 понадобятся Loginom AI Agent Desktop, подключённый к тому же стенду, и право записи в папку, где будет лежать тестовая копия пакета.

## 1. Открыть готовый Dashboard и сверить данные

1. Выберите узел **«По убыванию ROI»** и нажмите **Dashboard** над схемой.
2. Проверьте, что в шапке указаны выбранный узел, путь к `campaign-roi.lgp` и метка **«Версия»**. В поле **MinBudget** установите `0`, если там другое значение, и щёлкните вне поля.
3. Дождитесь появления показателей. Должны открыться Dashboard **«Куда уходит рекламный бюджет»**, два графика и таблица по пяти каналам. Итоги при пороге `0` — **500 кампаний**, бюджет **24 724 310**, выручка **51 971 418**, ROI **+110,2 %**.
4. Нажмите **«Данные узла»**. Найдите строку **Email** и сравните её с таблицей Dashboard. В обеих таблицах должно быть **109 кампаний** для Email.
5. Нажмите **«К dashboard»**, затем **«Вернуться к сценарию»**. Должна открыться схема сценария.

## 2. Пересчитать Dashboard с новым порогом

1. Снова откройте **Dashboard**. В поле **MinBudget** введите `10000` и щёлкните вне поля.
2. Дождитесь пересчёта. Активный порог должен стать **10 000**, а общий итог — **453 кампании**.
3. Нажмите **«Данные узла»**. В строке **Email** должно быть **97 кампаний**. Нажмите **«К dashboard»** и сверьте число с таблицей Dashboard.

## 3. Проверить пустой результат и вернуть данные

1. В поле **MinBudget** введите `100000` и щёлкните вне поля.
2. Дождитесь пересчёта. Dashboard должен показать пустой результат. Откройте **«Данные узла»** и проверьте сообщение **«Нет строк»**.
3. Верните **MinBudget** в `0` и щёлкните вне поля. После пересчёта нажмите **«К dashboard»**. Должны вернуться **500 кампаний** и все пять каналов.

## 4. Создать черновик в Desktop

1. Нажмите **«Вернуться к сценарию»**. Через **«Сохранить как»** сохраните пакет под новым именем в той же папке, например `campaign-roi-test.lgp`. Используйте свободное имя.
2. В открытой копии выберите **«По убыванию ROI»** и нажмите **«Создать dashboard»**. Должен открыться чат в Desktop. Если браузер предложит открыть Loginom AI Agent, согласитесь. Если чат не открылся, нажмите в Studio **«Открыть чат в Desktop»**.
3. Отправьте в чат «Создай Dashboard с заголовком “Кампании по каналам”. Покажи число кампаний по каждому каналу и общий итог».
4. Откройте ссылку на черновик из ответа. Проверьте заголовок, разбивку на пять каналов и общий итог **500 кампаний**.

## 5. Опубликовать черновик и открыть его в Studio

1. В том же чате напишите **«Опубликуй Dashboard»**.
2. В запросе подтверждения проверьте имя узла и путь к тестовой копии. Нажмите **«Разрешить один раз»**.
3. Дождитесь сообщения о готовности. В Studio вернитесь к сценарию тестовой копии и выберите узел заново. Если сборка ещё идёт, повторите выбор узла после её завершения.
4. Нажмите **Dashboard**. Проверьте заголовок **«Кампании по каналам»**, итог **500 кампаний** и строку **Email — 109**. Запишите метку **«Версия»** из шапки.

## 6. Изменить опубликованный Dashboard

1. В шапке Dashboard на тестовой копии нажмите **«Изменить в чате»**. Если Desktop не открылся, нажмите **«Открыть чат в Desktop»** в Studio.
2. Отправьте в чат «Поменяй заголовок на “Кампании по каналам — проверка”. Сохрани текущие показатели и разбивку по каналам».
3. Откройте черновик. Проверьте новый заголовок и итог **500 кампаний**.
4. Напишите **«Опубликуй Dashboard»**, проверьте путь к тестовой копии и нажмите **«Разрешить один раз»**.
5. После готовности сборки вернитесь к сценарию, выберите узел и снова нажмите **Dashboard**. Должны появиться новый заголовок и новая метка **«Версия»**. Итог должен остаться **500 кампаний**.

## Результаты прогона

Для каждого кейса отметьте **«Пройден»**, **«Не пройден»** или **«Заблокирован»**. При сбое запишите номер кейса и шага, фактический результат и версии Studio и Desktop. Приложите скриншот места, где результат отличается от ожидаемого.
