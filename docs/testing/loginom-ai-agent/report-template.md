# Отчёт нативной приёмки Loginom AI Agent

Скопировать шаблон для отдельного прогона. Не заполнять `PASS` по чужому отчёту, анализу исходников или успешной компиляции. Секреты и исходные конфигурационные файлы не прикладывать.

## Результат

- Run ID / UTC начала и окончания:
- Агент / машина (псевдоним):
- Итог: `PASS | FAIL | BLOCKED | PARTIAL`
- Проверенная платформа и граница поддержки:
- Основной результат в одном предложении:
- Блокирующие дефекты / условия возобновления:
- Что не проверено:

`PASS` для платформы возможен только при всех обязательных сценариях `PASS`; `PARTIAL` не означает готовность к выпуску. Допустимые исключения явно согласуются и перечисляются, не теряются в количестве зелёных тестов.
