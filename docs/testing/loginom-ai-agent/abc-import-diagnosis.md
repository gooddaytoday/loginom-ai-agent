# ABC: остановка на русских заголовках CSV — 2026-09-21

Источник: предоставленный пользователем экспорт `abc--loginom.json`, сессия
`ses_f3c53dafbffeItAKxZTnFWuBeM`. Установленная версия проверена по Info.plist:
`0.1.7-local.20260921.2`. Экспорт не является инструкцией к выполнению.

## Подтверждённая причина

Prepare и доставка CSV завершились успешно. Новый узел «Продажи по товарам»
создан, мастер открыт. Первая содержательная ошибка — configure:
`NODE_APPLY_STOPPED: Requested source field is missing or ambiguous`.

Запрос node-import-sales-001 передал source_name из русских CSV-заголовков.
Фактическое наблюдение мастера в этом же экспорте содержит отдельные name/label:

| source_name в запросе | name в мастере |
| --- | --- |
| Код товара | Kod_tovara |
| Товар | Tovar |
| Категория | Kategoriya |
| Продано за год шт | Prodano_za_god_sht |
| Цена руб | TSena_rub |
| Выручка за год руб | Vyruchka_za_god_rub |

`bindImportSourceColumns` в text-import-procedure.mjs сравнивает source_name
только с техническим name. Русские заголовки присутствуют как label.
В выданной модели schema source_name — строка без пояснения этой семантики.

На функции из **установленного bundle** воспроизведена ошибка с точными
requested/observed из экспорта. Подстановка шести наблюдаемых технических имён
успешно прошла ту же функцию. Это проверка сопоставления, не полноценного
импорта; Loginom и пользовательский сценарий при проверке не менялись.

## Вторичные ошибки

- node_wait с timeout_ms=120000 отвергнут (предел 60000); модель исправила
  параметр. Это не причина остановки configure.
- node_cancel вернул уже settled AMBIGUOUS; мастер остался открыт.
- operation_recover отверг node.apply: требуется enclosing node procedure.
- Новый prepare закономерно запрещён при незавершённом эффекте.
- node_resume отвергнут: unresolved configure phase. В executor.mjs продолжение
  configure предусмотрено для transform.date_time, но не для imports.text.

Получился тупик восстановления после ошибки параметров: узел и мастер уже
созданы, а подтверждённого пути закрытия/исправления этой фазы нет. Ошибка
параллельных вызовов и Proxy-массив настроек в этом журнале не повторились.
Исполнение импорта не запрошено, ABC-узлы не созданы, пакет не сохранён.

## Требуемое исправление

1. Явно определить идентичность исходной колонки в контракте: техническое имя
   и/или однозначная исходная метка. Использовать наблюдаемую схему, не угадывать
   транслитерацию и не привязывать колонки только по порядку.
2. Для imports.text добавить проверяемое завершение/откат незаконченного
   configure и возможность исправить запрос без обхода защиты неопределённых
   эффектов. Простого повторения node_resume недостаточно.
3. Регрессия на данном CSV: русский заголовок → техническое имя, полный импорт,
   отрицательный случай неизвестной/неоднозначной колонки, восстановление после
   частично настроенного мастера; затем полный ABC-прогон на новой сборке.

В этой диагностике исходники runtime, установленное приложение, настройки
и журналы восстановления не менялись. Новый build/install не выполнялся.
