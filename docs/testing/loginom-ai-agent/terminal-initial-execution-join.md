Selected original initial-execution association

This cut joins the existing five retained currentScript witnesses and their
original SRI receipts to the original host response receipts. It changes only
terminal-script-witness.mjs and terminal-root-association.mjs. It does not change
SRI installation, publisher algorithms, browser login, lender, invocation, packet,
readonly/Close/Save policy or the public protocol.

During the existing fixed realm collection each frozen witness may contain its
original frozen integrityReceipt. The collector checks its exact node, document,
URL and integrity against the witness and requires armedBeforeSource. It also
requires its existing execution/closure/native flags false. This happens inside
the guarded original capsule; recheck retains the same receipt and initializer
refs. JSON contains only metadata, never the node, receipt or defining closure.
No new evaluator, handle acquisition, callback or await is added.

The host, still in bindTerminalScriptWitness, requires original JSHandle custody
before admitting any integrity metadata. All five rows must carry the full
integrity/armedBeforeSource/initialExecutionObserved tuple. Each integrity must be
the canonical sha256-base64 of the exact previously verified response receipt,
joined by the full request URL and fixed canonical pin URL. Any partial metadata,
wrong hash/URL/observed marker, accessor or metadata without an original handle
refuses. Entirely absent metadata keeps the prior evidence-only path, with
selectedInitialExecutionJoined=false and ORIGINAL_SRI_RECEIPTS_UNAVAILABLE.
It does not repair missing SRI or adopt a late API.

The successful bounded fact is selectedInitialExecutionJoined=true: five original
execution events, original SRI node receipts, guarded original capsule/handle and
host response receipts are associated. It is not whole-load or lexical
qualification. All sourceExecutionQualified, closureIdentityQualified,
sourceBytesVerified, nativeReceiver and terminal authority predicates stay false.
H0 remains INVOCATION_UNAVAILABLE. An armed receipt alone, including one for a
blocked resource, cannot set this fact: original publisher/initializer/capsule
custody and the corresponding host response receipt are also required.

IIFEs. Real selected browser requests/frame and original fulfill tasks pass through
