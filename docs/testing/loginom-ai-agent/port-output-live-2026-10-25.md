## Модельные результаты

- Low-liquidity, candidate и baseline: независимые 35×5 значений и итоговый CSV совпали;
  нормальная очистка подтверждена. Cold проверил все пять типов узлов. После активации
  сохранённый Reform с autosync=true меняет физический порядок в обеих версиях;
  причина отдельно не установлена.
- Z-score, обе версии: независимый эталон рассчитан по всем 500 исходным строкам;
  доставленные модели prefix/агрегаты, итоговая confusion matrix и CSV совпали,
  очистка подтверждена. Модели построили графы без Join/Filter;
  эти типы дополнительно проверены отдельным управляемым графом.
- Sliding refresh: candidate прочитал новые значения того же источника/узла с новым
  execution, старые значения исчезли. Initial native full и оба ordinary чтения проверены;
  updated native full отсутствует. Baseline остановился на prepare, native cleanup BLOCKED,
  guard удерживается, пакет не идентифицирован; сравнение скорости невозможно.
- Multi-facts: ошибка модели — выдуманный путь skill, затем отказ обычной политики
  доступа к внешней директории. Draft создан, Save и native cleanup не подтверждены.
- Cartesian: ordinary значения, NULL отсутствующих комбинаций и CSV верны. Native full
  обоснованно отказал из-за неподдерживаемого Sort ancestry; агент сообщил ограничение.
- String counts: ordinary, native Int64 и CSV верны. В исходной фикстуре нет пустой
  строки, поэтому blank-семантика агрегата этим сценарием не проверена.
- Две draft CSV-задачи: все значения, CP1251, ведущие нули, CRLF, кавычки,
  Unicode, NULL/blank/zero сохранены. Date получил вид «Непрерывный» вместо
  «Дискретный» из draft SPEC. Это выбор настройки модели; reader передал её точно.
- Linear Regression: настоящий узел, оба выхода, независимые коэффициенты 3 и 2,
  RSS=8 и ненулевые остатки подтверждены; максимальная погрешность около 7,1e−15.
  Cold подтвердил Import и параметры/роли регрессии; сама регрессия не обучалась
  заново. Два её output mapping отдельно не подтверждены.
- K-means: настоящий узел с seed=42, оба выхода, независимое разбиение с точностью
  до перестановки номеров, центры −9,5/+9,5, расстояния 0,5 подтверждены.
  При cold найдено расхождение порядка output-definition UI Import до его Execute:
  warm [X, RowID], cold [RowID, X]. Физический cold порт не прочитан.
  Причина и связь с reader не установлены; baseline k-means не проверялся.
- REST: initial 200/503 и оба выхода верны; ровно два HTTP-запроса при исполнении,
  ни одного при чтении. Явный reread отказал до исполнения: generic admission требует
  receipt IDs, которые REST readback не создаёт. Соответствующий код совпадает с baseline;
  живой REST-прогон на baseline не проводился.
- JavaScript: 39 значений, physical order, full/sample и сохранность 285 байтов кода
  подтверждены. Модель получила полный source только после sample; требуемого полного
  source до sample нет. Исключение средней колонки проверено на входе, не в output mapping JS.
- Fidelity Luna и Sol: доставленная модели совокупность ответов покрыла все 45 исходных
  ячеек, включая Int64 min/max, 2^53±1, real, −0, JSON и полный текст 20 000 символов.

- Preview Luna: агрегаты ledger по всем 137 строкам подтверждены. Последняя строка
  и результаты wide не подтверждены; явный full refusal не запрашивался. Агент честно

- Preview Sol: независимая проверка всех 229 доставленных ячеек и итоговых утверждений

Все 21 назначенные модельные попытки завершены. Это не 21 PASS: ошибки задач,

## Оставшиеся ограничения

Превышение10000 ячеек, NaN/±Infinity, Int64 внутри Variant, unknown Variant,

Native foreign binding и inactive output
нельзя детерминированно вызвать через текущий публичный read API: он сам выбирает
binding и исполняет узел до чтения. Эти внутренние guards не будут объявлены проверенными
живьём по отказу неверного номера порта или пустому результату.
