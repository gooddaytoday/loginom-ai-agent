Комментарий о работе LAB-68, опубликованный в LAB-66, запустил Манки именно в LAB-66. Аналогично задание продолжить source LAB-67 из комментария LAB-69 запустило Манки в LAB-69. Регистратура получила адресные дополнения; уже запущенный разбор сохраняется, второго исполнителя в источнике назначать нельзя. Новые механизмы и изменения клиента не использовались.
