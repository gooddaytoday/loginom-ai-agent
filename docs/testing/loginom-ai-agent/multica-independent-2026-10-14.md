Старые отчёты обозначены историческими. Удалённые инструменты доступны в Git-истории, но не являются действующей инструкцией.

Остаток: публикация и API readback инструкций, удаление Регистратуры из сквада, актуализация checkpoints, реальные независимые продолжения, проверка одной передачи между ролями и удаление неиспользуемых установленных наборов. Полная приёмка узлов не заявлена.
