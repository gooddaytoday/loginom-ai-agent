Навигация на последней и первой странице сохраняет клавиатурный фокус.

## Офлайн-архив

В M6 проверен исходный список файлов производителя. Руководства в нём не было. В M7 [руководство администратора](../../../packages/dashboard/deploy/README.md) добавлено в общий список для копирования и расчёта `SHA256SUMS`. Проверены синтаксис семи примеров команд и ссылки руководства пользователя.

Оператор собирает архив на хосте штатной командой `bun run build:release --out <каталог>`. Входы сборки из репозитория и локально собранные `server.mjs` и `shell.js` совпадают с кандидатом. От оператора ожидаются SHA-256 архива, результат побайтной сверки README с исходным после распаковки с сохранением режимов и результат проверки всех записей `SHA256SUMS`, включая README.

## Самостоятельный пользовательский проход

Фактический установленный прогон ожидает подтверждения оператором поддерживаемого стенда, тестового автора с правом публикации и Desktop с обновлённым навыком. Манифест ресурсов обнаруженного Desktop 0.3.9 не содержит `loginom-dashboard/SKILL.md`. Перед стартом на выбранном Desktop требуется проверка целостности поставки навыков и побайтная сверка навыка M7.

Из `dashboard/fixture/dataset.csv` независимо посчитаны **500 кампаний, Email — 109** при `MinBudget=0`. На чистой копии учебного пакета автор должен самостоятельно пройти [руководство пользователя](../../../dashboard/README.md), создать dashboard в Desktop, открыть черновик, явно подтвердить публикацию, затем открыть её в Studio. В установленном прогоне остаётся сверить 500 и Email 109 с «Данными узла», сопоставить метку UTC с готовой публикацией и зафиксировать, понадобились ли подсказки. В результат прогона внести версию и режим Studio, тип и версию Desktop и артефакт сервера или SHA для dev master.

Установленная проверка живой таблицы с закрытием пакета и выходом из Studio и отдельная проверка strict HTTPS относятся к [бэклогу M6](../../superpowers/specs/2026-11-16-dashboard-m6-design.md#backlog-установленной-приёмки).
