## Причина выпуска

На macOS Desktop v0.3.0 узел JavaScript не настраивался (владелец, 3/3): `NODE_APPLY_STOPPED: Managed source full selection unconfirmed`.
Писатели исходника JavaScript нажимали `Control+A`, а на macOS это сдвиг курсора, а не выделение. #264 заменил клавишу на
`ControlOrMeta+A`, как в остальных редакторах runtime. Все хосты сквадов и CI работают на Linux, поэтому класс не был пойман.
