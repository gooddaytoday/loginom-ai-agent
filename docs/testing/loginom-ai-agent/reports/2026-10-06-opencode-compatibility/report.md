# OpenCode compatibility — локальный macOS кандидат

Приёмка через окно Dev-клиента: PASS. Два сообщения в одном постоянном чате получили завершённые ответы `FREE-OK` от `opencode/ling-3.1-flash-free`. Требование OpenCode 1.18.0 отсутствовало. Первый ответ прошёл штатные повторы после временной недоступности upstream; модель не переключалась.

- База: `f6f9b0106fb3f455e581df3ee7ccb2e13f64d1f3`; ветка `opencode-compatibility`.
- Коммит исходников кандидата: `108aa93fcce94f354251f44e3d16827b939d33a4`, чистое дерево при сборке. Последующий коммит отчёта не входит в бинарник.

- Значение приложения — `User-Agent: opencode/1.18.31`. На транспортном уровне SDK добавляет прежний суффикс `ai-sdk/provider-utils/4.0.23 runtime/bun/1.3.14`; проверен первый токен реально отправленного заголовка. Буквально весь транспортный заголовок не равен одному этому токену.
- Приоритет сохранён: настройки модели, затем `chat.headers` плагина. Остальные провайдеры, API и зависимости не менялись.

## Реальный провайдер и окно кандидата

Обычный клиент в двух изолированных профилях отправил одинаковый пользовательский запрос одной модели с одинаковой публичной авторизацией, менялся первый токен User-Agent: `opencode/0.1.16` получил HTTP426 с исходной ошибкой версии, `opencode/1.18.31` — HTTP429 `Endpoint is unavailable`. Служебные идентификаторы сессий различались. Это подтвердило снятие проверки версии, но само по себе не доказало успешный ответ. Неполный прямой HTTP-запрос получал HTTP403 с обеими версиями и не использован как приёмка.

Затем через окно собранного кандидата выбран именно `Ling 3.1 Flash Free`. Отправлены `Ответь ровно FREE-OK. Не используй инструменты.` и уточнение `Повтори своё предыдущее сообщение точно, без пояснений и без инструментов.`. В UI видны два ответа `FREE-OK`; независимое чтение постоянной БД подтвердило два assistant messages с `finish: stop`, временем завершения, нужными provider/model и без конечной ошибки. Сессия: `ses_eefa4b428ffemVyQviJgOYNpPs`.

Журналы подтвердили `packaged: true`, `onboardingTest: false`, версию `0.1.17-opencode.1`, обычный sidecar `v1` и обе основные генерации этой модели. Процесс запущен из каталога кандидата. Использован отдельный постоянный профиль `com.loginom.aiagent.dev`; существующие данные профиля сохранены. Начальный запуск задержался при чтении macOS Keychain; системный защищённый диалог был передан пользователю, автоматизация этого диалога не выполнялась. Последующий запуск был успешен.
