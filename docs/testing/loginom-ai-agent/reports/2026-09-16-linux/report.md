## Ограничения

- Windows/macOS не собирались и не запускались здесь; [нативные инструкции](../../README.md) подготовлены.
- Не проверены физический GPU, desktop portals и AppArmor реальной Ubuntu 24+; контейнеры не заменяют эти проверки.
- Собственный публичный канал обновлений и подпись не настроены. Локальная проверка обновления не включает публикацию.
- Для холодного существующего Grouping вызов apply с пустыми параметрами имеет известный timeout на input mapping. Проверенное открытие и выполнение сохранённого графа не переопределяет настройки.
- В Linux ключи хранятся открыто в приватных файлах согласно принятому решению. Переданный тестовый API-ключ отсутствует в архиве исходников и packaged files ([скан](secret-scan.json)).
- Старые OpenCode wrapper/desktop и исходный репозиторий Dock не удалялись. CI workflow подготовлен, но удалённый CI в этой задаче не запускался.
