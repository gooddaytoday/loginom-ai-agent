# Охота на баги 0.4.x и выпуск 0.4.1

23–24 ноября 2026 года. Linux (mas, mas2, mas3), сервер app.loginom.ai (с 23.11 во внешнем контуре), модель агента `opencode-go/deepseek-v4.1-flash`. Набор сценариев — [`bughunt-2026-11`](../bughunt-2026-11/README.md), отдельно от `evals/`; раннер — `scripts/node-acceptance/run-check.py` с `RUN_CHECK_MODEL`/`RUN_CHECK_AUTH` и приватными `--cases`.

Итоговая голова выпуска: `041@ab29a8a0`, тег `v0.4.1` на коммите версии `2eb327b3`.

## Набор

39 кейсов в трёх пакетах, у каждого независимый `oracle.py` и бюджет действий в `case.json`:

- **A — импорт:** CSV формы #1250 (BOM, `;`, кавычки, 3 400 × 33), cp1251 TSV, UTF-16 `|` без заголовка, преамбула и многострочные поля, 17 МБ, 400 столбцов, XLSX (второй лист, двухстрочный заголовок, предел 64 столбца), CSV + XLSX, 7 CSV разом, SQLite, LGD, JSON-файл, XML и XLS (честный отказ).
- **B — REST, JavaScript, Python:** GET/POST, коды 404/500 с описаниями, имитация ответа, тайм-аут, продолжение со сменой параметра, JS с входом и без входа, исключение JS, pandas, stdlib, запрет файлов и сети в Python.
- **C — правка и сквозные:** продолжения в том же чате (вставка фильтра, узел в конец и Excel, смена агрегатов, удаление узла), приложенный `.lgp`, JS без входа в пакете, переменные, сквозной сценарий из 7 узлов, подмодели и Условие, качество данных, «только загрузи файл».

Аудит лишних действий — `scripts/node-acceptance/bughunt-audit.py`.

- до 88 вызовов bash с чтением исходников runtime на сборке 0.4.0;
- чтение внутренних журналов diagnostics ради ID;
- локальные пересчёты итогов;

- чтение файлов вне рабочего каталога, включая приватные ожидания проверки (#1291).

#1274 убрал часть из них (предел Excel называется до узла, чтение исходников сократилось), но локальные пересчёты и `sleep` в финальной проверке остались.
