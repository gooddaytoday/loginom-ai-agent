## Дефекты и открытые пункты

- **D1 / Windows: `Plugin activation timed out` при первом холодном запуске.** Класс desktop/UI. Артефакт `aa3641ea…c2f5`. Воспроизводимость 1 из 2 прогонов на чистом
  профиле. Следующий шаг: несколько повторов `smoke` или диагностика.
- **D2 / REST: `REST_PACKAGE_NORMALIZATION_STILL_MODIFIED`.** Класс executor/session. Проверяющий, rest-get-plain: пакет остаётся изменённым после единственного дополнительного Save, модель
  отчиталась «сохранён». 1 из 3 прогонов проверяющего, исполнитель 2/2. Не разобран.
- **D3 / стенд: `research.auto_correlation` не проходит фазу `target`; `dock_storage_list` → `STORAGE_SOURCE_REFUSED`.** Класс Loginom/data или окружение. Воспроизводится пробой
  без модели и на v2, и целиком на `v0.4.2` — не регрессия переноса; стенд или окружение машины — не разделено.
- **D4 / exports-excel: `Export file read did not return to its workflow`.** Класс executor/session или стенд. 1 из 2 у исполнителя, пробой не воспроизведён — причина открыта.
- **Модель DeepSeek flash** — 11 отказов: встроенные `read`/`glob` по нелокальным путям и несуществующий инструмент (`CLI_TOOL_FAILED` по контракту 0.4.2), неверное прочтение
  задания. Не дефект переноса.

## Передача результата

- Голова `oc2-migration` — `152c7cdaac` и этот отчёт; незакоммиченного нет.
- Доказательства без секретов — каталог доказательств вне репозитория (`b61a`, `b61e`, `b62b`, `b62c`, `b62f`); прогоны узлов — в домашнем каталоге `lrun`.
- Решения владельца: (1) критерий проверяющего — один PASS или 2 из 3; при «2 из 3» нужны ещё 15–30 прогонов проверяющего и новая серия s3; (2) повтор серий для 5 узлов или
  зачесть как есть; (3) версия продукта до тега — смена `packages/desktop/package.json` меняет `packages`, и по RUNBOOK п. 7 узлы и B6.2-F придётся повторить на новом SHA.
- Ограничения стенда и модели отделены от дефектов платформы (D3, модель).
- Приёмка доказательств B6.2-F оркестратором — по первичным файлам: `g/results.json` (15 мутаций `red -> green`, счётчики после отката равны базе), отчёты smoke Windows (`smoke-192651` 42/42, `smoke-191453` 41/42 — `no-error-lines`), снимки уборки (различаются только время и свободное место, место вернулось — 54,3 ГБ), `sha256sum -c` артефактов Linux и сверка хешей Windows на стенде с `ci-summary.json`; `C:\lab\b62c`, временная учётная запись и процессы из папки на стенде отсутствуют (проверено вживую).
- На стенде app.loginom.ai прогоны оставили пакеты и CSV в папках `/agent2`, `/agent3`, `/agent4`; ничего не удалялось.
- В отчёте нет ключей, паролей, cookie, токенов и дампов профилей браузера.
