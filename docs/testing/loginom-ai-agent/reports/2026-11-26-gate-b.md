## Дефекты и открытые пункты

- **D1 / Windows: ошибки плагинов при первом запуске Desktop на чистом профиле.** Класс desktop/UI. Артефакт `aa3641ea…c2f5`. 5 из 12 запусков: `Plugin activation timed out`
  (`packages/app/src/runtime/plugin/host.tsx:133`, предел 30 с; после него `debug`, `file`, `review`, `browser`, `updater` выключены до перезапуска окна — по коду) — 1;
  Ipc `debug.memory`, `debug.heap`, `updater` `did not answer the subscribe` (`ipc.ts:29`, предел 10 с; восстановление в том же окне не подтверждено) — 4. Таймаут активации
  согласуется с холодным стартом службы 28–29 с, который был только в первом прогоне после доставки установщика (гипотеза — проверка нового бинаря Defender, не проверялась);
  причина Ipc-ошибки не установлена. Продукт не правился.
- **D2 / REST: `REST_PACKAGE_NORMALIZATION_STILL_MODIFIED`.** Класс executor/session. Проверяющий, rest-get-plain: пакет остаётся изменённым после единственного дополнительного Save, модель
  отчиталась «сохранён». 1 из 3 прогонов проверяющего, исполнитель 2/2. Не разобран.
- **D3 / стенд: `research.auto_correlation` не проходит фазу `target`; `dock_storage_list` → `STORAGE_SOURCE_REFUSED`.** Класс Loginom/data или окружение. Воспроизводится пробой
  без модели и на v2, и целиком на `v0.4.2` — не регрессия переноса; стенд или окружение машины — не разделено.
- **D4 / exports-excel.** Первая серия: `Export file read did not return to its workflow` (1 из 2, пробой не воспроизведён). Новая серия (0/2): оба раза `STORAGE_SOURCE_REFUSED`
  (`navigation_unconfirmed`) — тот же отказ, что в D3 и на `v0.4.2` (стенд или окружение машины — не разделено), — затем модель взяла встроенный `read`/`glob` → `CLI_TOOL_FAILED`. «Did not return» не повторилось, причина открыта.
- **D5 / холодное чтение сохранённого пакета в новом браузере.** Класс executor/session или стенд. Новая серия: c1-3 partition-random (`Observed control geometry changed`, `NOT_APPLIED`),
  c2-3 sampling-random (`NodeReadinessTimeout: native execution control for selected node`); модель, CSV, Save, port-read и оракул — PASS. Клиент `loginom-runtime` (`node-procedure.mjs`). Не разобран.
- **Модель DeepSeek flash** — 11 отказов первой серии и 2 новой (ещё 2 новой — после отказа Loginom в разделе файлов): встроенные `read`/`glob` по нелокальным путям и несуществующий инструмент
  (`CLI_TOOL_FAILED` по контракту 0.4.2), неверное прочтение задания. Не дефект переноса.
