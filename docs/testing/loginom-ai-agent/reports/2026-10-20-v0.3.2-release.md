## Известные ограничения

- Чтение и замена существующего узла JavaScript в переоткрытом пакете могут остановиться (`source admission refused: boundary`).
- Соединение, где выход JavaScript — второй вход, изредка останавливается на захвате превью-порта (`Managed preview native port changed`).
- Переподключение входа существующего Экспорта не поддержано (модель добавляет второй Экспорт).
- Ошибка страницы Loginom `reading 'Items'` в мастере импорта (стенд, редко).
- Живая проверка на macOS и Windows Desktop — за владельцем и тестировщиками; сквады работают на Linux.
