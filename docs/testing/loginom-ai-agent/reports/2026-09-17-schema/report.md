# Исправление схемы инструментов ChatGPT — 17 сентября 2026

Установленный DEB обновлён до **0.1.2**. Исходники: `16990dd2d465d982cd6fd8b36b6ccff9836207a8`. Текущий пользовательский сеанс не завершался принудительно; для загрузки исправления приложение необходимо полностью перезапустить.

## Причина

Преобразование схемы `loginom_dock_ui_action` в формат OpenAI превращало массив-константу допустимых этапов в enum с ошибочным типом string. Исправления только типа недостаточно: API также отвергает массив внутри enum. Исходная схема Dock является допустимой JSON Schema; ошибка находится на границе совместимости с провайдером.

В контролируемых запросах старая схема воспроизвела 400 с исходной ошибкой пользователя. Вариант без array enum получил 200 и завершённый ответ. Замена oneOf на anyOf сама по себе не устранила отказ.

## Изменение

Типы const/enum определяются по значениям. Для массива формируется items и, если применимо, фиксированная длина; точные составные варианты передаются в описании. Оригинальная схема Dock не изменяется. Настоящий `validateUiAction` по-прежнему отклоняет неправильное значение или порядок этапов.
