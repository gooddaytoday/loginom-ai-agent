## Диагностика Windows

Отдельная ветка `windows-proxy-diag`, commit `91369bfab2`,
[run38866284961](https://github.com/gooddaytoday/loginom-ai-agent/actions/runs/38866284961).
Диагностика оставила все assertions и timeouts, добавив удержание trap-соединения
до чтения Windows TCP owner. Оба CRL GET имеют User-Agent `Microsoft-CryptoAPI/10.0`;
владелец client-side socket — `C:\Windows\system32\svchost.exe`,
command line `-k NetworkService -p -s CryptSvc`, parent `services.exe`.

а действующий gate всё равно завершается FAIL. Product/runtime не менялись.
