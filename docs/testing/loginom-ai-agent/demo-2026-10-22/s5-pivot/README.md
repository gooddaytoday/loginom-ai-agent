# s5-pivot

15 продаж, все 9 пар регион × категория представлены. Итог 3 строки и 4 поля: Region/Office/Warehouse/Tech. Выручка 180847.50. Офис → Office, Склад → Warehouse, Техника → Tech. Сумма, без итогов и дополнительных категорий. После Кросс-таблицы «Параметры полей» задают имена, подписи, порядок и числовые типы; expected читает этот последний выход. Это осознанное дополнение цепочки из карточки, позволяющее не привязывать просьбу к внутренним C_*-именам. Основа: crosstable-fixed-sum; данные новые.

`python3 -B oracle.py` печатает эталонный JSON в stdout; необязательный первый аргумент — личный путь пакета с расширением `.lgp`. Правила изоляции входов и версия cold-check описаны в [общем README](../README.md). Модельного прогона в D1 не было.
