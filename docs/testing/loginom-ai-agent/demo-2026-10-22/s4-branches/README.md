# s4-branches

Три входа одинаковой схемы, всего 19 строк, итог 6 групп на 203009.00. Две одинаковые строки central.csv по 2520.00 означают две продажи; удаление повторов даст неверный результат. Возвраты отрицательны. Выход Сортировки: Branch/Category/Revenue. Новые данные.

`python3 -B oracle.py` печатает эталонный JSON в stdout; необязательный первый аргумент — личный путь пакета с расширением `.lgp`. Правила изоляции входов и версия cold-check описаны в [общем README](../README.md). Модельного прогона в D1 не было.
