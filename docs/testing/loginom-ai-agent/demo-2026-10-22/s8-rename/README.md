# s8-rename

Продолжение s1 в том же чате и открытом пакете: заменить имена и подписи полей
Region → Регион, Category → Категория, Revenue → Выручка, выгрузить revenue-ru.csv.
Итог — те же 6 строк и сумма 216781.00, порядок и числовые типы s1 сохранены.
Последний выход проверяется на «Параметрах полей» (`transform.reform_columns`).

1. Выполнить s1 с `prompt.md` и `expected.json` либо с парой
   `prompt-demo.md` / `expected-demo.json` для R1, сохранить пакет.
2. В том же сеансе отправить только `s8-rename/prompt.md`; исходный CSV повторно
   не прикладывать. Переименовать существующий отчёт, сохранить обновлённый пакет.
3. Для проверки обновлённого пакета использовать `s8-rename/expected.json`
   с фактическим личным `package_path`. Ожидания s1 после переименования неприменимы.

`data/sales.csv` побайтно совпадает с s1; копия нужна автономному oracle.
`python3 -B oracle.py` воспроизводит `expected.json` в stdout; необязательный
первый аргумент меняет только путь пакета. Oracle самостоятельно считает выручку
из CSV-байтов, а не читает ожидания или результат s1. Модельных прогонов не было.

s1 → s8 и s1 → s7 — отдельные продолжения исходного s1. После s7 остаётся только
Север; для полного шестистрочного s8 нужен исходный s1, до фильтра s7.
