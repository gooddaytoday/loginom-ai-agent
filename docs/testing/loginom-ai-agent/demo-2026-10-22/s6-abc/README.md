# s6-abc

12 товаров, общая выручка 100000.00. На границе 80% товар остаётся в A, на границе 95% — в B. A: 3 товара / 80000.00, B: 2 / 15000.00, C: 7 / 5000.00. Два нулевых товара входят в C. Классификация по доле после включения текущего товара; denominator рассчитывается из входа. Выход Группировки: ABCClass/Products/Revenue. Основа: abc-pareto-groups; компактные новые данные.

`python3 -B oracle.py` печатает эталонный JSON в stdout; необязательный первый аргумент — личный путь пакета с расширением `.lgp`. Правила изоляции входов и версия cold-check описаны в [общем README](../README.md). Модельного прогона в D1 не было.
