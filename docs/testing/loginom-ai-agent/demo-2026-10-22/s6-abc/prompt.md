В products.csv — выручка товаров за квартал. Подготовь ABC-анализ в Loginom: расположи товары по убыванию Revenue, при равенстве — по ProductID по возрастанию.
Для каждого товара накопленная доля — выручка этого и всех предыдущих товаров, делённая на общую выручку из файла.
Класс A: доля ≤ 80%, B: > 80% и ≤ 95%, C: > 95%; товар, пересекающий границу, относится к следующему классу. Товары без продаж тоже учитывай.
Для каждого класса нужны число товаров и суммарная выручка. Итоговые поля: ABCClass (текст), Products (целое), Revenue (число с дробной частью), в этом порядке; имена и подписи одинаковые.
Выгрузи abc.csv и сохрани выполненный сценарий. Порядок классов произвольный.
