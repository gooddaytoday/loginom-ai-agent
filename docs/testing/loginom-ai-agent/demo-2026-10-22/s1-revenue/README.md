# s1-revenue

Продажи 20 строк; 6 групп. Возвраты уменьшают сумму. Общая выручка 216781.00. Выход проверяется на Сортировке, поля Region/Category/Revenue; все группы и убывание выручки обязательны. Основа: FLOW-01 и sales-by-category.

`python3 -B oracle.py` печатает эталонный JSON в stdout; необязательный первый аргумент — личный путь пакета с расширением `.lgp`. Правила изоляции входов и версия cold-check описаны в [общем README](../README.md). Модельного прогона в D1 не было.
