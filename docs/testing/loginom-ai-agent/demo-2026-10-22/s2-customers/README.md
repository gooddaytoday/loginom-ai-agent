# s2-customers

12 клиентов, 8 активных. Коды содержат пробелы, разный регистр и пропущенный дефис. Полное отображение нестандартных кодов дано в просьбе. Нулевой лимит активного клиента сохраняется. Выход Фильтра: Code/Name/CreditLimit/Status, исходный порядок. Основа: идеи очистки articles-by-author и типов inventory-by-category; данные новые.

`python3 -B oracle.py` печатает эталонный JSON в stdout; необязательный первый аргумент — личный путь пакета с расширением `.lgp`. Правила изоляции входов и версия cold-check описаны в [общем README](../README.md). Модельного прогона в D1 не было.
