# s7-refine

Резерв: выполнить после успешного s1 в том же чате и пакете. Существующий отчёт ограничивается Севером; результат 2 строки, 54400.00 и 6182.00, сумма 60582.00. data/sales.csv побайтно совпадает с s1 и нужен автономному oracle; повторная загрузка не нужна. expected относится к обновлённому пакету и проверяет выход Фильтра после уже существующей Сортировки; экспорт переподключается к отфильтрованному отчёту.

`python3 -B oracle.py` печатает эталонный JSON в stdout; необязательный первый аргумент — личный путь пакета с расширением `.lgp`. Правила изоляции входов и версия cold-check описаны в [общем README](../README.md). Модельного прогона в D1 не было.
