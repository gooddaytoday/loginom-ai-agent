# Завершение параллельной обработки восьми узлов

## Принятая граница

09.10.2026 владелец поручил завершить работу существующего сквада Multica с восемью одновременными обработками. Полная приёмка всех восьми узлов отделена от готовности оркестрации. Сценарий или воспроизводимый дефект — результат диагностической обработки; PASS узла требует прежней полной приёмки подплана.

Используются LAB-45–LAB-52 и общая LAB-53 / draft PR44; роли Генератор → Исполнитель → Ревьюер последовательны внутри карточки. Между карточками нет общего барьера готовности. Caps 8/8/8, daemon12, штатный интервал3m; тест12 не требуется. Модели задаются действующими инструкциями сквада. Eval, LAB-29/30, общие очереди и OAuth не изменяются; слияние, выпуск и расписания не входят в работу.

## Реализация

- Общий admin flock сохраняется; первоначальная подготовка восьми card-admin последовательная, последующая подготовка карточек — с отдельными admin.
- Подтверждённые accounts переиспользуются; LAB-50/51 получают новые private identities с сохранением прежней UNKNOWN истории.
- Account bindings и текущий авторизованный observer задаются проверяемой конфигурацией, без нового source patch при смене settings. Ownership и непрерывность observer внутри операции сохраняются.
- Старая LAB-47 сверяется по текущему состоянию; неизвестные исторические факты не подменяются предположениями.
- После независимого source review требуется live bootstrap/migration/pair qualification, затем закрепление рабочего helper и запуск тех же восьми карточек.
