Нужна сводка серьёзных простоев по командам из incidents.csv. Поля файла: IncidentID, Team, Severity, Minutes. Учитывай только записи с Severity = critical и длительностью Minutes не меньше 30; Minutes — целое число. Для каждой команды, у которой есть такие записи, посчитай количество инцидентов Incidents и суммарную длительность Downtime. В downtime.csv выведи Team (текст), Incidents (целое), Downtime (целое), именно в этом порядке. Порядок строк — по убыванию Downtime, при равенстве — по Team по возрастанию. Сохрани сценарий.
