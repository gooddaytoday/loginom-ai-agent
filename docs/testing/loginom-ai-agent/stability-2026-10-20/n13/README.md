## Прокат по месяцам

Модели: только `prompt.md` и `data/` (rentals.csv). Этот README,
oracle и expected модели не передавать.

Покрытие оператора: Кросс-таблица. Выход: `rentals-summary.csv`.
121 строка; одна пара Shop × Month отсутствует, остальные повторяются 11 раз. Проверяются сумма, ноль вместо отсутствующего месяца и порядок колонок.

Синтетические данные воспроизводятся `../acceptance/n13-n20/generate.py`,
seed **20261013**. Python 3, стандартная библиотека; меньше 2000 строк.
CSV: UTF-8, запятая, заголовок, точка в числах; пустое поле — пропуск.
Oracle принимает также UTF-8 BOM и разделитель `;` или TAB, числовую десятичную запятую.
Строки, колонки и пустые значения проверяются по просьбе; числовые значения конечны.
CSV не содержит метаданных типов Loginom и не доказывает создание/сохранение пакета.

Проверка фактического CSV экспорта (эталон хранится в `expected/`):

```sh
python3 docs/testing/loginom-ai-agent/stability-2026-10-20/n13/oracle.py /path/to/rentals-summary.csv
```

Код 0 и `PASS` — принят; код ненулевой и `FAIL` — отклонён.
Расчёт независим от продукта, pandas, генератора и файлов expected.
Эталон и отрицательный контроль: `../acceptance/n13-n20/reference.py` (pandas + numpy),
команды и границы статической приёмки — в [подплане](../n13-n20-plan.md).
