## Режимы стендовых испытаний

Модели: [prompt.md](prompt.md), [bench.csv](data/bench.csv).
Оператору: [generate.py](generate.py), [oracle.py](oracle.py), [expected-demo.json](expected-demo.json).
Ожидаемое сочетание: импорт → Кластеризация → Группировка/средние → экспорт `bench-groups.csv`.
Идентификатор RowID — integer; Load, Heat, Vibration — real, единицы описаны в просьбе.
Генератор `generate.py`, seed **81022**, создаёт 21 строк и перемешивает их.
Доли-четверти точны в binary64. Все признаки используются в исходном масштабе,
без нормирования, число групп — **3**.

Oracle восстанавливает облака по самым большим разрывам первой координаты,
затем независимо проверяет евклидову разделимость всех пар точек и ближайшие центры.
Не использует центры/размеры из генератора, метки кластеров или результаты обучения.
Минимальное квадратное межгрупповое расстояние должно превышать максимальный
квадратный диаметр группы более чем в 100 раз. Итог содержит 3 строки;
размеры групп: 5, 7, 9, всего 21 точек.
`Points` — integer, затем MeanLoad, MeanHeat, MeanVibration — real; порядок колонок точный,
имена равны подписям. Порядок строк свободный (`ordered: false`). Группы сравниваются
как набор (размер, средние), без номеров кластеров. Для всех средних абсолютный
допуск 1e-8, относительный 1e-10; действует `max(abs, rel × |expected|)`.
Точные средние рассчитываются `Fraction`, округление в CSV результата не требуется.

CSV: UTF-8 без BOM, LF, заголовок, запятая, точка в числах; пропусков нет.
Данные полностью синтетические, без персональных данных. Модели передавать только
просьбу и входной CSV; oracle, expected и README остаются у оператора.

Воспроизведение из корня репозитория (Python 3, стандартная библиотека):

```sh
D7_CASE=docs/testing/loginom-ai-agent/stability-2026-10-20/n8
python3 -B "$D7_CASE/generate.py"
python3 -B "$D7_CASE/oracle.py" > ./d7-rebuilt.json
cmp "$D7_CASE/expected-demo.json" ./d7-rebuilt.json
D7_ABS=$(realpath "$D7_CASE")
(cd / && python3 -B "$D7_ABS/oracle.py") > ./d7-other-cwd.json
cmp "$D7_CASE/expected-demo.json" ./d7-other-cwd.json
python3 -B "$D7_CASE/oracle.py" '/<username>/d7-n8-<run-id>.lgp' > ./d7-run-expected.json
```

Один позиционный аргумент меняет только `package_path`; по умолчанию используется
пример `/stability-2026-10-20/n8.lgp`. Oracle читает только CSV относительно
`__file__`, не генератор, expected, результаты Loginom или сеть. Проверка формата
через `parseExpectedOutputs` и правила будущего прогона — в [общем README](../README.md).
Временные JSON не коммитить. `nodes` проверяет наличие основных типов, не топологию.
`export_input` проверяет таблицу перед экспортом, а не байты файла или факт сохранения.
Статический расчёт не подтверждает выполнение, экспорт, сохранение или cold-check.
