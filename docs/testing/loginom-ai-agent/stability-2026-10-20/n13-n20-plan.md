## 3. Воспроизведение

Из корня checkout, Python 3; reference требует pandas и numpy:

```sh
python3 docs/testing/loginom-ai-agent/stability-2026-10-20/acceptance/n13-n20/generate.py
python3 docs/testing/loginom-ai-agent/stability-2026-10-20/acceptance/n13-n20/reference.py --write-expected
python3 docs/testing/loginom-ai-agent/stability-2026-10-20/acceptance/n13-n20/reference.py
```

`--write-expected` — явное обновление эталонов. Обычный запуск эталоны не меняет,
строит независимые ответы во временном каталоге, запускает каждый oracle на них
и на испорченных CSV. Запуск из другого cwd допустим. Oracle не читает expected,
reference, генератор, сеть или код продукта. Для реального экспорта:
`python3 .../n13/oracle.py /path/to/rentals-summary.csv` (аналогично n14–n20).
