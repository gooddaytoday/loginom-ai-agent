## q5: Итого по категориям

Продолжение [s4-branches](../../../demo-2026-10-22/s4-branches/prompt-demo.md)
в том же чате и сохранённом пакете. Отправить только [prompt.md](prompt.md),
исходные CSV повторно не прикладывать. Это отдельная ветвь от исходного результата,
а не продолжение предыдущего q. Порядок запуска и подстановка личных путей —
в [общей инструкции](../README.md).

Что меняется: Дополнительный итог: сложить филиалы внутри Category, оставить Category и Revenue, сортировать по убыванию Revenue.

Исходные CSV: [central.csv](../../../demo-2026-10-22/s4-branches/data/central.csv), [north.csv](../../../demo-2026-10-22/s4-branches/data/north.csv), [south.csv](../../../demo-2026-10-22/s4-branches/data/south.csv). Oracle самостоятельно пересчитывает исходный сценарий
из этих файлов, затем применяет продолжение; он не читает expected, другие oracle
или результат Loginom. Полный итог — 2 строк в [expected-demo.json](expected-demo.json).
`column_order: exact` фиксирует порядок колонок из просьбы; `ordered: true`
задаёт проверку порядка строк. Типы и подписи остальных колонок — как в исходном демо.

Пакет-шаблон: `/demo-2026-10-22/s4-branches.lgp` (тот же, что у исходного сценария).
Точное назначение экспорта-шаблона: `/demo-2026-10-22/branches-categories.csv`.
Перед прогоном заменить оба пути на личные; второй аргумент oracle должен совпасть
с полным назначением CSV из задания. Старые экспорты допустимы: `export_input`
выбирается по `export_destination`, как в s8-rename.
