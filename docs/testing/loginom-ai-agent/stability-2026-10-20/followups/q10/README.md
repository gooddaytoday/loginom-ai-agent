## q10: Средняя выручка на товар

Продолжение [s6-abc](../../../demo-2026-10-22/s6-abc/prompt-demo.md)
в том же чате и сохранённом пакете. Отправить только [prompt.md](prompt.md),
исходные CSV повторно не прикладывать. Это отдельная ветвь от исходного результата,
а не продолжение предыдущего q. Порядок запуска и подстановка личных путей —
в [общей инструкции](../README.md).

Что меняется: Добавить AverageRevenue = Revenue / Products, округление до копеек HALF_UP; нулевые товары входят в Products исходного ABC.

Исходные CSV: [products.csv](../../../demo-2026-10-22/s6-abc/data/products.csv). Oracle самостоятельно пересчитывает исходный сценарий
из этих файлов, затем применяет продолжение; он не читает expected, другие oracle
или результат Loginom. Полный итог — 3 строк в [expected-demo.json](expected-demo.json).
`column_order: exact` фиксирует порядок колонок из просьбы; `ordered: false`
задаёт проверку порядка строк. Типы и подписи остальных колонок — как в исходном демо.

Пакет-шаблон: `/demo-2026-10-22/s6-abc.lgp` (тот же, что у исходного сценария).
Точное назначение экспорта-шаблона: `/demo-2026-10-22/abc-average.csv`.
Перед прогоном заменить оба пути на личные; второй аргумент oracle должен совпасть
с полным назначением CSV из задания. Старые экспорты допустимы: `export_input`
выбирается по `export_destination`, как в s8-rename.

Средние: A — 26666.67, B — 7500.00, C — 714.29. Только для AverageRevenue
задан `tolerance.abs = 0.000001` из-за представления десятичных копеек в binary64.
