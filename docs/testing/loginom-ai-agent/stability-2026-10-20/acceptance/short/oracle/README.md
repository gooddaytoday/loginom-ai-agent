## Независимый расчёт p1–p8

Каждая задача получает `oracle.py`: стандартная библиотека Python, входы
только собственные CSV, пути относительно `__file__`, JSON в stdout.
Не читать expected, результаты модели, пакеты Loginom и сеть.
Для точной дробной арифметики подходят `Decimal`/`Fraction`; приближения
сопровождать явными допусками. Образец — [n1 oracle](../../../n1/oracle.py).

Без аргумента stdout побайтно равен сохранённому `expected-demo.json`,
в том числе при запуске из другого текущего каталога. Аргумент личного пути
пакета меняет только `package_path`. Восемь таких сравнений и реальные вызовы
`parseExpectedOutputs` описать в командах воспроизведения корневого README.

Oracle считает бизнес-результат, но не выбирает за зрителя неоговорённые
имена, метки и порядок как обязательные условия. Правила —
[подплан](../../../short-plan.md), [expected](../expected/README.md).

## Дополнение p9–p16 / D7f

Oracle p9/p10/p15 восстанавливают облака по разрывам и проверяют геометрию
в исходном масштабе, с нормированием диапазоном и z-score; не читают номера
групп из генератора. p11/p12/p16 — точные центрированные суммы МНК и
ортогональность остатков. p13 — контракт успешного HTTP-ответа без сети.
p14 читает XML из своего XLSX, разрешая связи книги и первого листа;
операторскую CSV-копию не читает. Остальные oracle читают только свои CSV.
Команды для всех восьми комплектов — [в README](../../../README.md#d7f-короткие-просьбы-p9-p16).
