## Входы p1–p8

Исполнитель создаёт собственные CSV и генератор с фиксированным seed для
каждой задачи. 10–40 строк данных в файле; UTF-8 без BOM, заголовок,
запятая, точка в числах, синтетика без персональных данных.

Повторная генерация должна побайтно воспроизводить CSV. Oracle читает
записанные CSV, а не повторяет генератор вместо чтения. Схемы, единицы,
seed и команды описать в README задачи. Данные должны позволять понять
нужный результат из короткой просьбы без скрытых правил в операторском README.

Структуру можно смотреть в [n1/data](../../../n1/data/), но существующие
данные и предметные области не копировать. Контракт — [подплан](../../../short-plan.md).
