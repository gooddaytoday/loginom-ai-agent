Подготовить шесть новых задач n7–n12 по [подплану D7b](../../v2-plan.md).
Это операторское назначение Тест-Манки #1, не запрос для модели.

Нужны две кластеризации, две линейные регрессии, один REST-запрос к
`https://httpbin.org/anything` и одно сочетание подготовки данных с обучением
и экспортом. В каждой задаче — бизнес-просьба, синтетические данные 10–40 строк,
детерминированный генератор с seed, независимый oracle, полученный из него
`expected-demo.json` и README. Сначала данные и oracle, затем эталон;
модельные прогоны не выполнять. Готовые n1–n6 не переделывать.

Приёмка: 6/6 oracle воспроизводят эталоны, все expected принимаются существующим
`parseExpectedOutputs`, таблица покрытия README дополнена, только документы
и данные, PR в `demo-022`, итоговая таблица до 8 строк. Срок 19.10.2026 06:00 PT.
Подготовительный комплект задаёт требования и ссылки; он не содержит готовых
новых CSV или вымышленных результатов и не означает завершённую поставку D7b.
