## Учебные программы

Модели: только [prompt.md](prompt.md) и [enrollments.csv](data/enrollments.csv).
Оператору: [oracle.py](oracle.py), [expected-demo.json](expected-demo.json).
Ожидаемое сочетание: импорт(ы) → Замена → Фильтр → Калькулятор → Кросс-таблица → Параметры полей → экспорт `training.csv`.
Дополнительные узлы допустимы; эталон фиксирует бизнес-результат на входе экспорта,
а `nodes` — наличие основных типов, без проверки топологии и кратности.

Разный регистр кодов, несколько записей на ячейку; cancelled/pending исключаются. Контроль: Business = 74.50, Engineering = 73.50, всего 148.00; 3 строки.
Все данные синтетические. Денежные расчёты — Decimal; выбранные значения точно
представимы в binary64, допуск и промежуточное округление не нужны.
Имена и подписи итоговых полей совпадают. Порядок колонок фиксирован;
порядок строк определён в просьбе и `ordered` эталона.
Oracle читает только CSV относительно своего файла и выводит JSON в stdout.
Без аргументов воспроизводит эталон; один аргумент меняет только `package_path`.
Команды проверки и будущих прогонов: [общая инструкция](../README.md).
Статический расчёт не подтверждает выполнение сценария в Loginom.
