Помоги сравнить тарифы на отправку посылки весом 2 кг. В tariffs.csv есть Carrier, ZoneCode, MaxKg, Base, PerKg. Исправь ZoneCode по полному списку: « n » → North, N → North, S → South, « s » → South, C → Central, « c » → Central. В результате назови это поле Zone. MaxKg, Base и PerKg сделай вещественными числами. Для каждого тарифа посчитай Quote = Base + 2 × PerKg без промежуточного округления; все тарифы допускают 2 кг. В shipping-quotes.csv нужны по порядку Carrier (текст), Zone (текст), MaxKg, Base, PerKg, Quote (все четыре — вещественные). Строки расположи по возрастанию Quote, при равенстве — по Carrier по возрастанию. Сохрани сценарий.
