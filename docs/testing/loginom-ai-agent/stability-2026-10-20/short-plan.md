## 3. Oracle и свободные варианты ответа

Сначала просьба и данные, затем независимый расчёт и expected. Oracle читает
только свои CSV, использует стандартную библиотеку Python, пути относительно
`__file__`; не читает expected, пакет, модельный результат или сеть.
Без аргумента stdout побайтно совпадает с `expected-demo.json`; аргумент пути
пакета меняет только `package_path`. Числовые приближения имеют явный допуск.

Фиксировать только то, что однозначно следует из просьбы и данных. Не заданные
просьбой имена и порядок колонок, метки и порядок строк не превращать
в обязательные условия. Применять существующие `label_any: true`,
`column_order: any` и `ordered: false`, где соответствующее свойство свободно.
`label_any` освобождает метку, но не имя поля: не выдавать его за wildcard
для имён. Не копировать из подробных n-задач строгие схемы без обоснования.
Выбирать задачи и форму ожидаемого результата, позволяющие выразить эту свободу
существующим форматом. Невыразимое условие не считать проверенным и не заменять
жёстким именем; продукт и matcher в этой карточке не расширять.

Все expected содержат `export_destination`, используют `export_input`
и принимаются существующим `parseExpectedOutputs`. README объясняет назначение
пути экспорта и какие его части заданы просьбой или окружением будущего запуска;
служебный путь не должен маскировать дополнительное бизнес-требование.
Правила: [expected](acceptance/short/expected/README.md),
[oracle](acceptance/short/oracle/README.md).

### 3. Расчёт и допустимая свобода

Oracle читает только свои входы: CSV либо XML внутри XLSX, стандартной библиотекой
Python, относительно `__file__`. Не читает генератор, expected, пакет, ответ модели
или сеть. Кластеры восстанавливаются по геометрии облаков без номеров;
МНК-прямая вычисляется точными центрированными суммами Fraction и проверкой остатков.
Разные прогнозы на разных X однозначно задают подобранную прямую; отдельная
неоговорённая схема коэффициентов не фиксируется.
HTTP — контракт успешного отражения Code/Route и Method/HttpStatusCode,
без изменчивых IP, времени, URL и заголовков. [Источник контракта](https://httpbin.org/).
Доступность сервиса и происхождение значений требуют будущего живого аудита.

Все expected используют `export_input` с `export_destination`, `label_any: true`,
`column_order: any`, `ordered: false`. Имена полей определены просьбами/входами;
неоговорённые метки и порядок не ограничиваются. Номера кластеров исключены из
результата; промежуточные имена свободны. `label_any` не освобождает имена.
Сумма TotalPollen — real; счётчики строк — integer. Другой числовой тип
требует операторского разбора: matcher не выражает его свободу.
Для real допуск `max(1e-8, 1e-10 × |expected|)`.
Папка `/stability-2026-10-20/` задаётся оператором в окружении будущего запуска,
имя экспорта задано просьбой. Аргумент oracle меняет только `package_path`.
