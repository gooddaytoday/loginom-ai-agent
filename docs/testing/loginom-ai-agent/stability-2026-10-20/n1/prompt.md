Подготовь список дефицита для склада. В requests.csv строки заявок: ReqID — номер строки, SKU — товар, Units — требуемое целое количество. В stock.csv по одной строке на товар, Available — целый остаток; все товары заявок есть в остатках. Сначала посчитай общую потребность каждого товара по всем заявкам, затем дефицит Shortage = Requested − Available. Нужны только товары с положительным дефицитом. В shortages.csv выведи колонки SKU (текст), Requested, Available, Shortage (все три — целые числа) именно в этом порядке. Строки расположи по убыванию Shortage, при равенстве — по SKU по возрастанию. Сохрани сценарий.
