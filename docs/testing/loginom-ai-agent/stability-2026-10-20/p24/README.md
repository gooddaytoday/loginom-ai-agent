## p24: короткий вариант s8-rename

Начальное состояние: успешно выполненный **исходный s1**, в том же чате и пакете. Модели отправить только [просьбу](prompt.md); CSV повторно не прикладывать. p23 и p24 — отдельные продолжения s1: p24 нельзя запускать после p23/s7. Копия sales.csv нужна только автономному oracle.

Просьба содержит **16 слов** (разделение по пробельным символам), одну
неточность — опечатку **Catgory → Category**. В отчёте s1 единственное поле категории — Category; пропущена буква e. Два перечисления задают соответствие Region → Регион, Category → Категория, Revenue → Выручка.
Других намеренных неточностей нет; формат CSV явно задан расширением файла.

Верный бизнес-результат: Отдельное продолжение исходного s1: все 6 строк, сумма 216781.00, прежние порядок и типы. Меняются русские названия колонок и имя выгрузки.

Данные и [oracle](oracle.py) побайтно совпадают с [исходным s8-rename](../../demo-2026-10-22/s8-rename/README.md)
на SHA `9f2d305e32e841d206bf8d04d25ebd039156cd29`.
Входы: [sales.csv](data/sales.csv). Новые данные и генератор не создаются.
У исходного s8 oracle и expected.json расходятся по технической форме: oracle выдаёт русские имена и transform.reform_columns, expected — английские имена с русскими подписями и export_input. Бизнес-таблица (подписи, типы, значения и порядок всех 6 строк) совпадает. Проверка p24 сравнивает её по уникальным подписям; побайтный PASS не заявляется. Оба исходных представления сохранены без исправлений. [Демо-эталон](expected-demo.json) также скопирован без изменений.

Короткая просьба проверяет сохранение бизнес-смысла, а техническая схема
исходного эталона (имена/подписи, integer/real, обязательные типы узлов) сохранена
по заданию LAB-119. Эти ограничения не объявляются свободными и не доказываются
одной краткой фразой; альтернативная схема требует операторской оценки.
Порядок строк проверяется только там, где он задан сценарием.

Воспроизведение: `python3 -B oracle.py` из этого каталога; необязательный аргумент
меняет только `package_path`. Значение по умолчанию остаётся путём исходного s-сценария.

сравнение с эталонами. Это статический PASS расчёта, не модельный/native/cold PASS.
