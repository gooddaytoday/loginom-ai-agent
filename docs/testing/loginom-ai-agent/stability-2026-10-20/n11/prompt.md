Key — строки с синтетическими кодами, 12 независимых запросов. Для каждой строки
отправь GET на https://httpbin.org/anything с query-параметрами RequestId и Key,
взяв значения из этой строки. Из JSON-ответа используй именно args.RequestId,
args.Key и method, а также фактический код HTTP-ответа. Нужен echoes.csv с колонками
RequestId, Key, Method (строки), HttpStatusCode (целое) в таком порядке. RequestId
и Key в результате должны быть отражёнными значениями ответа, а не копией входа;
метод Method должен быть GET. Порядок строк свободный. IP, время, URL, заголовки
и сырой JSON не нужны. Сохрани сценарий.
