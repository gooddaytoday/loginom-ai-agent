## Private witness bound gate on full-script methods

The private capsule now owns a pending/armed/active/consumed state and WeakMap token membership for each storage call. Its DispatchMessageAsync overlay requires that exact state inside the delegate activation before invoking the original transport. A fixture beforeDispatch callback is not an admission path. No observer, no breakpoint, copied token/lower and repeated arm do not dispatch storage.

At the actual pre-call debugger pause, retainBoundPause requires the live active lower object, original mkdel completion/result, precreation FileStorage, verified packet/initial, retained method and full-script operator metadata. The fixed supported bg.rtl.rpc.js SHA256 is `11ac2c63d2e8162b974f57d14e0f4f57b19cc80d3d39797be377e22eced6a973`. Operator metadata is evidence from the fixed Node observer; it is not a public JSON permission. The live lower is private until this pause and is never reacquired from host DTOs. armBoundPause accepts only that same token once; refused pause admission preserves the original raw reason through refuseBoundPause.

The witness installs its own guarded delegate.apply overlay while preserving both original delegate and returned function objects. The overlay requires armed state, original receiver, and the same current lower; it enters the activation. Dispatch consumes that state exactly once and creates the witness's frozen `FileStorage.<method>:bound` receipt. The receipt is the same object seen by the private inspector and includes original packet/initial, mkdel call/completion, callee/delegate/receiver, request and token. Only this receipt has boundCallQualified true. Delegate/global closure qualification, broad nativeReceiversQualified and all four authority flags remain false.

The Node observer derives FunctionLocation from the retained function object, obtains the complete parsed script and validates its full SHA. A linear header-offset index finds the containing function; its own `$sm();` must resolve to the exact breakpoint location. An excerpt FunctionExpression is rejected for this route. Actual script/function/frame references, not labels, `_targets` or function text, establish the call-site identity. Pause comparison and resume remain synchronous with the existing original managed/root control checks; no controller, timer or budget is created.

The new VM composition executes fifteen full pinned vendor files through bg.rtl.rpc.js. It retains the four methods produced by that complete IIFE and installs those exact function objects in the existing fixture definition table before publisher capture/creation. It does not compile their excerpts. Other constructor/namespace/application/native/session/SDK/transport/PID/DOM operands remain labelled fixture doubles; broad initial-load/lexical/native qualification is not claimed. The positive has no fixture gate and uses the unchanged packet/control route. Browser page/CDP and stock H0 remain out of scope.

Seventeen new `witness bound` controls cover the positive four calls; absent observer, a fixture allow hook and missing breakpoint; local replacement/Proxy; full source hash, copied lower/token and getter0 refusal; excerpt refusal and replay arm; six raw reasons with original Task status 3; and original abort false/absolute expiry before resume. Positive calls remain `[0,907,909,910,911]`, writes zero. `NATIVE_LEXICAL_QUALIFICATION_MISSING`, componentReady false and stock H0 refusal remain unchanged. Closed matrices are not repeated.

The first full-script scan was stopped by exact own PID before creation: quadratic line mapping consumed CPU. The replacement indexes offsets once per script. The earlier generic not-armed errors on abort/deadline and replay are preserved in diagnostics; the final route propagates the first refusal instead. These are preparation/intermediate failures, not acceptance evidence. Existing excerpt-only controls cannot qualify the new mandatory full-script witness gate.
