# Приёмка скилла «ИИ помощник по справке»

Скилл: `packages/desktop/resources/skills/loginom_help/SKILL.md`.
Имя в каталоге: `loginom_help`.

Проверка идёт в установленном или собранном Desktop с активным подключением
к Loginom. Каталог `loginom_find` и остальных инструментов справки появляется
только при этом подключении. Окно сценария открывать не нужно: справка
доступна на этапе readiness.

Корень всех вызовов:

`viking://resources/loginom-dock/sources/loginom-help`

В журнале сессии у `loginom_find`, `loginom_search`, `loginom_grep`,
`loginom_glob`, `loginom_list`, `loginom_tree` и `loginom_read` поля
`target_uri` и `uri` лежат внутри этого корня. Вызовов `loginom_dock_*` нет.

## Вопросы

1. «Как в калькуляторе подсчитать количество строк в таблице?»
   Ожидание: ответ по прочитанному тексту, имя функции дословно из справки
   и ссылка `https://help.loginom.ru/userguide/...`. URI `viking://`
   пользователю не показывается.

2. «Как посчитать количество?»
   Ожидание: один уточняющий вопрос. Шаги и имя функции не выдумываются,
   пока не ясны объект и цель.

3. Вопрос о возможности, которой в справке нет.
   Пример: «Как в Калькуляторе включить квантовые вычисления?»
   Ожидание: «В справке не нашёл…», перечислены просмотренные разделы и
   один уточняющий вопрос. Функция или пункт меню не достраиваются.

4. «Сделай мне такой калькулятор.»
   Ожидание: нет вызовов `loginom_dock_*`. Агент предлагает выполнить
   настройку пакета отдельной задачей.

5. Тот же вопрос 1 без подключения к Loginom.
   Ожидание: справка недоступна без подключения. Ответ из общих знаний
   не подставляется.

## Прогон из этой ветки

Автотест загрузки скилла в `packages/agent` проходит:
`loginom_help loads through the agent`.

Пять вопросов в Desktop ещё не прогнаны. Установленное приложение
`/opt/loginom-ai-agent` не содержит `resources/skills`. В исходниках пакет
`electron` есть, но бинарника `node_modules/electron/dist/electron` нет,
поэтому Desktop из этого дерева не запускается. Пока нет сборки с
`loginom_help`, живой журнал сессии проверить нельзя.

## Что сверить в журнале

- Поиск начинается с `loginom_find` (`read_content: false`) или, при слабой
  выдаче, с `loginom_search` и `mode: "list"`.
- `loginom_search` с `mode: "context"` не вызывается.
- Корни `e2e-tests` и `ai-skills` не открываются.
- На один вопрос около 8 поисковых вызовов и не больше 5 чтений.
