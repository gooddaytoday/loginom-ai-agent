association. It does not implement a successful native creation provider.

call, its original lender facts and load token. The load owner must belong to the

different peer. The call's existing guard retains typed input, message, handle

before post-await checks. A successful recheck still refuses with
`LOGINOM_ORIGINAL_PREPARE_INVOCATION_UNAVAILABLE`, cause
`LOADED_NATIVE_PROVIDER_NOT_BOUND`. Missing association/load have distinct causes.
