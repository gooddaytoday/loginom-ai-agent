В приложенном numbers.csv разделитель «;», первая строка — имена полей: ID и Value, оба целые.

Импортируй файл и добавь узел JavaScript «Долгий расчёт»: он передаёт ID и Value без изменений и добавляет целое поле Double = Value * 2, а перед выводом строк ждёт 60 секунд активным ожиданием по часам — так я проверяю поведение при долгом выполнении. Сначала создай и настрой этот узел без выполнения.

Затем запусти выполнение узла «Долгий расчёт» и сразу, не дожидаясь окончания, удали этот узел из сценария. Если удалить выполняющийся узел нельзя, не повторяй попытку и не удаляй узел после завершения: дождись окончания расчёта, выгрузи его результат в doubled.csv (UTF-8, разделитель «;», заголовок из имён полей) и сохрани пакет в {{PACKAGE_PATH}}, затем закрой его и выйди из Loginom. В ответе сообщи, почему узел не был удалён.
