# Удаление узла сценария: приёмка (LAB-1721)

Инструмент `dock_node_delete` удаляет один узел текущего workflow по scoped ref
только по просьбе пользователя. Отказ до мутации: узел отсутствует или неоднозначен,
заблокирован или выполняется, служебный граничный узел Подмодели/Цикла, другой
workflow, несовпадение подписи, идёт другая операция Dock. Жест — выделение тела
узла, «Удалить выбранное» и подтверждение; граф после удаления должен отличаться
ровно на узел и его собственные связи. Save в эффект не входит.

| Сценарий | Задача | Проверка |
|---|---|---|
| `node-delete` | 4 узла, удалить фильтр по просьбе, переподключить импорт к сортировке | один SUCCEEDED delete, CSV 6 строк по убыванию Amount, Save, cold без `transform.filter_data` |
| `node-delete-refused` | удалить JS-узел во время 60-секундного выполнения (меньше бюджета execute 120 с) | все ответы delete NOT_APPLIED, есть `NODE_OPERATION_RUNNING`; узел, CSV, Save, cold |

`expected.json` заморожены до прогонов; oracle — стандартное сравнение run-check.
