# Границы технической проверки

Назначение фиксирует узел, режимы, исходный SHA, критерии и пределы изменений. Организация задач и подготовка среды находятся вне клиентского репозитория.

Не расширять охват без решения владельца. Разделять реализацию, техническую проверку клиента, аналитическую правильность, интеграцию и релиз. Доказательство одной стадии не заменяет остальные. Для каждого вывода указывать SHA, платформу и границы.
