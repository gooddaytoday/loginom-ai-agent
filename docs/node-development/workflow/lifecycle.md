# Возобновление технической работы

Сохранить короткий checkpoint: SHA, подтверждённые результаты, незавершённые действия и следующий шаг. При возобновлении проверить фактический checkout, чистоту исходников и целостность кандидата. Если зависимости или клиент повреждены, пересобрать.

Прерванный запуск без итогового результата не считается проверкой. Наличие PID, возраст каталога и принудительное завершение не доказывают освобождение серверной сессии. Закрывать только собственный пакет и аккаунт с подтверждённой идентичностью. Не удалять чужие данные.
