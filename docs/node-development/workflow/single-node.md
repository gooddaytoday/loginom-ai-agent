# Работа над одним узлом

Следовать [RUNBOOK](../RUNBOOK.md). Прочитать подплан, исследовать интерфейс, зафиксировать независимые ожидания до прогона, реализовать только назначенные режимы и проверить адресными тестами. Затем выполнить CLI-приёмку и cold-check точного опубликованного SHA.

При неопределённости сохранить конкретный вопрос, наблюдения и ограничения. Не снижать критерии и не объявлять частичный результат принятым.
