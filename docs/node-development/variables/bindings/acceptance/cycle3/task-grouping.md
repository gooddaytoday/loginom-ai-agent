Импортируйте modes.csv: UTF-8, разделитель ;, заголовок, двойные кавычки,
NULL-маркер \N. RowID и Amount — целые, Region и Text — строки.
Создайте пользовательские переменные сценария Flag (логическая, false)
и Sentinel (строка, keep).

Настройте одну Группировку: по Region, сумма Amount. Итог: Region, Metric
(вещественное). Признак «сортировать результат» должен браться из переменной
Flag и оставаться с ней связан; кэширование не меняйте. Выполните сценарий
и выгрузите весь результат в CSV.

Теперь измените только значение Flag на true, сохранив остальные переменные.
Выполните тот же сценарий и снова выгрузите весь результат в отдельный CSV.
Группировку между выполнениями не перенастраивайте и вторую не создавайте.

CSV: UTF-8, разделитель запятая, заголовок с техническими именами полей,
пропуск — `?`. Сохраните пакет в {{PACKAGE_PATH}} с последним значением
переменной. Откройте сохранённый пакет заново и выполните сценарий без
настройки Группировки; выгрузите результат. В конце закройте пакет и выйдите.
