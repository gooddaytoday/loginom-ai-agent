Импортируйте modes.csv: UTF-8, разделитель ;, заголовок, двойные кавычки,
NULL-маркер \N. RowID и Amount — целые, Word — строка. NULL и пустая строка
различаются. Создайте пользовательские переменные сценария Flag (логическая,
false) и Sentinel (строка, keep).

Настройте одну Сортировку: Word по возрастанию без учёта регистра, затем
RowID по возрастанию. Итоговые поля — RowID, Word, Amount; сохраните каждую
строку. Признак «сравнение с учётом локали» должен браться из переменной Flag
и оставаться с ней связан. Выполните сценарий и выгрузите весь результат в CSV.

Теперь измените только значение Flag на true, сохранив остальные переменные.
Выполните тот же
сценарий и снова выгрузите весь результат в отдельный CSV. Ключи и регистр
не меняйте, Сортировку между выполнениями не перенастраивайте и вторую не создавайте.

CSV: UTF-8, разделитель запятая, заголовок с техническими именами полей,
пропуск — `?`, пустые строки оставьте пустыми. Сохраните пакет
в {{PACKAGE_PATH}} с последним значением переменной. Откройте сохранённый пакет
заново и выполните сценарий без настройки Сортировки; выгрузите результат.
В конце закройте пакет и выйдите.
