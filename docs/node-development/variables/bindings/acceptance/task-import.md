Есть два текстовых файла import-a.csv и import-b.csv с полями RowID и Amount.
Оба поля целые, знак вопроса означает пропуск. Поместите оба файла в свой
каталог файлов Loginom и создайте пользовательские переменные сценария:
CsvPath (строка с путём первого файла) и Sentinel (строка keep).

Настройте один Импорт текста так, чтобы имя файла бралось из CsvPath.
Импортируйте первый файл и выгрузите прочитанные данные в CSV: UTF-8,
разделитель запятая, заголовки RowID и Amount, пропуск — `?`.

Затем измените только значение CsvPath на путь второго файла. Остальные
переменные оставьте как есть. Выполните тот же Импорт и выгрузите его результат
в отдельный CSV. Импорт между выполнениями не перенастраивайте, второй узел
импорта не создавайте. Сохраните привязку имени файла к переменной.

Сохраните пакет с путём второго файла, откройте его заново и повторите
выполнение без настройки Импорта; выгрузите результат в CSV.
В конце закройте пакет и выйдите.
