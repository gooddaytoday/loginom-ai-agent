В голове также есть PR, влитые 06.11 в `v040-loginom-sync` и пришедшие через #765: #776 (рецепт «родитель — потомок»), #785, #786, #787, #788, #789, #790, #793, #794 (LGD). - **В работе** — открытый PR в `v040` на 12.11: #983 и #995 (Конечные классы, внешнее разбиение, LAB-1324), #967 (Ассоциативные правила, исключение по максимальной поддержке, LAB-1282), #929 (план W1 Variant-выхода переменных, docs, LAB-1191). Все PR из колонки «В работе» снимка `ecb11c0e` влиты.
- **Осталось** — разрывы и предложения плана минус влитое. «предл.» — критерии предложены, решения владельца в источнике нет; «утв.» — выдана карточка цикла или решение владельца записано; «огр. 7.4.2» — нет штатного пути в Loginom 7.4.2, цикл не планируется.
- **Циклов** — оценка из plan/discovery/README узла (без вычета открытых PR, если не сказано иное). «н/у» — не установлено: оценки в источниках нет.
- **Комплект** — для следующего цикла. С этого снимка определение проверяемое: **готов** — task, fixture, oracle и expected лежат в `origin/v040`, `oracle --check` проходит офлайн, и документы узла не называют для цикла решение владельца, изменение публичного контракта или общий код. Типовая фраза этапа 0 «критерии утверждает владелец» готовности не снимает: её закрывает выдача карточки цикла. **предл.** — файлы есть, но не сверены с native или в тексте есть оговорка; **решение** — комплект есть, но цикл ждёт названного решения владельца; **нет** — файлов нет или они израсходованы.
