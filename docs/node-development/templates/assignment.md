# Назначение узла

Узел назначается карточкой Multica. Её текст, объём, параметры и стоп-условия задаются в разделе 0 подплана узла по [шаблону](node-plan.md). Роли, модель, аккаунты и параллельность берутся из конфигурации Multica; в карточке их не дублировать.

Исполнитель читает [RUNBOOK](../RUNBOOK.md) и подплан узла, выполняет только назначенный этап и ведёт историю попыток в комментариях карточки. Предел модельного прогона — 7200 секунд. Merge и релиз — отдельная команда владельца.

Прежний шаблон назначения кампании и связанные журналы — в [истории](../history/legacy-orchestration/README.md).
