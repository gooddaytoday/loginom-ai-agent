## Заметки черновика

Табличные роли как у кластеризации; выход с номером кластера, вероятностью принадлежности и исходными полями, второй выход — центры. Help не обещает полную матрицу posterior: её нельзя выдумывать из одного столбца вероятности. Смысл независимости переменных — модель covariance; медианная модификация меняет M-шаг. Lifecycle обучения требуется подтвердить на этой версии, сохраняя отличие от обычного execute.

Независимые заранее записанные облака с ненулевой дисперсией внутри каждого кластера, seed фиксирован. Группы сравнивать как множества RowID после перестановки labels. Вероятности проверять independent Gaussian-mixture likelihood только когда discovery предоставляет параметры covariance/весов; иначе oracle подтверждает диапазон, принадлежность, центры/метрики и независимую эталонную модель на оговорённом fixture, не объявляя проверенными недоступные posterior. Допуск центров на разделённых симметричных облаках atol=1e-3 задаётся заранее; повторное применение сохранённой модели atol=1e-8.

Узловые отказы: Вырожденная covariance, недопустимое число кластеров/порог, отсутствующая нормировка; недоступные параметры распределения остаются ограничением полного численного oracle.
