## Предлагаемое разбиение на этапы

Разбиение — гипотеза до этапа 0. Каждый этап должен приниматься самостоятельно; общие изменения, нужные этапу, входят в его же карточку.

- `research-autocorrelation:s1` — Временная АКФ и полный выход. Требования: `research-autocorrelation:r01`, `research-autocorrelation:r02`.
- `research-autocorrelation:s2` — Частотная/автоматическая АКФ и ЧАКФ. Требования: `research-autocorrelation:r03`, `research-autocorrelation:r04`, `research-autocorrelation:r05`. После: `research-autocorrelation:s1`.

## Заметки черновика

Табличный упорядоченный вход с выбранными числовыми полями; выход содержит лаг, АКФ, ошибку, значимость и опциональную ЧАКФ. Количество отсчётов не превышает длину входа. Порядок строк — часть данных, дата не сортируется автоматически. Для нескольких выбранных полей способ идентификации результатов нужно подтвердить. Обучение не навязывается.

Oracle центрирует фиксированный ряд и явно считает сумму попарных произведений для каждого лага; используемый знаменатель, значение ЧАКФ при лаге0 и формула ошибки сначала сопоставляются с версией Loginom. Для частотного пути добавить 64 детерминированных наблюдения, не требующих полного долгого входа. При статистических различиях не ослаблять atol после неудачной попытки; закрепить объяснение до неё.

Узловые отказы: Неверное число отсчётов и выбор нечислового поля; несогласованные массивы лагов/метрик; потеря порядка входа. Шаги вычисления не повторять при неизвестном execution.
