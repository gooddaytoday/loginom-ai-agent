## Предлагаемое разбиение на этапы

Разбиение — гипотеза до этапа 0. Каждый этап должен приниматься самостоятельно; общие изменения, нужные этапу, входят в его же карточку.

- `exports-kafka:s1` — Ключ/сообщение и независимое чтение broker. Требования: `exports-kafka:r01`. Среда: Enterprise/Cloud, изолированный Kafka topic.
- `exports-kafka:s2` — Пачки, Producer и отказы. Требования: `exports-kafka:r02`, `exports-kafka:r03`, `exports-kafka:r04`. После: `exports-kafka:s1`.

## Заметки черновика

Подключение Kafka + исходная таблица + необязательные управляющие переменные → публикация сообщений; табличного результата Help не задаёт.

PLAINTEXT, SASL_Plaintext, SSL, SASL_SSL; SASL PLAIN/SCRAM-SHA-256/SCRAM-SHA-512 — отдельные профили подключения. Итоговый порядок проверять внутри партиции; общего порядка между партициями не обещать.

Отдельный topic и независимый consumer. Вход 5 сообщений с ключами A,B,A,NULL,empty и payload с кириллицей/JSON; каждый case имеет уникальный correlation marker. Отдельный producer не используется для ожидаемых экспортированных сообщений.

Публикация может завершиться частично; конфигурация producer не означает exactly-once. Не очищать общий topic и не переиспользовать его для повтора.
