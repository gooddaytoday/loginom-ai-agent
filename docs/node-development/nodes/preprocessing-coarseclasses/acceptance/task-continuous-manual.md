NULL ?, двойная кавычка, десятичная точка. RowID и X — целые непрерывные,
Target — дискретная строка, метки всех полей равны именам.

событие yes; RowID не участвует в обучении. Задай два класса X: от 0 до 7
включительно и больше 7 до 14 включительно. Предварительное квантование выключи.

именно в таком порядке. Сохрани значения, типы, NULL, порядок строк и полей,
