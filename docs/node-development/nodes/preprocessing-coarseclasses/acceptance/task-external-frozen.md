Построй сценарий Loginom из двух приложенных CSV. Оба файла — UTF-8, запятая,
заголовок в первой строке, десятичная точка, двойная кавычка, `?` для NULL.

Основные данные — zero-frequency.csv: RowID целое, Segment/Target/Note строки,
Segment и Target дискретные. Сохрани исходные значения и порядок строк.
Готовое разбиение — external-classes.csv: ColumnName и UniqueValue строки,
ClassNumber целое. Это определение классов Segment: B имеет номер 0, A — номер 1.

Добавь один узел «Конечные классы». Подай основные данные на основной вход,
готовые классы — на дополнительный табличный вход. Во внешней таблице назначь
ColumnName идентификатором признака, ClassNumber номером класса, UniqueValue
категорией. Включи использование заданного разбиения как готового, без оптимизации.
Segment — входной признак, Target — цель, событие yes; остальные поля unused.
Минимальная доля 5%, максимум 2 класса, равномерность 0%.

Обучи и выполни узел. Сохрани состав предоставленных классов, вычисли
частоты, WoE, IV и значимость по четырём основным строкам. Не имитируй внешний
вход вычисляемым столбцом или JavaScript. Прочитай все три выхода и экспортируй
строки в rows.csv, параметры классов в classes.csv и значимость в significance.csv
в этом порядке: UTF-8,
технические заголовки, десятичная точка, `?` для NULL.
