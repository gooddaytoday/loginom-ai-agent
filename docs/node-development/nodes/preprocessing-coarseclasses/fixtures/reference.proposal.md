# Конечные классы (`preprocessing.coarse_classes`)

В UI узел называется «Конечные классы». Назначь один входной признак,
бинарную строковую цель и точное event_value. Остальные поля остаются unused
и сохраняются. min_class_percent и uniformity_percent задаются в процентах,
max_classes — верхний предел, не обещанное точное число классов.
`internal` явно обучает, затем выполняет. `apply` использует существующий
обученный узел без Train и без коммита просмотренного draft:
`parameters:{}`, `inputs:[]`, `mappings:[]`, `finish:"execute"`.

## Непрерывный признак

Для numeric/continuous поля `continuous` задаёт prequanting, count при включённом
предварительном квантовании и include_upper. Тип и вид исходного поля не меняй.
В ручном разбиении проверь все границы, включение верхних краёв и метки.
Внешнее разбиение требует отдельного табличного входа 1; не подменяй его
переменными или вычислением классов в JavaScript. Каноническая дискретная таблица:
ColumnName:string, ClassNumber:integer, UniqueValue:string. Используй готовое
разбиение без оптимизации. Входной номер задаёт группу категорий; native-выход
может перенумеровать классы. Состав классов сохраняется, фактические номера
надо перечитать с портов. Минимальный трёхпольный CSV пока является предложением.
Ручные, внешние и frozen-параметры допускаются только после подтверждения
соответствующих native controls. Их описание в проекте не доказывает доступность.

## Выходы и сохранённая модель

Явно прочитай `read.ports:[0,1,2]`: строки с ClassNum/ClassMark/ClassSignificant,
параметры классов, общий IV/значимость. Производные поля идут сразу за признаком.
ClassSignificant — вклад класса в IV. WoE = ln(доля не-событий / доля событий),
доли для этой формулы берутся от общих событий/не-событий; EventRate в отчёте
класса — доля внутри класса. Не считай из округлённых отображений.
Непрерывные LowerBound/UpperBound на порте 1 — typed Variant, не строки UI.

При apply сохраняй статистику обучения. Новые/NULL-категории и нулевые частоты
не допускаются, пока native-поведение и независимые ожидания не подтверждены.
Не назначай им автоматически 0, новый класс или коэффициент сглаживания.
После проверки трёх портов отдельно сохрани пакет.
