2. base, метка «Основа», тип Целый: 2; сделайте выражение промежуточным.

измените только base на 4, повторно выполните и прочитайте весь выход.
Сохраните имена, метки, типы и порядок остальных выражений. Промежуточная
основа нужна для расчёта, в выходные переменные она входить не должна.

настройками и проверьте переменные. Закройте пакет и завершите сеанс.
