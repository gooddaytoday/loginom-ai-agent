## Предлагаемое разбиение на этапы

Разбиение — гипотеза до этапа 0. Каждый этап должен приниматься самостоятельно; общие изменения, нужные этапу, входят в его же карточку.

- `variables-vartodata:s1` — Переменные в столбцы. Требования: `variables-vartodata:r01`.
- `variables-vartodata:s2` — Переменные в строки и смешанные типы. Требования: `variables-vartodata:r02`, `variables-vartodata:r03`. После: `variables-vartodata:s1`.

## Заметки черновика

Вход — набор переменных, выход — таблица. Режим столбцов формирует одну запись, режим строк разворачивает переменные в записи с именем, меткой и значением. Смешанные типы в режиме строк требуют проверки фактического типа колонки значения. Variant-reader является предпосылкой полной проверки смешанных значений, но тип колонки не объявляется Variant без discovery.

Текущие `node-target-browser.mjs` и `node-contracts.mjs` работают с табличными портами; перед handler нужны типизированные ссылки/связи и независимое чтение переменных. Общий lifecycle `node-apply.mjs` сохранить.

Установить тип значения при смешанном входе и правила пустого набора. Для проверки исходные переменные готовятся fixture, не требуется готовая «Таблица в переменные».
