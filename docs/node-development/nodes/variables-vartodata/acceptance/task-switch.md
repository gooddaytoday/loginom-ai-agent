В подготовленном пакете есть источник initial из modes.json и настроенный узел
«Переменные в таблицу», который выводит значения в столбцы. Переключи этот же
узел в вывод строками и покажи все переменные с именами, метками и типами значений.
В источнике замени набор на changed: измени сумму, удали пустую строку,
добавь долю; остальные переменные сохрани. Повтори преобразование, не создавая
новый преобразователь. Затем верни вывод в столбцы и покажи весь результат.
Сохрани существующие связи и пакет как {{PACKAGE_PATH}}.
