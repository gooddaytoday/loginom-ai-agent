Преобразуй подготовленный набор variant из modes.json узлом «Переменные в
таблицу»: сначала в столбцы, затем в строки. Исходная переменная имеет
переменный тип, её значение — строка «19». Покажи объявленный тип поля и
фактический тип значения; не превращай строку в число.
Затем подключи подготовленный пустой набор вместо прежнего источника,
повтори режим строк и покажи структуру и количество записей. Не оставляй
значения предыдущего выполнения и не заменяй пустой набор отсутствием связи.
Сохрани пакет как {{PACKAGE_PATH}}.
