# Переменные в таблицу (`variables.to_table`)

Этап 1: `mode:"columns"`, `parameters:{}`. Сначала прочитай карточку типа через
`dock_action_describe`. Подключи проверенный выход **переменных** к входу 0 по
типизированной ссылке W1. Номер порта сам по себе не определяет его вид:
у сценария есть несколько служебных наборов переменных. Не подменяй выход
переменных табличным портом или управляющим портом узла.

Одна непустая последовательность переменных становится одной строкой.
Имена, метки, типы и порядок сохраняются. NULL отличается от пустой строки,
FALSE и нуля. Дата сохраняет миллисекунды гражданского времени без добавления
часового пояса. Значения задаёт источник; параметры конвертера их не создают.

Для выполнения используй `finish:"execute"`, прочитай табличный выход 0 и затем
сохрани пакет отдельно. `finish:"done"` только применяет настройки. Обучаемой
модели и отдельного режима применения нет. Для существующего узла не меняй
режим молча. Режим строк, Variant, пустой набор и служебные переменные не входят
в этап 1. При отказе мастера прочитай причину кнопкой ошибки; при незавершённой
операции продолжай тот же `operation_id`.
