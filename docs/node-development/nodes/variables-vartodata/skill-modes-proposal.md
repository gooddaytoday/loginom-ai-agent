# variables.to_table — предложение LAB-1038

Проект node reference после утверждения и реализации, не текущая возможность.
Используй `dock_node_apply`, `target.type:"variables.to_table"`,
`mode:"columns"` либо `"rows"`, `parameters:{}`, `inputs:[]`.
Передай ровно один `variable_inputs`:
`{source:NodeRef,output:наблюдённый_номер,input:0,kind:"variables"}` из свежего
графа. Табличный и управляющий порты не заменяют переменные. У «Переменных
сценария» пользовательские значения находятся на выходе 4.

columns: одна строка, имена/метки/типы/порядок полей из источника.
rows: поля `Name string`, `DisplayName string`, `Value variant`, по строке
на переменную в исходном порядке. Прочитай subtype каждого Value, включая
typed NULL; не заменяй значения строковым preview. NULL отличается от пустой
строки, false и 0. Гражданская дата сохраняется до миллисекунд без timezone;
числа читаются с подтверждённой точностью.

Предлагается переключать режим **того же существующего узла**. Сохраняй его
NodeRef и связь. После смены режима заново прочитай схему выхода 0:
таблица 1×N превращается в N×3, а не в новые значения старых полей.
Не переноси имена mappings от предыдущей ориентации. При `mappings:[]`
используй текущую полную native схему; явное соответствие должно подходить
новой схеме, иначе отказ до изменения. Поведение существующих custom mappings
ещё требует решения, молчаливый сброс не допускается.

После изменения исходного набора повторно выполняй прежний преобразователь.
Добавленные переменные появляются, удалённые исчезают, прежние значения
не остаются в кеше. Предлагаемый Variant-вход ограничен строкой «19» с
проверкой declared variant и cell_type string; другие subtype не доказаны.
Пустой подключённый источник в rows: та же схема из трёх полей, ноль строк.
Кратность columns с нулём полей не определена этим предложением; отсутствие
связи не заменяет подключённый пустой набор. До решения такие columns отклонять.

`finish:"execute"`, `read.ports:[0]`, `require_exact_numbers:true`,
`sample_rows` на весь набор (≤100). Сохрани пакет отдельным
`package.save_checkpoint`, проверь квитанцию и новый профиль/cold.
Done не доказывает выполнение; Close отменяет настройки.
Не меняй источник вместо ориентации, не подменяй преобразователь JavaScript
или таблицей констант. После reopen получи новые preparation/refs.
