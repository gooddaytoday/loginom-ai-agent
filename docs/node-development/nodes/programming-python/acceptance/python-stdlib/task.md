Импортируй values.csv в новый сценарий Loginom: UTF-8, разделитель запятая, первая
строка — заголовок, десятичная точка, маркер пустого значения «?». Пустой текст
в кавычках должен остаться пустой строкой. Id — целое, Amount — вещественное,
Text — строка, Flag — логическое, Date — дата и время без часового пояса.

После импорта создай один стандартный узел «Python», подключённый к таблице.
Задай в мастере фиксированную схему выхода из шести полей в таком порядке:
Id (целое), Amount (вещественное), AmountScaled (вещественное), Text (строка),
Flag (логическое), Date (дата и время); формирование столбцов из кода не включай.
Сохрани в узле ровно код из calculation.py: он пересчитывает сумму с коэффициентом 3
и сохраняет пропуски. Сторонние библиотеки, сеть, файлы и окружения не используй.

Выполни узел и прочитай весь его выход: порядок строк и полей, типы и пропуски
как в результате узла. При ошибке выполнения передай точный текст ошибки Loginom,
не выдумывай результат. Сохрани пакет в {{PACKAGE_PATH}} и заверши работу.
