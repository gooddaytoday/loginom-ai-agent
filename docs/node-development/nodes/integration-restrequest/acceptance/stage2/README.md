Комплект r03 зафиксирован до изменений обработчика: коммит `f78f1a2c3d`.
Модели передаются только `task.md` с новым путём пакета и `data/requests.csv`.
Метки столбцов заданием не определены; `label_any` требует W-правку LAB-94
([PR #118](https://github.com/gooddaytoday/loginom-ai-agent/pull/118)).

`python3 oracle.py --check` проверяет воспроизводимость `expected.json` без сети
и Loginom. Ожидания следуют контракту публичных `/status/200` и `/status/404`:
две строки, точные RequestId/HttpStatusCode и логический HasError. Изменчивые
описания ошибок, даты, IP и служебные идентификаторы не сравниваются.
Сам oracle не является свидетельством выполнения HTTP-запросов или cold PASS.

Выполнение и расчёт результата производятся в сохранённом сценарии Loginom.
Коды ответа и ошибка берутся из фактического дополнительного выхода REST,
а не подставляются по входным URL. Повторы, таймауты, имитация и auth/TLS
не входят в r03.
