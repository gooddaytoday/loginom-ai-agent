Проверьте отправку двух тестовых записей из requests.csv через REST-сервис https://httpbin.org/anything; это публичное эхо, реальные API и секреты не нужны.
Импортируйте CSV UTF-8 с запятой и заголовком; все четыре поля считайте строками, включая When, и сохраняйте их текст без изменений.
Для каждой записи получите отдельный ответ пятью методами, в пяти ветках с названиями REST GET, REST DELETE, REST POST, REST PUT и REST PATCH.
Для GET, DELETE и POST передайте RequestId, Key и When в строке запроса с теми же именами и в таком порядке.
Для PUT добавьте RequestId единственным сегментом после /anything; для PATCH подставьте RequestId в адрес https://httpbin.org/anything/:RequestId.
Для POST, PUT и PATCH отправьте точный текст Body в теле сообщения с типом text/plain; ответ ожидается application/json.
Во всех пяти ветках добавьте заголовок X-Lab86 со значением wave2; аутентификация не требуется, проверку сертификатов оставьте включённой, повторы выключите.
Покажите ответы сервиса и дополнительные сведения о завершении каждого запроса.
Экспортируйте таблицу ответов каждой ветки в отдельный текстовый CSV UTF-8 рядом с пакетом: get.csv, delete.csv, post.csv, put.csv, patch.csv.
