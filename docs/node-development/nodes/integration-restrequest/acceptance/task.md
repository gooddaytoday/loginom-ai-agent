Для каждой строки requests.csv запроси https://httpbin.org/anything с параметрами RequestId и Key.
Из ответа сервиса возьми вернувшиеся значения RequestId и Key и код HTTP-ответа; сохрани эти три столбца в результате.
Выгрузи результат в текстовый CSV UTF-8 рядом с пакетом и сохрани сценарий в {{PACKAGE_PATH}}.
Входной CSV — UTF-8, с заголовком и разделителем-запятой; RequestId и Key — строки.
