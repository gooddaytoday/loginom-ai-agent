Отправь обе строки requests.csv в https://httpbin.org/anything методом PATCH. Body передай как исходное тело UTF-8 с Content-Type application/json, без query-параметров.
Построй только импорт → один REST-узел → экспорт, без Слияний, Объединений, Калькуляторов и JS. JSON ответа не разбирай. С порта 0 REST выгрузи исходные RequestID (целое) и Response (строка) в patch-body.csv: UTF-8, запятая, заголовок; значения, NULL и порядок столбцов сохрани. Должно быть две строки. Фактические HTTP-коды покажи чтением порта 1 этого же REST, не соединяй таблицы.
Сохрани пакет в {{PACKAGE_PATH}} и скачай CSV рядом с пакетом.
