Для строк requests.csv сделай GET к https://httpbin.org/anything тремя способами: RequestId и Key в строке запроса, два дополнительных сегмента пути, затем подстановка этих значений в https://httpbin.org/anything/{RequestId}/{Key}.
Передавай исходные значения без предварительного кодирования. Покажи фактический url из каждого ответа в виде абсолютного URI с кодированием пробелов и не-ASCII символов (для использования в другом HTTP-клиенте), а также HTTP-код вместе с исходным RequestId и способом: UrlMode, RequestId, Url, HttpStatusCode.
Выгрузи шесть строк в url-modes.csv (UTF-8, запятая, заголовок) рядом с пакетом и сохрани сценарий в {{PACKAGE_PATH}}.
