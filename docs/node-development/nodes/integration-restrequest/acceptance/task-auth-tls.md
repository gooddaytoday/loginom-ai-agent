Используй заранее подготовленные оператором REST-подключения LabBasic к https://postman-echo.com/basic-auth и LabBearer к https://httpbin.org/bearer. Учетные данные уже сохранены; проверка сертификата включена.
Выполни GET через каждое подключение. Возьми authenticated из ответа сервиса; сам токен, пароль и Authorization нигде не показывай и не сохраняй в результат. Полное исходное тело авторизации в ответ не выводи.
Выгрузи auth-tls.csv: AuthMode (Basic или Bearer), Authenticated (логическое из ответа), HttpStatusCode (фактическое число). CSV — UTF-8, запятая, заголовок, рядом с пакетом.
Сохрани сценарий в {{PACKAGE_PATH}}; секреты не включай в названия, экспорт или ответ.
