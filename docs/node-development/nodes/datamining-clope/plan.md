## Предлагаемое разбиение на этапы

Разбиение — гипотеза до этапа 0. Каждый этап должен приниматься самостоятельно; общие изменения, нужные этапу, входят в его же карточку.

- `datamining-clope:s1` — CLOPE и независимые N/W/S. Требования: `datamining-clope:r01`, `datamining-clope:r02`.
- `datamining-clope:s2` — Оба входа, все ограничения и применение. Требования: `datamining-clope:r03`, `datamining-clope:r04`, `datamining-clope:r05`. После: `datamining-clope:s1`.

## Заметки черновика

CLOPE принимает основную/дополнительную таблицы транзакций с дискретными полями Транзакция и Элемент. Два выхода: назначение каждой транзакции кластеру и параметры N (транзакции), W (уникальные элементы), S (мощность). Число кластеров выбирается алгоритмом; коэффициент отталкивания и limits его ограничивают. Требуется обучение.

T1={A,B}, T2={A,B}, T3={X,Y}, T4={X,Y}, T5={A,B,C}. Независимый расчёт для каждого найденного кластера проверяет N, W, S; для небольшого случая перебрать возможные разбиения и записать стоимость, но не требовать от эвристики глобального максимума без спецификации. Для принятия алгоритмического режима использовать заранее закреплённый reference результат на однозначном fixture, сравнивая множества кластеров с точными IDs без нумерации. При r=1/2.6/4 подтвердить чтение настроек и проверяемые структурные ограничения, не обещать строго монотонное число кластеров.

Узловые отказы: Неподходящие типы и отсутствие ролей, r вне диапазона, разрыв обучения/сохранения; output старого обучения не подходит новому входу.
