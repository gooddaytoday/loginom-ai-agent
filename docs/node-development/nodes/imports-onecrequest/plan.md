## Предлагаемое разбиение на этапы

Разбиение — гипотеза до этапа 0. Каждый этап должен приниматься самостоятельно; общие изменения, нужные этапу, входят в его же карточку.

- `imports-onecrequest:s1` — Запрос к независимой базе 1С. Требования: `imports-onecrequest:r01`. Среда: Windows, 1С COM, тестовая база.
- `imports-onecrequest:s2` — Параметры, макросы и версии 1С. Требования: `imports-onecrequest:r02`, `imports-onecrequest:r03`, `imports-onecrequest:r04`. После: `imports-onecrequest:s1`.

## Заметки черновика

Обязательное 1С COM-подключение + необязательные управляющие переменные → таблица. Только Windows; REST/OData относится к другим узлам.

Изолированная учебная база 1С с двумя товарами, ценами 10 и 25, датами и пустым реквизитом. Независимый запрос в консоли 1С закрепляет таблицу значений/типов; read-only роль для основного набора.

При неясном выполнении выяснить состояние запроса; не подменять механизм 1С другим протоколом. Секреты подключения остаются во внешнем окружении.
