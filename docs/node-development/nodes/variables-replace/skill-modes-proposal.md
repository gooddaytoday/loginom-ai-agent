# variables.replace — предложение LAB-1031

Это предложение для этапа 1, не текущая поддержка runtime.
Узел получает переменные через variable_inputs, вход 0, выход переменных 0;
табличного входа нет. Сначала прочитай полную карточку типа.

exact сохраняет прежние ограничения: пары одного типа, строки с учётом
регистра, precision=0, other=keep. Для исследованного расширения предлагается
mode=rules. Для каждой rules задай variable:{kind:"input_variable",name},
type входной переменной и полное правило. Неперечисленные правила сохраняются.

Строковые пары from/to можно сопоставлять без учёта регистра:
case_sensitive=false; проверено RED по ключу red → blue. Подтверждён только ASCII.
Числовым парам задай неотрицательную native precision: 1.25 совпало с 1.2
при precision=0.1 и стало 2.5. Это не округление результата; граница допуска
и абсолютная/относительная шкала пока не проверены.

regex_pairs:[{pattern:"^Ab-[0-9]+$",replacement:"matched"}] использует
отдельную native-группу регулярных выражений для строк. Проверен якорный
ASCII-шаблон и постоянная строка замены. Не смешивай regex и exact для одной
переменной в этом срезе: порядок групп, захваты и глобальная замена не проверены.
Не подменяй проверяемый узел Калькулятором или JavaScript.

other=keep сохраняет несовпавшее исходное значение, null задаёт typed NULL,
value использует same-type other_value. Для null/value таблица пар может
отсутствовать. Другие политики остальных в карточку этого среза не включены.
NULL, пустая строка, false и 0 различаются. Пары не образуют каскад.

Имена, метки, типы и порядок сохраняются. Native-мастер добавляет «Замена»
к меткам обработанных переменных; обработчик должен восстановить исходные
метки так же, как в exact. Читай полный typed-выход, read:{ports:[],variable_ports:[0]},
finish=execute; затем отдельно Save и проверка повторного открытия.
Для fixture с неизменённым Variant нужна аддитивная поддержка Variant в W1.

Смена типа, обработка Variant и datetime-ключей не предлагаются для вызова
в этом срезе: у typed-пробы Save/reopen дал native-ошибку назначения «Активное»
для Variant; datetime-редактор отбросил ненулевые миллисекунды. Такие запросы
следует отклонять до мутации до завершения отдельного исследования.
