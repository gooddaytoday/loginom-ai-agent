В новом пакете создайте пользовательские переменные сценария из приложенного
variables.json, сохранив имена, метки, типы, порядок и различие между NULL
и пустой строкой.

Добавьте «Замену (переменные)» и подключите к ней пользовательские переменные.
Внесите точные пары из раздела initial файла rules.json. Учитывайте регистр,
сравнивайте числа точно, типы переменных сохраняйте. Если соответствия нет,
оставляйте исходное значение. Переменные, для которых правил нет, не меняйте.
Покажите полный набор выходных переменных после выполнения.

В том же узле замените таблицу правил только для переменной из раздела update.
Повторите расчёт и покажите полный результат. Затем измените только исходное
значение из source_update, выполните прежний узел без перенастройки и снова
покажите все выходные переменные. Сохраните пакет после последнего расчёта
в {{PACKAGE_PATH}}, закройте пакет и выйдите из Loginom.
