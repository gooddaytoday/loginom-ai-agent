Продолжите пакет с настроенной нечувствительной к регистру заменой Color,
регулярным выражением для Code и точностью 0.1 для Amount.
В том же узле Замены настройте следующие изменения:

1. Для TextNum замените строку "007" на целое 7, сохраняя остальные значения.
   Тип значения замены отличается от исходного; проверьте объявленный тип выхода.
2. Для mixed замените целое значение 7 на строку seven, сохраняя тип переменной Variant.
3. Для report_date задайте точную пару 7 ноября 2026 года 23:59:58.000 →
   8 ноября 2026 года 23:59:58.000. Сравнивайте до миллисекунд: исходная
   дата 23:59:58.123 не равна ключу этой пары.
4. Для Other заменяйте остальные значения на строку default.

Сохраните технические имена, исходные метки и порядок переменных.
Выполните узел, прочитайте весь исходный выход, сохранив различие
объявленного Variant и типа его значения. Сохраните пакет, повторно откройте,
выполните с сохранёнными настройками, проверьте выход, закройте и завершите сеанс.
