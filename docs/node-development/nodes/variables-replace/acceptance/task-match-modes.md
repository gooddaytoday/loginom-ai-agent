Создайте источник по modes-source.json в одном узле «Переменные сценария»: все
8 переменных в порядке источника. Подключите к нему один
узел Замены переменных и настройте в нём одновременно:

1. Для Color замену red на blue без учёта регистра.
2. Для Code замену значения, подходящего под регулярное выражение
   ^Ab-[0-9]+$, на строку matched.
3. Для Amount замену 1.2 на 2.5 с точностью сравнения 0.1.
4. Для Other замену остальных значений на пропущенное, без таблицы точных пар.

Другие переменные сохраняются. Сохраните технические имена, исходные метки,
типы и порядок при первичном выполнении. Выполните этот узел и прочитайте весь исходный выход
переменных, различая NULL и пустую строку и сохраняя типы.
Сохраните пакет. После повторного открытия выполните узел с сохранёнными
настройками и проверьте весь выход. После открытия допустим штатный порядок
переменных Loginom при включённой автосинхронизации; значения, типы и метки точные. Закройте пакет и завершите сеанс.
