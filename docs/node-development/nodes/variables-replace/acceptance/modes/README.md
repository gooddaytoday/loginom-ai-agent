Комплект этапа 0 — предложение, не регистрация сценария run-check.
`match_modes` проверяет значения независимым re/casefold/Decimal oracle для
фиксированного fixture. Предлагаемые имена, метки, типы и порядок сохраняются
как в exact; native-метки по умолчанию отличаются, handler должен их восстановить.
`types_probe` фиксирует данные Execute; Save/reopen отказал с назначением
«Активное» для Variant. Этот probe не входит в callable-карточку и не готов
к положительной приёмке до исследования допустимого назначения и W1 Variant.
Datetime-пара имеет .000; исходное .123 не совпадает. Ввод .123 native-редактор
округлил до .000 — этот факт описан в discovery, а не скрыт oracle.
Модель получает только пользовательское задание и нужные fixtures;
oracle/expected ей не передаются. Проверка: `python3 oracle.py --check`.
