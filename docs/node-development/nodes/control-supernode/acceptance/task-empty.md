Импортируйте предоставленный empty.csv с заголовком и без строк.
Задайте типы RowID — целое, Amount — вещественное, Note — строка,
Flag — логическое, Moment — дата и время. Создайте Подмодель с одним
обязательным табличным входом Input и выходом Output; внутри создайте
Калькулятор, передающий исходные поля и добавляющий вещественное Doubled
как Amount, умноженное на два. Соедините обе табличные границы.
Выполните Подмодель и прочитайте её полный внешний выход, включая схему.
Сохраните пустой результат с заголовком в empty-result.csv рядом с пакетом.
Сохраните пакет в {{PACKAGE_PATH}}, закройте его и завершите сеанс.
