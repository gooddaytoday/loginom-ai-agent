Создайте пакет с Подмоделью, которая вычисляет смещение страницы без Цикла.

У Подмодели один вход переменных Params с меткой «Параметры» и один табличный
выход Answers с меткой «Ответы». Табличного входа нет. Во входе переменных
задайте в таком порядке: Page (целый, 99), Limit (целый, 2), без пропусков.
Внешний источник переменных не нужен.

Внутри Подмодели подключите переменные входного узла к узлу «Переменные в таблицу»
в режиме «В столбцы». Его таблицу подключите к Калькулятору, а к обычному входу
переменных Калькулятора — те же переменные входного узла. Создайте целое поле
Skip по формуле Var.Page * Var.Limit. Сохраните поля Page и Limit.
Передайте результат Калькулятора в порядке Skip, Page, Limit в выход Подмодели.
Не создавайте вложенных Подмоделей и Циклов.

Выполните Подмодель, прочитайте весь выход с именами, типами и значениями.
Выгрузите результат в supernode-vars.csv рядом с пакетом. Сохраните пакет
по пути {{PACKAGE_PATH}}, закройте пакет и завершите сеанс.
