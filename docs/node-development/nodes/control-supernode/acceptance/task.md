Создайте пакет для расчёта сумм внутри Подмодели. Импортируйте предоставленный
input.csv: UTF-8, разделитель запятая, первая строка — заголовок, десятичная точка,
маркер пустого значения «?». Пустой текст в Note должен оставаться пустой строкой.
RowID — целое, Amount — вещественное, Note — строка, Flag — логическое,
Moment — дата и время без часового пояса.

Создайте Подмодель с одним обязательным табличным входом Input
с меткой «Исходные данные» и одним табличным выходом Output с меткой «Результат».
Подключите импорт к её входу. Войдите внутрь и создайте Калькулятор,
передающий все исходные поля и добавляющий в конце вещественное поле Doubled:
Amount, умноженное на два; если Amount пусто, Doubled тоже должно быть пусто.
Свяжите входной узел с Калькулятором, а его результат — с выходным узлом.
Подмодели внутри Подмодели не нужны.

Вернитесь наружу, выполните Подмодель и прочитайте весь её выход,
сохранив исходный порядок строк и полей, повторы и типы.
Выгрузите результат в initial.csv рядом с пакетом.
Замените файл у того же импорта на replacement.csv, сохранив существующие
Подмодель, Калькулятор и связи. Повторно выполните Подмодель и прочитайте
её полный внешний выход. Выгрузите его в result.csv рядом с пакетом.
Сохраните пакет по пути {{PACKAGE_PATH}}. Закройте пакет и завершите сеанс.
