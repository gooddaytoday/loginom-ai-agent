Создай новый пакет для сверки операций с деталями. Исходные файлы — `left.csv` (операции) и `right.csv` (детали). Оба файла имеют UTF-8, заголовок в первой строке, разделитель `;`, маркер пропуска `NULL`. Поля LKey, LValue, RKey, RValue — дискретные строки; Part и PartR — дискретные целые. Сохрани исходные имена, метки, типы и пропуски, не переименовывай и не исключай поля при импорте.

Сопоставляй операции с деталями одновременно по LKey ↔ RKey и Part ↔ PartR, с учётом регистра строк. Построй два отдельных результата узла «Слияние»: «Операции с деталями» — внутреннее соединение, «Все операции» — левое соединение. Сохрани в обоих результатах все поля операций и деталей, включая ключи деталей. Все повторные совпадения должны сохраняться; операции без деталей должны оставаться только в левом результате, с пропусками в полях деталей.

Выполни оба результата, прочитай все строки и поля с точными значениями и типами, поясни различия. После всех чтений сохрани пакет в новый путь `{{PACKAGE_PATH}}`. Закрой свой пакет и выйди из своего сеанса.
