Найди записи основной таблицы left.csv, для которых нет пары в right.csv, средствами Loginom. В приложенных CSV разделитель «;», первая строка содержит имена полей; все поля строковые.

Основной таблицей должна быть left.csv, присоединяемой — right.csv. Используй узел «Слияние» с операцией «Разность». Свяжи LKey с RKey и LPart с RPart одновременно, с учётом регистра. Отключи добавление присоединяемых ключевых полей. Результат должен содержать исходные поля и имена основной таблицы.

Выполни узел, проверь результат и выгрузи его в difference-result.csv: UTF-8, разделитель «;», заголовок из имён полей, NULL как NULL. Порядок строк и столбцов в CSV свободный. Сохрани пакет в {{PACKAGE_PATH}}, затем закрой его и выйди из Loginom.
