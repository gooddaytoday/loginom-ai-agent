Сопоставь две приложенные таблицы left.csv и right.csv в Loginom. В них разделитель «;», первая строка содержит имена полей; все поля строковые.

Основной таблицей должна быть left.csv, присоединяемой — right.csv. Используй узел «Слияние» с операцией «Правое соединение». Свяжи LKey с RKey и LPart с RPart одновременно, с учётом регистра. Сохрани все совпадения, включая повторные, и все записи правой таблицы без пары. Включи присоединяемые ключевые поля. Сохрани исходные имена всех выходных полей.

Выполни узел, проверь результат и выгрузи его в right-result.csv: UTF-8, разделитель «;», заголовок из имён полей, NULL как NULL. Порядок строк и столбцов в CSV свободный. Сохрани пакет в {{PACKAGE_PATH}}, затем закрой его и выйди из Loginom.
