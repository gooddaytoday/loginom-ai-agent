Импортируй types.csv: UTF-8, разделитель ;, заголовок, двойные кавычки,
NULL-маркер \N, десятичная точка. RowID — целое, Region — строка,
Price — вещественное, Day — дата (год-месяц-день), Flag — логическое.
Типы задай явно, исходный порядок записей сохрани.

Сгруппируй по Region и рассчитай по Flag: минимум (FlagMin), максимум
(FlagMax), наиболее частое значение (FlagMode), число различных значений
(FlagValues) и число пропусков (FlagMissing). Flag должен остаться
логическим, не заменяй его числом 0/1 или строкой.

Покажи весь результат с типами полей и выгрузи полный CSV с техническими
именами, маркером NULL для пропусков. Сохрани пакет в {{PACKAGE_PATH}}.
После нового открытия выполни сохранённый сценарий без повторной настройки,
покажи и выгрузи результат.
