Импортируй variant.csv: UTF-8, разделитель ;, заголовок, двойные кавычки,
NULL-маркер \N, десятичная точка. RowID и IntValue — целые, RealValue —
вещественное, TextValue — строка. Типы задай явно.

Сверни IntValue, RealValue и TextValue в одно поле Values переменного типа,
в этом порядке; RowID оставь информационным полем, пустые значения не
исключай. Выполни и покажи этот промежуточный результат с подтипами.

Затем сгруппируй его по RowID и для Values найди: число значений (Cells),
число пропусков (EmptyCells), первое (FirstValue) и последнее (LastValue)
значение в порядке после свёртки, включая пустые. Сохрани исходные подтипы
целое/вещественное/строка; не заменяй переменное поле строкой.

Покажи весь результат и выгрузи полный CSV с техническими именами,
маркером NULL для пропусков. Сохрани пакет в {{PACKAGE_PATH}}. После
нового открытия выполни сохранённый сценарий без повторной настройки,
покажи и выгрузи результат.
