Импортируй mode-tie.csv: UTF-8, разделитель ;, заголовок, двойные кавычки,
NULL-маркер \N. RowID и Amount — целые, Region и Text — строки. Типы задай
явно, исходный порядок записей сохрани.

Сгруппируй по Region и найди моду Amount (AmountMode) и Text (TextMode)
без учёта пропусков. Если несколько значений встречаются одинаково часто,
используй штатный результат этой агрегации, не выбирай значение вручную.

Покажи весь результат и выгрузи полный CSV с техническими именами,
маркером NULL для пропусков. Сохрани пакет в {{PACKAGE_PATH}}. После
нового открытия выполни сохранённый сценарий без повторной настройки,
покажи и выгрузи результат.
