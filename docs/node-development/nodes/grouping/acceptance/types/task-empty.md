Импортируй empty.csv: UTF-8, разделитель ;, заголовок, двойные кавычки,
NULL-маркер \N, десятичная точка. В файле только заголовок. Region —
строка, Amount — целое, Price — вещественное, Day — дата (год-месяц-день),
Flag — логическое. Типы задай явно.

Сгруппируй по Region: число записей по Amount (Rows), сумма Price (Total),
самая ранняя дата Day (FirstDay) и максимум Flag (AnyFlag). Записей нет —
результат должен остаться пустой таблицей с этими полями и типами, без
выдуманных строк и нулей.

Покажи результат со структурой полей и выгрузи CSV с техническими именами
в заголовке. Сохрани пакет в {{PACKAGE_PATH}}. После нового открытия
выполни сохранённый сценарий без повторной настройки, покажи и выгрузи
результат.
