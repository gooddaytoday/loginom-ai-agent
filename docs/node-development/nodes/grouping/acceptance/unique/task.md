В customers.csv находятся клиенты по регионам. Импортируй CSV UTF-8 с разделителем ;,
заголовком в первой строке, двойными кавычками и маркером NULL \N.
Region и Customer — строки, CustomerId — целое число. Сохрани отличие пустой
строки Customer от NULL; пустые CustomerId считай пропусками.

Создай одну Группировку по Region с обычным количеством строк Customer
(выход Rows, метка «Строки») и выполни её. Затем перенастрой этот же узел:
сохрани Rows и добавь количество уникальных Customer (UniqueCustomers, метка
«Уникальные клиенты») и CustomerId (UniqueIds, метка «Уникальные номера»).
Переименуй сам узел в «Клиенты по регионам» и выполни его повторно.
NULL не включай в уникальный подсчёт; пустая строка Customer — отдельное
значение. Не создавай вторую Группировку для перенастройки.

Итоговые поля: Region, Rows, UniqueCustomers, UniqueIds. Покажи весь небольшой
результат. Выгрузи его в customers-summary.csv с техническими именами полей
в заголовке и сохрани пакет.
