Создай новый пакет {{PACKAGE_PATH}}: импорт five-aggregates.csv узлом «Данные» → «Группировка» с именем «Итоги».

Импорт: UTF-8, заголовок, без пропуска строк, разделитель «;», ограничитель двойная кавычка, десятичный разделитель «.», Null — \N. Поля по порядку с одноимёнными метками: Region — строка дискретного вида, Amount — вещественное непрерывного вида, RowID — целое непрерывного вида.

Сгруппируй по Region. Показатели Amount по порядку: сумма — Amount_sum, количество строк — Amount_count, среднее — Amount_avg, минимум — Amount_min, максимум — Amount_max. Метки показателей совпадают с именами. Выход: Region и перечисленные показатели; количество учитывает Null, среднее пропуски не учитывает.
