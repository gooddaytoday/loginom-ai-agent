Создай новый пакет {{PACKAGE_PATH}}: импорт multiple-keys.csv узлом «Данные» → «Группировка» с именем «Итоги».

Импорт: UTF-8, заголовок, без пропуска строк, разделитель «;», ограничитель двойная кавычка, десятичный разделитель «.», Null — \N. Поля по порядку с одноимёнными метками: Region, Product — строки дискретного вида; Amount — вещественное, Quantity — целое, оба непрерывного вида.

Ключи сводки по порядку: Region, Product. Показатели Amount: сумма — Amount_sum, количество строк — Amount_count, среднее — Amount_avg, минимум — Amount_min, максимум — Amount_max; затем сумма Quantity — Quantity_sum. Метки показателей совпадают с именами; выход содержит ключи и только эти показатели в указанном порядке. Количество учитывает Null, среднее пропуски не учитывает.

Выполни сводку и сохрани пакет {{PACKAGE_PATH}}.
