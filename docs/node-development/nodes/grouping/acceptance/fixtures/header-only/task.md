Создай новый пакет {{PACKAGE_PATH}}: импорт header-only.csv узлом «Данные» → «Группировка» с именем «Итоги».

Импорт: UTF-8, заголовок, без пропуска строк, разделитель «;», ограничитель двойная кавычка, десятичный разделитель «.», Null — \N. Поля по порядку с одноимёнными метками: Region — строка дискретного вида, Amount — вещественное непрерывного вида, Text — строка дискретного вида.

Сгруппируй по Region. Показатели Amount по порядку: сумма — Amount_sum, количество строк — Amount_count, среднее — Amount_avg, минимум — Amount_min, максимум — Amount_max; затем количество строк Text — Text_count. Метки показателей совпадают с именами; выход содержит Region и только эти показатели в указанном порядке. Количество учитывает Null и пустые строки, среднее пропуски не учитывает.

Выполни сводку и сохрани пакет {{PACKAGE_PATH}}.
