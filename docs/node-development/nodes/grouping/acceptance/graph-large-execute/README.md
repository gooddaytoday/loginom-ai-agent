# Большой граф: выполнение выбранного узла

`source.lgp` содержит 40 независимых фоновых калькуляторов переменных. Он получен из `variables-vartodata/fixtures/source.lgp`: XML-узел клонирован с уникальными GUID и подписями, размещён сеткой; PackageIndex использует XML без бинарных дублей. Штатная source-package фаза run-check загружает, открывает, сохраняет и закрывает пакет до модели.

Модели передаются только task.md и customers.csv. expected.json повторяет независимые ожидания grouping-unique и перечисляет фоновые узлы. Число узлов и сохранность подписей дополнительно сверяются по журналу production-observe; штатная проверка nodes проверяет наличие типов, а не число одинаковых типов. Выполнение и повторная настройка группировки, полный CSV, Save, холодное выполнение и cleanup проверяются штатным run-check; новый механизм верификации не добавляется.
