Создай новый пакет {{PACKAGE_PATH}} в Loginom с двумя аналитическими узлами: «Текстовый файл» с именем «Данные» и подключённая «Группировка» с именем «Итоги». Используй предоставленный grouping.csv; размести его рядом с пакетом и подтверди исходные байты и SHA-256.

Импортируй UTF-8 с заголовком, без пропуска строк, разделитель «;», ограничитель двойная кавычка, десятичный разделитель «.», маркер Null — \N. Сохрани исходный порядок, имена и метки полей: Group, Segment, Amount, Other, Text. Group, Segment и Text — строки дискретного вида; Amount — вещественное, Other — целое непрерывного вида. Выполни импорт и прочитай весь результат.

Сначала составь сводку по Group. Показатели по порядку: сумма Amount — Total («Сумма»), количество строк Amount — Rows («Строки»), среднее Amount — Average («Среднее»), минимум Amount — Minimum («Минимум»), максимум Amount — Maximum («Максимум»), количество строк Text — TextRows («Количество строк»). Оставь только запрошенные функции. Количество учитывает строки с Null и пустотой; среднее пропуски не учитывает. Проверь все группы, типы и значения, сохрани промежуточный пакет без закрытия с суффиксом .draft.lgp.

Затем измени тот же узел «Итоги», сохраняя его идентичность и связь. Новые ключи по порядку Segment, Group. Полностью замени показатели на сумму Other — OtherTotal («Сумма»), среднее Amount — MeanAmount («Сумма»), количество строк Text — TextRows («Количество строк»). В выходе отключи автосинхронизацию, исключи Segment; активные поля по порядку Group, OtherTotal, MeanAmount, TextRows. Сохрани прочие настройки и входное сопоставление. Выполни и прочитай весь результат, сравни каждую группу с независимым расчётом по входным данным, сохраняя Null, пустую строку и дробную точность.

Сохрани окончательный пакет {{PACKAGE_PATH}}. Закрой и заново открой именно его. Проверь сохранённые узлы, связь, параметры и выходные поля. Повторно выполни оба существующих узла без изменения настроек и прочитай все выходные строки. Закрой свои пакеты и выйди из своего сеанса с подтверждением.
