# Задание: Группировка

Импортируй приложенный CSV в Loginom. В данных есть колонки `Category` и `Amount`.

Построй сценарий:

1. Узел импорта текста из приложенного файла.
2. Узел группировки (`transform.group_data`): сгруппируй по `Category` и посчитай сумму `Amount`. Имя меры результата — `Total`.

Выполни сценарий и сохрани результат в новый пакет по пути:

`/lab-slot-a/node-pipeline-grouping.lgp`

Не перезаписывай существующий файл. Не удаляй и не изменяй чужие пакеты.
