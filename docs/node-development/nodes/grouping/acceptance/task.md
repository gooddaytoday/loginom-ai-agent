Создай новый пакет {{PACKAGE_PATH}} в Loginom: импорт grouping.csv узлом «Текстовый файл» с именем «Данные» → «Группировка» с именем «Итоги».

Импорт: UTF-8, заголовок, без пропуска строк, разделитель «;», ограничитель двойная кавычка, десятичный разделитель «.», Null — \N. Поля по порядку с одноимёнными метками: Group, Segment, Amount, Other, Text; Group, Segment, Text — строки дискретного вида, Amount — вещественное, Other — целое непрерывного вида.

Выполни сводку по Group: сумма Amount — Total («Сумма»), количество строк Amount — Rows («Строки»), среднее Amount — Average («Среднее»), минимум Amount — Minimum («Минимум»), максимум Amount — Maximum («Максимум»), количество строк Text — TextRows («Количество строк»). Только эти показатели в указанном порядке; количество учитывает Null и пустоту, среднее пропуски не учитывает.

Затем перенастрой тот же узел «Итоги»: ключи Segment, Group; вместо прежних показателей — сумма Other — OtherTotal («Сумма»), среднее Amount — MeanAmount («Сумма»), количество строк Text — TextRows («Количество строк»). Отключи автосинхронизацию выхода, исключи Segment; активные поля по порядку Group, OtherTotal, MeanAmount, TextRows. Остальные настройки прежние.

Выполни итоговую группировку и сохрани пакет {{PACKAGE_PATH}}.
