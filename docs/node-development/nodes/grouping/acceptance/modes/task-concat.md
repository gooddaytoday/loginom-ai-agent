Импортируй modes.csv: UTF-8, разделитель ;, заголовок, двойные кавычки,
NULL-маркер \N. RowID и Amount — целые, Region и Text — строки.
Пустая строка Text отличается от NULL. Сохрани исходный порядок записей.

Сгруппируй по Region и собери списки Amount и Text. Итоговые поля:
Region, Metric (строковый список чисел), TextMetric (строковый список текста).
Для обоих разделитель |; значения Text заключай в двойные кавычки,
числа оставляй без ограничителя. NULL не включай; пустой Text включай.

На одном узле последовательно покажи и выгрузи три результата:
1. Без сортировки и без удаления повторов: порядок исходных строк.
2. Только уникальные значения, по возрастанию.
3. Только уникальные значения, по убыванию.
Изменения затрагивают оба показателя; не создавай заменяющие узлы.
Сохрани финальный вариант в {{PACKAGE_PATH}}. После нового открытия
выполни сохранённый сценарий без настройки, покажи и выгрузи весь результат.
CSV должен отличать NULL от пустого значения.
