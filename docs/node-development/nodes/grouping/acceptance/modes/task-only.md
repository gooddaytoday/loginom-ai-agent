Импортируй modes.csv: UTF-8, разделитель ;, заголовок, двойные кавычки,
NULL-маркер \N. RowID и Amount — целые, Region и Text — строки.
Пустая строка Text отличается от NULL. Сохрани исходный порядок записей.

Сгруппируй по Region и примени «Единственный» к Amount и Text.
Верни значение, если все значения поля группы совпадают; иначе — NULL.
Повтор одинакового значения не делает группу неоднозначной.
Итоговые поля: Region, Metric (целое), TextMetric (строка).

Покажи весь результат и выгрузи полный CSV с техническими именами полей,
маркером NULL для пропусков и сохранением пустых строк. Повторно задай ту же
агрегацию этому же узлу и выполни его: состав результата должен сохраниться.
Сохрани пакет в {{PACKAGE_PATH}}. После нового открытия выполни сохранённый
сценарий без повторной настройки, покажи и выгрузи результат.
