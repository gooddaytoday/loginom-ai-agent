Подготовь дерево document из input.json; when должен иметь тип Дата/Время с миллисекундами, остальные типы заданы в types. Сначала выдай дату в ISO 8601, затем на том же узле выключи ISO и задай формат даты DD.MM.YYYY и времени hh:mm:ss.zzz. Не меняй само время и другие параметры.

Работай в новом собственном пакете. Покажи полный результат и типы, экспортируй каждую итоговую таблицу в отдельный CSV. Сохрани пакет в {{PACKAGE_PATH}}, закрой пакет и выйди из учётной записи. Если настройка недоступна, сообщи наблюдаемую причину без подмены результата.
