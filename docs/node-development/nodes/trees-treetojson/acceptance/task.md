В documents.csv находится документ с позициями. Импортируй RowID как целое,
Document как строку; первая строка — заголовок, разделитель — запятая,
кавычки ограничивают текст. Преобразуй документ в типизированное дерево
с автоматически определённой структурой и автоматическим выбором корня.

Прочитай полное дерево и снова представь его одной компактной JSON-строкой,
без служебного имени Root, с техническими именами полей. Сохрани порядок
позиций, числовые и логические значения, NULL и пустые строки. Если скалярное
поле в одной позиции отсутствует, сохрани значение NULL, полученное в дереве.
Покажи полный результат и сохрани пакет в {{PACKAGE_PATH}}.
