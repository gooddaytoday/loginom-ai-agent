## Границы

Таблица + XSD connection + необязательные управляющие переменные → таблица XML-документов и ID; это не файл экспорта.

В подплане 5 требований и 2 этапов до полного функционального покрытия. Первый этап — соответствие xsd и все виды группирования документов.

- Официальные источники: Help 7.4, прочитаны 2026-10-02; точные ссылки/версии и requirement IDs находятся в плане.
- Проверено: статический реестр, existing runtime patterns и документация. Live discovery, source tests и автономная CLI-приёмка не выполнялись.
