# Квантование (`preprocessing.binning`)

## Обучение и применение

Используй штатное Квантование. `internal` строит интервалы по текущему входу;
`apply` выполняет существующий узел по сохранённым интервалам без обучения:
`parameters:{}`, `inputs:[]`, `mappings:[]`, `finish:"execute"`.
Прочитай оба выхода `read.ports:[0,1]`: строки и диапазоны.
Исходные поля, порядок строк, NULL и пустые строки сохраняются.
Производные поля располагаются сразу после квантуемого поля.
Done сохраняет настройки узла; пакет сохраняй отдельно.

## Числовые поля и DateTime

В `parameters.binning` укажи точное `field`, `method`, параметры метода.
`count` — количество интервалов, `width` — ширина, `frequency` — плитки;
`size` положителен, у count/frequency целый. `limits:[lower,upper]` задаёт
крайние пределы; отсутствие обоих пределов означает автоматический выбор,
а не подстановку min/max. У DateTime используй civil ISO без преобразования
часового пояса и точные миллисекунды. Смешанные типы границ отклоняй.

`sd` использует `sd_coefficient:1|2|3`, то есть ±1/±2/±3 СКО и открытые хвосты.
`rounding` и `open_ends:{lower,upper}` задаются явно; источник не округляется.
У frequency `measure:"count"|"sum"` и `ties` выбирают правило совпадений:
next, current, unchanged, equal_tiles. Random не допускается без утверждённого
критерия недетерминированного результата. Суммы для DateTime не предлагай.

## Материализованные интервалы

`manual` задаёт `intervals` с lower/upper, lower_included/upper_included, label.
`labels` переименовывает материализованные интервалы по их порядку.
Редактируй только интервалы выбранного поля; после правки перечитай соседнюю
границу и тип включения. Если сначала требуется расчёт, обучи до ручной правки.
Не запускай повторное обучение после неё: оно может заменить сохранённую модель.
В apply сохраняй границы, метки, порядок и флаги, затем читай оба порта.
Переменные и внешние интервалы не входят в это расширение.
