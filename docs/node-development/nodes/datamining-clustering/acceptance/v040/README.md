## Предлагаемая приёмка после снятия блокировки

`oracle.py` читает только CSV; `expected.json` — независимое предложение,
**не stock expected**. Непроверенные схемы и семантика явно перечислены.
Точные integer/string/boolean/NULL и типы; допуски только для real.
Изменение существующего узла без пересоздания, два повтора при тех же
настройках, полный CSV/все порты, Save, cold без повторной настройки,
cleanup и правило 2/3 на одном SHA остаются обязательными на этапе 1.
Новых проверяющих механизмов в этой ветке нет; нельзя засчитать PASS
по одному аналитическому расчёту либо игнорировать нерешённые поля.

Воспроизведение из каталога v040:

```sh
python3 oracle.py > expected.json
python3 oracle.py --check
```
