На warm-пробе группы {1,2,3,4} и {5,6}; независимое среднее даёт (5.1,5.1) и (20.1,2.1). Нумерация Cluster не является рангом. В oracle g-means проверяет min≤count≤max, точное покрытие входа, среднее каждого назначенного кластера и расстояния; не требует произвольного «истинного k=3».
`probe*.csv` воспроизводят живую пробу. `train.csv`/`holdout.csv` — отдельный предложенный фиксированный k=3 apply-пример с заранее вычисленными центрами (2,2),(20,2),(2,20); не выдаётся за выполненный g-means.

Пути этапа 1: `clustering-{parameters,context,procedure,node,readback,output}.mjs`. Apply требует пропустить Teach и честно отразить отсутствие training в readback; g-means — сохранить auto/min/max/threshold и не сравнивать centers с произвольным фиксированным k.
