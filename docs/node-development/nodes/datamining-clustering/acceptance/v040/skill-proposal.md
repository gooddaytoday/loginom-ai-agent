# Предложение навыка v040, не активная инструкция

Кластеризация: k_means — фиксированное число; g_means — min_clusters,
max_clusters и threshold. Обучение выполняется явно перед Execute.
Для apply используй тот же сохранённый обученный узел, без retrain;
прочитай назначения/расстояния (0) и центры (1) до и после holdout.
Числовые признаки задай через features, идентификаторы сохрани вне features.
Номера кластеров — метки. Центры в исходных единицах, расстояния —
в пространстве выбранной нормализации. Не меняй смешанные нормализаторы
без явного запроса. Ручной исходный диапазон и контроль диапазона задавай
только по просьбе пользователя и после подтверждения UI.
Нормализация «Отношение» заблокирована: её нет в наблюдённых списках UI.
Не подменяй её другой нормализацией. Контракт и численная семантика ещё
не утверждены. Сохрани пакет после чтений и экспорта.
