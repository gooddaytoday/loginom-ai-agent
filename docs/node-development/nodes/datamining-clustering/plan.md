## Предлагаемое разбиение на этапы

Разбиение — гипотеза до этапа 0. Каждый этап должен приниматься самостоятельно; общие изменения, нужные этапу, входят в его же карточку.

- `datamining-clustering:s1` — Фиксированный k-means. Требования: `datamining-clustering:r01`, `datamining-clustering:r02`.
- `datamining-clustering:s2` — g-means и нормализация. Требования: `datamining-clustering:r03`, `datamining-clustering:r04`, `datamining-clustering:r05`. После: `datamining-clustering:s1`.

## Заметки черновика

Табличный вход, роли Используемое/Не задано. Два выхода: исходные строки с номером кластера/расстоянием и центры кластеров. Непригодны поля с NULL, дискретной единственной категорией или нулевой непрерывной дисперсией. k-means задаёт число; g-means подбирает его в интервале. Обучение подтверждено Help.

Три группы по четыре точки вокруг (0,0),(20,0),(0,20), с симметричными смещениями ±0.1; k=3, seed фиксирован, нормализация выключена. Ожидаемые центры известны; atol=1e-8 и независимые евклидовы расстояния. В Help граница ручного числа сформулирована «больше 2»: этап discovery проверяет 2/3 и не добавляет обещание k=2. Для g-means фиксировать пары separated/overlapping и проверять инварианты и согласованность сохранённой модели, без универсального критерия истинного числа кластеров.

Узловые отказы: Несовпавшая input identity, изменение нормировки после обучения, seed не подтверждён; не перезапускать обучение до выяснения неизвестного эффекта.
