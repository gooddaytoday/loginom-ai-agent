Ручная диагностическая проверка до реализации поддержки внешнего справочника;
не самостоятельный модельный сценарий run-check.

Подай input.csv на основной вход одного узла «Замена», rules.csv — на второй
табличный вход. CSV: UTF-8, разделитель ;, заголовки, пропуск ?.
Id — целое; остальные поля обоих файлов — строки.
Для Code выбери внешнюю таблицу: Value — «Значение», Replacement — «Замена»,
Info — «Информационное», Ignored — «Не используемое».
Оставляй несовпавшие значения, сравнивай с учётом регистра.

Выполни узел. Ожидается отказ «Значение дублируется в таблице замен»:
две строки AB-12 не образуют успешный выход ни с FIRST, ни с SECOND.
Не удаляй дубликаты, не выбирай первое/последнее значение и не размножай
основные строки автоматически. Сохрани диагностическое сообщение.
Для положительной проверки используй отдельный rules-unique.csv и task-external.md.
