# Начальный комплект приёмки Замены

Статус: подготовлен частично, не принят. См. `../discovery.md`.

`data/` и `fixtures/` сохраняют прежние входы и ожидания без изменений.
`source-manifest.json` фиксирует размеры и SHA до прогона.
`python3 oracle.py` воспроизводит `expected.json` без импорта runtime.
Перед запуском подставить назначенный путь пакета вместо `{{PACKAGE_PATH}}`
в копии ожиданий и задания; каталог — вместо `{{STORAGE_DIRECTORY}}`.
Oracle, fixtures и expected модели не передаются.

Задание сохраняет прежний typed/partial/mode-switch/persistence сценарий.
Проверка основных выходов подготовлена, адаптация аудита промежуточных
квитанций, негативных отказов и остальной адресной матрицы не завершена.
Наличие этого каталога не означает PASS или полный охват подплана.

Добавлены `transcript-audit.py <attempt-directory> <fixtures-directory>` для
проверки полных свежих результатов Typed/Preserved, частичных patches и смены
режима, сохранения и повторного выполнения без передачи настроек;
`contract-preflight.mjs` проверяет локальные отказы и не считается live-приёмкой.
`expected.json` включает независимые схемы CSV для проверки static_sources.
Модель получает только `task.txt` и два CSV в отдельном каталоге; эти аудиторы
запускает внешний исполнитель после завершения CLI.
