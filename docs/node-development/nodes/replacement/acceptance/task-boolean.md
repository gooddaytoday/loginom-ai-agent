Подготовь логический признак из Status в input.csv с помощью одного узла
«Замена». CSV — UTF-8, разделитель ;, заголовки, пропуск ?, Id — целое,
остальные исходные поля — строки. Пустая строка отличается от пропуска.

Точные регистрозависимые пары: yes → логическое true, no → логическое false.
Все остальные значения, включая исходный пропуск, замени на пропуск.
Замени Status результатом логического типа и сохрани признак Status_Replaced.
Id, Code и Keep не меняй. Порядок полей: Id, Code, Status, Status_Replaced, Keep.
Повторно выполни тот же узел без изменения правил.
