Подготовь типизированные поля по таблицам соответствий в одном узле «Замена».
Вход input.csv: UTF-8, разделитель ;, первая строка — заголовки, NULL — маркер пропуска.
Id — целое; IntText, RealText, DateText и Keep — строки, пустые строки сохраняй отдельно от NULL.
Точные пары:
- IntText: строку «12» замени целым 12, «-7» — целым -7, «42» — целым 42.
- RealText: строку «1.25» замени вещественным 1.25, «-2.5» — вещественным -2.5, «9.125» — вещественным 9.125.
- DateText: строку «2026-11-01» замени датой 1 ноября 2026, «2024-02-29» — 29 февраля 2024, «2024-01-01» — 1 января 2024. Время у дат — 00:00:00.
Сравнение строк регистрозависимое. Во всех трёх полях остальные значения, включая исходные пропуски и пустые строки, заменяй на пропуск. Не разбирай автоматически значения, отсутствующие в словарях.
Замени исходные три поля значениями соответствующих типов; сохрани логические признаки замены. Id и Keep оставь без изменений.
Порядок результата: Id, IntText, IntText_Replaced, RealText, RealText_Replaced, DateText, DateText_Replaced, Keep.
Выполни узел, выгрузи результат с техническими именами колонок и маркером NULL, даты — yyyy-mm-dd hh:nn:ss.
Сохрани готовый сценарий в {{PACKAGE_PATH}}.
