Нормализуй коды товаров из `input.csv`: разделитель `;`, UTF-8, заголовок в первой строке, маркер пропуска `NULL`.
Поля: Id — целое, Code и Keep — строковые; пустое строковое поле сохраняй пустой строкой.
В узле «Замена» задай для Code правила регулярных выражений без учёта регистра, в указанном порядке:
`(?i)AB-([0-9]{2})` → буквальный текст `SKU-$1`; затем `^AB-00$` → буквальный текст `ZERO`.
Первое совпавшее правило заменяет всю ячейку; если ни одно не подошло, установи пропуск.
Выбери замену исходного Code, сохрани логический Code_Replaced; Id и Keep не изменяй.
Расположи выходные поля в порядке Id, Code, Code_Replaced, Keep.
Выполни узел и сохрани готовый сценарий в `{{PACKAGE_PATH}}`.
