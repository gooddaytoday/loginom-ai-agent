В input.csv преобразуй Status одним узлом «Замена»: точное регистрозависимое
yes замени логическим true. Остальные значения оставь без изменения,
включая строку no, unknown и исходный пропуск.
Результат заменяет Status, признак замены сохрани. Порядок полей:
Id, Code, Status, Status_Replaced, Keep. CSV — UTF-8, разделитель ;,
заголовки, пропуск ?, Id — целое, исходные остальные поля — строки.
Повторно выполни тот же узел без изменения настроек.

Выгрузи всю таблицу с техническими именами и маркером пропуска ?, сохрани
сценарий в {{PACKAGE_PATH}}. В сохранённом результате должны различаться
логическое true и исходные строковые значения.
