В input.csv замени Code одним узлом «Замена». CSV — UTF-8, разделитель ;,
заголовки, пропуск ?, Id — целое, остальные поля — строки.

Шаблон AB-([0-9]{2}) ищи с учётом регистра в любой части строки.
Первое совпадение заменяет всю ячейку целой константой 9.
Остальные значения, включая пустую строку и пропуск, замени на пропуск.
Code в результате должен быть целым; сохрани Code_Replaced, Id, Status, Keep.
Порядок полей: Id, Code, Code_Replaced, Status, Keep.

с техническими именами колонок и маркером пропуска ?, сохрани в {{PACKAGE_PATH}}.
