В input.csv обработай Code одним узлом «Замена» с двумя таблицами правил.
CSV — UTF-8, ;, заголовки, пропуск ?, Id — целое, остальные поля — строки.
В точной регистрозависимой таблице задай AB-12 → EXACT-FIRST.
В таблице регулярных выражений задай AB-([0-9]{2}) → строковую константу REGEX,
поиск чувствителен к регистру, совпадение может занимать часть строки.
Точная таблица имеет приоритет перед регулярными выражениями.
Прочие значения, пустые строки и пропуски сохрани.

Замени Code результатом, сохрани признак Code_Replaced и прочие исходные поля.
Порядок: Id, Code, Code_Replaced, Status, Keep.
Повторно выполни тот же узел, выгрузи полный результат с техническими именами
и пропуском ?, сохрани сценарий в {{PACKAGE_PATH}}.
