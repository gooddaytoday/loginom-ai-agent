## Блокировка независимой проверки происхождения

Назначение фиксирует общий каталог `/lab-73-replacement`. В общем
`scripts/node-acceptance/static-source-proof.mjs:65` холодное чтение импорта
принимает только `/<account>/<file>`; в `:159` независимое скачивание также
принудительно входит в каталог аккаунта. `cold-check.mjs:126` вызывает этот
путь при `expected.static_sources`. Каталог карточки не соответствует этому
контракту ни для Манки, ни для Ловца.

Наблюдение сделано по коду, а не по завершённому холодному прогону.
Удаление `static_sources` убрало бы проверку происхождения, перенос входов в
частный каталог изменил бы назначение и доступ Ловца. Подплан запрещает
изменять общую оболочку/`cold-check.mjs` без решения владельца.

Требуется согласовать поддержку назначенного общего каталога в независимой
проверке происхождения. Модельный прогон, адресные live-сценарии и независимая
приёмка — `not_checked`; PASS не заявляется. Аккаунты и ACL не изменены.
