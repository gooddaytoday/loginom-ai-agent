## Обучение и наблюдённые результаты

Источник `design.csv`: 16 строк полного факторного плана, независимые X1/X2/X3,
Y=3+2X1+0.5X2+0.25E, E=±1. Цель импортируется явно как real/continuous:
native UI не предлагает назначение «Выходное» для целого/строкового поля.
После изменения десятичного разделителя нужно заново определить типы
(`ImportTextFileParamsWizard;ColumnDefsTuning;btnRefreshData`); изменение
формата само по себе не преобразовало ранее определённую строковую Y.

сохранённую модель. Файлы 36,38,41 сняты после Execute без явного Teach и
**не доказывают переобучение новым методом**. Их заменяют 47,48,44.

## Нормализация

`W;NormTuneWizard;colDisplayName_<поле>` выбирает поле, `btnEdit` открывает
`W;ColumnsEditForm;cbxNormType;...`. Числовой X1: нет, min/max, [-1;1], [0;1],
абсолютное масштабирование, стандартизация, отношение (13,18). Каждый вариант
выбран и показан, без отдельного обучения для каждой трансформации.
Min/max открывает `NormSettingsForm;MinMaxNormParamsForm;edtMin/edtMax` (14).
Отношение — `QuotientNormParamsForm`: статистика min/max/mean/sum/SD либо
заданный делитель (15–16). Статистики с нулевым знаменателем не испытаны.
`ControlRangeSettings;cbxControlRangeType` предлагает нет/ошибка/винсоризация;
есть ручной и исходный диапазоны, кнопка получения диапазона (17).
Границы, ошибка на holdout, винсоризация и формула SD ещё не подтверждены.

Для Boolean IsTest и строкового Category список нормализаторов содержит
**только «Индикатор»** (59,65), повторно после активации и обучения строкового
входа — тот же список (70). `DiscreteNormParamsForm;cbxReferenceType` предлагает
первое/последнее/редкое/частое/явное значение (67). Отдельного варианта
«Индикатор без опорной категории» в наблюдённом списке нет.

На `categorical.csv` (A/B/C, шесть строк каждой категории) Enter обучен с первой
опорной категорией и показом её коэффициента (68). Константа≈2.99, X≈2.02,
Category A=0, B=3, C=1. **Name повторяется «Category»**, различитель — UniqueValues.
Тип UniqueValues — string, подтверждён редактором столбца (69), не Variant.
Изменение опорной категории, tie редкой/частой, скрытие опорного коэффициента
и неизвестные категории в holdout пока не исполнялись.

## Выборки и валидация

`W;LearnPartitionWizard;pedSamplingMethod`: случайный/последовательный/по столбцу
(19–21,25). Выбор по столбцу открывает
`ByColumnMethodForm;pedPartitionColumn`, таблица размеров отключается.
Размеры train/test имеют строки и проценты; seed —
`RandSeedEdit;edtRandSeed;ValueControl`. Последовательный выбран при 100% train.
Смешанные размеры/перестановка train-unused-test, колонка с true и новый случайный
seed отдельно не проверены: для этого предложен `partition.csv` с двумя
контрольными строками Y=±999, которые обязаны остаться вне обучения.

`ValidationSettings;pedLearnValidationMethod`: нет/K-fold/Монте-Карло (22).
K-fold открывает `pedKFoldsSamplingMethod` (случайный/последовательный, 54)
и `pedFolds`; Монте-Карло — `pedIterations` и доли выборок (23–24).
Обе валидации исполнены с автоматическим методом (56,58).
Наблюдённые автоматически выбранные коэффициенты не превращены в expected.

## Полные выходы и привязки

Число портов от выбора метода не изменилось: таблицы 0/1 и переменные 2.
Выход 0 сохраняет `<target>_rergession` и исходные поля. В этом исследовании
полное точное чтение выхода 0/CSV не выполнялось; обещать новую схему
или неизменность порядка столбцов на основании preview нельзя.

Выход 1 native по умолчанию содержит девять столбцов: Name, DisplayName,
UniqueValues, Y_coefficients, Y_stdError, Y_TStat, Y_PValue, Y_lowerBound,
Y_upperBound (33,68–69). Текущий handler сам исключает семь столбцов,
оставляя Name/коэффициент: это локальный пробел `linregression-output.mjs`.
У константы DisplayName/UniqueValues=NULL; у непрерывных UniqueValues=NULL.

Выход 2: TotalSamples, TotalSelectedSamples, TrainSamples, LogLikelihood, R2,
AdjustedR2, StdDev, DFE, ModelDF, FStatistic, AIC, AICc, BIC, HQC, ModelPValue.
Для Forward (34): 16/16/16, DFE=13, ModelDF=2, F=442. Полная статистика в oracle
вычисляется по формулам; коэффициенты и p/CI не берутся из этих округлений.
Information criteria в предложении нормированы на n; native preview AIC≈0.44,
AICc≈0.57, BIC≈0.59, HQC≈0.45 совместим с таким определением, точное совпадение
ещё требует typed read/cold. Старое `requires_W4` не доказывает отсутствие
инфраструктуры сейчас: в базе есть `variable_inventory` со скалярным допуском.
Нужна интеграция самого типа и отдельная проверка существующего reader.

Меню `mn;mniShowControlVariablesPort` существует и нажато на собственном узле
(61–62). После показа порт нарисован, но его отдельного `data-tid` в DOM нет;
`...;Input_Var-1` отсутствует, переключатели привязок без соединения не видны
(63). Координатный обход/подмена native JS не применялись. **Связь, привязка и
переобучение с изменённой переменной не воспроизведены.**

## Ограничения, решение владельца, уборка

Недоступны в исследованном списке: нормализация отклонением, простая,
разность/обратная разность, Гельмерт/обратный Гельмерт, индекс и отдельный
индикатор без опорной категории. Это расхождение прежнего подплана со стендом,
не заявка на реализацию несуществующего UI. Привязки заблокированы отсутствующим
data-tid. Автопоиск требует критерия качества, которого exact-zero smoke не даёт.
LASSO/Elastic Net требуют уточнения математического objective.

Предложение циклов, задания пользователя, oracle и ожидаемые документы —
[acceptance/modes/README.md](acceptance/modes/README.md). Ни один новый режим
не зарегистрирован. SKILL.md и общий код не менялись. Статус карточки blocked
до решения по перечисленным ограничениям; PR — предмет такого решения.

Собственный черновик закрыт через `MF;MainMenuForm;btnClosePackage` с явным
«Не сохранять»; native PackageNodes.Count=0, выход через
`MF;AppMenuForm;btnLogOut`, форма входа видна. `cleanup.json` — наблюдение UI,
не успешная квитанция runtime: штатный cleanup прежде отказал UNSAVED_CHANGES.
Два собственных входных CSV оставлены в личном каталоге для воспроизведения.
CLI-сборок, запущенных моделей и браузеров после завершения нет.
