# Линейная регрессия: предложение справки типа

Это проект для утверждения; доступность определяется `dock_action_describe`,
не этим документом. Сначала прочитай карточку `datamining.lin_regression`.

`enter` обучает/переобучает; `apply` применяет сохранённую модель. Для apply
сохрани роли и настройки, укажи существующий узел, `inputs:[]`, `finish:"execute"`.
После смены настроек требуется явное обучение: обычное выполнение может
применить прежнюю модель. Не выдавай применение за переобучение.

Предикторы перечислены в `input_fields`, цель — `target_field`. В native UI цель
обязательно вещественная и непрерывная; целое поле предварительно преобразуй
в импорте. Идентификаторы и тестовый флаг не делай предикторами.

Предложенные методы: Forward добавляет факторы, Backward исключает, Stepwise
перепроверяет включённые. Критерии: F с порогами включения/исключения,
R², adjusted R², AIC, AICc, BIC, HQC. R² без штрафа может оставить слабый фактор.
Константа, точность и доверительный уровень задаются в детальных настройках.
Редактирование константы доступно при отключённой денормализации.

Ridge использует L2, LASSO — L1, Elastic Net — обе регуляризации. При ручной
настройке укажи коэффициенты явно; при автоматической — метод валидации,
доли/колоды и seed. Не подставляй ручную λ вместо автоматического выбора.
Точный численный контракт LASSO/Elastic Net и качество автоматического поиска
в этом предложении ещё не утверждены.

Нормализация задаётся отдельно для каждого поля: нет, min/max, [-1;1], [0;1],
абсолютная, стандартизация, отношение. Для отношения выбери статистику или
ненулевой делитель. Контроль диапазона: нет, ошибка, винсоризация; явный диапазон
не равен диапазону, выученному на train. Денормализация возвращает коэффициенты
в исходные единицы. Смена нормализатора требует переобучения.

Для дискретного входа на исследованном стенде доступен только «Индикатор»;
опорная категория выбирается первой, последней, редкой, частой либо явно.
Не обещай отклонение, разности, Гельмерт и индекс: их нет в наблюдённом списке.
При равных частотах лучше явно задать опорную категорию. Переключатель показа
опорных коэффициентов меняет строки выхода коэффициентов.

Разбиение: случайное с фиксированным seed; последовательное с размерами
в строках/процентах и порядком train/unused/test; по Boolean-колонке
true=test, false=train. Test не должен участвовать в обучении. Валидация:
нет, K-fold со способом сэмплинга и числом колод, Монте-Карло с итерациями
и долями. Валидация применяется внутри train при автоматическом выборе.

Выход 0: `<target>_rergession` и исходные поля; написание native имени сохраняется.
Выход 1: Name, DisplayName, UniqueValues, коэффициенты, SE, t, p и границы CI.
У константы DisplayName/UniqueValues = NULL. У категорий Name повторяется:
отличай строки по UniqueValues; не придумывай имена Category_A.
Выход 2 — переменные сводки: счётчики, log-likelihood, R²/adjusted R²,
StdDev, DFE, ModelDF, F, p, AIC/AICc/BIC/HQC. Это отдельный порт, не таблица.
Читай фактическую схему; не подменяй NULL/∞ нулём и preview точными числами.

Привязки параметров к управляющим переменным остаются отдельным заблокированным
предложением. Нужны соединённый управляющий вход, точные имена и типы переменных,
readback сохранённой привязки и переобучение после изменения её значения.
Не изменяй литерал вместо требуемой привязки и не обходи отсутствующий data-tid.
