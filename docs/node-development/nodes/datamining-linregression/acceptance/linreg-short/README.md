Две строки и три фактора плюс константа: обучение Enter должно вернуть ошибку Loginom о недостаточном числе строк. Положительный прогноз не ожидается.

Штатное имя run-check: `linreg-short`, без `--case-root`. Модели передаются только task.md и входной CSV из data/; expected.json и oracle.py остаются в оснастке.

Критерий ожидаемой ошибки: инструмент вернул ожидаемый текст ошибки Loginom/исключения, последний ответ пользователю содержит этот текст, экспорт не запрошен и скачанный CSV отсутствует. После ошибки подтверждены Save, закрытие пакета без discard, logout и runtime-close ACK. Это не upload_only: Save обязателен. CSV и cold неприменимы; `--cold` пропускает только этот ожидаемый отказ, положительные сценарии проверяются полностью. Иная ошибка, отсутствие ответа, Save или уборки дают FAIL.
