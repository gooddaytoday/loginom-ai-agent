В приложенном modes.csv два поля: Code (строка) и Amount (вещественное), три
строки. CSV в UTF-8, разделитель — запятая, десятичный разделитель — точка.
Сохрани исходные типы и порядок строк и полей.

1. Создай Калькулятор переменных с двумя строковыми переменными:
   ExcelPath = {{EXCEL_INITIAL_DESTINATION}} и SheetName = Январь.
   Выполни его.
2. Настрой один Экспорт в Excel-файл (Excel 2007, .xlsx, заголовки — имена
   полей) так, чтобы имя файла бралось из ExcelPath, а имя листа — из SheetName.
   Путь и лист вручную не вписывай. Существующий файл не заменяй.
   Выполни экспорт и предоставь полученную книгу для скачивания.
3. Измени в том же Калькуляторе переменных только значения:
   ExcelPath = {{EXCEL_FINAL_DESTINATION}}, SheetName = Февраль. Выполни его снова.
   Тот же Экспорт не перенастраивай и второй не создавай: выполни его ещё раз,
   книга должна появиться по новому пути с новым именем листа.
   Предоставь вторую книгу для скачивания. Первую книгу не трогай.

Сохрани пакет в {{PACKAGE_PATH}}. После открытия пакета у Экспорта должны
остаться привязки имени файла и листа к переменным, а не их текущие значения.
