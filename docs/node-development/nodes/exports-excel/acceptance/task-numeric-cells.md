Выгрузи modes.csv в две новые книги numeric.xlsx и numeric.xls соответствующих
форматов Excel. Code — строка, Amount — вещественное число. В каждой книге
один лист «Данные», первая строка — имена полей, исходный порядок сохранён.
В Amount нужен числовой формат с двумя знаками после десятичного разделителя
и разделением тысяч. Числа должны оставаться числами с исходной точностью:
1234.56789 должно отображаться с двумя знаками, но храниться без округления.
