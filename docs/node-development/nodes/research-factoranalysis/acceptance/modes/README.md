Пути в таблице относительно этого каталога; matrix/update также доступны
в `../../fixtures/` (канонические копии старого oracle).
Импорт задаёт явные типы, UTF-8, запятую, десятичную точку, заголовок, NULL `?`.
У rotation.csv X=3u+v, Y=2u+2v+w, Z=u+3w для всех восьми u/v/w=±1:
полный ранг, отличающиеся собственные значения, нет тривиального вращения.
rank.csv имеет точный ранг 1 и ненулевые дисперсии всех трёх признаков.

`python3 -B …/acceptance/modes/oracle.py --write` генерирует expected.json;
`--check` сверяет его с независимым расчётом и проверяет спектр, выбор числа
факторов, улучшение критерия вращения и сохранение общностей. Вход oracle —
только CSV и независимый старый PCA oracle, никаких чтений Loginom/runtime.
Для вращений выбран Kaiser-вариант: совпали нагрузки и scores обоих портов
при одном общем знаке Factor2, без перестановки осей. Вариант без нормировки
оставлен диагностически, не является допустимым результатом. Для всех
положительных случаев в `cases` добавлены полные typed предложения обоих портов.
Для NULL oracle независимо вычисляет marginal μ/SD и pairwise E[XiXj],
затем R=(E[XiXj]−μ_iμ_j)/(SD_i SD_j); это не pairwise Pearson.
На данном fixture R имеет аналитические λ=1±sqrt(a²+b²),1 и
проверяемую реконструкцию R=L Lᵀ. Ожидания не считываются из native модели.
Все указанные критерии всё ещё требуют утверждения владельцем;
all-NULL, все константы, не-PSD R и порог eigenvalue ровно на λ вне предложения.
Cap=1 наблюдён: Factor2/3 физически отсутствуют, это не NULL/0 колонки.

Предлагается сохранить стандарт: оба полных порта, исходные значения/типы/NULL,
точный порядок, abs=1e-8/rel=1e-10, один согласованный знак фактора между портами,
CSV обоих портов, Save, cold без перенастройки, cleanup, ≥2/3 + независимые 2/3
на одном SHA. Перестановки осей и сравнение только подпространств не разрешены.
Если native потребует иной критерий или новый matcher, сначала решение владельца.
Для наблюдённых NULL/констант/ранга предлагаются полные таблицы;
математическая сверка не заменяет модельный PASS и cold.
