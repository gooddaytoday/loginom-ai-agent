# Excel файл (`imports.excel`): предложение, не установленный навык

Перед настройкой получи карточку `dock_action_describe({node_types:["imports.excel"]})`.
Доставляй исходную книгу; преобразование в CSV не заменяет Excel-импорт.
Выбирай лист точным именем. Для именованного диапазона передавай его точное имя
отдельно от листа и явно выбирай продолжение до последней строки. При нескольких
подходящих объектах запроси выбор пользователя.

Срез ёмкости предлагает до 64 полей и 1000 строк заголовка. Эти границы требуют
утверждения и проверки: в исследовании прочитаны 16 полей и 11 строк заголовка.
Поля задавай в исходном порядке, включая правые невидимые столбцы. `source_name`
сохраняет исходный заголовок при ASCII-техническом `name`. Составные заголовки
соединяются подчёркиванием. `boolean` сохраняет false отдельно от NULL.

При ручной схеме `auto_columns:none` обязателен полный явный список полей.
`new` добавляет новые позиции, сохраняя имена прежних; это не matching по заголовку.
`all` перестраивает схему; при `all` ручная настройка
недоступна. После изменения книги сравни фактическую текущую схему и результат.
Старый preview и прежнее выполнение не подтверждают новые данные. Динамические
определения не считай сохранёнными без проверки Save/cold. Не восстанавливай
исчезнувшие поля и не переключай политику ради прохождения проверки.

Для нескольких книг используй явный список либо маску в подтверждённом каталоге.
Каждый файл должен иметь собственное доказательство доставки. Маска требует
полного списка совпадений и проверки отсутствия лишних книг. UI показывает
разделитель списка как `｜` (U+FF5C); не считай отображаемый текст одним путём.
При последовательной обработке сохраняй порядок списка; при параллельной проверяй
множество строк, количество и кратность. Число потоков: авто, 2, 4, 8, 16, 32.

Сведения о файле добавляются к таблице после исходных полей: имя, относительный
или абсолютный путь; каждый вариант доступен с временем модификации. Наблюдены
`FileName:string`, `FileTime:datetime`. Путь и время сверяй с серверными сведениями
о фактически загруженном файле. Локальное время файла и ZIP timestamp не подходят.

Имя файла может приходить из строковой переменной через вход переменных 0
(native `Input_Var-1`); это не табличный и не управляющий вход. Используй точную
наблюдённую переменную и проверенный текущий путь. После изменения значения
повтори выполнение того же узла, сохрани привязку и проверь свежий результат.
Поддержка этой ветки требует отдельного допуска; обычный путь не заменяет binding.

XLSM хранит исходную книгу; макросы не запускай. Наличие расширения XLS в диалоге
не доказывает доступный importer: на исследованном стенде получена ошибка чтения.
HTTP/HTTPS и Basic требуют собственного доступного источника и безопасного
подключения; пароль в параметрах модели, URL или отчёте не передавай. При отсутствии
стенда сообщи ограничение. Не заменяй удалённый источник локальным скачиванием.

После выполнения прочитай все строки небольшого результата и фактические типы,
затем сохрани пакет. Приёмка отдельно проверяет CSV, Save, свежий cold Execute и
cleanup на том же SHA. Oracle и expected модели не передаются. Предложение
не означает, что перечисленные возможности уже поддержаны обработчиком.
