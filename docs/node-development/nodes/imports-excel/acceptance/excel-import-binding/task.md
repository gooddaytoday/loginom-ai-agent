Есть две книги Excel sales-a.xlsx и sales-b.xlsx: лист Data, поля Id и Amount,
оба целые. Поместите обе книги в свой каталог файлов Loginom и создайте
пользовательские переменные сценария: ExcelPath (строка с путём первой книги)
и Sentinel (строка keep).

Настройте один Импорт из Excel так, чтобы имя файла книги бралось из ExcelPath.
Импортируйте первую книгу и выгрузите прочитанные данные в CSV: UTF-8,
разделитель запятая, заголовки Id и Amount.

Затем измените только значение ExcelPath на путь второй книги. Остальные
переменные оставьте как есть. Выполните тот же Импорт и выгрузите его результат
в отдельный CSV. Импорт между выполнениями не перенастраивайте, второй узел
импорта не создавайте. Сохраните привязку имени файла к переменной.

Сохраните пакет с путём второй книги, откройте его заново и повторите
выполнение без настройки Импорта; выгрузите результат в CSV.
В конце закройте пакет и выйдите.
