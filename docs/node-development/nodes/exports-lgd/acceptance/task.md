Построй новый сценарий Loginom по приложенным typed.csv и schema.json.
CSV содержит заголовок, разделитель — запятая, дробная часть — точка,
кодировка — UTF-8, маркер пропуска — \N. Пустая строка отличается от пропуска.
schema.json задаёт имена, метки, типы и виды полей; сохрани порядок столбцов и строк.

Экспортируй всю таблицу в новый файл {{EXPORT_DIRECTORY}}/roundtrip.lgd,
используя штатные LZ4 и контрольную сумму сжатых данных. Существующий файл
не перезаписывай. Передай полученный LGD как результат. Импортируй этот файл
обратно в том же сценарии, сохранив свойства полей и пропуски, проверь результат
и сохрани пакет в {{PACKAGE_PATH}}.
