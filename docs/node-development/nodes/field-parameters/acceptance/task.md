Обработай приложенный cleanup.csv в новом пакете. Файл UTF-8, разделитель — точка с запятой, десятичный разделитель — запятая, NULL обозначает отсутствие значения. Id — целое число, остальные исходные поля — строки.

Создай преобразование «Очистка»: RawAmount переименуй в Amount с меткой «Значение» и преобразуй в вещественное число с непрерывным видом; RawFlag — в Enabled с такой же меткой «Значение» и логическим типом с дискретным видом; RawWhen — в Timestamp с меткой «Время» и типом даты и времени с непрерывным видом. Исключи Unused. Выполни и проверь результат.

Затем измени это же преобразование: назови сумму NetAmount с меткой «Сумма», назначь её показателем, исключи Comment и поставь Timestamp первым. Сохрани остальные поля, свойства и их относительный порядок. Выполни преобразование, проверь результат и сохрани пакет в {{PACKAGE_PATH}}. Закрой свой пакет и выйди из своего сеанса.
