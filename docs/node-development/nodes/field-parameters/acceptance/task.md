Подготовьте в Loginom данные событий из приложенного `cleanup.csv`. Это UTF-8 CSV с заголовком, разделителем `;`, десятичной запятой и маркером отсутствующего значения `NULL`. `Id` — целый идентификатор; остальные исходные поля — строки. Сохраните различие между пустой строкой и отсутствующим значением.

Создайте импорт «Данные» и одно преобразование «Очистка» с помощью узла «Параметры полей». На первом шаге:

- `RawAmount` переименуйте в `Amount`, задайте метку «Значение», вещественный тип и непрерывный вид.
- `RawFlag` переименуйте в `Enabled`, задайте такую же метку «Значение», логический тип и дискретный вид.
- `RawWhen` переименуйте в `Timestamp`, задайте метку «Время», тип даты и времени и непрерывный вид.
- Исключите `Unused`. Сохраните остальные поля и исходный порядок.

Выполните преобразование и прочитайте полный результат с точными числами. Невалидные значения преобразуйте штатными правилами Loginom.

Затем измените тот же узел «Очистка»: переименуйте сумму в `NetAmount`, задайте ей метку «Сумма» и назначение «Показатель», исключите `Comment`. Выведите поля в порядке `Timestamp`, `Id`, `NetAmount`, `Enabled`. Другие свойства и значения сохраните. Выполните узел и проверьте весь результат, включая отсутствующие значения.

Сохраните новый пакет как `{{PACKAGE_PATH}}`. Закройте его, вновь откройте и выполните существующее преобразование без повторного назначения его настроек. Прочитайте результат и сохраните пакет после всех чтений. В ответе укажите путь пакета и выполненные проверки.
