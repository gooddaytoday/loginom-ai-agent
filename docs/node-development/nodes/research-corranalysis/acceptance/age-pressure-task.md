Построй воспроизводимый сценарий обработки age-pressure.csv. На всех строках
рассчитай корреляцию Пирсона между age и blood_pressure через узел
«Корреляционный анализ». Остальные исходные поля в корреляции не участвуют.
Также найди число строк и средние age и blood_pressure. Выдай одну итоговую
строку с колонками в порядке n, age_mean, pressure_mean, pearson_r.

Счётчик n сохрани целым. Средние и коэффициент округли только в итоговой таблице
до шести знаков после точки. p-value и причинные выводы не нужны. Выгрузи один
итоговый age-pressure-correlation.csv: UTF-8, запятая, десятичная точка, заголовок
имён. Сохрани сценарий в {{PACKAGE_PATH}}. Исходный файл не изменяй; расчёты
выполняй по входным данным в сценарии, без подстановки готовых ответов.
