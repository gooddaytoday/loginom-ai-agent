## 2. Этап 1 — наборы числовых полей и Pearson

Предлагаемая граница: непустой вход, не менее двух совместных наблюдений на
каждую пару. Частичные NULL исключаются попарно; константное поле даёт NULL.
Пустой источник, полностью пустые пары и одна совместная строка остаются r05
этапа 3; native на пустом источнике вывел значения, совпавшие с прежними. Этот результат

Границу явно утверждает владелец; она не является результатом реализации.

Наборы могут пересекаться: self и симметричные пары сохраняются. Поля следуют
порядку входной схемы узла после input mapping; порядок массива запроса не
сортирует результат. Снаружи второй набор, внутри первый.

### Предлагаемый API и readback

`first_set`, `second_set` — массивы точных технических имён. Полная JSON Schema
с description каждого свойства/элемента — `fixtures/parameter-schema.json`.
Новый узел требует оба непустых набора. На существующем пропуск сохраняет набор;
переданный массив полностью заменяет его, снимая все лишние флажки.
Модель получает строковый enum `pearson`, не native numeric enum/caPirson.

Semantics для NODE_TYPES — текст в discovery: точный выход, порядок, NULL,
Execute без обучения и границы метрики. Mode pearson задаёт только Пирсон;
остальные флажки выключены. Запросы иных метрик/категориального кодирования
отклоняются до мутации с понятной причиной.

Компактный readback: mode, оба полных набора в native порядке,
coefficients=[pearson], source node/port, существующая идентичность узла,
схема выхода, число пар и output_port=0. Не дублировать весь UI, receipts не нужны.

типы, строки и NULL точны; только Pirson имеет tolerance abs=1e-6.

### Реализация и размер

Новые собственные `corr-analysis-{node,parameters,procedure,context,readback,output}.mjs`
и адресные тесты в client. Аддитивные регистрации NODE_TYPES/NodeType,
node-support, node-api, node-procedure, node-result-schema/user-results и
соответствующего readback; свой раздел `packages/product/skills/loginom-automation`;
собственные сценарии run-check. Образцы — Кластеризация / Линейная регрессия
