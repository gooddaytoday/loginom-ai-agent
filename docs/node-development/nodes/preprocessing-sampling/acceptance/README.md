Предложение критериев LAB-533, не утверждённая приёмка.

`task.md` охватывает только последовательный режим. Полный назначенный срез
включает ещё «Отбор со смещением» и остаётся blocked: см. `../discovery.md`.
Не считать этот сокращённый сценарий выполнением всей карточки.

`python3 oracle.py` независимо строит expected из CSV срезами Python;
генератор не импортирует Loginom/runtime и не читает фактические результаты.
`expected.json` должен побайтно совпадать с выводом генератора.
Порядок строк и полей точный, integer/string/NULL сравниваются точно;
численных вычислений с real в этом основном наборе нет, tolerance=0
(отсутствие допуска в existing matcher). Метки входных полей свободные.

Перед этапом 1 владелец утверждает критерии, затем run-check получает только
task.md и data/. Oracle, expected и дополнительные fixtures в workspace модели
не передаются. Для запуска использовать штатный `run-check --cases` либо
аддитивную регистрацию сценария, без собственного раннера. Сейчас NOT_RUN:
runtime type не зарегистрирован, сборка CLI по карточке запрещена.

Ожидания: первые RowID 1..5, последние 16..20, по 5 строк; суммы Value 150/900.
`../fixtures/update.csv`: после смены источника тех же узлов — 101..105 и
116..120, значения Value смещены на 1000; новое source identity обязательно.
`null.csv` предлагает перенос NULL, пустой строки и real без преобразований;
`empty.csv` — 0 строк с сохранением схемы. Эти расширения пока не включены
в основной task/expected и не объявляются проверенными.
