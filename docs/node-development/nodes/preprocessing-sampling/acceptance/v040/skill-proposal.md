# Предложение навыка v040, не активная инструкция

Сэмплинг: sequential, random, stratified, biased и uniform.
Для uniform выбирай «Равномерный случайный», укажи count, seed и
uniform_group_size в строках. Размер группы отличается от размера выборки.
Не подменяй равномерный метод обычным случайным или последовательным.
У существующего узла пропущенные настройки сохраняются.
Выполни узел без обучения, прочитай полный выход 0, сохрани значения
и типы исходных столбцов. При повторе сохраняй вход, seed и размер группы.
Точный состав не предсказывай по чужому генератору случайных чисел.
Для stratified нужны дискретные strata_fields; для biased — bias_field
и полные bias_factors. После CSV отдельно сохрани пакет.
