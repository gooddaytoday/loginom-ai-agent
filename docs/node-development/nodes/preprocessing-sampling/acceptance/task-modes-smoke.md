Из modes.csv создай источник с полями RowID и Value — целые, Class — дискретная строка. Сохрани все значения и исходный порядок полей RowID, Class, Value.
На этом источнике создай три узла «Сэмплинг» с названиями «Случайные все», «Страты все», «Смещение все». У каждого размер выборки — 20 строк, начальное значение генератора — 42.
Для «Случайные все» используй метод «Случайный»; для «Страты все» — «Стратифицированный» по Class; для «Смещение все» — «Отбор со смещением» по Class, факторы A=1 и B=1.
Выполни узлы и выгрузи полные таблицы в sampling-1.csv, sampling-2.csv, sampling-3.csv (UTF-8, запятая, заголовки имён). Порядок файлов соответствует трём узлам. Сохрани пакет.
