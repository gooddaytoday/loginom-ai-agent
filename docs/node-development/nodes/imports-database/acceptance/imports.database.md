# imports.database — Импорт из базы данных (SQLite)

Узел читает одну таблицу/представление или один SELECT через подключение SQLite
текущего модуля к файлу `.db` в хранилище пользователя. Запись в базу не выполняется.

- `connection.database_path` — точный путь файла в хранилище (`/папка/people.db`).
  Подключение создаётся или переиспользуется по этому пути; тест подключения должен
  пройти до настройки узла.
- `mode: table` + `table` — таблица или представление целиком; `fields` — подмножество
  в нужном порядке. Порядок строк не гарантирован: для порядка используйте `mode: sql`.
- `mode: sql` + `sql` — один SELECT; порядок строк задаёт `ORDER BY`.
- Типы выхода берутся из объявленных типов столбцов SQLite: INTEGER → целый,
  TEXT → строка, REAL → вещественный, BOOLEAN → логический, DATETIME → дата/время.
- Существующий узел с `{}` сохраняет настройки; повторное выполнение читает базу заново.

Не поддержано в этом срезе: фильтры, параметры и макросы, «Игнорировать ошибки»,
тайм-аут, другие СУБД, выход переменных. Такие запросы отклоняются до изменений.
