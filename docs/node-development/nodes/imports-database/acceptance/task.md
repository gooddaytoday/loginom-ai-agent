В хранилище Loginom загружен файл базы данных SQLite people.db. Подключись к нему
и импортируй в новый сценарий таблицу People целиком: все поля в исходном порядке,
типы и пропуски как в базе. Не заменяй пропуски нулями или пустыми строками.
Отдельным импортом выполни запрос, который возвращает сумму, номер и метку активных
записей по убыванию номера. Выполни оба импорта, проверь результат и сохрани пакет
в {{PACKAGE_PATH}}.
