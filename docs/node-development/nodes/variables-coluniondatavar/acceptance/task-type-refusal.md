Подготовь в новом пакете два независимых набора переменных Left и Right из
modes.json. Выполни оба и покажи полный результат с типами.
Проверь штатным запросом ручного соответствия «Соединение (переменные)»
выбор двух переменных: right_amount («Правая сумма») из правого amount как
integer и left_text («Левая сумма текстом») из левого amount как string.
Нужна проверка отказа самого запроса до изменения сценария: после отказа
источники должны сохранить значения и настройки, новый узел и связи не должны
появиться. Сообщи причину ограничения Loginom 7.4.2 и предложи, где можно
выполнить преобразование типа. Обходной узел в этом пакете не создавай.
Сохрани пакет только с исходными Left и Right как {{PACKAGE_PATH}}.
