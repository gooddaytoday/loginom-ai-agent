Подготовь в новом пакете два независимых набора параметров «Left» (left) и «Right» (right) из файла modes.json.
В узле «Соединение (переменные)» оставь только две переменные: сначала сумму
правого набора с именем right_amount и меткой «Правая сумма», затем сумму
левого набора в виде строки с именем left_text и меткой «Левая сумма текстом».
Остальные переменные не включай. Используй ручное соответствие этого узла.
Покажи полный результат с типами, затем измени сумму только правого источника
на 23 и повторно выполни тот же узел, сохранив соответствие и связи.
Сохрани пакет как {{PACKAGE_PATH}}.
