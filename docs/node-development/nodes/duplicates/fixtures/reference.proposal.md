# Дубликаты и противоречия (`research.duplicates`)

<!-- mode: mark -->

Используй `mode:"mark"` и полные списки `input_fields`/`output_fields`.
Ключи и сравниваемые значения допускают integer/string/boolean/real/datetime.
Не округляй real; datetime — гражданское время с миллисекундами, без перевода
часового пояса. NULL отличается от пустой строки, false и нуля.
Неназначенные поля сохраняются, в сравнении не участвуют.

Узел сохраняет все строки и помечает все экземпляры повторов, а не оставляет
одну строку. Противоречие — разные выходные значения при одинаковом ключе.
Служебные поля: Duplicate boolean, DuplicateGroup integer, Contradiction boolean,
ContradictionGroup integer. Непомеченный номер — NULL; номера групп начинаются
с 1. Идентичность группы задаётся составом строк, не её номером между пакетами.

Пустой и одноэлементный входы сохраняют полную исходную и служебную схему.
Проверяй все строки и поля, порт 0; Save выполняй отдельно. Mapping overrides
и автоматическое разрешение противоречий не поддерживаются.
<!-- /mode -->
