По train.csv постройте логистическую регрессию для Target по X.
Target — строковая бинарная цель, событие — yes, второй класс — no.
Используйте ручной метод Enter с константой, без нормализации, регуляризации
и весов; все строки используйте для обучения, без валидации и поправки
на долю событий. Задайте порог решения 0.8.
Покажите для каждой исходной строки предсказанный класс и вероятность yes,
сохранив исходные поля, включая пустые значения Note. RowID — идентификатор,
Note — комментарий; они не являются факторами.
Выгрузите результат в CSV и сохраните сценарий в {{PACKAGE_PATH}}.
Формат файла: UTF-8, первая строка — заголовок, разделитель — запятая,
десятичная точка, знак вопроса обозначает пропущенное значение.
