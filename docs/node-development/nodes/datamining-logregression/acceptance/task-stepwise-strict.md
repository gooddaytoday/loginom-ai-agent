Используй приложенный selection.csv для оценки вероятности события yes в поле Target.

Создай импорт CSV: UTF-8, заголовок в первой строке, разделитель запятая,
десятичная точка, пустое значение ?. Задай типы явно: RowID — целый,
X и Noise — вещественные непрерывные, Target и Note — строковые дискретные.
Метки исходных полей задай равными их именам.
Не заменяй пропуски Note и сохрани все исходные строки и поля.

Построй бинарную логистическую регрессию. Отключи автоматическую настройку,
выбери Stepwise (пошаговое включение/исключение), событие yes задай явно. Кандидаты в факторы — X и Noise,
целевое поле — Target; RowID и Note в обучение не включай.
Используй детальные настройки: критерий отбора Deviance, порог значимости при добавлении фактора 0 и при исключении 0.2.
Порог отсечения вероятности — 0.8, точность решения — 0.0000000001.
Включи константу, не нормализуй факторы, оставь их множители равными 1,
не закрепляй факторы как неудаляемые. Обучай на 100% строк, без весов,
валидации, регуляризации и ручной поправки на долю событий.

в prediction-stepwise-strict.csv: все исходные поля и штатные поля прогноза,
