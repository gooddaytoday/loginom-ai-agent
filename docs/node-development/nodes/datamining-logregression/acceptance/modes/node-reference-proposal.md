# Логистическая регрессия — предложение после ручных циклов

Для бинарной строковой цели используй `datamining.log_regression`. Запроси
карточку типа через `dock_action_describe` до настройки. Обучение: `enter`,
`forward`, `backward`, `stepwise`, `ridge`, `lasso`, `elastic_net`; явные
`input_fields`, `target_field`, метка `event` и `threshold`. Событие при p >= порог.
Входы числовые, цель дискретная с двумя непустыми категориями; остальные поля
сохраняются. Execute в обучающих режимах сначала вызывает Teach.

`apply` — только существующая обученная модель с прежними ролями и параметрами,
`inputs:[]`, `finish:"execute"`; выполнить текущий вход без Teach. NULL в цели
допустим для применения. Новые обучающие данные требуют обучающего режима.

Порт 0 — прогноз и исходные поля; порт 1 — коэффициенты и статистика;
переменный порт 2 — сводка. Читай нужный выход через соответствующий табличный
или переменный канал карточки. Полный порт коэффициентов нужен для интервалов
и отношения шансов. Для чтения сводки используй точные наблюдённые имена.
Значение TrainClsErrorPercentage ещё требует решения владельца.

`weight_field` — положительные Real-веса частот при обучении; это поле не фактор.
У Integer роль «Вес» в UI отсутствует.
`normalization` задаёт единый нормализатор факторов. Сохраняй штатное кодирование
цели и возвращай коэффициенты в исходных единицах. При Enter изменение масштаба
с константой сохраняет вероятности; с регуляризацией это уже другая модель.

`partition` задаёт обучающую и тестовую доли, способ отбора и seed либо поле
разбиения. `validation` задаёт K-fold или Монте-Карло внутри обучения. Не считай
точный состав случайных выборок без независимого обоснования; проверяй сохранённые
настройки, воспроизводимость и сценарий по согласованному expected.

Ручная регуляризация: `regularization.ridge` для Ridge,
`regularization.lasso` для LASSO, оба для Elastic Net. Значения неотрицательные;
функция потерь — сумма отрицательных log-likelihood + λL1|β| + λL2β²/2,
константа не штрафуется. Автонастройка, scoring/калибровка, привязки переменных,
категориальные факторы и остальные расширения требуют отдельных циклов.

Это текст будущей справки, а не объявление поддержки в текущем продукте.
