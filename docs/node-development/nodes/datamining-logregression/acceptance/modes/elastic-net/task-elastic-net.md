По train.csv обучите логистическую регрессию методом Elastic Net. Оба коэффициента регуляризации задайте вручную равными 1. X → Target, событие yes, порог 0.8, константа, без нормализации, все строки в обучении. Покажите прогнозы для всех строк. Затем повторите настройку и обучение того же узла с теми же параметрами.

Сохраните пакет в своём каталоге. Проверьте результат после повторного открытия. Исходные поля и пропуски сохраните; не заменяйте модель вычислением формулы. Для табличного результата выгрузите CSV с техническими именами полей.
