По partition.csv обучите логистическую регрессию Enter: X → Target, событие yes, порог 0.8, без нормализации. Импортируйте Split как логический столбец (false/true), Fold — как целый. Разделите обучение и тест по столбцу Split: false — обучение, true — тест. Split и Fold не используйте как факторы. Получите прогноз для всех строк и размеры выборок в сводке; не обучайте модель на тестовых строках.

Сохраните пакет в своём каталоге. Проверьте результат после повторного открытия. Исходные поля и пропуски сохраните; не заменяйте модель вычислением формулы. Для табличного результата выгрузите CSV с техническими именами полей.
