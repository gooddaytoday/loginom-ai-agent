`https://app.loginom.ai/app/?testable=true`.
База: `v039@7ffdfef329681f6252e98f25c56ca6384bea602b`.
Использован только worker назначенной пары; новый профиль и собственный пакет.
CLI не собирался. Это native-исследование и предложение для этапа 1,

## Выбор метода и критериев — наблюдено по data-tid

Корень основного мастера: `MF;TF-1;WizrdMCF` (суффикс вкладки динамический).
На странице `LogRegressionWizard` нужно выключить
`pedAutoMethod;ValueControl;DisplayEl`, затем открыть
`pedRegressionMethod;ValueControl;trg_picker`.
В `...;boundlist` доступны Enter, Forward, Backward, Stepwise, Ridge,
LASSO и Elastic-net. Назначенный срез — три метода:

| Метод | Native значение | Суффикс наблюдённой опции |
|---|---:|---|
| Forward | 1 | `Forward_(Пошаговое_включение)` |
| Backward | 2 | `Backward_(Пошаговое_исключение)` |
| Stepwise | 3 | `Stepwise_(Пошаговое_включение/исключение)` |

Метод не меняет набор страниц: входные роли → нормализация → разбиение →
параметры → детальные настройки → описание. Для детальной страницы нужно
`pedUseDetailedSettings=true`. Native индексы остаются деталями драйвера;
публичные режимы предлагаются строками `forward`, `backward`, `stepwise`.

Детальная страница — `LogRegressionWizard-1`. Поля:

| data-tid после имени страницы | Значение / поведение |
|---|---|
| `pedRegSelQuality;ValueControl` | По умолчанию AIC. Picker содержит Deviance, AIC, AICc, BIC, Ханнана—Куинна. |
| `pedAddSignificance;ValueControl` | По умолчанию 0.05; UI min=0, max=1. |
| `pedRemoveSignificance;ValueControl` | По умолчанию 0.1; UI min=0, max=1. |
| `pedEpsilon;ValueControl` | Принято 0.0000000001. |
| `pedThreshold;ValueControl` | Принято 0.8; это порог прогноза, отдельный от порогов отбора. |
| `pedIntercept;ValueControl` | true, заблокировано при denormalize=true. |

Реальное состояние disabled считано у компонента, привязанного к точному
DOM-элементу по `data-tid`; отсутствие `aria-disabled` не означает доступность.

| Критерий | Forward | Backward | Stepwise |
|---|---|---|---|
| Deviance | Добавление доступно; исключение disabled | Добавление disabled; исключение доступно | Оба порога доступны |
| AIC | Оба порога disabled | Оба порога disabled | Оба порога disabled |

Список остальных информационных критериев наблюдён в picker; их численное
поведение и состояние порогов ещё требуют отдельной живой проверки.
При смене метода и следующем открытии детальной страницы критерий вернулся
к AIC. Поэтому порядок будущего драйвера: метод → открыть детали →
явно выбрать критерий → заполнить только применимые пороги → прочитать значения.
На Stepwise/Deviance через input/Tab приняты и прочитаны 0.01 / 0.2.
Перехвата или подмены внутреннего JS Loginom нет: жесты — Playwright,
native getters читают только привязанные UI-контролы и загруженные записи.

## Роли, входы и выходы

Роли остаются прежними: X и Noise — вещественные непрерывные входные,
Target — строковая дискретная цель с no/yes; RowID и Note — без роли.
В `NormTuneWizard` для факторов наблюдены «Нет», множитель 1,
неудаляемое=false; Target — штатное кодирование «Отклонение».
Эти свойства факторов необходимо проверять: закреплённый фактор или иной
множитель меняет смысл отбора. Событие выбрано через наблюдённые
`pedEventId;ValueControl;boundlist;0/1` с подписями `0 (no)`, `1 (yes)`.

Порты те же: `Input_Data-0`, `Output_Data-0`, `Output_Data-1`, `Output_Var-2`.
Новых портов переключение метода не добавляет. Прогноз — порт 0;
коэффициенты — порт 1; сводка переменных — порт 2. Расширять чтение портов
1/2 и W4 для этого среза не предлагается.

После явного `mn;mniTeachNode` Stepwise, Forward и Backward с Deviance на
данных `fixtures/selection.csv`
порт 0 открыт двойным кликом `Graph;<собственный узел>;Output_Data-0`.
В `ModelForm;PreviewWindow;PreviewForm;DataSetForm;grdDataTable;grd-1;tbl`
для каждого метода полностью загружены 64 записи. Все 64×9 значения сверены с независимым
oracle: максимальная ошибка вероятности **2.3304e-9**, остальные ячейки точны,
21 NULL Note сохранены, порядок RowID 1..64 сохранён.

Четыре служебных поля совпадают с Enter: PredictionEvent,
PredictionProbability, ActualEvent, Target_predicted; исходные пять остаются.
**Исключённый Noise не удаляется из таблицы прогноза.** Меняются вероятности
модели, а не набор исходных колонок. Наблюдённый тёплый порядок этого
диагностического импорта: служебные четыре, RowID/Target/Note/X/Noise
(типы факторов менялись после первоначального открытия mapping).
Backward сохранён штатным `package.save_checkpoint`: save_completed=true,
workflow_preserved=true. После закрытия/logout без discard в новом профиле
пакет открыт заново; `mn;mniActivateNode` **без настройки/Teach** вернул те же
64×9 значения. Порядок исходных полей этого импорта после reopen:
**Target/X/Noise/RowID/Note** — используемые поля, затем поля без роли,
с учётом изменённого вручную порядка источника RowID/Target/Note/X/Noise.
Порядок X/Noise/Target/RowID/Note в cold expected пока **предложение** для
нового штатного импорта исходного CSV; его нужно подтвердить на этапе 1.
Этот native reopen не является запуском stock cold-check.mjs.

## Независимый расчёт и границы

64 строки, оба класса представлены при каждом X и Noise, 21 NULL только в Note.
Численные ожидания созданы до Teach, не извлечены из Loginom.
`acceptance/selection/oracle.py` решает score-уравнения Newton/IRLS и считает
log-likelihood всех четырёх подмножеств факторов. Deviance сравнивает вложенные
модели через LR с одной степенью свободы; информационные критерии считают
константу в числе параметров. Это независимая математическая модель,
а не утверждение о реализации необследованных критериев Loginom.

| Подмножество | log-likelihood | Коэффициенты |
|---|---:|---|
| Только константа | -44.3614195558 | 0 |
| X | -31.5227277309 | 0; 0.898810170457 |
| Noise | -44.2363380482 | 0; 0.125163142954 |
| X, Noise (Enter) | -31.3254069920 | 0; 0.905990641381; 0.197934120753 |

LR p(X относительно константы)=4.0353e-7;
p(Noise при наличии X)=0.52987. Для entry=0.01 / removal=0.2
все 15 независимых сочетаний метода и критерия оставляют X.
Максимальное отличие от Enter — **0.0493226**, намного больше допуска 1e-8.
Строгий entry=1e-9 даёт модель только с константой; мягкие 0.95/0.99 — X+Noise.
Эти две пробы пока рассчитаны офлайн и не объявляются native PASS.

Не исследованы численно информационные критерии,
полная траектория включений/исключений при коррелированных факторах,
граничные p-value, веса, категориальные факторы, пустой/вырожденный вход,
Save/reopen Forward/Stepwise и холодный порядок штатного импорта.
