Импортируй rows.csv: UTF-8, точка с запятой, первая строка — заголовок,
NULL — пропуск. RowID — целое, Score — вещественное, Seen — дата и время
без часового пояса, Region — строка.

Создай пользовательские переменные сценария: MinScore (вещественная, 2.5) и
Since (дата и время, 2024-03-01 00:00:00). Настрой один Фильтр строк:
Score не меньше MinScore и одновременно Seen не раньше Since. Оба порога
должны оставаться связаны с переменными. Выполни и выгрузи в CSV оба
результата: соответствующие и остальные строки (UTF-8, разделитель запятая,
пропуск — NULL, все четыре поля).

Затем измени только значения: MinScore = 0.5, Since = 2024-02-29 00:00:00.
Выполни тот же Фильтр без перенастройки, второй Фильтр не создавай; снова
выгрузи оба результата в отдельные CSV. Сохрани пакет в {{PACKAGE_PATH}}:
после открытия пороги должны браться из переменных. Закрой пакет и выйди.
