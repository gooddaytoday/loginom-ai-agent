Импортируй variables.csv в Loginom: RowID и Amount — целые, Category — строка,
? означает пропуск. В отдельном исполняемом узле «Калькулятор (переменные)» создай переменную codes
строкового типа со значением 10,20. Стандартным «Фильтром строк» раздели
таблицу по условию: Amount входит в список, заданный переменной codes.
Сохрани подходящие и остальные строки в разные CSV со всеми исходными полями.

Измени только codes на 15, повторно выполни тот же фильтр и сохрани оба
обновлённых выхода в новые CSV. Фильтр должен сохранить ссылку на codes.
В CSV нужны имена полей в заголовке, разделитель запятая и ? для пропусков.
Сохрани пакет в {{PACKAGE_PATH}}, закрой его и выйди из Loginom.

Источник управляющих значений — исполняемый калькулятор переменных, не builtin «Переменные сценария». Сначала выполни источник; после изменения его выражений выполни его снова, затем тот же Фильтр. Имена и метки управляющих переменных должны совпадать.
