# Заполнение пропусков (`preprocessing.data_recovery`)

Предложение LAB-1012, до утверждения не действующий навык.

Используй `mode:"impute"`, полный `fields`, явные `max_nulls_percent` 0–100
и `ordered`. Неперечисленные поля не обрабатываются, existing `parameters:{}`
сохраняет настройки. Все методы заменяют только настоящий NULL;
пустая строка, false, ноль и текст null не становятся NULL автоматически.

Прежние методы сохраняются: `mean` для непрерывных integer/real,
`zero` для числовых полей, `constant` со строковым `value` для дискретной строки.
Нулевой метод заполняет пропуски независимо от порога, даже all-null;
статистические методы могут оставлять NULL выше порога и без известных данных.

Предложенные дополнения: `median` для непрерывных чисел, `most_probable`
для дискретных значений, `previous` и `linear` для упорядоченных наблюдений,
`random` для штатного случайного восстановления, `delete` для удаления строк
с пропуском выбранного поля. Точное соответствие кодам UI — в подплане;
не угадывай код метода по позиции в меню.

`previous` и `linear` требуют `ordered:true`: порядок — физический порядок
входа, а не сортировка по идентификатору. Сохраняй существующие известные
значения и необрабатываемые поля. Линейный сценарий имеет известные концы
и равные интервалы; экстраполяция и другие интерполяции не утверждены.
Случайный приёмочный пример имеет единственное уникальное известное значение,
поэтому проверяется точно без копирования алгоритма случайности Loginom.
Не утверждай по нему распределение на входе с разными значениями.

Числовая константа, качество, привязки к переменным и управление seed не
получают поддержку только из-за добавления названий методов в предложение.
Числовое `value` и строка "0" для обхода типа остаются запрещёнными до
подтверждения отдельного нативного контроля и утверждения владельцем.
`finish:"execute"`, читай полный порт 0 и сохраняй пакет отдельно.
