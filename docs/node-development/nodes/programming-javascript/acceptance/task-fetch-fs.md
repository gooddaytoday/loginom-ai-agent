Используй JavaScript без входной таблицы. Получи заказы из
`{{FIXTURE_BASE_URL}}/orders`, рассчитай суммы и подготовь в `{{FS_ROOT}}/output`
summary.csv: UTF-8 без BOM, разделитель «;», заголовок ID;Amount, строки
по возрастанию ID, денежные суммы с двумя знаками после точки, LF после каждой
строки, включая последнюю. Отправь точные байты этого файла POST-запросом
на `{{FIXTURE_BASE_URL}}/reports` с типом содержимого text/csv.
Выведи одну строку Rows, Amount, FileName, ByteCount, ReceiptNo: количество
заказов, общая сумма, summary.csv, размер файла, номер квитанции службы.
Не отправляй отчёт повторно при настройке или чтении результата. При неизвестном
исходе остановись. Сохрани combined.csv и `{{PACKAGE_PATH}}`.
После повторного открытия проверяющий отдельно назначит новое выполнение
с новым пустым журналом службы. Файл оставь для независимой проверки.
