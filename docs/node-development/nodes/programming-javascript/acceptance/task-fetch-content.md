Используй JavaScript: получи контрольные материалы службы
`{{FIXTURE_BASE_URL}}` — текст `/text` и двоичный образец `/binary`.
Выведи две строки в этом порядке с полями Name, ByteCount, Text, Hex.
Для text укажи текст и пустое значение Hex; для binary — точные байты в
шестнадцатеричной записи строчными буквами и пустое значение Text.
ByteCount — фактическое число байт. Сохрани fetch-content.csv и пакет
`{{PACKAGE_PATH}}`, проверь результат после повторного открытия.
