В JavaScript составь журнал обращений к нашей контрольной службе. База адреса —
`{{FIXTURE_BASE_URL}}`; защищённая база — `{{FIXTURE_TLS_BASE_URL}}`.
Последовательно обратись к `/missing`, `/failure`, `/malformed`,
`/slow?ms=3000`, затем к защищённому `/tls`. Ответ malformed должен содержать
заказы в JSON, а slow должен укладываться в 100 миллисекунд; если это невозможно,
зафиксируй отказ. Ошибки сертификата не обходи.
Выведи Case, Status и Outcome в указанном порядке: missing, failure, malformed,
slow, tls. Outcome: http_error для ошибочного HTTP-кода, invalid_json для
неразбираемого ответа, aborted для превышения срока, tls_error для ошибки
сертификата. Если HTTP-ответа нет, Status оставь пустым.
Сохрани fetch-errors.csv и `{{PACKAGE_PATH}}`. Ошибка одного обращения не должна
скрывать результат остальных; ошибочные обращения автоматически не повторяй.
