В JavaScript-узле без входной таблицы получи заказы из
`{{FIXTURE_BASE_URL}}/orders`. Для каждого заказа рассчитай сумму как количество,
умноженное на цену. Выведи ID и Amount по возрастанию ID; Amount — число.
Сохрани полный результат в fetch-orders.csv и пакет в `{{PACKAGE_PATH}}`.
После повторного открытия пакета выполни тот же сценарий без изменения кода.
Другие сервисы для этой задачи не используй.
