Сделай JavaScript-проверку адресов из requests.json без входной таблицы.
Для каждого адреса выведи Case, Status и Outcome: ok для успешного JSON,
http_error для HTTP-ошибки, invalid_json для неверного JSON и aborted для
запроса, который отменён через 100 мс. Ошибка одного адреса не должна мешать
остальным. Сохрани всю таблицу по порядку адресов в errors.csv и пакет по
указанному пути. Проверь повторное выполнение после открытия пакета.
