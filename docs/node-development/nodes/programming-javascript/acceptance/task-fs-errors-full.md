В JavaScript проверь защищённую подготовку материалов в `{{FS_ROOT}}/errors`.
В keep.txt находится текст KEEP; его нельзя перезаписывать, если он уже есть.
Попробуй создать его с текстом REPLACE при условии отсутствия, затем прочитай
его фактическое содержимое. Также прочитай missing.txt и закрытый для чтения
denied.txt: эти контрольные условия заранее подготовлены проверяющим в твоём
каталоге. Не обходи ограничения доступа и не меняй эти два файла.
Выведи Case, Outcome, Text в порядке exclusive, missing, permission.
Outcome: exists, missing, denied соответственно; Text для exclusive — фактический
текст keep.txt, в остальных строках оставь пустым. Не считай ошибку чтения
успешной пустой строкой. Сохрани fs-errors.csv и `{{PACKAGE_PATH}}`.
