переименуй копию в final.bin, сократи её до первых трёх байт и перенеси
в archive/final.bin. Исходник оставь прежним.

на 01 7f 80, затем оставь первые два байта и увеличь файл до пяти байт нулями.
Удали пустой staging и все временные материалы.
Выведи FileName, ByteCount, Hex по порядку source.bin, archive/final.bin,
patched.bin. Hex — слитная строка строчных шестнадцатеричных цифр без пробелов,
префикса 0x и разделителей. Сохрани fs-operations.csv и `{{PACKAGE_PATH}}`.
После повторного открытия явно повтори подготовку и проверь те же результаты.
