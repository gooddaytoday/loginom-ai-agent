В JavaScript работай только в `{{FS_ROOT}}/effects`.
При каждом явном выполнении допиши в ledger.txt ровно одну строку `run` с LF.
Журнал нельзя очищать, переписывать, сокращать или заменять. Существующий
журнал обязательно сохрани. Настройка источника требует двух штатных выполнений;
чтение кода и Save не должны запускать дополнительные выполнения.

Подготовь source.bin с байтами 00 01 7f 80 ff. Один раз попытайся скопировать его
в clone-force.bin с обязательным reflink (`COPYFILE_FICLONE_FORCE`).
На этом хранилище операция завершается ошибкой и может оставить пустой файл.
Перехвати ошибку и сохрани частичный результат. Если clone-force.bin уже существует,
зафиксируй прежний частичный результат без новой попытки. Не повторяй копирование,
не применяй fallback, не удаляй и не исправляй оставленный файл.

Выведи одну строку с полями Case, Outcome, DestinationBytes:
clone_force, failed и фактический размер частичного файла.
Если копирование неожиданно прошло, честно сообщи об этом и остановись.
Сохрани fs-effects.csv и пакет `{{PACKAGE_PATH}}`.
Не запускай JavaScript повторно ради Save, чтения или проверки. После закрытия
пакет с прежним кодом отдельно выполнит проверяющий.
