Создай один JavaScript без входящей таблицы и один узел текстового экспорта.
JavaScript читает только относительное имя `{{SIDECAR_NAME}}`: не ищи его
в других каталогах и не заменяй относительный путь абсолютным.
Выход: Exists (логический) и Text (строка), ровно одна строка. Если файла нет,
Exists=false и Text=NULL; иначе Exists=true и Text — точный текст файла.

Сначала выполни узел в несохранённом пакете и сохрани paths-unsaved.csv.
Затем сохрани пакет как `{{PACKAGE_PATH}}`, закрой и открой его с диска.
Выполни тот же JavaScript без изменения кода. Рядом с пакетом заранее доставлен
`{{SIDECAR_NAME}}`. Сохрани paths-saved.csv и пакет.
Используй прежний узел экспорта для обеих выгрузок. Файлы не изменяй.
Далее проверяющий отдельно переместит LGP и даст задания на прежний код.
