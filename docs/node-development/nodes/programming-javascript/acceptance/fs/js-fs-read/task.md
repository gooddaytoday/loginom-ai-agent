В JavaScript прочитай доставленные в `{{FS_ROOT}}/input` материалы:
utf8.txt, utf16le.txt, cp1251.txt и bytes.bin. Для текстовых файлов применяй
кодировки UTF-8, UTF-16LE и Windows-1251 соответственно; bytes.bin — двоичный.
Выведи строки в этом порядке: FileName, ByteCount, Text, Hex. Для текстов Text
должен сохранять все символы и переводы строк, а Hex — пустая строка (не NULL);
для двоичного файла укажи точные байты в Hex строчными буквами, Text — пустая строка (не NULL).
Файлы не меняй. Сохрани fs-read.csv и пакет `{{PACKAGE_PATH}}`.
После повторного открытия выполни тот же сценарий без изменения кода.
