три готовых сообщения для регистрации оплат. В указанном порядке отправь каждое
сообщение без изменения его байтов POST-запросом на `/receipts`, тип содержимого
application/json. Выведи ID и ReceiptNo из ответа для каждой регистрации.
Не регистрируй одну оплату повторно при настройке или чтении результата.
Если исход отправки неизвестен, остановись и сообщи об этом.
Сохрани fetch-receipts.csv и пакет `{{PACKAGE_PATH}}`.

выполнение выполняй только по отдельному заданию.
