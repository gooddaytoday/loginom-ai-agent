В JavaScript последовательно получи заказы через адреса нашей службы
`{{FIXTURE_BASE_URL}}/redirect/301`, `/redirect/302`, `/redirect/307`.
Выведи для каждого обращения Code (код из адреса), Count (количество заказов)
и Amount (общая сумма заказов). Исходный порядок адресов сохрани.
Сохрани fetch-redirects.csv и `{{PACKAGE_PATH}}`; после повторного открытия
проверь полный результат. Не обращайся к другим службам.
