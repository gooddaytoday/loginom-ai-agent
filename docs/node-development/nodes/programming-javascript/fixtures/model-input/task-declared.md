# Расчёт продаж

По приложенному sales.csv создайте и выполните сценарий Loginom с узлом
JavaScript. Денежные суммы заданы в целых копейках. Для каждой исходной строки
рассчитайте стоимость количества товаров с учётом процентной скидки;
отрицательное количество означает возврат. Дробных копеек в этих данных нет.

В результате оставьте поля в следующем порядке:

- RowID — исходный целочисленный идентификатор;
- CustomerKey — название клиента без пробелов по краям, в нижнем регистре;
- NetCents — итоговая сумма в целых копейках;
- Status — строка «возврат», «ноль» или «продажа» в зависимости от итоговой суммы.

Сохраните все исходные строки и их порядок. Задайте состав и типы выходных полей
заранее в настройках узла. Программа должна заполнять эту структуру.
Покажите весь небольшой результат и сохраните пакет по
уникальному пути, указанному в сообщении задания.
