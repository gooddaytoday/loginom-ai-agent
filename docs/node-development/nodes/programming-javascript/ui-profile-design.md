# JavaScript: профиль своего мастера G1/J22

Следующий scoped live результат после [response budgets](response-budget-design.md).
Основания — G1 в [discovery](discovery.md), J22 и допустимая замена недоступного
FullType явным identity-контрактом в [плане](plan.md). Source/direct J21 и actual
candidate/CLI — разные уровни проверки.

## Существующая граница

`createJavascriptManagedSourceAdapter` открывает Setting только подготовленного
existing JS GUID с native graph/icon proof. При `schemaMode=preserve` он читает
сохранённые columns/generation, проходит owned Columns→Code и закрывает мастер
через существующий discard. `handle.task` сохраняет исходный deadline и selection
lease; `inspectManagedJavascriptStage` проверяет этот lease, один пакет,
package/workflow/node/model/DOM, account/build/origin и чужие masks/dialogs.

`readJavascriptG1Type` уже читает own cached controller/engine/module proxy
metadata на Code page; не запрашивает cast, remote getters или FullType.
Его `runtime_full_type:null/full_type_observed:false` нельзя повысить по XML
или имени иконки. Исторический сериализованный `TBGJavaScriptEngine` остаётся
историческим evidence.

## Ограниченный observer

Добавить private operator observer через существующие managed page/stage read
guards, с единственным browser context. Использовать его на реальных visible
Columns и Code pages обоих сохранённых modes. Helper принимает только retained
host task; модель не выбирает callback, selectors, node или engine.

Наблюдать bounded inventory видимых buttons/checkboxes/radio/combobox/select
своего wizard root: exact TID/role/type, короткие labels/title/qtip, disabled/
checked и собственное cached scalar значение picker, если оно действительно
наблюдено. Не читать содержимое CodeMirror через DOM-контейнеры, credentials,
чужие окна или remote proxy properties. Не открывать помощника, dropdown или
другой engine ради определения его существования. Не извлекать инструкции из
текста controls. Overflow/ambiguous roots/owner drift отказывают.

На Code page дополнительно читать существующий G1 cache witness. Сверить
source/settings digest до/после, сохранить точную настройку generation и
последовательность conditional pages. Не менять source/columns/mappings,
не делать Done/Save/explicit Execute. Columns→Code navigation остаётся
потенциально эффектной по G2: отсутствие скрытого выполнения не заявляется.

Interpreter результата устанавливает presence по действительным controls и
их смыслу, а не одному regexp. Checkbox генерации выходных столбцов не является
AI assistant или engine selector. Отсутствие касается наблюдённых visible
pages/controls, а не скрытых menus и всех будущих builds. Если engine selector
наблюдён и влияет на исполнение, текущий выбор требуется в контракте/readback;
до выяснения не закрывать gate. Assistant не вызывается при любом результате.

## Identity decision и приёмка

Если FullType недоступен без нового remote обращения, явно документировать
альтернативу: exact prepared native JS GUID/workflow/package, свежая vendor
icon, собственный native Code controller/DOM и его cached engine proxy witness.
Установить точные ограничения альтернативы по live результату; не утверждать
наблюдение server FullType или полной engine conformance. Возможность замены
закреплена в плане, но эта запись сама G1 не закрывает.

Сначала addressed fixtures: foreign node/root/controller, inherited/accessor
properties, duplicate controls, mask/dialog, drift и response bound. Проверять,
что observer не вызывает remote getter/cast или gesture. Затем зафиксировать
helper/cases/oracle и выполнить последовательные fresh headed Code/Declared
profiles на том же стенде7.4.2. Каждый пакет закрыть, logout/browser close и
actual process absence проверить отдельно. Unknown effect не переигрывать.

Independent audit сопоставляет inventory и реальные allowed gesture receipts,
source/settings/owner witnesses и cleanup; только после него обновить G1/J22.
J24, module policy, cold long source, Done refusal и F остаются открытыми.
