Используй строковый столбец mixed из documents.csv. Файл в UTF-8,
разделитель точка с запятой, заголовки в первой строке, кавычки двойные;
импортируй все три столбца как строки.

Преобразуй JSON из mixed в дерево с автоматической структурой и
автоматическим корнем. В поле value записей items сохрани исходный тип и
значение каждого элемента: целое, строку, логическое false, NULL, дробное
число и большое целое без потери точности. Не превращай числа и логические
значения в строки.

Работай в новом собственном пакете. Покажи полное дерево, его структуру и
типы. Сохрани пакет в {{PACKAGE_PATH}}, закрой пакет и выйди из учётной
записи. Если настройка недоступна, сообщи наблюдаемую причину без подмены
результата.
