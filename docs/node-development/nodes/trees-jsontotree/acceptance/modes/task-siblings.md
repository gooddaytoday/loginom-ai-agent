Используй document.json без when. Преобразуй JSON в дерево: items, tags и вложенные parts сохраняют собственные границы, длины и порядок. Покажи все экземпляры дерева, не заменяй результат таблицей.

Работай в новом собственном пакете. Покажи полный результат и типы, экспортируй каждую итоговую таблицу в отдельный CSV. Сохрани пакет в {{PACKAGE_PATH}}, закрой пакет и выйди из учётной записи. Если настройка недоступна, сообщи наблюдаемую причину без подмены результата.
