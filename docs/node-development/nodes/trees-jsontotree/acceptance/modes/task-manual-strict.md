Построй структуру Root/rows с полями id (Целый, метка Номер) и code (Строковый, метка Код) вручную по manual-schema.json. На valid выполни строгое чтение. Затем используй mismatch при включённом строгом соответствии; сообщи собственную ошибку платформы и не выдавай частичный успех. В отдельном пакете проверь strict_false_probe с выключенным строгим соответствием: лишнее поле не включай в объявленную структуру.

Работай в новом собственном пакете. Покажи полный результат и типы, экспортируй каждую итоговую таблицу в отдельный CSV. Сохрани пакет в {{PACKAGE_PATH}}, закрой пакет и выйди из учётной записи. Если настройка недоступна, сообщи наблюдаемую причину без подмены результата.
