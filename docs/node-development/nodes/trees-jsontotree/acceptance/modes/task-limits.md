Проверь преобразование JSON в дерево на граничных данных из limits.json.
В отдельном новом пакете для каждого случая проверь полный результат на
допустимой границе и явный отказ за ней: число экземпляров, глубина,
размер JSON в UTF-8. Ограничения не увеличивай и данные не обрезай.
Большой допустимый вход может не поместиться в типизированный ответ:
размер входного файла и размер полного ответа проверяются отдельно.
При отказе сообщи наблюдаемую причину, не выдавай частичный результат за полный.
Сохрани положительные пакеты в {{PACKAGE_PATH}}, закрой пакеты и выйди.
