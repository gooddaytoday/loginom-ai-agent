В приложенном `documents.csv` сохранён JSON-ответ сервиса о позициях заказа.
Файл в UTF-8, разделитель запятая, заголовки в первой строке, кавычки двойные.
Импортируй RowID как целое число, Document как строку. Сохрани все исходные поля.

Разбери Document узлом «JSON в дерево» с автоматическим определением структуры
и корня. Покажи полное дерево с типами, порядком полей, всеми элементами массива
и точными числовыми значениями. Различай пропуск и пустую строку;
отсутствующий note показывай как пропуск. Большое целое число должно
сохраниться без округления.

Подключи выход дерева к узлу «Дерево в таблицу». Получи одну запись на позицию
из items. Выведи поля в порядке id, active, sku, qty, price, note, с короткими
именами полей. Повторяй id и active для каждой позиции. Отсутствующий note
показывай как пропуск. Сохрани исходный порядок позиций, нулевое количество,
ложное логическое значение и пустую строку. Покажи все записи и типы полей.

После всех чтений сохрани готовый пакет в `{{PACKAGE_PATH}}`.
