# JSON в дерево (`trees.from_json`)

<!-- mode: auto_structure -->
Один JSON object из одной строки строкового поля. Выполни источник и прочитай
его полностью. Используй `mode:"auto_structure"`,
`parameters:{json_field:"Document",root_mode:"auto"}`, `finish:"execute"`,
`read:{ports:[0],sample_rows:100,require_exact_numbers:true}`.

Предложение LAB-1136 после утверждения: объекты и массивы объектов внутри
повторяющихся записей; пустой массив имеет ноль экземпляров, пустой объект
сохраняет контейнер. Отсутствующий scalar материализуется как типизированный
NULL, включая поля пустого объекта, выведенные по соседним записям.
NULL отличается от пустой строки, false и нуля. Смешанный лист требует
Variant с точным типом каждой ячейки; не преобразуй его в строку.

Порт 0 — дерево: полностью прочитай `tree.schema` и `tree.instances`,
порядок схемы и всех экземпляров, границы каждого массива, типы, NULL
и точные значения. Int64 передавай десятичной строкой.
Предложение не разрешает подменять дерево таблицей, JavaScript или
вычислениями по вложению. При недоступном точном чтении сообщи ограничение.
Сохрани пакет отдельно. NULL-only имеет Variant; всегда пустой массив
сохраняет схему `is_array:true,is_container:false,type:variant`
и ноль экземпляров. Всегда пустой объект сохраняет контейнер без дочерних полей.

Пределы прежние: 256 экземпляров, глубина 16, 1 MiB; превышение — отказ
без усечения. Несколько корневых строк, sibling arrays, непустые scalar arrays,
ручная схема, XSD, forced root и даты в это предложение не входят.
`trees.to_table` имеет собственную область поддержки; поддержка вложенного
дерева не обещает его автоматического табличного разворачивания.
