Создайте пакет, в котором режим отчёта по заказам выбирается переменной.
Импортируйте предоставленный orders.csv: UTF-8, разделитель запятая, первая строка —
заголовок, десятичная точка, маркер пустого значения «?». Пустой текст в Note должен
оставаться пустой строкой. OrderID — целое, Region — строка, Amount — вещественное,
Paid — логическое, Note — строка.

В переменных сценария задайте целую переменную Mode со значением 1.
Добавьте Условие с двумя входами: таблица заказов и переменные сценария.
Таблица заказов должна передаваться на выход каждой ветви без изменений.
Создайте одну ветвь Detailed: она выбирается, когда Mode равно 1; во всех
остальных случаях работает ветвь «Иначе». Других ветвей и условий не нужно.

Выполните Условие и прочитайте весь выход выбранной ветви, сохранив порядок строк
и полей, пустые значения и типы. Убедитесь, что ветвь «Иначе» при этом не выполнялась.
Выгрузите результат в detailed.csv рядом с пакетом.
Затем измените только значение Mode на 0, не перенастраивая Условие и связи.
Повторно выполните Условие и прочитайте весь выход ветви «Иначе»; убедитесь,
что ветвь Detailed не выполнялась. Выгрузите результат в other.csv рядом с пакетом.
Сохраните пакет по пути {{PACKAGE_PATH}}. Закройте пакет и завершите сеанс.
