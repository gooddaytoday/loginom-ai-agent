# Предложение навыка v040, не активная инструкция

Ассоциативные правила: fp_growth для обучения, apply только существующей
сохранённой модели без переобучения. Основной вход содержит дискретные
строковые Transaction/Item, по одной позиции на строку. Вспомогательный
вход: назначь нужным столбцам роль «Элемент», затем выбери их в фильтре
«Содержащие выбранные элементы». Не трактуй невыбранный Boolean Keep
как условие отбора и не подменяй этот фильтр списком следствий.
Поддержка и достоверность в параметрах — проценты, на выходах — доли.
Минимальный лифт — отношение; max_items ограничивает общую длину,
max_consequents — длину следствия. Читай наборы (0), правила (1),
рекомендации (2), не выводи точные числа из округлённой таблицы.
Не рекомендуй уже присутствующий товар. При конкуренции правил не
придумывай ранжирование: его критерий пока не установлен.
Сохрани исходную модель для holdout и пакет после экспорта.
