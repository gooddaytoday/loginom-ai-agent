# Явно выбираемое автосопоставление, Loginom 7.4.2

Проверено 1 ноября 2026 на `https://app.loginom.ai/app/?testable=true`,
Linux/Chromium 1246, на базе `0461406e825d1f4bd1fafaca934bfd9573774f77`.
Входные схемы до реализации записаны в
`acceptance/union-auto-match/discovery-cases.json`; бизнес-ожидания независимо
вычисляются `acceptance/union-auto-match/oracle.py` из трёх исходных CSV.

Контекстное меню открывается правой кнопкой на ячейке присоединяемого поля,
например `MF;TF-1;WizrdMCF;UnionDataWizard;normalHeaderCt;col1_Code`.
Команды: `mnUnionGrid;mniLinksAuto` («Автоматически связать все поля») и
`mnUnionGrid;mniRemoveLinks` («Удалить все связи»).
Отдельных UI-команд для имени и метки нет. Нативная команда сначала связывает
имя+тип, затем метку+тип; уже установленные пары сохраняет.

После удаления всех связей и повторной автосвязи наблюдалась полная карта:

| Главное поле | Присоединяемое поле | Результат |
|---|---|---|
| Code:string | code:string | Пара, регистр игнорируется |
| Amount:real | Amount:real (другой индекс) | Пара |
| CaseKey:string | casekey:string | Пара |
| Wrong:integer | Wrong:string | Без пары |
| Left:string, метка Shared | Other:string, метка Shared | Пара |
| Right:string, метка Shared | Other уже занят | Без пары |
| отсутствует | Solo:string | Без пары |

Повтор команды дал ту же карту. Неоднозначную метку нативный мастер разрешает
первым подходящим полем. API запрещает такой выбор: `UNION_AUTO_MATCH_AMBIGUOUS`
до изменения узла/Execute; явная карта разрешает неоднозначность.
Выбранный `name_type`/`label_type` определяет требуемую полную карту. После
нативной команды существующий редактор удаляет лишние пары, применяет явные
переопределения и сверяет всю итоговую карту, включая `main:null`.

`readUnionBrowser` подтвердил `verified:true`, `inventory_complete:true`,
все шесть полей обоих входов, четыре пары и `unmatched:["Wrong","Solo"]`.
Он читает полные локальные хранилища мастера, проверяет прямую и обратную
связь и равенство типов; виртуализация строк/столбцов не сокращает карту.
Запись выполняется только жестами на видимых ячейках с прокруткой.
Нативные методы и RPC для изменения карты напрямую не вызываются.

Живой сценарий обнаружил отдельную границу наблюдения: меню `mnUnionGrid`
отсоединено от поддерева мастера. После успешного правого клика журнал
показывал его в `interaction.covering`, но область чтения оставалась
`MF;TF-1;WizrdMCF`, поэтому команда не попадала в `ui.elements`.
Чтение использует существующий механизм выбора единственного меню как
отдельной области; неоднозначные области отклоняются. Идентичность узла,
входные схемы и итоговая карта по-прежнему проверяются независимо от меню.

Поля без пары сохраняются отдельными выходными столбцами. Коллизии имён
требуют явного изменения входа или включения префикса; типы не преобразуются.
Выбор режима API не является сохранённой настройкой Loginom: readback
возвращает фактически наблюдённые пары и отдельные столбцы.
