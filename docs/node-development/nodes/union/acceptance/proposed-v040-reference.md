# Объединение (`transform.union_data`)

## Объединение

Для добавления строк таблиц используй `transform.union_data`, `mode:"append_all"`.
Если пользователь просит объединить по одинаковым полям, задай
`parameters.auto_match:"name_type"`; для одинаковых меток — `"label_type"`.
Сравнение без учёта регистра и только при одинаковом типе. Вход 0 — главная
таблица; `tables:[{port:1,fields:[]},…]` перечисляет все остальные входы
последовательно. `prefixes:{enabled:false,name:"Union",label:"Объединение"}`
сохраняет имена полей без пары; при коллизии имён явно настрой вход или префикс.
Повторы строк сохраняются. Когда имена различаются, используй явную карту
`fields:[{source:"ИмяВхода",main:"ИмяГлавного"},…]`; `main:null` сохраняет
отдельный столбец. Явные записи имеют приоритет над автосопоставлением.
Без `auto_match` карта должна покрывать каждое поле каждого входа.
Неоднозначность требует явной карты и отклоняется до Execute.
Проверь итоговые `configuration.readback.tables`, включая поля без пары.
Повторную настройку делай на том же existing ref с сохранением входов.

# Объединение (`transform.union_data`)

Предложение этапа 0; до реализации используй действующие `append_all`,
`name_type`/`label_type` и явные карты полей.

Предлагается `auto_match:"name_then_label_type"`: сначала зарезервировать пары
имя+тип, затем сопоставить оставшиеся свободные поля по метке+типу. Явные
`tables[].fields` имеют приоритет, включая `main:null`. Типы должны совпадать.
Неоднозначность требует явной карты. Сохранить все повторы строк и поля без пары.

Автоматическая метка в общей странице описания узла не меняет табличный
результат. Метку, которую пользователь не задавал, не следует закреплять строкой
в oracle. Для нового узла не задавай `target.label`, если пользователь оставил
метку автоматической: общая процедура переименовывает только при явном label.
Отдельного бизнес-режима и правки обработчика объединения это не создаёт.

DISTINCT не объявляется поддержанным: в исследованном мастере нет такого
переключателя. `task-distinct.md` и его математический oracle — отложенное
предложение, которое нельзя запускать как принятый режим узла.
