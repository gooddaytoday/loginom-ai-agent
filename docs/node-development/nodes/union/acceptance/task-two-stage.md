Объедини main.csv и second.csv в этом порядке, сохранив повторяющиеся строки. В main.csv Code — строка с меткой «Код», Backup — строка с меткой «Резерв», Amount — целое число с меткой «Сумма». В second.csv Code и Reserve — строки с меткой «Резерв», Amount — целое число с меткой «Другая сумма».

Сопоставь поля автоматически: сначала по техническому имени и типу, затем оставшиеся по метке и типу. Приоритет технического имени должен сохраняться при несовпадении меток. Результат должен содержать исходные столбцы главной таблицы Code, Backup, Amount, без префиксов.

Выгрузи результат в two-stage-result.csv с техническими именами, разделителем «;» и NULL для пропусков. Сохрани сценарий в {{PACKAGE_PATH}}.
