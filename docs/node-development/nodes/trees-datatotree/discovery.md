| Поле после `TreeToJSONWizard;` | Подпись | Исходное значение |

| `pedPrettifyJSON;ValueControl` | Выдавать форматированный JSON | false |
| `pedDisplayNameAsKey;ValueControl` | Формировать JSON имена из меток узлов | false |
| `pedMultiRowOutput;ValueControl` | Формировать набор строк для массива корневых узлов | false |
