# Произвольная структура, группировка и типы — предложение LAB-1042

Этап 0; runtime не изменён. [Живое исследование и общий стоп](modes-discovery.md).
[Комплект и задания](acceptance/modes/README.md), [ожидания](acceptance/modes/expected.json),
[входы](fixtures/modes/input.json). Критерии не утверждены.

Пять адресных циклов: массивы (включая соседние и scalar arrays), группировка
повторяющихся ключей, дата/Variant, пустой вход, редактор/глубина.
Вход A/x/2, B/y/0, A/z/NULL различает строки и группировку, first-occurrence
и сортировку; grouped proposal — A[x,z], B[y]. Реальное правило native пока
не наблюдалось. Даты civil с .789/.001; Variant integer 9007199254740993,
Boolean false и пустая String задаются независимо от CSV inference.

Обычный результат — полное типизированное дерево порта 0, не таблица.
Пустой источник предполагает Root с items=[], но объявленные Group/Code/Qty
остаются в schema. Глубина editor fixture 5 проверяет прежнее ограничение
обработчика на один вложенный object, сохраняя общий предел 16.
Значения, schema/порядок/метки/типы, изменение существующего узла и cold
проверяются отдельно; одинаковые ключи без запроса не группируются.

Наблюдено: ручной редактор и список типов с datetime/variant. Группировка,
scalar arrays, пустой результат и данные **not_checked**.
Общие stop: typed tree reader не принимает datetime/variant и scalar array;
локальный max 64 структуры, instance/root ограничения. До решения владельца
не расширять эти guards и публичный контракт. Оценка: 5 циклов плюс доля
двух общих циклов, без новой CLI-сборки на этапе 0.
