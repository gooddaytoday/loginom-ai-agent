Из файла org.csv постройте оргструктуру компании по связям между строками:
id — строковый идентификатор, parent_id — идентификатор родителя, name — название.
Сохраните ведущие нули идентификаторов. Пустая ячейка parent_id при импорте
означает NULL и задаёт корень. Потомок может находиться в файле раньше родителя.

Нужна вложенная иерархия «Компания → ИТ → Группа данных → Аналитик», а также
«Поддержка» внутри ИТ. У каждого элемента сохраните id, parent_id и name,
добавьте массив children с непосредственными потомками; у листа он пустой.
Сохраните порядок соседних элементов по порядку их строк в файле.
Верните один JSON-документ с массивом roots, без технической обёртки Root.

Используйте штатные «Таблица в дерево» и «Дерево в JSON». Проверьте полное дерево
и JSON, сохраните пакет в указанное место. Если штатный режим связей id/parent_id
недоступен, явно сообщите об ограничении и не подменяйте его другой обработкой.
