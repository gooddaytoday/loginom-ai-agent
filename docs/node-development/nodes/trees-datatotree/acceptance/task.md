Подготовь представление позиций заказов из orders.csv. Первая строка — заголовок,
разделитель — запятая, десятичный знак — точка, знак ? означает NULL.
RowID, OrderID и ExternalID — целые, SKU и Note — строки, Qty — целое,
Price — вещественное, Active — логическое. Пустая строка отличается от NULL.

Построй дерево с корневым объектом Root и массивом items. Каждой исходной строке
соответствует отдельный элемент массива в исходном порядке; одинаковые OrderID
не объединяй. В элементе сначала размести RowID, OrderID, ExternalID, затем
объект details с полями SKU, Qty, Price, Active, Note именно в этом порядке.
Используй технические имена как метки и сохраняй исходные типы значений.

Прочитай полное дерево и преобразуй его в одну компактную JSON-строку,
исключив служебное имя Root. Для JSON используй имена полей, сохрани массив,
числа, логические значения, NULL, пустые строки и специальные символы.
