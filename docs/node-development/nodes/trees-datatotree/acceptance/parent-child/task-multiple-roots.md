Из multiple-roots.csv постройте вложенную оргструктуру по строковым id и
parent_id. Пустой parent_id означает NULL-корень. Сохраните оба корня в порядке
их строк: Филиал, затем Штаб. Внутри Штаба сохраните порядок: Второй отдел,
затем Первый отдел. Потомок может предшествовать родителю в файле.

Получите на существующих узлах Loginom один JSON-документ
с массивом roots; каждый элемент содержит id, parent_id, name и children,
у листьев children пустой; технической обёртки Root нет. Все три входных поля
импортируйте как строки. Проверьте полное дерево, JSON и сохраните пакет.
