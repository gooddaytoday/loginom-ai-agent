Из orphan.csv постройте вложенную оргструктуру на существующих узлах Loginom.
Все поля id, parent_id, name — строки; пустой parent_id — NULL-корень.
Если parent_id указывает на отсутствующий id, выполнение должно завершиться
ошибкой с перечнем id строк-сирот; передайте точный текст ошибки. Не теряйте
строки, не превращайте сирот в корни, не исправляйте данные и не создавайте
частичное дерево или экспорт. Сохраните пакет с настроенным вычислением.
