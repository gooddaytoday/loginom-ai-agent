# Дерево в таблицу

Прочитай карточку trees.to_table и полное дерево источника. selected_nodes
выбирает пути схемы без индексов экземпляров, в порядке листьев схемы.
Предки выбираются автоматически. repeat_parents управляет повтором значений
родителей, NULL не равен пустой строке, нулю и false.

Индексная колонка — отдельный выбор у массива; глобальный индекс должен
проверяться между несколькими родителями. Это данные, а не UI row index.
Базу индекса и native имена подтвердить до использования; не угадывай их.
composite_names и composite_labels включают составные имена и метки;
label_separator выбирается только из наблюдаемого списка платформы.
Имя и метка проверяются отдельно. Выбор более 64 листьев сохраняет все поля;
полное дерево остаётся в пределах 256 узлов, глубины 16 и 1 MiB.
Совместное разворачивание sibling arrays требует подтверждённого native
правила кратности и порядка; не подменяй его zip или произведением по догадке.

Явный selected_paths заменяет весь выбор; пропущенные настройки сохраняются.
Выход 0 — таблица: прочитай все строки, имена, метки, типы и порядок полей,
экспортируй CSV, сохрани пакет. Cold выполняет сохранённый узел без настройки.
XSD и переменные вне области. Новые возможности — предложение LAB-1042,
не утверждение поддержки текущим runtime; native-пробы обязательны.
