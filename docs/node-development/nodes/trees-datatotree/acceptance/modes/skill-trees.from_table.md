# Таблица в дерево

Сначала прочитай карточку типа и полный источник с точными именами и типами.
manual_structure задаёт полный список nodes родитель → дети. Root — object;
массивы и вложенные контейнеры задаются явно. source_field нужен только листу.
Явный список заменяет структуру; parameters:{} на существующем сохраняет её.

Обычный режим сохраняет каждую строку отдельно. Группировка — только по явно
заданным ключам, с согласованным правилом порядка, без молчаливой агрегации.
Порядок детей определяется структурой, порядок массивов — исходными строками.
Дата/время — civil с миллисекундами, без пересчёта часового пояса; Variant
сохраняет подтип каждой ячейки. Int64 передаётся точным десятичным текстом.
NULL, пустая строка, 0 и false различаются. Пустой вход сохраняет схему.

Редактор добавляет дочерний/соседний узел, меняет имя, метку, тип, массив,
контейнер и порядок. Ограничения полного дерева: 256 экземпляров, глубина 16,
1 MiB ответа. При превышении нужен отказ, усечение не допускается.
Done подтверждает настройки; Execute пересчитывает вход; Save отдельно.
XSD и переменные не входят. Это предложение LAB-1042 до native-проб и решения
владельца: не считать новые возможности доступными в текущем runtime.
