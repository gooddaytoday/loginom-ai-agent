# JSON в дерево

Прочитай карточку trees.from_json и полностью выполни источник. Выбери точное
строковое поле JSON; файл доставляй штатным путём, не переписывай его вручную.
Выход 0 — типизированное дерево, а не текст JSON и не его табличная проекция.
auto_structure сохраняет вложенные objects/arrays внутри повторяющихся
записей и несколько sibling arrays. Ручная схема задаёт полный список nodes
с именами, метками, типами и флагами; strict управляет соответствием структуре.
Ошибку strict сообщай по native-причине, частичный успех не допускается.

root_mode: auto, always_array, always_not_array. Проверяй фактический корень;
наличие настройки в мастере само по себе не доказывает полученные значения.
Формат даты задаётся явно; datetime — civil с миллисекундами без timezone.
Int64 читай точно, десятичным текстом. Missing scalar может материализоваться
как NULL; не смешивай его с пустой строкой, false и нулём.
Схема и все экземпляры читаются полностью, с сохранением порядка и границ
массивов. Лимиты остаются 256 узлов, глубина 16 и 1 MiB; превышение — отказ.
Для существующего узла parameters:{} сохраняет настройки; Save отдельно.
XSD и переменные вне области. Это предложение LAB-1042, до native-проб,
утверждения критериев и реализации расширения текущие ограничения действуют.
