# Дерево в JSON

Прочитай карточку типа и полное типизированное дерево источника. Tree output 0
подключается к tree input 0; выход сериализатора 0 — строковая таблица.
serialize сохраняет самостоятельные sibling arrays и их порядок.
exclude_root управляет технической обёрткой; pretty — форматированием;
keys names/labels выбирает технические имена либо фактические метки.
Не выдумывай метки, не допускай коллизий ключей.

Корневой массив при multi_row=false образует один JSON-документ, при true —
одну строку на элемент. Пустой массив соответственно даёт документ [] либо
ноль строк при сохранённой строковой схеме. Эти правила требуют native-пробы.
Дата/время: ISO 8601 либо явные форматы даты и времени без смены civil-значения.
Int64 не округляй через Number. NULL отличается от пустой строки, 0 и false.
Полный JSON читается без preview-усечения; сохраняй порядок массивов.
На существующем узле пропущенные параметры сохраняются. Done — настройка,
Execute — свежие данные; Save отдельно, cold без повторной настройки.
XSD и переменные не входят. Новые возможности — предложение LAB-1042,
не описание доступного текущего runtime. Лимиты дерева 256/16/1 MiB прежние.
