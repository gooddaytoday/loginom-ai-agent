Используй rows.csv и описание типов input.json. Построй массив объектов с When и Value. When — дата/время с миллисекундами без часового пояса. Value — переменный тип: большое целое, логическое false, пустая строка; не приводи все значения к строкам. Перед преобразованием проверь фактические типы источника.

Работай в новом собственном пакете. Покажи полный результат и типы, экспортируй каждую итоговую таблицу в отдельный CSV. Сохрани пакет в {{PACKAGE_PATH}}, закрой пакет и выйди из учётной записи. Если настройка недоступна, сообщи наблюдаемую причину без подмены результата.
