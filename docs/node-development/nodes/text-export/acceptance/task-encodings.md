Из encodings.csv выгрузи три файла для разных получателей: western.csv в
Windows-1252 без BOM, utf16-le.csv в UTF-16 LE с BOM, utf16-be.csv в UTF-16 BE с BOM.
Оба столбца — строки. Сохрани все символы, строки и их порядок.
Имена столбцов в первой строке, разделитель — точка с запятой, окончания CRLF,
включая последнюю строку. Кавычки нужны только при необходимости.
Доставь три файла и сохрани пакет в {{PACKAGE_PATH}}.
