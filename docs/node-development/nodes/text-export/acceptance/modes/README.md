Это **предложение LAB-1011**, ожидающее решения владельца, не принятые режимы.
Актуальные UI-наблюдения, блокеры, критерии и оценка — в разделе LAB-1011
[подплана](../../plan.md). Runtime и действующий skill не изменены.

`expected.json` и `oracle.py` проверяют fixed width, кодировки и отдельно
заблокированный числовой формат. Бизнес-задания — `../task-*.md`, источники —
`../../fixtures/`. Модели передаются только задание и соответствующий CSV.

`proposed-card.json`, `proposed-reference.md`, `proposed-route.txt` — проект
модельных инструкций **доступного поднабора после реализации**. Они не являются
текущим ответом инструментов и не регистрируют режимы.

Из корня репозитория:

```sh
python3 docs/node-development/nodes/text-export/acceptance/modes/oracle.py --self-check
node docs/node-development/nodes/text-export/acceptance/modes/schema-size.mjs
```

Второй скрипт проверяет также Excel-проект в соседнем узле. Для сознательного
пересоздания документационных карточек/строк/ref добавьте `--write`.
Модельный apply измеряется через userNodeTool; полная schema имеет отдельный замер
без лимита. Runtime не изменяется. Хеш-поля карточек — нулевые заглушки.
