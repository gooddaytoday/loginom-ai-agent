Из formats.csv подготовь amounts.csv. Code — строка, Amount и Money —
вещественные числа; Money содержит денежные суммы. Обоим числовым полям
задай при экспорте ровно два знака после точки без разделения тысяч.
Сохрани исходные числовые значения в сценарии, порядок строк и столбцов.
В файле нужны имена полей, разделитель — точка с запятой, UTF-8 без BOM,
окончания CRLF, включая последнюю строку. Доставь файл и сохрани пакет
в {{PACKAGE_PATH}}.
