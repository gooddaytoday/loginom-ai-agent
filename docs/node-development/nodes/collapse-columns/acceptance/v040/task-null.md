Создай пакет {{PACKAGE_PATH}} из all-null.csv: Id/I — целые, R — вещественное
с точкой, S — строка, B — логическое, D — дата/время. Знак ? означает NULL;
кавычки вокруг пустой строки означают пустую строку. Сохрани порядок строк.

В узле «Свёртка столбцов» явно сопоставь все входные поля: Id → RowID,
I → Units, R → R, S → Text, B → B, D → D, без изменения их типов.
Метки сопоставленных полей сделай равными их новым именам.
RowID — информационное поле. Транспонируй в порядке Text, Units, R, B, D.
Не игнорируй NULL. На выходе сохрани все пять полей в порядке и с именами
RowID, Field (имя исходного поля), FieldLabel (метка), Cell (значение),
Kind (тип исходного поля). Для Cell задай метку «Значение».

Прочитай все строки с типами значений, скачай null.csv с техническими
именами в заголовке и маркером ? для NULL, сохрани пакет. После открытия выполни тот же узел
без изменения настроек.
