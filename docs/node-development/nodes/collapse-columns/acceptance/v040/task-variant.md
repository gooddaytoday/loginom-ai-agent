Создай пакет {{PACKAGE_PATH}} из mixed.csv: Id/I — целые, R — вещественное
с точкой, S — строка, B — логическое, D — дата/время; ? — NULL.
Сохрани исходный порядок записей и пустые строки.

Первой «Свёрткой столбцов» оставь Id информационным полем и транспонируй
I, R, S, B, D именно в этом порядке, не игнорируя NULL. На выходе явно
сопоставь Id → RowID, Names → SourceName, DisplayNames → SourceLabel,
Values → Cell (метка «Значение»), DataTypes → SourceType. Все поля сохрани.

Передай этот смешанный столбец Cell во вторую «Свёртку столбцов».
Назови второй узел «Повторная свёртка». Во второй оставь только RowID
информационным, транспонируй только Cell,
не игнорируй NULL. Сохрани пять выходных полей в порядке RowID, Field,
FieldLabel, Cell, Kind; метку Cell задай «Значение».
Поле Cell должно сохранять тип каждого исходного
значения: целое, вещественное, строка, логическое, дата/время или NULL.

Прочитай весь результат второй свёртки с типами ячеек, скачай variant.csv
с техническими заголовками и маркером ? для NULL и сохрани пакет. Повторное открытие и выполнение
не должны менять значения или настройки двух свёрток.
