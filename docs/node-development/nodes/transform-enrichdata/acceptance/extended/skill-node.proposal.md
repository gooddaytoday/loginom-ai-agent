# Дополнение данных

Предложение этапа 0; до реализации доступен прежний срез из карточки типа.

Для добавления столбцов справочников используй `transform.enrich_data`,
`mode:"left"`. Вход 0 — главная таблица, входы 1..14 — справочники;
предел следует из существующего лимита 15 табличных входов запроса.
Третий и четвёртый справочники требуют тех же ключей, что первые два.
Каждый справочник независимо связан с исходной главной таблицей.

Перед настройкой прочитай `dock_action_describe` для типа. Полностью задай
`enrichment.tables=[{port,keys:[{main,lookup}]}]` по порядку портов без разрывов,
используя точные имена полей и одинаковые типы ключей. Составной ключ —
несколько пар; это не выражение. Нужны полные `enrichment.prefixes`:
`enabled`, буквальные `name` и `label`. Фактические имена выхода читай после
применения: нативные суффиксы разрешают совпадения имён.

NULL совпадает с NULL, пустая строка отличается от пропуска. Каждое совпадение
сохраняется; дубликаты разных справочников перемножаются. Главная строка без
совпадения сохраняется с NULL справа, другие справочники по-прежнему ищут
по исходной главной строке. Ключи справочников не входят в результат.
Остальные поля добавляются в порядке входов с сохранением типов.

Новый узел требует главную таблицу и все объявленные справочники в `inputs`.
Изменение состава входов требует полной конфигурации, включая прежние ключи
и префиксы. Пропуск enrichment на существующем узле сохраняет настройки
только при неизменных источниках. Для смены данных перенастрой прежний импорт,
выполни его, затем прежнее Дополнение: `parameters:{}`, `inputs:[]`,
`mappings:[]`, `finish:"execute"`.

Для точного порядка полей используй выходной mapping порта 0,
`autosync:false` и полный fields layout. Прочитай весь малый результат:
`read:{ports:[0],coverage:"sample",sample_rows:100,require_exact_numbers:true}`,
проверь `sample_complete`. Покрытие full требует отдельного согласованного
расширения общего reader; эта карточка его не объявляет.
CSV выгружай с `null_marker:"?"`, сохраняя пустую строку отдельно от NULL.
Сохрани готовый пакет и проверь новое открытие и выполнение.

В нативном мастере не обнаружены выбор другого соединения, редактор
вычисляемого ключа или преобразование типа ключа. При таком запросе сообщи
границу; не выдавай upstream-обход за режим Дополнения. Привязки к переменным
не входят в этот объём. Обучение не требуется.
