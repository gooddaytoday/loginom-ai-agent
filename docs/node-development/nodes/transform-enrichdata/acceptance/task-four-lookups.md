Дополни main.csv четырьмя справочниками ref-a.csv, ref-b.csv, ref-c.csv,
ref-d.csv в одном узле «Дополнение данных». CSV — UTF-8, запятая, заголовки,
пропуск ?, пустая строка сохраняется отдельно. RowID и Key — целые,
Note и значения справочников — строки.

Каждый справочник независимо связан по Key с исходной главной таблицей.
Сохрани все главные строки, все сочетания совпадений и совпадения пропущенных
ключей. Ненайденные значения — пропуски. Префиксы выключи.
Сначала выполни узел с тремя первыми справочниками, затем добавь четвёртый
к тому же узлу. Сохрани прежние связи и настройки.
Конечный порядок полей: RowID, Key, Note, A, B, C, D; правые Key не выводи.

Повторно выполни тот же узел без изменения настроек, выгрузи полный конечный
результат с техническими именами и маркером пропуска ?, сохрани сценарий
в {{PACKAGE_PATH}}.
