## Заметки черновика

Нового handler нет. Переиспользовать пару input mappings Join и динамические входы Union; сопоставление каждого joined input остаётся привязано к основной таблице, не к результату предыдущего join.

Main keys [1,2,3]; B=[(1,b1),(2,b2)], C=[(1,c1),(3,c3)]. Получить (1,b1,c1),(2,b2,NULL),(3,NULL,c3). Дополнить B дубликатом key1 и отдельно закрепить кратность при нескольких правых совпадениях.
