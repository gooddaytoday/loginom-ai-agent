Создайте пакет для трёх последовательных запросов страниц через Цикл.

Создайте Подмодель с одним входом переменных и одним табличным выходом Answers,
без табличного входа. Во входе переменных задайте целые Page=99 и Limit=2
в таком порядке, без пропущенных значений.

Внутри подключите входной узел переменных к «Переменные в таблицу» в режиме
«В столбцы». Одну полученную строку Page/Limit подайте в Калькулятор;
к его обычному входу переменных подключите те же переменные входного узла.
Создайте целое поле Skip по формуле Var.Page * Var.Limit; сохраните также
поля Page и Limit. Порядок результата Калькулятора — Skip, Page, Limit.
Выполните это тело для получения полной схемы перед настройкой REST.

В модуле Подмодели создайте REST-подключение: GET
https://httpbin.org/response-headers, без аутентификации, проверку сертификата
не отключайте. Задайте URL query-параметры limit и skip. Добавьте REST-запрос
с табличным входом от Калькулятора: limit получает поле Limit, skip — поле Skip.
Порт 0 REST (RequestID и Response) соедините с табличным выходом Подмодели.
Подмодели внутри Подмодели не нужны.

Добавьте Цикл по этой Подмодели: «Заданные итерации», ровно 3 итерации,
переменная цикла — Page из её входа переменных. Включите добавление
идентификаторов итераций. Параллельность выключите, ошибки не игнорируйте,
собственную конфигурацию не сохраняйте. Внешний источник переменных не нужен.

Выполните Цикл и прочитайте весь выход в порядке итераций с полным текстом
Response. Сохраните имена, типы и порядок полей RequestID, Response, IterationId.
Выгрузите результат в for-rest.csv рядом с пакетом.
Сохраните пакет по пути {{PACKAGE_PATH}}. Закройте пакет и завершите сеанс.
