## Срез

Групповая обработка, группы по одной строке, без параллельности, без идентификаторов
итераций, ошибки не игнорируются. Заключённый узел — Подмодель с одним табличным входом
Page и выходом Answers. Вход Подмодели связан с импортом (схема для настройки тела),
вход Цикла — тоже с импортом.

| Случай | Задание | Тело Подмодели | Ожидание | Сеть |
|---|---|---|---|---|
| rest | `task.md` | REST GET `https://httpbin.org/response-headers`, query limit←Limit, skip←Skip; выход — порт 0 REST | `expected.json` | httpbin.org со стенда |
| offline | `task-offline.md` | Калькулятор `LastIndex = Skip + Limit − 1` | `expected-offline.json` | нет |

1. Execute Цикла и полный выход порта 0: по строке на итерацию, 3 строки в порядке страниц.
   Три разных ответа доказывают три итерации с разными Skip.
2. CSV `pages-result.csv` / `pages-offline.csv`; Save после последнего чтения; cold
   Execute без восстановления настроек, итог совпадает с expected.
3. Readback: заключённый узел (ref), производный компонент, вид цикла и размер группы,
   флаги, фактические порты Цикла.
4. Отрицательные адресные проверки: FOR, постусловие, параллельность, запрещённый тип
   заключённого узла (Условие, Цикл, Выполнение узла, Узел-ссылка), чужой workflow —
   отказ до мутации; native причина из `btnError`.
5. Исполнитель ≥2/3 PASS на одном SHA; независимая приёмка 2/3 на том же SHA.

## Числа и типы

| Случай | Поля | Строки |
|---|---|---|
| offline | PageNo, Limit, Skip, LastIndex — integer | (1,2,0,1), (2,2,2,3), (3,2,4,5) |
| rest | RequestID integer, Response string | RequestID 0 в каждой итерации; Response — тело httpbin для skip 0, 2, 4 |

Response — точный текст: JSON с отступом 2, ключи по алфавиту, перевод строки в конце,
`Content-Length` = длине тела (98 байт). Oracle вычисляет его тем же правилом, что httpbin;
13.11.2026 три ответа живого httpbin (с freak) совпали побайтно. Если проба покажет, что
REST меняет текст (обрезает перевод строки), правится oracle до прогонов, не после.
RequestID — индекс строки внутри итерации, поэтому 0 у всех трёх строк.
