Создайте пакет, который обрабатывает страницы по одной, без обращения к сети.
Импортируйте предоставленный pages.csv: UTF-8, разделитель запятая, первая строка —
заголовок. PageNo, Limit и Skip — целые; одна строка описывает одну страницу.

Создайте Подмодель с одним обязательным табличным входом Page и одним табличным
выходом Answers. Подключите импорт к её входу. Внутри Подмодели создайте Калькулятор,
который передаёт все входные поля и добавляет в конце целое поле LastIndex:
Skip + Limit − 1. Свяжите входной узел с Калькулятором, а его результат — с выходным
узлом. Подмодели внутри Подмодели не нужны.

Добавьте Цикл, который выполняет эту Подмодель отдельно для каждой страницы:
групповая обработка группами по одной строке, без параллельной обработки,
без идентификаторов итераций, ошибки не игнорировать. Подключите импорт ко входу Цикла.
Выполните Цикл и прочитайте весь его выход в порядке страниц, сохранив порядок полей
и типы. Выгрузите результат в pages-offline.csv рядом с пакетом.
Сохраните пакет по пути {{PACKAGE_PATH}}. Закройте пакет и завершите сеанс.
