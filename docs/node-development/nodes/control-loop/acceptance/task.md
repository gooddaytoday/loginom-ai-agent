Создайте пакет, который загружает ответы REST-сервиса постранично.
Импортируйте предоставленный pages.csv: UTF-8, разделитель запятая, первая строка —
заголовок. PageNo, Limit и Skip — целые; одна строка описывает одну страницу.

Создайте Подмодель с одним обязательным табличным входом Page и одним табличным
выходом Answers. Подключите импорт к её входу. Внутри Подмодели выполните GET-запрос
к https://httpbin.org/response-headers для каждой входной строки: параметр строки
запроса limit берётся из поля Limit, skip — из поля Skip. На выход Подмодели передайте
ответ REST-запроса как есть: номер запроса и исходный текст ответа, без разбора JSON.
Подмодели внутри Подмодели не нужны.

Добавьте Цикл, который выполняет эту Подмодель отдельно для каждой страницы:
групповая обработка группами по одной строке, без параллельной обработки,
без идентификаторов итераций, ошибки не игнорировать. Подключите импорт ко входу Цикла.
Выполните Цикл и прочитайте весь его выход: ответы всех страниц в порядке страниц,
текст ответа без изменений. Выгрузите результат в pages-result.csv рядом с пакетом.
Сохраните пакет по пути {{PACKAGE_PATH}}. Закройте пакет и завершите сеанс.
