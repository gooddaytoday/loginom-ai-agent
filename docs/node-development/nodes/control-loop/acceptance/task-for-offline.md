Создайте пакет, который вычисляет смещения трёх страниц без обращения к сети.

Создайте Подмодель с одним входом переменных и одним табличным выходом Answers.
Табличный вход ей не нужен. Во входе переменных задайте две целые переменные
в таком порядке: Page со значением 99 и Limit со значением 2; значения не пропущены.

Внутри Подмодели подключите переменные входного узла к узлу «Переменные в таблицу»
в режиме «В столбцы», чтобы получилась одна строка с Page и Limit. Добавьте
Калькулятор: его табличный вход получает эту строку, а обычный вход переменных —
те же переменные входного узла. Вычислите целое поле Skip как произведение
переменных Page и Limit: Var.Page * Var.Limit. Передайте также поля Page и Limit.
Результат Калькулятора в порядке Skip, Page, Limit свяжите с выходом Подмодели.
Подмодели внутри Подмодели не нужны.

Добавьте Цикл по этой Подмодели: «Заданные итерации», ровно 3 итерации,
переменная цикла — Page из её входа переменных. Включите добавление
идентификаторов итераций. Параллельность выключите, ошибки не игнорируйте,
собственную конфигурацию не сохраняйте. Внешний источник переменных не нужен.

Выполните Цикл и прочитайте весь табличный выход в порядке итераций, сохранив
имена, типы и порядок полей Skip, Page, Limit, IterationId. Выгрузите результат
в for-offline.csv рядом с пакетом. Сохраните пакет по пути {{PACKAGE_PATH}}.
Закройте пакет и завершите сеанс.
