
Предложение после утверждения этапа 1: parameters.syntax задаёт один язык
всего узла: expression или javascript; API mode остаётся expression.
Для нового узла пропуск syntax означает expression, для существующего —
сохранение языка. JavaScript-формула — тело с return; поле и выражение доступны
по имени, при конфликте выражение — через this.Expr.Name. this.Field не используй.
В Loginom явные Field.Name и Expr.Name различают поле и выражение.
intermediate и cached — флаги отдельного выражения; order включает также
промежуточные. Промежуточные не входят в выход 0. Смена языка не переводит
формулы. Предпросмотр не заменяет полный выход. Критерии JavaScript в LAB-990:
«ждёт решения по расхождению»; пять диагностических опытов не установили
причину первоначальных NULL, хотя повтор исходной формулы совпал с oracle.
Var.* здесь не расширяется.
