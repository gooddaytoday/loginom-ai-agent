Создай новый сценарий продаж из узла «Текстовый файл» с именем «Продажи» и подключённого к нему «Калькулятора» с именем «Расчёт». Приложен sales.csv: UTF-8, заголовок в первой строке, разделитель «;», ограничитель — двойная кавычка, десятичный разделитель — точка, маркер пропуска — \N. Используй все исходные поля с исходными именами, метками и порядком: Id и Quantity — непрерывные целые числа, UnitPrice — непрерывное вещественное число, Region и Comment — дискретные строки. Выполни импорт и прочитай все строки.

Во входном сопоставлении Калькулятора отключи автосинхронизацию и переименуй Quantity в Qty с меткой «Количество». Остальные входные поля, их свойства и порядок сохрани.

На языке выражений Loginom создай ровно пять вычислений в следующем порядке. Revenue — вещественная сумма продажи по исходной цене и количеству, метка «Сумма». Adjusted — вещественная сумма Revenue с поправкой на одну десятитысячную, тоже с меткой «Сумма»; используй результат предыдущего вычисления. UnitPrice — удвоенная исходная цена, вещественное число с меткой UnitPrice, с заменой существующего поля. Note — строка с меткой «Комментарий»: для пропущенного Comment текст missing, иначе исходный комментарий с восклицательным знаком в конце; пустая строка отличается от пропуска. Moment — дата/время с меткой «Дата», полночь 29 февраля 2024 года. Другие свойства выражений оставь стандартными.

В выходном сопоставлении отключи автосинхронизацию, исключи Region и задай порядок активных полей: Id, Qty, Revenue, Adjusted, UnitPrice, Note, Moment, Comment. Метки исходных полей сохрани. Выполни Калькулятор и покажи все строки и поля с точными числами, сохранив отличие пропуска от пустой строки и нуля. Сумма продажи должна использовать цену до удвоения.

После всех чтений сохрани пакет в новый путь {{PACKAGE_PATH}}. Пакет должен содержать только два указанных аналитических узла и связь между ними. Сообщи путь пакета, число строк и полей результата и ограничения проверки. Решай задачу самостоятельно через доступные средства Loginom; формулы рассчитывает Loginom.
