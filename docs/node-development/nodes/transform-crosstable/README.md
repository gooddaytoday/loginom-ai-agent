Устойчивый ID: `component.transform.CrossTable`. Slug: `transform-crosstable`. Исторический подплан 15.

## Текущее состояние

Обработчик `transform.cross_table` зарегистрирован в публичном Dock API: ключи строк, одно дискретное
измерение колонок, числовые факты Sum/Min/Max/Avg. Подсчёт строк — сумма подготовленного Quantity=1.
Native fixed сохраняет полный набор категорий при настройке; новые категории идут в «Прочие»,
передача явного подмножества отклоняется по решению владельца.

Исторический серверный Fixed PASS на `1e994aa50` не закрывает независимый Mac Sliding FAIL
на том же SHA. После смены CSV публичный reader сравнивал динамический выход со старой схемой.
Адресная доработка разрешена владельцем; актуальные серверные сценарии 9→7 и C→D (9→9),
повторное чтение с исходной операцией, сохранение/cold/cleanup и независимая child-проверка
описаны в [подплане](plan.md). До их завершения нет принятого узла, интеграции или выпуска.
