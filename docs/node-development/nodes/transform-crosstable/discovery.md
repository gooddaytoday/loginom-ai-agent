# CrossTable: наблюдения стенда

Loginom 7.4.2 Enterprise (`bg.app.Version`, `bg.app.PlatformEdition`; отдельный build номер интерфейс не показывает), стенд из назначения, собственный worker-аккаунт, Linux x64. Наблюдения получены штатными процедурами runtime с `?testable=true` в собственных диагностических пакетах 2026-10-02…2026-10-05. Ключевые выводы подтверждены независимым cold-чтением сохранённых пакетов. Хронология попыток, восстановления сессий и сырые журналы — в карточках LAB-10, LAB-12, LAB-13 и приватных каталогах попыток.

## Интерфейс

- Палитра «Трансформация / Кросс-таблица», иконка `bg-vendor-icon-crosstab`. Мастер `WizrdMCF;CrossTabWizard`, заголовок ровно «Кросс-таблица». Один табличный вход и выход.
- Списки `grdDataFields` и `grdUsedFields`; роли — `frmMoveButtons;btnMove0/1/2` («Колонки», «Строки», «Факты»), native `Disposition` 1/2/3. Up/Down меняют `Order` внутри роли; Delete на выбранной строке снимает назначение. Удалённая запись получает `Disposition=0`, `Order=-1` и сохраняет прежний `GroupFunctions`.
- Одна `data-tid` ячейки может встречаться и в summary row: выбирать строку, привязанную к record.
- Для continuous поля кнопка «Колонки» недоступна; «Строки» и «Факты» доступны.
- Режим переключает общий `pedSlidingUniqueValues;ValueControl` через его DisplayEl. Радиокнопки `ColumnEditDialog;rbSlidingUniqueValues/rbGroupValues` только отражают режим.
- `ColumnEditDialog`: `cbNullGroup`, `cbOtherGroup` (в fixed доступны, по умолчанию false; в sliding недоступны, но хранят прежние значения — смена режима их не очищает), `fldSlidingUniqueValuesMinCount` (в sliding, по умолчанию 0), `btnApply`. Диалог — модальное окно вне корня мастера.
- `FactorEditDialog`: чекбоксы функций; выбор подтверждать по native значению, не по `input.checked`. Мастер упорядочивает выбранные факты по порядку входных полей; нужный порядок задавать Up/Down и проверять.
- Общие настройки: разделитель меток — ровно `.`, `|`, `->`, «Пробел» (значение — один пробел), по умолчанию `|`; «Уникальные значения как имена полей» выключено; «Ограничение количества значений» 0, недоступно в fixed.
- После параметров идут соответствие столбцов («Настройка соответствия между столбцами») и общие свойства узла. До первого Execute выходной маппинг пуст. `btnExecute` в DOM не означает видимости на текущей странице. Причину отказа читать из видимой кнопки ошибки.
- Имя узла задаётся GUID-привязанным переименованием (`target.label`); подтверждается readback.

## Функции и типы

Порядок битов маски: sum, count, min, max, avg, stddev, sum_squares, unique_count, null_count, first, last. «Единственного» в мастере 7.4.2 нет.

| Тип факта | Маска | Функции | По умолчанию |
|---|---:|---|---|
| integer, real | 2047 | все 11 | Сумма |
| string, Boolean | 1934 | count, min, max, unique, null, first, last | Количество |
| DateTime | 1982 | те же и avg, stddev | Количество |
| Variant | 1934 | как у string | — |

Типы результата: сумма целого — real; Count, UniqueCount, NullCount — integer; Min, Max, First, Last сохраняют тип факта (у Variant — native subtype); Avg — real для чисел, DateTime для дат; StdDev — real (для дат — в днях).

- StdDev — делитель n−1. На `2, 4, 4, 4, 5, 5, 7, 9` получено `2.138089935299395`. Native порядок вычисления: `sqrt((Σx²/n − mean²)·n/(n−1))` в binary64; он существен для больших OADate.
- First и Last учитывают NULL и порядок исходных записей.
- Variant Min включает NULL как нижнее значение; скалярный Min пропуски игнорирует.
- Целочисленный парсер импорта не принимает `2.0`: такие значения становятся NULL.
- Изменение типа поля в существующем импорте не меняет его прежний выходной маппинг; для другого типа нужен отдельный импорт.

## Семантика режимов

Вход: Region, Category — строки; Amount, Quantity — real; NULL-маркер `?`.

| Случай | Наблюдение |
|---|---|
| Fixed, оба флага | Region, `<...>` (NULL), исходные категории, `<Прочее>` |
| Fixed, смена источника без перенастройки | Исчезнувшая категория остаётся пустой колонкой; новая попадает в `<Прочее>` |
| Повторная настройка fixed | Категории пересобираются по текущему входу — это не повторное чтение |
| Sliding, смена источника без перенастройки | Состав колонок следует данным: добавление, удаление, замена; исчезнувшая категория, включая NULL, удаляется |
| Sliding, пустой вход | 0 строк, только ключи строк |
| NULL, пустая строка, пробел, литерал `null` | Отдельные категории |
| Пустое пересечение, all-null | Пустые ячейки, не 0 |
| Минимум 3, одна категория | Резерв: 3 группы, лишние с метками `2|…`, `3|…` и пустыми ячейками |
| Ограничение 1 | Верхняя граница групп, включая резерв; остальные категории отбрасываются без ошибки |
| Два измерения колонок | Декартово произведение категорий, включая ненаблюдавшиеся сочетания |
| Без измерений колонок | Имя `Amount_Sum`, метка `Amount|Сумма` |

## Имена, метки и порядок полей

- Имена `C_n_<факт>_<Функция>`, метки `<категория>|<факт>|<функция по-русски>`. Позиция `C_n` не является идентичностью категории: в sliding номера переиспользуются.
- Один факт с одной функцией и одним измерением: имя `C_1`, метка `A`. Два измерения: метка `A|<...>|Amount|Сумма`, префикс категорий плоский.
- Порядок: внутри категории — факты и функции (Sum, Min, Max, Avg); при двух фактах — сначала все поля первого факта, затем второго.
- Пустая категория: метка без ведущего разделителя (`Amount|Сумма` или `Amount.Сумма`); пробел — с ним (` |Amount|…`).
- «Уникальные значения как имена»: NULL — `NullGroup_Amount_Sum`, пустая — `Amount_Sum`, пробел — `__Amount_Sum`. Коллизии транслитерации получают суффикс: `A_1` → `A_1_Amount_Sum`, `A-1` → `A_1_Amount_Sum_1`, `Privet` и `Привет` различаются суффиксом `_1`. Метки сохраняют исходную категорию.
- Смена разделителя меняет только метки.
- Новые поля в существующем выходном маппинге добавляются в конец; порядок ролей и материализованных полей не совпадает, фактическую схему снимать после Execute.

## W2: размер вложений

Native запись `bg.filedialog.FileStore`, привязанная к текущей grid: `FileName`, `FilePath` (полный путь, совпадает с id), `Type=0`, `Size` — точное целое число байт. Видимая ячейка: `900`, `1,023`, `1,536`, `1,702`, `1,937`, `1,048,576` — без единиц и округления. Скачивание `wide.csv` (1702 байта) совпало по SHA256 с fixture.

## Переменные

- Без привязки `VariableControl` имеет `value=null` и скрыт; статический ValueControl виден.
- Локальные переменные ограничения (integer), имён по категориям (Boolean) и разделителя (string) создаются и привязываются через собственный picker; смена значений тех же ID с повторным выполнением меняет схему. После открытия сохранённого пакета без кэша определений привязки читаются только после открытия и отмены редактора определений.
- Скрытый управляющий порт открывается обычным кликом по нативной подписи (снимает toolbar), затем один right-click по проверенной точке тела.

## Выход узла

- У всех источников собственного выхода `Required=true`; команда исключения скрыта. Удаление строки сопоставления не применяется: Done отвечает «Обязательному входному столбцу … не сопоставлен выходной».
- Исключение поля работает в отдельном downstream «Параметры полей» и сохраняется после нового открытия.
- Переименование и порядок собственного выхода применяются при выключенной автосинхронизации.
- Повторное включение сохранённой автосинхронизации через основной мастер останавливается на Native Next. Через отдельный собственный выход включение проходит, состав прежних полей сохраняется, после снятия ограничения выход расширяется.
- Cancel неизменённого редактора выходного порта деактивирует порт и заменяет тело узла; чтение выполнять через Preview после свежего Execute.

## Перестановка входа

После обратной перестановки полей выхода отдельного импорта и повторного применения ролей по именам native input mapping содержит полный переставленный инвентарь источника и прежний порядок целевых полей, связи один-к-одному. Смысл колонок и значения сохраняются.

## Особенности чтения

- Table сразу после открытия может вернуть старую схему и 0 строк при `isLoading=false`; позднее чтение того же grid даёт новые данные.
- ASCII-пробел и пустая строка отображаются в DOM как NBSP; значение брать из кэша записи. Литерал `null` остаётся строкой, `?` — NULL.
- `FColumnInfosStore` выхода не содержит `DataKind`; вид данных виден только в полном редакторе выходного порта.
- Native-чтение ограничено 50 строками × 8 колонками и 1 MiB, протокол 321. Шире — точный formatted reader с проверкой точности чисел.
- Для чтения Variant предок должен быть исполнен в текущей группе процессов: история хранит ограниченное число групп, и ранний импорт из неё выпадает.
- При заполненной видимой области автоматическое размещение нового узла отказывает; выручает свободный ряд ниже и штатное уменьшение масштаба.
- Поле ниже видимой области списка мастера выбирается прокруткой единственного view.
- Быстрые fill/Tab при смене источника импорта иногда оставляли прежний путь; между ними нужно наблюдение.
