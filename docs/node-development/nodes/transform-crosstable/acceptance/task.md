# Задание: Кросс-таблица

Импортируй `base.csv` с полями `Region`, `Category`, `Amount`, `Quantity`; символ `?` означает NULL. `Quantity` уже содержит единицу для каждой исходной строки.

Построй `transform.cross_table`: строки — `Region`, колонка — `Category`, режим — fixed с нативным полным набором категорий источника, включёнными группами «Пропущенные» и «Прочие». Для `Amount` включи сумму, минимум, максимум и среднее; для `Quantity` — сумму. Выполни узел.

Затем измени источник того же импорта на `changed.csv` с той же схемой, снова выполни существующий CrossTable и прочитай итоговую таблицу. Проверь, что новая категория D попала в «Прочие», исчезнувшая C осталась колонкой, и функции сохранились. Сохрани пакет по пути:

`{{PACKAGE_PATH}}`

Не перезаписывай существующий файл и не изменяй чужие пакеты.
