## Предлагаемое разбиение на этапы

Разбиение — гипотеза до этапа 0. Каждый этап должен приниматься самостоятельно; общие изменения, нужные этапу, входят в его же карточку.

- `transform-ungroupdata:s1` — Заданные и вычисляемые доли. Требования: `transform-ungroupdata:r01`, `transform-ungroupdata:r02`.
- `transform-ungroupdata:s2` — Сезонность и качество. Требования: `transform-ungroupdata:r03`, `transform-ungroupdata:r04`. После: `transform-ungroupdata:s1`.

## Заметки черновика

Нового handler нет. Переиспользовать наблюдение двух таблиц Join; роли групп/разгруппируемого/наименования/долей сохранять независимо. Сезонный режим имеет дополнительный выход и schema, поэтому не встраивать его молча в scalar s1.

Группа G, total=100, позиции a/b с долями 0.25/0.75 →25/75; расчёт долей по весам 1/3 даёт то же. Для total=10 и трёх равных весов после округления проверить остаток каждого метода балансировки. Сезонный fixture — независимый ряд нескольких полных периодов с известным профилем.
