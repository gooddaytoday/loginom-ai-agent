Для «Случайные все» используй метод «Случайный»; для «Страты все» — «Стратифицированный» по Class; для «Смещение все» — «Отбор со смещением» по Class, факторы A=1 и B=1.
Выполни узлы и выгрузи полные таблицы в partition-1.csv, partition-2.csv, partition-3.csv, partition-4.csv, partition-5.csv, partition-6.csv, partition-7.csv, partition-8.csv, partition-9.csv (UTF-8, запятая, заголовки имён).
