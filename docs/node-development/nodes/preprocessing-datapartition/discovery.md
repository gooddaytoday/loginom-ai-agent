# Разбиение на множества: checkpoint LAB-533

Общее исследование пары, наблюдённые data-tid, ограничения, предложение
контракта и измерение схемы: [discovery пары](../preprocessing-sampling/discovery.md).

Подтверждены палитра, Loginom 7.4.2, PartitionComponentWizard, наличие
«Последовательного» метода с перестановкой трёх групп, один табличный вход
и три табличных выхода. Численная семантика и схемы этих выходов не проверены.

Пакет предложений находится в fixtures/ и acceptance/. Этап 0 пары остановлен
из-за неподтверждённого детерминированного контракта смещения у Сэмплинга.
`ready_for_development` не заявляется; expected — предложение владельцу.
