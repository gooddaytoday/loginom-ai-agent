## 2. Предложение этапа 1

Явные train_count/test_count в строках, сумма не больше входа, порядок
выделения test → train → unused, приоритет test в начале. Другие порядки —
только явно заданные и проверенные в UI; proposal enum ещё не утверждён.
Предлагаемые выходы: 0 общий с Boolean-признаком test, 1 train, 2 test.
Смысл и фактические схемы портов подлежат переподтверждению до регистрации.
Нельзя выдавать графическое наличие трёх портов за наблюдённые значения.

Создание и обновление того же узла, неизменённые незапрошенные настройки,
readback явных размеров/порядка/приоритета и идентичность источника/портов.
Полные результаты всех трёх портов после одного свежего выполнения,
сохранение и cold reopen. Искусственное обучение не вводить.
NODE_TYPES semantics и descriptions — предложения из общего discovery и
parameter-schema.proposal.json; строковые enum, компактный readback.

Собственный обработчик по образцу нескольких выходов Кластеризации и
одношагового редактора «Дата и время». Общие изменения — только разрешённая
аддитивная регистрация, свой раздел skill и сценарий run-check. Старая W3
не требуется автоматически: в текущей базе expected-outputs.mjs уже
адресует несколько портов одного узла и ordered matching. Если обнаружится
новая общая нужда — stop, а не самостоятельное изменение контракта.

## 3. Предложенные fixtures и oracle

rows.csv совпадает с набором Сэмплинга: RowID integer 1..20, Class string A/B,
Value integer RowID*10; поля в исходном порядке. CSV UTF-8, заголовок,
запятая, десятичная точка, NULL `?`; пустая строка отличается от NULL.
Для отдельной расширенной матрицы предложены update.csv, empty.csv, null.csv.

Независимый stdlib oracle.py использует только Python-срезы входа:
test=rows[:5], train=rows[5:15], общий=rows[:15] с признаком test у первых 5.
Ожидания портов 0/1/2: 15/10/5 строк, суммы Value 1200/1050/150,
ordered=true, column_order=exact, tolerance=0. Имя Boolean-признака свободное
(name_any), предлагается расположение после трёх входных полей.
Это предложение владельцу; фактический UI контракт ещё не проверен.
В workspace модели идут только task.md и data/rows.csv, не oracle/expected.
