Предложение LAB-998, этап 0; runtime не изменяется. Шесть task — шесть
будущих циклов: cache, threads, auto, locale, case, variant.
`expected.json` — контейнер предложений, **не stock expected/регистрация**.
Основная и изменённая настройки проверяются на одном узле, последнее
состояние сохраняется и независимо выполняется после нового открытия.

Модель получает только выбранный task и соответствующий CSV из `fixtures/`.
Cache/threads/auto/locale/case используют modes.csv. Variant использует
variant-wide.csv: обычный явный scalar import и существующая Свертка столбцов
дают типизированный источник без нового режима импорта и без JavaScript.
variant.csv служил только ручной диагностике UI, не заменяет этот источник.
Oracle/expected/manifest модели не передаются.

```sh
python3 docs/node-development/nodes/sorting/acceptance/modes/oracle.py
python3 docs/node-development/nodes/sorting/acceptance/modes/oracle.py --check
```

Oracle строит полные строки из CSV и использует явные правила **узкого
алфавита fixture**. Для заявленного русского сравнения а/б/я идут перед
латинской a; при учёте регистра строчные перед прописными, при игнорировании
равенство разрешает RowID. Это декларация предлагаемого контракта, не
системный Python locale и не общий Unicode comparator. В бинарном режиме
игнорирование регистра действует только на ASCII Latin; кириллица остаётся
различной. NULL ниже пустой строки, обе сохраняются отдельными строками.
Идентификатор локали UI этим исследованием не установлен: до приёмки нужно
зафиксировать настройки назначенной пары. Смена локали не может молча
перегенерировать expected по результату Loginom.

Variant: numeric Integer/Real сравниваются численно, NULL раньше непустых,
String после numeric. Вторичные RowID/Names устраняют равенства. Typed matcher
проверяет подтип каждой ячейки существующим bounded native decoder: CSV не
различает числовой подтип и строку. Предложенный источник содержит три NULL,
которые нельзя потерять при Collapse. Общий порядок Boolean/DateTime/других
Variant-подтипов и locale-aware Variant не заявлен.

Стандарт приёмки сохраняется: точный порядок **всех строк**, исходные значения
и кратности, все CSV, схема/порядок полей, `label_any`, Save, новое открытие,
cold Execute без конфигурации, typed read и cleanup. Cache/число потоков
не меняют результат; сохранённый максимум и 0-auto проверяются readback.
Скорость и фактическое количество рабочих потоков не являются критерием.
Новых decoder/матчеров/публичных механизмов проверки не предлагается.
