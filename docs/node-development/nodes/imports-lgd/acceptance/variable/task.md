Импортируй variable-a.lgd через путь из строковой переменной SourceFile. Источник переменной — исполняемый «Калькулятор (переменные)» с именем и меткой SourceFile. Имя файла в мастере импорта должно быть связано с этой переменной, а не задано литералом. Сначала выполни источник переменной, затем импорт. Сохрани все исходные значения и свойства полей, метки и порядок. Выгрузи полную первую таблицу в before.csv.

На том же источнике переменных измени SourceFile на путь второго доставленного файла variable-b.lgd, снова выполни источник, затем тот же LGD-узел. Связь имени файла с SourceFile сохрани. Выгрузи полную новую таблицу в after.csv; не создавай второй LGD-узел. Проверка checksum остаётся включённой.

Сохрани пакет как {{PACKAGE_PATH}}. В нём должны сохраниться источник переменной, связь и выбранный второй файл, чтобы пакет выполнялся после повторного открытия.
