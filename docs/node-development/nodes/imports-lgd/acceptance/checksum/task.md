Импортируй три файла Loginom Data: checksum-none.lgd, checksum-compressed.lgd и checksum-both.lgd. Назови узлы «Нет суммы», «Сжатая сумма» и «Обе суммы» соответственно. Сначала выполни все три импорта с включённой проверкой контрольной суммы.

Затем на том же узле «Обе суммы» явно выключи проверку checksum, снова выполни импорт и сравни полный результат с предыдущим чтением. Для двух остальных узлов оставь проверку включённой. Выключение проверки требуется только для этого корректного файла; при любой ошибке контрольной суммы остановись и сообщи исходную причину.

Сохрани исходные значения, типы и свойства полей, метки, порядок, пропуски и пустые строки. Выгрузи полные итоговые таблицы: «Нет суммы» — none.csv, «Сжатая сумма» — compressed.csv, «Обе суммы» — both.csv. Сохрани пакет как {{PACKAGE_PATH}}.
