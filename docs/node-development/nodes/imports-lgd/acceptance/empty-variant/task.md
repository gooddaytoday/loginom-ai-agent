Импортируй два доставленных Loginom Data файла отдельными нативными узлами. Назови импорт empty.lgd «Пустой», импорт variant.lgd — «Variant». Проверку контрольной суммы оставь включённой. Сохрани исходные имена, метки, типы, виды и порядок полей, порядок строк, NULL и пустые строки.

Для пустого файла подтверди сохранённую схему и отсутствие строк. Для Variant прочитай весь набор с точными типами ячеек. Выгрузи и скачай полные результаты в empty.csv и variant.csv соответственно, включая заголовок пустого набора.

Сохрани пакет как {{PACKAGE_PATH}}, чтобы оба источника и их свойства сохранились после повторного открытия.
