Сценарий `lgd-import-compression` использует три 64-bit LGD, полученные штатным узлом «Экспорт в Loginom Data» через мастер Loginom 7.4.2 на `app.loginom.ai/app/?testable=true`.

До экспорта заданы исходные значения `../../fixtures/properties-values.csv` и свойства `../../fixtures/properties-schema.json`: 5 строк, 4 поля, метка RecordId «Идентификатор», точный порядок, три NULL, пустая строка и локальное время. Независимый CSV-oracle формирует `expected.json`; модели доступны только задание и три бинарных LGD.

Сжатие и разрядность импортированного файла сверяются с информационными полями мастера. Проверка checksum включена во всех случаях. Cold повторно выполняет каждый сохранённый импорт, сверяет весь набор и сохранённые свойства без перенастройки; CSV, Save, закрытие пакета и logout обязательны.

32-bit LGD и DDF исключены решением назначения: на стенде нет 32-битного Loginom и Deductor для штатного создания и проверки файлов. Их поддержка не заявляется; действующие отказы сохранены.
