Импортируй три приложенных файла Loginom Data по отдельности: compression-none.lgd, compression-lzo.lgd и compression-lz4.lgd. Назови узлы «Без сжатия», «LZO» и «LZ4» соответственно.

Сохрани все исходные значения и свойства полей, включая метки, порядок строк и столбцов, пропуски и пустые строки. Проверь информацию о сжатии, разрядности и контрольной сумме в мастере каждого импорта. Проверку контрольной суммы оставь включённой. Выполни все три импорта.

Выгрузи полные таблицы в CSV: без сжатия — none.csv, LZO — lzo.csv, LZ4 — lz4.csv. Сохрани пакет как {{PACKAGE_PATH}}.
