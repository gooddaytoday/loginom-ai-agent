# Экспорт LGD — предложение навыка

Получай parameter_schema через dock_action_describe(node_types:["exports.lgd"]).
Один табличный input 0, режим native. lgd_export: destination — новый .lgd
в собственном каталоге; compression="lz4", checksum="compressed", overwrite="reject".
Все четыре поля обязательны при создании; {} сохраняет существующие настройки.
У экспорта нет табличного выхода: read.ports=[], результат output.file_artifacts.
Execute создаёт файл; Done сохраняет настройки; Close отменяет черновик.
Сохраняй имена, метки, виды, типы, порядок полей/строк и NULL/пустые строки.
Никакого обучения, перезаписи, append, DDF, переменных и других алгоритмов сжатия.
Сохрани пакет отдельным Save. Обратный импорт сам по себе не доказывает
независимую правильность формата файла.
