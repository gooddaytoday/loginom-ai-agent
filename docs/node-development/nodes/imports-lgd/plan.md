## Предлагаемое разбиение на этапы

Разбиение — гипотеза до этапа 0. Каждый этап должен приниматься самостоятельно; общие изменения, нужные этапу, входят в его же карточку.

- `imports-lgd:s1` — Самостоятельный LGD fixture. Требования: `imports-lgd:r01`.
- `imports-lgd:s2` — Форматы, checksum и переменные. Требования: `imports-lgd:r02`, `imports-lgd:r03`, `imports-lgd:r04`. После: `imports-lgd:s1`. Среда: Принятые 32/64-bit LGD и DDF fixtures.

## Заметки черновика

Необязательные управляющие переменные → таблица с метаданными из LGD; поддерживается также исторический DDF.

Внешний проверяющий заранее готовит принятые .lgd/.ddf и manifest значений/схемы на stock Loginom/Deductor, без нового export handler. Набор содержит integer, real, datetime, boolean, строку, NULL, empty; отдельные пустой и повреждённый файлы.

Проверять provenance байтов; corrupt-файлы только копии в выделенном каталоге. Не считать выключенную checksum способом исправления повреждения.
