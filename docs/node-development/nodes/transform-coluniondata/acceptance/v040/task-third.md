Создай пакет {{PACKAGE_PATH}}. Загрузи main.csv, attached.csv и third.csv,
сохрани порядок строк. ID — целые, Amount — вещественное с точкой,
Code — строка. В «Соединение» главная таблица — main, первая присоединённая —
attached, вторая — third. Соединяй по позиции, без ключей и сортировки.

Число строк должно соответствовать максимальному набору; короткие наборы
повторяй целиком. Сохрани все поля. Задай окончательный порядок и технические
имена: RowID, MainCode, Amount, AttachedID, AttachedCode, ThirdID, ThirdCode.
Три Code должны происходить из своих таблиц. Метки можно сохранить исходными.

Прочитай все строки, скачай third-repeat.csv с техническими заголовками,
сохрани пакет. После повторного открытия выполни существующий узел без
изменения его настроек и проверь тот же результат.
