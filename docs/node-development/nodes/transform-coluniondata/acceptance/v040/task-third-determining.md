Создай пакет {{PACKAGE_PATH}} из main.csv, attached.csv и third.csv.
ID — целые, Amount — вещественное с точкой, Code — строка.
Сохрани порядок строк. В одном узле «Соединение» подключи main как главную
таблицу, attached как первую присоединённую, third как вторую. Строки соединяй
по позиции, без ключей и сортировки.
Число строк определяй второй присоединённой таблицей, отсутствующие строки
заполняй пропусками. Сохрани все поля в порядке RowID, MainCode, Amount,
AttachedID, AttachedCode, ThirdID, ThirdCode. Метки можно сохранить исходными.
Прочитай результат, скачай third-determining.csv с техническими заголовками,
сохрани пакет. После повторного открытия выполни существующий узел без
изменения его настроек и проверь тот же результат.
