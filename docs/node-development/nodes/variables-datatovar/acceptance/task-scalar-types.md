Открой подготовленную для задания копию пакета {{PACKAGE_PATH}}.
В нём один JavaScript-источник с готовой таблицей; исходный узел и данные сохрани.

Добавь после него «Таблица в переменные». Обработай поля S, B, D в этом
порядке. Для каждого вычисли количество строк, минимум, максимум, моду,
число различных непустых значений, число пропусков, первое, последнее
и единственное различное значение. Для S также получи список различных
непустых значений в порядке появления: разделитель запятая, без обрамления.
Пустую строку S сохрани как значение, отдельно от пропуска.

Выполни узел и покажи весь исходный выход переменных: имена, метки, типы,
точные значения; для дат сохрани миллисекунды без часового пояса.
Сохрани пакет по новому пути и сообщи его. Дополнительные вычисляющие узлы
и экспорт таблицы не требуются.
