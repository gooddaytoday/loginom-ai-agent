# variables.from_table / aggregate

Получает один набор переменных из текущей таблицы. Это агрегирование всей
таблицы. Этап 1: sum, count, min, max, avg числовых полей; другие функции и
типы входных полей не поддерживаются. Указывай техническое имя поля и
полный набор функций. Count включает NULL-строки; остальные функции
пропускают NULL. Сумма и среднее вещественные; количество целое, минимум
и максимум сохраняют числовой тип входного поля.

Внутри поля результат следует native-порядку sum,count,min,max,avg.
Несколько функций дают отдельные переменные; для X наблюдены X_Sum,
X_Count, X_Min, X_Max, X_Avg. Имена/метки читай из результата, не формируй
их произвольно. Выполняй узел после смены данных; обучение не требуется.

Читай выход переменных 0 с типами и точными значениями через W1. Показ
значений через промежуточную таблицу не доказывает исходный порт переменных.
При замене источника сохраняй выбранные агрегаты; заново выполни, проверь
полный результат и сохрани пакет. Пустой вход и все NULL не эквивалентны
нулевому значению; следуй проверенному контракту узла.
