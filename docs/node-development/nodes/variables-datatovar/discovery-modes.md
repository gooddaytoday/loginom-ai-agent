`8943d291b046698d67828f19dcca88aab790cf2c`.
Только testable-стенд и второй аккаунт назначенной пары. Это подготовка
исследования, не независимая приёмка и не PASS новых режимов.

Подготовлен [маленький CSV](fixtures/modes.csv) с четырьмя строками:
N integer, S string, B boolean, D datetime с миллисекундами, K integer.
Имена и метки совпадают, вид данных «Дискретный», все поля используются.
CSV штатно доставлен в собственный каталог; существующий imports.text/delimited
успешно настроен, выполнен и прочитан. Ошибка отсутствующего каталога журнала
до доставки исправлена локально, до любых UI эффектов; runtime не менялся.

Создан собственный узел «Таблица в переменные» и подтверждена его связь с
TableSource, таблица 0 → таблица 0. Наблюдённые TID:
`MF;TF-1;Graph;Таблица_в_переменные;Input_Data-0`,
`Output_Var-0`, `Setting` (`table-discovery.jsonl:5,7`, вложение отчёта).

До открытия мастера произошёл разрыв связи. Выполнено второе из двух
разрешённых переподключений; затем новые исследования остановлены.
Диалог: `msgbox;cnt;cnt;cmp` — «Обнаружен разрыв связи. Восстановить сессию?»,
`msgbox;tlb;yes` — «Восстановить» (`table-discovery.jsonl:6–7`).

FactorEditDialog и названия функций выше известны из прежнего
[discovery](discovery.md); наличие этих режимов в текущем UI не заявляется
без нового снимка. Ни один из них не помечается «нет в 7.4.2».
Табличного выхода этот узел не предлагает: при продолжении сравнивать
полный исходный выход переменных 0, включая реальные native имена и типы.

Новые task/oracle/expected пока не готовы: без UI неизвестны доступность
функций по типам, типы результата, имена и порядок. Карточка расширения,
reference, размеры после режимов и циклы реализации не оценены.
Базовая реальная карточка aggregate — 3475 Б. Старый числовой срез из пяти
функций не менялся. Следующий шаг — исследовать функции N и константного K,
затем S/B/D и отдельно Variant; до runtime-кода предложить критерии владельцу.
