## Агрегаты и типы — наблюдено

Для discovery использован собственный JavaScript-источник с объявленными
X Integer и Category String и явными малыми строками. Это вспомогательный
источник исследования; в бизнес-задании предлагается исходный CSV,
не замена проверяемого узла JavaScript-кодом.

Выбраны sum,count,min,max,avg для X. После Execute открыт **исходный
Output_Var-0**. Native VariablesForm store содержит Name, DisplayName,
DataType, ValueVariant; форматированный DOM не является точным reader.

| Имя | Метка | Тип | X=[2,4,6] | X=[2,NULL,4] | Пустая таблица |
|---|---|---|---|---|---|
| X_Sum | X\|Сумма | real | 12 | 6 | NULL |
| X_Count | X\|Количество | integer | 3 | 3 | 0 |
| X_Min | X\|Минимум | integer | 2 | 2 | NULL |
| X_Max | X\|Максимум | integer | 6 | 4 | NULL |
| X_Avg | X\|Среднее | real | 4 | 3 | NULL |

Порядок совпал со строками таблицы выше. Типы native 3 real, 4 integer;
сумма целого входа всё равно real. NULL исключается из числового расчёта,
но count включает такую строку. На пустом входе схема из пяти переменных
сохраняется; NULL не превращается в ноль. Данные источника менялись и тот
же узел повторно выполнялся без перенастройки агрегатов.

Replacement `[8,12]` в том же узле без перенастройки агрегатов дал
`20,2,8,12,10`, типы и порядок сохранились.
Все числа, включая необследованные варианты, остаются предложением для
утверждения, а не доказательством работы будущего handler.

## Предложение и непроверенные случаи

Основной scope: пять агрегатов числовых полей; [общий контракт предложения](../variables-calculator/contract.md).
Комплект: `fixtures/{values,replace,null,empty}.csv`, `acceptance/task.md`,
Python oracle и expected с ordered/typed-port/tolerance. Нет собственного
нового verifier; чтение и cold-проверка переменных требуют принятого W1.
Oracle и expected модели не передаются.

`not_checked`: единственный выбранный агрегат и его итоговое имя;
несколько полей и порядок между ними; обратный порядок выбора функций;
все значения NULL; агрегация real-источника; нечисловые функции/типы;
потерянный источник; холодное открытие и модельные прогоны.
Вход первой строки как отдельный режим не предлагается: наблюдён мастер
агрегирования. Для режима first потребовалась бы отдельная область работ.
