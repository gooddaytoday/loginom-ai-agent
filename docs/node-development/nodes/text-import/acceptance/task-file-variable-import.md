В новом пакете `{{PACKAGE_PATH}}` настрой загрузку ежедневных продаж из CSV.
Файлы `sales-2026-11-05.csv` и `sales-2026-11-06.csv` приложены; размести их
в разрешённой папке `{{INPUTS_DIR}}`, сохранив эти имена.

Полный путь к загружаемому файлу задавай строковой переменной InputFile,
подключённой к импорту. Сначала загрузи продажи за 5 ноября 2026 года, затем
измени только значение InputFile и повтори тот же импорт за 6 ноября.
Узел импорта и его настройки формата и полей должны остаться теми же.

Формат — UTF-8, запятая, заголовки в первой строке, без пропуска строк.
Id и Amount — целые, Item — строка; пустое Item сохраняй пустой строкой,
для пропуска используй маркер NULL. Сохрани порядок полей Id, Item, Amount
и порядок строк файла. Покажи результат каждого запуска и выгрузи его
в отдельный CSV в `{{EXPORTS_DIR}}`. Сохрани пакет для повторного открытия.
