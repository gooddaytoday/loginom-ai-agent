Загрузи все месячные выгрузки `sales_*.csv` из приложенных файлов одной таблицей
через один импорт текстовых файлов. Другие выгрузки не включай. Добавь столбец
`FileName`, чтобы было видно, из какого файла получена каждая строка.

Файлы в UTF-8, разделитель — точка с запятой, десятичный разделитель — точка,
ограничитель текста — двойная кавычка, `\N` означает пропуск. Первая строка
каждого файла содержит заголовок. Сохрани повторяющиеся записи и пустые строки
в текстовых ячейках. `SaleID` — целое число, `Month` и `Note` — строки,
`Amount` — вещественное число. Порядок столбцов:
`SaleID, Month, Amount, Note, FileName`.

Используй маску имени файла, чтобы при следующем выполнении можно было подхватить
новую месячную выгрузку без изменения настройки импорта. Обрабатывай файлы
последовательно. Покажи объединённые данные, выгрузи их в CSV и сохрани пакет
в `{{PACKAGE_PATH}}`.
