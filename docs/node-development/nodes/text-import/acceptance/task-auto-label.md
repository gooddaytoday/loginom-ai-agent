Загрузите typed.csv в один импорт текста и включите автоматическую метку узла.
Замените источник этого же узла на typed-update.csv, обновите типы всех полей
и убедитесь, что метка следует имени файла. Покажите и выгрузите таблицу в `auto-label.csv`.
Затем задайте узлу пользовательскую метку «Ежедневные продажи»; при повторном
выборе первого, а затем второго источника эта метка должна сохраниться.
Ещё раз выгрузите результат второго файла в `custom-label.csv` и сохраните пакет в {{PACKAGE_PATH}}.
