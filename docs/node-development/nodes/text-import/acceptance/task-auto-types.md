Загрузите typed.csv в один узел импорта текста. Первая строка — заголовки,
разделитель — точка с запятой, десятичный разделитель — точка.
Определите типы всех полей по данным: идентификатор, сумма, признак активности,
дата события и примечание. Выполните повторный анализ типов по двум строкам,
сохраните названия и все исходные значения, включая секунды времени.
Покажите результат и выгрузите полную таблицу в CSV без округления сумм,
с датой yyyy-mm-dd HH:mm:ss. Сохраните пакет в {{PACKAGE_PATH}}.
