В documents.csv (UTF-8, разделитель запятая, заголовки в первой строке, двойные кавычки; RowID — целое, Document — строка) каждая строка Document содержит один JSON-объект. Строка RowID 1 — документ партии: подготовь из неё дерево, выбери batch, items/code, items/qty и индекс массива items. Отдельно подготовь одно дерево из строк RowID 2 и 3 — группы A с позициями x, z и B с позицией y; каждая строка — свой корень. Выбери group, items/code и глобальный индекс items: он должен продолжаться между группами. batch и group повторяй в каждой строке. Покажи полные таблицы, реальные имена и типы индексных колонок.
