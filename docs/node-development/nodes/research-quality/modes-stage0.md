## Подготовленные различители

`fixtures/types.csv` и `acceptance/task-types.md`: boolean и datetime,
дискретные integer/real, контрольные continuous RowID и discrete Text,
typed NULL. Нужно наблюдать тип/вид каждого поля до Quality и все пять
выходов, включая native тип Moda. Входной variant и continuous string этим
fixture не покрыты: для них нужен наблюдённый штатный источник и своё задание.

`acceptance/task-hidden-settings.md` / `task-apply.md` используют
`../preprocessing-elimoutlier/fixtures/policies.csv` и `policies-apply.csv`
(путь относительно каталога этого узла). Один набор — обучение, другой —
контроль применения сохранённой модели. Эталонов этих режимов пока **нет**:
не наблюдены схема, способы выбора и численная семантика. Старый oracle
`acceptance/oracle.py` остаётся эталоном только прежнего profile и не
расширяется на неизвестные типы молча. Нового verifier не вводится.

Старый `discovery.md` отмечает отсутствие алгоритмического мастера и
сериализованные MaxNullsPercent/ActionNull/ActionOut/ActionExtr. Это исторические
наблюдения; на текущем этапе недоступность controls не перепроверена.
Нельзя менять XML пакета или вызывать engine RPC, чтобы обойти отсутствующий
UI. Если controls или apply действительно отсутствуют в UI — это отдельный
stop по назначению, а не разрешение реализовать скрытую настройку.

## Продолжение и оценка

Перед утверждением критериев: прочитать DOM страниц/входных свойств, выяснить
наличие controls, выполнить каждый тип по отдельности; установить влияние
скрытых политик на все порты; отличить обучение от применения прежней модели;
затем подготовить независимую формулу и полный typed expected.

Собственные пути: `client/lib/quality-parameters.mjs` ограничивает источник
integer/real/string и проверяет виды; `quality-procedure.mjs` сохраняет native
default mapping; `quality-node.mjs`, `quality-readback.mjs` фиксируют profile;
`quality-output.mjs` проверяет пять схем, `quality-moda.mjs` адресно декодирует
только variant Moda порта 4. Расширение входных типов не разрешает расширять
этот decoder или общий численный бюджет без наблюдения и решения владельца.

Условная оценка: 2–3 цикла на типы, ещё 2–3 на настройки/apply, **если UI
их предоставляет** и достаточно аддитивных собственных изменений. Сейчас
потребность в общем изменении неизвестна; реализуемость скрытых настроек
не установлена. Числа не являются обещанием полного объёма.

`model-contract/modes-type-card.proposal.json` сохраняет parameters={} и

не полная схема будущих режимов. Проекты файла навыка и строки маршрута —
рядом. Только после нового исследования можно оценить полный контракт.
