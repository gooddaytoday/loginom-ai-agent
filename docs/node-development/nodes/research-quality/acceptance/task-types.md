Импортируй types.csv: RowID — целый непрерывный, Flag — логический дискретный, Stamp — дата/время непрерывный (yyyy-mm-dd), Code — целый дискретный, Measure — вещественный дискретный, Text — строковый дискретный. Первая строка — заголовки, разделитель — запятая, ? — неизвестное значение, true/false — логические значения. Исследуй таблицу штатным узлом «Качество данных», покажи все пять полных результатов, выгрузи каждый в отдельный CSV и скачай файлы. Сохрани пакет как {{PACKAGE_PATH}}.
