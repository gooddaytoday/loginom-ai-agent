# Качество данных — research.quality

Предложение этапа 0, не объявление доступного обработчика. Режим: `profile`;
`parameters: {}`. Бери путь справочника из ссылки в SKILL.md буквально.

Используй штатный узел «Исследование → Качество данных», когда пользователь
просит исследовать качество таблицы. Этот режим покрывает непрерывные integer/real
и дискретные string. Иные типы и скрытые настройки пока не поддерживаются.

Подключи вход 0. У узла нет отдельного мастера алгоритма: доступны пять страниц
выходных полей и описание узла. Не передавай выдуманные пороги, методы исправления
или числовые enum. Часть страниц требует разрешённой адресной правки reader.
Отказ мастера читай из кнопки «Подробнее».

Читай все пять табличных портов одного выполнения:

| Индекс | Native name | Подпись |
|---:|---|---|
| 0 | OutData | Выходной набор |
| 1 | OutDataOut | Выбросы |
| 2 | OutDataExtr | Экстремальные значения |
| 3 | OutDataNull | Пропуски |
| 4 | SummaryTable | Итоговая таблица |

В исследованной штатной конфигурации 0 и 3 сохраняют весь вход, а 1/2 пусты,
в том числе при положительных счётчиках выбросов и экстремумов. Не трактуй
названия портов как условия отбора строк и не обещай исправление пропусков.

Итоговая таблица содержит по строке на входное поле, в порядке полей:
`N` — порядковый номер от 1, `DisplayName` — метка, `DataType`/`DataKind` —
нативные подписи типа/вида; `Null`, `Out`, `Extr` — счётчики по полю;
`Avg` — среднее без NULL; `Median` — верхнее среднее наблюдение, а не
полусумма двух средних; `Moda` — мода. Пустая строка отличается от NULL.

Для непрерывного числового поля Moda — центр самого частого интервала
гистограммы, а не обязательно одно из исходных чисел. Для дискретных строк
это самое частое значение; в проверенных связках A/B при равенстве выбрана B.
Числовая и строковая мода лежат в общей колонке variant. Обычный форматированный
текст Table не доказывает точные байты и native subtype variant.

После смены источника выполни тот же узел и проверь свежие пять результатов.
Команда «Обучить узел» наблюдалась; отдельный режим применения сохранённой модели
не подтверждён и не поддерживается этим предложением. Сохрани пакет после чтений.
При неизвестном эффекте не повторяй запуск; сначала прочитай состояние операции.

Компактный readback должен отдавать режим, имена/типы/виды входных полей,
привязки всех выходов и проверенные отображения столбцов. Невидимые в мастере
MaxNullsPercent и действия над пропусками/выбросами отмечай как недоступные
для UI-readback; не выдавай известные заводские умолчания за прочитанные настройки.
