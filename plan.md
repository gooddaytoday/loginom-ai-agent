# План реализации сборки Loginom AI Agent для macOS

Дата: 2026-09-19.

## Цель и принятые решения

Подготовить тестовые сборки Desktop и CLI для macOS 14+ Apple Silicon, воспроизводимые локально и в GitHub Actions.

Результаты:

- Desktop: DMG и ZIP.
- CLI: TAR.GZ и инструкция установки.
- Манифесты, контрольные суммы, архив исходников и отчёт проверок.

Использовать канал `dev`, backend v1 и независимые профили Desktop/CLI. Подпись собственного кода — ad-hoc, без Developer ID и notarization. Полные сценарии проверять на текущем Mac с macOS 27; сборку и автономный запуск — дополнительно в CI на macOS 14.

Публичная публикация, автообновление и полная GUI-приёмка на чистой macOS 14 в этот этап не входят.

## Правила ведения плана

- Агент отмечает `[x]` только после выполнения работы и соответствующей проверки.
- Этап считается завершённым после выполнения всех его обязательных пунктов.
- После каждого этапа обновлять раздел «Точка продолжения»: результат, доказательства, ограничения и следующий шаг.
- Заблокированные пункты оставлять незавершёнными с указанием причины.
- Различать проверки исходников, собранного артефакта и установленного приложения.
- Не сохранять секреты и сырые диагностические журналы в Git.

## Критерий завершения

Все семь этапов завершены; локальная и CI-сборка успешны; установленные артефакты прошли предусмотренные сценарии; результаты сохранены в документации.

Ad-hoc сборка не подтверждает доверие Gatekeeper и бесшовное обновление Keychain. Developer ID, notarization, публичный релиз и автообновление требуют отдельной работы.
