# Node14: версия повторной оценки run8 и независимое открытие

**RC ветки подтверждён: версия повторной оценки V2 — 206/206 PASS,
12/12 результатов после независимого нового открытия.** Исторический frozen
FAIL run8 сохранён отдельно. Новый модельный прогон не запускался.

## Основание и границы

Назначение `node14:full8-versioned-audit-and-fresh:21b05b3e` разрешило отдельно
версионированную переоценку неизменного Hermes run8 и новое независимое открытие.
Новый Hermes9 для исправления аудитора не запускался. Runtime, продуктовый API,
цель, fixtures, Decimal oracle и прежний полный reader не менялись.

Исходный run `20260914-124616-9e88066c` выполнил 27 успешных операций,
один доказанный NOT_APPLIED placement и native save. Его исторический
`final-audit-frozen.json` остался FAIL. 45 исходных квитанций сверяются по
неизменному Git-якорю `39380d11` до и после каждой повторной оценки.

## Явная версия проверки

Из kit8 восстановлены и повторно сверены все 256 исходных файлов harness.
Все 156 runtime-входов совпадают с исходным запросом. Разрешены ровно три
изменения проверяющего кода из `21b05b3e476d9b600b2ad5f77f71e73a90c75e9a`:
`artifact_delivery_evidence.py`, `existing_import_evidence.py`,
`missing_values_acceptance.py`. Для каждого сохранены старый и новый SHA,
точный diff и его SHA. Остальные исходные harness-входы должны совпадать.

Оригинальный аудитор выполняется целиком и сохраняет отказ `frozen:false`.
Новый отчёт отдельно использует `versioned_source_provenance`; старый guard,
его результат и исходные доказательства не переписаны. V1 сохранила preflight
144/145 PASS с единственным отсутствовавшим независимым открытием и послужила
входом неизменному reader. Финальная V2 явно перечисляет прежние обязательные
условия с разрешённой заменой frozen на provenance и требует ровно 12 наборов
каждого из пяти видов доказательств сохранения. V1 и её отчёт сохранены;
финальный код V2 имеет отдельный SHA. Новых запусков reader из-за этого нет.

Проверки версии: 3 теста PASS; отдельно проверены незаявленные изменения,
подмена SHA, неполный состав входов, изменение исходных байтов при той же длине,
пропуск/отказ каждого обязательного условия и лишний результат. Ранее проверены
530 Python-тестов и 8 отклонённых подмен настоящего existing-import журнала;
эти исторические проверки не объявляются повторно запущенными.

## Ограничения

Байты источников после открытия повторно не скачиваются:
`source_bytes_reverified_after_reopen:false`. Область доказательства — ранее
проверенная загрузка точных байтов, сохранённые source path/format/schema,
повторное выполнение зависимости и полные выходные данные после нового открытия.
Это не утверждение о новом побайтовом скачивании исходных файлов.

Результат относится к этой ветке и candidate test4.2, не к main или установленному
клиенту. Merge, push, deploy, переустановка общего плагина и новые модели не выполнялись.
Исторический комплект9 остался неиспользованным. Координатор читает канонический
отчёт самостоятельно; заблокированная межзадачная передача не повторялась.
