## Дата/время в точном чтении

Выполнение `MatrixSource` подтверждено общим execution driver, но завершающий
диагностический скрипт остановился при восстановлении исходного формата «Таблицы».

переключение строки после ввода пустой маски подставляет `DD/MM/YYYY`.
Прямая кнопка Apply после пустой маски сохраняет исходный пустой формат:
это подтверждено новым открытием диалога и чтением нативной записи.

поля, затем открывает диалог, проверяет исходные значения и закрывает проверку
через Cancel. `matrix-restore-defaults-3.json` подтвердил все пять исходных дат.
Добавлен regression test, запрещающий переключение поля после ввода пустой маски.
`component-tests-10.log`: 122 PASS; предыдущий полный workspace-ui/procedure/import
набор `component-tests-9.log`: 366 PASS. Эти проверки не заменяют полную операцию.

Сохранение общего runtime корректно отказало с `OPERATION_STILL_PENDING`:

диагностики обновлялся workspace observer. Подтверждённые примеры:

- string `3,545` → real 3.545, но string `3,545` → integer Null;
- real `2,5` → integer 2, `-2,5` → -2, `3,545` → 4;

- string → string сохраняет пустую строку отдельно от Null;
- date/time ↔ числовые типы использует дату 1899-12-30 как ноль;
  real `-42,2` → 1899-11-18 04:48:00, не арифметический UTC timestamp;
