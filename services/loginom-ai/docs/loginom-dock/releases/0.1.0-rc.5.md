# Loginom Dock 0.1.0-rc.5 — версия исходников

9 сентября 2026 подготовлен новый release candidate текущей ветки `main`.
Тег: `loginom-dock@0.1.0-rc.5`. База перед повышением версии — `996fde11`.
Номер rc.5 был свободен; rc.3 и rc.4 ранее использовались во внутренних версиях.

В клиенте, package lock, Codex manifest/MCP/hooks и Hermes manifest/adapter
согласован номер `0.1.0-rc.5`. Проверено, что относительно базы в этих семи
файлах изменились только строки версии; зависимости и поведение не менялись.

После повышения версии прошли 1083 клиентских теста (1 пропущен) и 400
Python-тестов приёмочных проверок. `git diff --check` прошёл.
Последняя живая приёмка поведения — Hermes `20260909-175609-3c41b0a2`,
45/45 independent PASS, **до изменения номера версии**. Это не новая
живая приёмка изменившегося runtime pin.
[Доказательства и ограничения исправлений](../../plans/loginom-dock/03-review-followup.md).

Этап ограничен версией и тегом в Git. Установочные архивы не собирались и не
публиковались; `landing/release.json` продолжает описывать публичный выпуск
`0.1.0-rc.2-fix`. Сайт, сервер, активный каталог и установленный клиент не
обновлялись. RC не означает завершения полного аналитического выпуска V5.
Для публикации архивов требуется отдельная сборка на Dock VPS, проверка
опубликованных файлов и последующее обновление release manifest сайта.
