## Установка и загрузка

Оба штатных install.sh --agent выполнены из серверного Mac-комплекта.
Hermes Python adapter установлен из GitHub по тому же sourceCommit, его байты
и оба skill совпали с bundle. Обе Dock storage-конфигурации побайтно прежние;
в Hermes config изменена только регистрация Dock. Модель, provider и другие
настройки сохранились. Шесть точных RC7 hooks Codex штатно подтверждены через
hooks/list → config/batchWrite → hooks/list:6/6trusted. Чужие hooks не менялись.

Перезапуск затронул оба разных Hermes host:

- Desktop: обычный macOS Quit настоящего `com.nousresearch.hermes`, с сохранённой
  штатной проверкой активной работы; старые app/core/MCP55563/55637/55759 завершились.
  Открыто то же приложение из `hermes-agent/apps/desktop/release/mac-arm64/Hermes.app`,
  новые app/core50846/50897. `/Applications/Hermes.app` — другой установщик и не использовался.
- Messaging gateway: штатный gateway restart, старый39123 завершён, новый51817,
  свежий active_agents0. Его перезапуск сам по себе не обновляет Desktop.
- Новые router PIDs51057/51836 используют установленный hermes-mcp.mjs RC7.
  Native origin receipts обоих подтвердили initialize/tools/list и корректное
  закрытие временного discovery bridge. Это не завершение внешнего router:
  процесс остаётся готов к пользовательским задачам.

Computer Use, UI-клики, принудительное подтверждение Quit, модели и новые
аналитические задачи не запускались. Утерянный прежний workflow автоматически
не восстанавливался. После перезапуска требуется новое пользовательское сообщение
с файлом/явной ссылкой, чтобы native hook выдал новый current-turn ticket.

## Сайт, ограничения и откат

release.json обновлён только после публичного download/hash read-back.
Серверный preview проверен скриптом:6сочетаний агент/ОС, ссылки, копирование,
FAQ, desktop/mobile без переполнения. Снимки просмотрены. Новый Caddy валиден;

в рамках исправления не создавался. Новая GUI-приёмка Linux/Windows остаётся
отложенной по решению пользователя; здесь проверены сборки и Linux source tests.

до16изолированных задач до закрытия подключения; автоматического вытеснения нет.
