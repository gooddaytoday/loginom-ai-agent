## Подтверждённые дефекты

| Дефект | До исправления в реальном UI | Исправление и повторная проверка |
| --- | --- | --- |
| Порядок ключей field | `{name:"Id",kind:"input_field"}` оставлял незавершённую настройку с timeout `field selection committed` | Семантическое сравнение kind/name; тот же запрос настроил Id >= 3 |
| Замена длинного сохранённого фильтра | Созданы через Clone и сохранены 100 условий; после reopen последняя строка y=2620, scrollTop=0; `remove exact final filter row unavailable` | Ограниченная прокрутка к последней строке, проверка порядка record_id и схемы; 100 условий успешно заменены одним |
| Выбор невидимого поля | В списке 1001 пункт, Field1000 расположен на y=24268, maxTop=23725; timeout `exact input field option` | Прокрутка по наблюдаемым пунктам и владельцу списка; проверены Field1000, Field0020 и снова Field1000 |
| Граница 1000 полей | Native store содержит 1000 полей + служебный RowNumberer; reader выдаёт `filter_inventory` | Раздельные лимиты 1000 реальных полей и одного служебного пункта; тот же store прочитан полностью |

из принадлежащего фильтру FColumnInfoStore. Остановка при изменении схемы, условий,
владельца или отсутствии прогресса прокрутки сохранена.
