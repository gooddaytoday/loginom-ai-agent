## Границы

Поддержаны ограниченные имена ASCII до128 символов, до128 выражений,
формулы до2048 символов/128 LF-строк, пять типов и синтаксис Loginom «Выражение».
Произвольное удаление выражений и JavaScript не входят в первый набор.
Входные исключения не поддержаны; выходное исключение допускается только
для необязательного неунаследованного поля. Неподдержанный режим не объявляется
готовым обработчиком. DateTime не получает выдуманный timezone; ограничения
представления и точности возвращаются с выходом.

Принятый исходный обработчик не означает production release: V5, публикация
артефактов, обновление клиента и остальные аналитические обработчики остаются
отдельной работой. Калькулятор не закрывает весь сценарий продаж двух ветвей.
