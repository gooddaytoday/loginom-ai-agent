# Node17: исправлено открытие редактора импортируемого поля

13 сентября 2026. Ветка `codex/node-17-text-export`, база исправления `8ae370c8`.
Полная автономная приёмка **не пройдена**. Кандидат готов к следующему полному
прогону после выделения координатором единственного слота Hermes.

Второй прогон `20260913-193235-fa902eea` остановился на Typed: изменение вида
поля `stamp` с «Дискретный» на «Непрерывный». На шаге 74 двойное нажатие
отклонено до жеста: `NOT_APPLIED / UI_EPOCH_CHANGED`, эффект отсутствует,
локальная очистка подтверждена. Узел в целом вернул `AMBIGUOUS` с неподтверждённой
очисткой; Hermes остановился. Exit 0 не означает успеха. Собственные процессы
завершены, слот освобождён. Исходные квитанции сохранены.

Открытие редакторов type/data_kind теперь использует существующий `channel.perform`:
не более двух обновлений ссылки после доказанного отказа до жеста. Перед повтором
должны совпасть владелец мастера, поле и его свойства, страница и ячейка.
Глобальная защита эпохи и повторы при неопределённом эффекте не менялись.

Проверки:

- 98 целевых Node-тестов PASS, включая смену поля/владельца/страницы,
  неопределённый эффект, незавершённую очистку и предел повторов.
- 21 Python-тест PASS; проверены подмены runtime, состава исходников и доказательств.
- Прямое воспроизведение до исправления прошло без повторения плавающего отказа.
  После исправления отдельный видимый Loginom 7.4.2, `test-2`, `/test-2`:
  `unavailable:artifact-20f9c11b471b1346`, импорт 3×5 выполнен.
  Независимые аудиторы подтвердили доставку исходных байтов, настройки из UI,
  типы, значения всех строк и возвращение в сценарий. Сохранение/переоткрытие
  пакета этим локальным тестом не проверялось. Собственный браузер завершён.
- Проверка подключения Hermes прошла без запуска модели:
  `openai-codex / gpt-5.6-sol / low`, существующая подписка.

Новый runtime `2897649a8d2120d25e4c80af8af2c6cdd834023b5bda1a1bd5baf073c6e9ba32`.
Из 155 runtime-файлов изменён только `packages/loginom-runtime/client/lib/text-import-procedure.mjs`.
Manifest фиксирует текущие исходники и эту разницу; прежние проверки экспорта
и наблюдателя сохраняют исторический runtime. Новая версия не объявляется
прошедшей полную приёмку на основании старых квитанций.

Первый запуск аудитора после второго Hermes остановился на уже изменённом
локальном pin импорта. Этот результат сохранён в `full-audit.json`; после
обновления pin отдельный `full-audit-after-pin-refresh.json` отверг тот же прогон
по `user_node_error`. Ни один не является успешной приёмкой.
