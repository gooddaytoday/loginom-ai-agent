# Установка Loginom Enterprise 7.4.2 с Dashboard M7

Инструкция предназначена для чистого Linux-сервера x86-64. Установка создаёт новую базу Loginom. Обновление действующей установки и перенос её данных требуют отдельной процедуры.

## Подготовьте сервер

- Нужны Docker Engine 29.1.3 или новее, плагин Docker Compose 2.40.3 или новее, systemd с journald, Python 3 и `curl` с поддержкой gzip и Brotli. Нужны права `sudo` и локальный Docker Engine с системным сокетом. Для локального Guardant также нужен `iproute2`, а для установки службы `glds` из комплекта — `dpkg`.
- Оставьте минимум 4 ГиБ на файловой системе Docker и 1 ГиБ на распаковку в `/opt`. Если файловая система общая, потребуется 5 ГиБ. Loginom размещает файлы приложения в `/opt/loginom-release`, а рабочие данные в `/var/lib/loginom-release`. Dashboard использует `/opt/loginom-release-dashboard` и `/var/opt/loginom-dashboard`.
- Выберите DNS-имя или IPv4-адрес, по которому Studio будет доступна серверу и рабочим местам. Нужны два свободных TCP-порта. По умолчанию Studio использует `80`, а приложения Dashboard — `8101`. Оба порта должны быть доступны в доверенной сети. Этот комплект поднимает HTTP. Для доступа через недоверенную сеть понадобится отдельная настройка HTTPS.
- Подготовьте лицензию. Для сетевого Guardant нужен адрес сервера, доступного из Docker-сети, и при необходимости адрес резерва. На выделенном сервере можно использовать уже активированный локальный Guardant SP Net. Режим локального ключа перенастраивает системный `glds`. Если тот обслуживает другие машины, выберите сетевой режим.

Подготовьте Docker и системные инструменты заранее. Образы Enterprise и Dashboard уже входят в архив. При установке они загружаются с диска. Для новой локальной активации потребуются файл `.grdvd`, серийный номер и доступ к `activation.guardant.ru`. Ключ будет привязан к этой машине. Если интернет недоступен, используйте сетевой Guardant или выполните штатную офлайн-активацию до установки.

## Перенесите комплект и запустите установку

Скопируйте четыре файла в один каталог на сервере.

- `loginom-release-7.4.2-6e72ef0f1824-dashboard-m7.tar`
- `loginom-release-7.4.2-6e72ef0f1824-dashboard-m7.tar.sha256`
- `install-all.sh`
- `INSTALL.md`

Выполните в этом каталоге.

```sh
chmod +x install-all.sh
sudo ./install-all.sh
```

Установщик сверит контрольные суммы, запросит имя Studio, оба порта и способ лицензирования. Чтобы принять предложенное значение, нажмите Enter. Серийный номер нового локального ключа вводится скрыто.

### Смените пароль через SSH-туннель

Сначала Studio принимает подключения только на `127.0.0.1` сервера. Оставьте установщик открытым и запустите на рабочем месте команду, которую он напечатает. Вот команда для Studio на порту 80.

```sh
ssh -N -o ExitOnForwardFailure=yes -L 127.0.0.1:8080:127.0.0.1:80 user@studio.example.test
```

Откройте в браузере `http://127.0.0.1:8080/app/`. Если порт 8080 занят на рабочем месте, замените его свободным портом в начале параметра `-L` и в адресе браузера. Войдите как `admin` с начальным паролем `admin` и смените его в форме Studio. Выйдите и войдите с новым паролем. Вернитесь в терминал установщика и подтвердите успешный вход. После проверки скрипт откроет внешний порт Studio, установит Dashboard и запустит серверные проверки. Для дальнейшей работы используйте итоговый URL из терминала.

### Если установку прервали

Сохраните тот же комплект и повторите `sudo ./install-all.sh`. Скрипт использует параметры своей установки и продолжает с учётом её состояния. Если лицензия недоступна, исправьте доступ к Guardant и повторите запуск. При неопределённом результате активации сначала проверьте её статус на сервере. Если скрипт обнаружил существующую установку или данные, происхождение которых не подтверждено, разберите причину по сообщению в терминале.

## Проверьте Dashboard с рабочего места

В приёмке на Ubuntu публикация прошла с Loginom AI Agent Desktop `0.3.9`. Вариант `0.3.9-m7.1` дважды остановился до открытия черновика с ошибкой `LOGINOM_RUNTIME_CLEANUP_FAILED`.

1. Убедитесь, что установщик вывел `Publication PASS`, `Server checks PASS` и `Cleanup PASS`. Эти сообщения относятся к проверке на сервере.
2. Откройте URL Studio на рабочем месте и подключите к нему установленный Loginom AI Agent Desktop с поддержкой Dashboard M7. Войдите в Studio под пользователем с правом записи в тестовый пакет.
3. Выберите узел с табличным выходом и нажмите «Создать dashboard». Откройте черновик в Desktop, проверьте его, запросите публикацию и подтвердите её кнопкой «Разрешить один раз».
4. Откройте опубликованный Dashboard в новой сессии Studio и сверьте его данные с выходом узла. Для примера со значениями `10, 20, 30, 40, 50` ожидаются пять строк и сумма `150`. При фильтре «значение ≥ 30» ожидаются три строки и сумма `120`.
