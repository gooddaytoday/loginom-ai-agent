# Loginom AI Agent

Desktop-приложение для работы с Loginom с помощью AI. Клиент Loginom Dock встроен в приложение вместе с Node.js, Playwright и Chromium. Основано на OpenCode; сведения об исходном проекте и лицензиях сохранены в [архиве документации](docs/upstream/README.md).

## Linux

Поддерживаемая цель: Ubuntu 22.04+ и Debian 12+, x86_64. Основной установщик — DEB, дополнительный переносимый вариант — AppImage. Локальные кандидаты находятся в `packages/desktop/dist`; публикация и цифровая подпись не выполнялись.

```sh
sudo apt install ./loginom-ai-agent-linux-amd64.deb
```

После установки запустите **Loginom AI Agent**. Мастер первого запуска спрашивает ключ Loginom AI сервера, адрес Loginom, имя пользователя и пароль. Адрес по умолчанию — `https://app.loginom.ai`, пользователь — `user`, пароль пустой. Те же поля доступны в разделе **Loginom** настроек. Папка файлов определяется по имени пользователя: `/<пользователь>`.

Модель подключается отдельно через обычные настройки провайдеров приложения. Встроенный Dock не требует установки плагина, Node.js, Python или браузера на машине пользователя. В Linux секреты сохраняются в открытом виде с правами 0600 в приватном каталоге профиля.

Workspace-зависимости устанавливаются Bun 1.3.14. Тесты и `bun typecheck` запускаются из каталогов соответствующих пакетов, не из корня. Сборка закрепляет версии и хеши runtime; при первом запуске приложение ничего не устанавливает через npm.

Автообновление отключено до проверки собственного канала обновлений. Старые OpenCode wrapper/desktop и репозиторий Loginom Dock автоматически не удаляются. Клиентские интеграции Codex/Hermes сохранены в архиве переноса и не входят в активную разработку приложения.
